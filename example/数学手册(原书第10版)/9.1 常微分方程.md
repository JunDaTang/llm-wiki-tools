### 9.1 常微分方程

1. 一般的 阶常微分方程

其隐式 (implicit form) 有如下形式

$$
F \big [ x, y (x), y ^ {\prime} (x), \dots , y ^ {(n)} (x) \big ] = 0.\tag{9.1}
$$

如果从这个方程中解出了 $y ^ { ( n ) } ( x )$ ），那么它就是一个 阶常微分方程的显式 (explicitform).

2. 解或积分

一个微分方程的解或积分是在一个区间 $a \leqslant x \leqslant b$ （此区间也可以是无限的）上满足这个方程的每个函数一个包含 个任意常数 $c _ { 1 } , c _ { 2 } , \cdots , c _ { n }$ 的解被称为通解 (general solution) 或通积分 (general integral) ．如果这些常数的值被确定，就得到了一个特别积分 (particular integral) 或一个特解 (particular solution) ．这些常数的值可以被 个附加条件所确定．如果 及其直至 $n - 1$ 阶导数的值在区[a, b] 的一个端点处被指定，那么求解的问题被称为一个初值问题 (initial valueproblem) ．如果在区间的两个端点都有给定的值，则求解的问题被称为一个边值问(boundary value problem).

·微分方程 $- y ^ { \prime } \sin x + y \cos x = 1$ 有通解 $y = \cos x + c \sin x$ 对千条件 $c = 0 .$ ，得到特解 $y = \cos x$

3. 初值问题

如果对千一个 阶常微分方程的解 $y = y ( x )$ ，在 $x _ { 0 }$ 处给定了 个值 $y ( x _ { 0 } )$ $y ^ { \prime } ( x _ { 0 } ) , \cdot \cdot \cdot , y ^ { ( n - 1 ) } ( x _ { 0 } )$ ，那么就给出了一个初值问题 (initial value problem) ．这些值被称为初值 (initial value) 或初始条件 (initial conditions) ．对千 $n$ 阶常微分方程通解的 个未知常数 $c _ { 1 } , c _ { 2 } , \cdots , c _ { n }$ 你，它们形成了 个方程的一个方程组．

·一个特殊的弹性弹簧—质量系统的谐运动可以通过初值问题：具有初始条件 $y ( 0 ) =$ $y _ { 0 } , y ^ { \prime } ( 0 ) = 0$ 的 $y ^ { \prime \prime } + y = 0$ 进行建模．其解为 $y = y _ { 0 } \cos x$

4. 边值问题

如果一个常微分方程的解和／或其导数在其定义域中的儿个点处被给出，那么这些值被称为边界条件 (boundary conditions)．具有边界条件的一个微分方程被称为边值问题

·端点固定和均匀负载的细棒形成的曲线由具有边界条件 $y ( 0 ) = 0 , y ( 1 ) = 0$ 的微分方程 $y ^ { \prime \prime } = x - x ^ { 2 } ( 0 \leqslant x \leqslant 1 )$ 所描述其解为 $y = \frac { x ^ { 3 } } { 6 } - \frac { x ^ { 4 } } { 1 2 } - \frac { x } { 1 2 }$
