5.4.1.2 素数

1. 素数的定义和性质

正整数 $p ( p > 1 )$ 称为素数，当且仅当 是它在正整数集 中仅有的因子．不是素数的正整数称为合数

对千每个整数，最小的不为 的正因子是一个素数存在无穷多个素数

正整数 $p ( p > 1 )$ 是素数，当且仅当对千任意正整数 $a , b , p | ( a b )$ 蕴涵 $p | a$ 或 $p | b$

2. 埃拉托色尼 (Eratosthenes) 筛法

应用埃拉托色尼筛法，可以确定每个小千给定的正整数 的素数：

a) 列出所有 的正整数．

b) 下方画一道横线，并去掉其后所有 的倍数．

c) 如果 $p$ 是第一个没有去掉也没有在下方画横线的数，那么在 下方画一道横线并去掉每个 的倍数（从 $2 p$ 开始，按原列出的表计数）．

d) 对每个 $p ( p \leqslant { \sqrt { n } } )$ 重复步骤 c)，并停止算法．

每个下方画了横线而没有去掉的数都是素数这样就得到所有 $\leqslant n$ 的素数

素数称作整数集的素元素

3. 素数对

相差 的两个素数形成一个素数对（李生素数）．

■ (3, 5), (5, 7), (11, 13), (17, 19), (29, 31), (41, 43), (59, 61), (71, 73), (101,103) 是素 数对

4. 三素数组

出现在四个连续奇数中的三个素数称作三素数组．

■ (5, 7, 11),(7, 11, 13),(11, 13, 17),(13, 17, 19),(17, 19, 23),(37, 41, 43) 是三素数组

5. 四素数组

如果五个连续奇数中的前两个和后两个都是素数对，那么这四个数称作一个四素数组

■ (5, 7, 11, 13),(11, 13, 17, 19),(101, 103, 107, 109),(191, 193, 197, 199) 是四素数组存在无穷多个素数对、三素数组和四素数组的猜想还未被证明

6. 梅森素数

如果 $2 ^ { k } - 1 , k \in \mathbb { N }$ 是素数，那么 也是素数数 $2 ^ { p } - 1 ( p$ 是素数）称作梅森(Mersenne) 数．一个本身是素数的梅森数 $2 ^ { p } - 1$ 称作梅森素数

• 对千下列最初几个 的值： 2, 3, 5, 7, 13, 17, 19, 31, 61, 89, 107, 等等， $2 ^ { p } - 1$ 是素数

近几年来最大的已知素数总是梅森素数，例如 $2 ^ { 4 3 1 1 2 6 0 9 } - 1 ( 2 0 0 8$ 年），$2 ^ { 5 7 8 8 5 1 6 1 } - 1 ( 2 0 1 3$ 年）．与此相反，对千其他自然数形式为 $2 ^ { k } - 1$ 的数可以用相对简单的方式检验它们是素数：设 $p > 2$ 是一个素数，定义自然数列 $s _ { 1 } = 4 , s _ { i + 1 } : =$ $s _ { i } ^ { 2 } - 2 ( i \geqslant 1 )$ ．数 $2 ^ { p } - 1$ 是素数，当且仅当数列的项 $s _ { p - 1 }$ 可被 $2 ^ { p } - 1$ 整除

基千这个命题的素数判别法称为卢卡斯－莱默 (Lucas-Lehmer) 判别法．

7. 费马素数

如果数 $2 ^ { k } + 1 , k \in \mathbb { N }$ 是一个奇素数，那么 的幕数 $2 ^ { k } + 1 , k \in \mathbb { N }$ 称为费马数如果一个费马数是素数，那么它称作费马素数

8. 初等数论基本定理

每个正整数 $n > 1$ 可以表示为素数的乘积．这种表示除因子次序外是唯一的．因此称 恰有一个素因子分解式．

$$

$$

类似地整数（除—1,0,1) 可表示为素元素之积，除因子的次序和符号外表示是唯一的．

9. 标准素因子分解

正整数的素因子分解式中因子通常按它们的大小排列，并且相同的因子组成幕．如果规定不出现的素数的指数为 ，那么每个正整数由它的素因子分解式的指数序列唯一确定
