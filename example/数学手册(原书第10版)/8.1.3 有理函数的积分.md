#### 8.1.3 有理函数的积分

有理函数的积分总可由初等函数表示．

8.1.3.1 整有理函数（多项式）的积分

整有理函数的积分可直接通过逐项积分来计算：

$$
\begin{array}{c} {\int (a _ {n} x ^ {n} + a _ {n - 1} x ^ {n - 1} + \dots + a _ {1} x + a _ {0}) \mathrm{d} x} \\ {= \frac {a _ {n}}{n + 1} x ^ {n + 1} + \frac {a _ {n - 1}}{n} x ^ {n} + \dots + \frac {a _ {1}}{2} x ^ {2} + a _ {0} x + C.} \end{array}\tag{8.13}
$$

8.1.3.2 分数有理函数的积分

被积函数为分数有理函数的积分 $\int \frac { P \left( x \right) } { Q \left( x \right) } \mathrm { d } x$ ，其中 $P \left( x \right) , Q \left( x \right)$ 分别为 次和次多项式可用代数方法变换成易千积分的形式步骤如下：

(1) 利用最大公因子将分数化简，由此 $P \left( x \right) , Q \left( x \right)$ 没有公因子．

(2) 将表达式的整部与有理部分分开．若 $m \geqslant n$ 则用 $Q \left( x \right)$ 除 $P \left( x \right)$ ，得到的多项式和真分式应该可积

(3) 将分母 $Q \left( x \right)$ 分解成线性因式与二次因式（参见第 57 1.6.3.2) 的乘积：

$$
Q (x) = a _ {n} (x - \alpha) ^ {k} (x - \beta) ^ {l} \dots (x ^ {2} + p x + q) ^ {r} (x ^ {2} + p ^ {\prime} x + q ^ {\prime}) ^ {s} \dots ,\tag{8.14a}
$$

其中

$$
\frac {p ^ {2}}{4} - q <   0, \frac {p ^ {\prime 2}}{4} - q ^ {\prime} <   0, \dots .\tag{8.14b}
$$

(4) 将常系数 $a _ { n }$ 提到积分号的外边．

(5) 将分式分解成部分分式之和：相除后得到的真分式不能进一步化简，但其分母被分解成了不可约因式的乘积，进而能分解成部分分式之和（参见第 181.1.7.3)，且每个部分分式都容易积分．

8.1.3.3 部分分式分解的四种情况

1. 分母的所有根均为实单根

$$
Q (x) = (x - \alpha) (x - \beta) \dots (x - \lambda).\tag{8.15a}
$$

a) 分解形式如下：

$$
\frac {P (x)}{Q (x)} = \frac {A}{x - \alpha} + \frac {B}{x - \beta} + \dots + \frac {L}{x - \lambda},\tag{8.15b}
$$

其中

$$
A = \frac {P (\alpha)}{Q ^ {\prime} (\alpha)}, B = \frac {P (\beta)}{Q ^ {\prime} (\beta)}, \dots , L = \frac {P (\lambda)}{Q ^ {\prime} (\lambda)}.\tag{8.15c}
$$

b) $A , B , C , \cdots , L$ 也可由待定系数法来计算（参见第 20 1.1.7.3, 4.).

c) 由公式

$$
\int {\frac {A \mathrm{d} x}{x - \alpha}} = A \ln | x - \alpha |\tag{8.15d}
$$

积分．

$$
\begin{array}{r l} & I = \int \frac {(2 x + 3) \mathrm{d} x}{x ^ {3} + x ^ {2} - 2 x}: \\ & \frac {2 x + 3}{x (x - 1) (x + 2)} = \frac {A}{x} + \frac {B}{x - 1} + \frac {C}{x + 2}, \\ & A = \frac {P (0)}{Q ^ {\prime} (0)} = \left(\frac {2 x + 3}{3 x ^ {2} + 2 x - 2}\right) _ {x = 0} = - \frac {3}{2}, \\ & B = \left(\frac {2 x + 3}{3 x ^ {2} + 2 x - 2}\right) _ {x = 1} = \frac {5}{3}, \\ & C = \left(\frac {2 x + 3}{3 x ^ {2} + 2 x - 2}\right) _ {x = - 2} = - \frac {1}{6}, \\ & I = \int \left(\frac {- \frac {3}{2}}{x} + \frac {\frac {5}{3}}{x - 1} + \frac {- \frac {1}{6}}{x + 2}\right) \mathrm{d} x \\ & \qquad = - \frac {3}{2} \ln | x | + \frac {5}{3} \ln | x - 1 | - \frac {1}{6} \ln | x + 2 | + C _ {1} = \ln \left| \frac {C (x - 1) ^ {5 / 3}}{x ^ {3 / 2} (x + 2) ^ {1 / 6}} \right|. \end{array}
$$

2. 分母的所有根均为实数，但其中一些为多重根

$$
Q (x) = (x - \alpha) ^ {l} (x - \beta) ^ {m} \dots .\tag{8.16a}
$$

a) 分解形式如下：

$$
\begin{array}{r l} & {\frac {P (x)}{Q (x)} = \frac {A _ {1}}{(x - \alpha)} + \frac {A _ {2}}{(x - \alpha) ^ {2}} + \dots + \frac {A _ {l}}{(x - \alpha) ^ {l}}} \\ & {\qquad + \frac {B _ {1}}{(x - \beta)} + \frac {B _ {2}}{(x - \beta) ^ {2}} + \dots + \frac {B _ {m}}{(x - \beta) ^ {m}} + \dots .} \end{array}\tag{8.16b}
$$

b) 常数 $A _ { 1 } , A _ { 2 } , \cdots , A _ { l } , B _ { 1 } , B _ { 2 } , \cdots , B _ { m } , \cdots$ ·可由待定系数法来计算（参见第20 1.1.7.3,4.).

c) 由公式

$$
\int \frac {A _ {1} \mathrm{d} x}{x - \alpha} = A _ {1} \ln | x - \alpha |, \quad \int \frac {A _ {k} \mathrm{d} x}{(x - \alpha) ^ {k}} = - \frac {A _ {k}}{(k - 1) (x - \alpha) ^ {k - 1}} \quad (k > 1)\tag{8.16c}
$$

积分．

$$
I = \int {\frac {x ^ {3} + 1}{x (x - 1) ^ {3}}} \mathrm{d} x: \frac {x ^ {3} + 1}{x (x - 1) ^ {3}} = \frac {A}{x} + \frac {B _ {1}}{x - 1} + \frac {B _ {2}}{(x - 1) ^ {2}} + \frac {B _ {3}}{(x - 1) ^ {3}}.
$$

由待定系数法得到 $A + B _ { 1 } = 1 , \ - 3 A - 2 B _ { 1 } + B _ { 2 } = 0 , 3 A + B _ { 1 } - B _ { 2 } + B _ { 3 } =$ $0 , \ - A = 1$ ，故 $A = - 1 , B _ { 1 } = 2 , B _ { 2 } = 1 , B _ { 3 } = 2$ 积分结果为

$$
\begin{array}{l} I = \int \left[ - \frac {1}{x} + \frac {2}{x - 1} + \frac {1}{(x - 1) ^ {2}} + \frac {2}{(x - 1) ^ {3}} \right] \mathrm{d} x \\ = - \ln | x | + 2 \ln | x - 1 | - \frac {1}{x - 1} - \frac {1}{(x - 1) ^ {2}} + C \\ = \ln \left| \frac {(x - 1) ^ {2}}{x} \right| - \frac {x}{(x - 1) ^ {2}} + C. \end{array}
$$

3. 分母的某些根为单复根

假设分母 $Q \left( x \right)$ 的所有系数均为实数，若 $Q \left( x \right)$ 有一个单复根，则其共扼复数也为一个根，可将其组成一个二次多项式

$$
Q (x) = (x - \alpha) ^ {l} (x - \beta) ^ {m} \dots (x ^ {2} + p x + q) (x ^ {2} + p ^ {\prime} x + q ^ {\prime}) \dots .\tag{8.17a}
$$

因为其中的二次多项式没有 根，故

$$
\frac {p ^ {2}}{4} <   q, \frac {p ^ {\prime 2}}{4} <   q ^ {\prime}, \dots .\tag{8.17b}
$$

a) 分解形式如下：

$$
\begin{array}{l} \frac {P (x)}{Q (x)} = \frac {A _ {1}}{x - \alpha} + \frac {A _ {2}}{(x - \alpha) ^ {2}} + \dots + \frac {A _ {l}}{(x - \alpha) ^ {l}} + \frac {B _ {1}}{x - \beta} + \frac {B _ {2}}{(x - \beta) ^ {2}} + \dots + \frac {B _ {m}}{(x - \beta) ^ {m}} \\ \quad + \frac {C x + D}{x ^ {2} + p x + q} + \frac {E x + F}{x ^ {2} + p ^ {\prime} x + q ^ {\prime}} + \dots . \end{array} \tag {8.17c}
$$

b) 利用待定系数法来计算常数（参见第 20 1.1.7.3, 4.).

c) 由公式计算 $\frac { C x + D } { x ^ { 2 } + p x + q }$ 的积分

$$
\int {\frac {(C x + D) \mathrm{d} x}{x ^ {2} + p x + q}} = \frac {C}{2} \ln | x ^ {2} + p x + q | + \frac {D - C p / 2}{\sqrt {q - p ^ {2} / 4}} \arctan {\frac {x + p / 2}{\sqrt {q - p ^ {2} / 4}}}.\tag{8.17d}
$$

${ \textbf { \textsf { u } } } I = \int { \frac { 4 \mathrm { d } x } { x ^ { 3 } + 4 x } } : { \frac { 4 } { x ^ { 3 } + 4 x } } = { \frac { A } { x } } + { \frac { C x + D } { x ^ { 2 } + 4 } }$ ．由待定系数法可得方程 $A + C =$ $0 , D = 0 , 4 A = 4$ , $A = 1 , C = - 1 , D = 0$ , 千是

$$
I = \int \left(\frac {1}{x} - \frac {x}{x ^ {2} + 4}\right) \mathrm{d} x = \ln | x | - \frac {1}{2} \ln (x ^ {2} + 4) + \ln | C _ {1} | = \ln \left| \frac {C _ {1} x}{\sqrt {x ^ {2} + 4}} \right|,
$$

在这种特殊情况中， arctan 这一项为 0.

4. 分母中某些根为多重复根

$$
Q (x) = (x - \alpha) ^ {k} (x - \beta) ^ {l} \dots (x ^ {2} + p x + q) ^ {m} (x ^ {2} + p ^ {\prime} x + q ^ {\prime}) ^ {n} \dots .\tag{8.18a}
$$

a) 分解形式如下：

$$
\begin{array}{r l} \frac {P (x)}{Q (x)} = & \frac {A _ {1}}{x - \alpha} + \frac {A _ {2}}{(x - \alpha) ^ {2}} + \dots + \frac {A _ {k}}{(x - \alpha) ^ {k}} + \frac {B _ {1}}{x - \beta} + \frac {B _ {2}}{(x - \beta) ^ {2}} + \dots + \frac {B _ {l}}{(x - \beta) ^ {l}} \\ & + \frac {C _ {1} x + D _ {1}}{x ^ {2} + p x + q} + \frac {C _ {2} x + D _ {2}}{(x ^ {2} + p x + q) ^ {2}} + \dots + \frac {C _ {m} x + D _ {m}}{(x ^ {2} + p x + q) ^ {m}} \\ & + \frac {E _ {1} x + F _ {1}}{x ^ {2} + p ^ {\prime} x + q ^ {\prime}} + \frac {E _ {2} x + F _ {2}}{(x ^ {2} + p ^ {\prime} x + q ^ {\prime}) ^ {2}} + \dots + \frac {E _ {n} x + F _ {n}}{(x ^ {2} + p ^ {\prime} x + q ^ {\prime}) ^ {n}}. \end{array} \tag {8.18b}
$$

b) 利用待定系数法来计算常数

c) $m > 1$ 时按下面步骤计算表达式 $\frac { C _ { m } x + D _ { m } } { \left( x ^ { 2 } + p x + q \right) ^ { m } }$ 的积分：

a) 将分子作变换

$$
C _ {m} x + D _ {m} = \frac {C _ {m}}{2} (2 x + p) + \left(D _ {m} - \frac {C _ {m} p}{2}\right).\tag{8.18c}
$$

6) 将被积函数分解成两个加式的和，其中第一个加式能直接进行积分：

$$
\int {\frac {C _ {m}}{2}} {\frac {(2 x + p) \mathrm{d} x}{(x ^ {2} + p x + q) ^ {m}}} = - {\frac {C _ {m}}{2 (m - 1)}} {\frac {1}{(x ^ {2} + p x + q) ^ {m - 1}}}.\tag{8.18d}
$$

Y) 第二个加式可不用考虑系数，利用下面的递归公式积分

$$
\begin{array}{r l} & {\int \frac {\mathrm{d} x}{(x ^ {2} + p x + q) ^ {m}} = \frac {x + p / 2}{2 (m - 1) (q - p ^ {2} / 4) (x ^ {2} + p x + q) ^ {m - 1}}} \\ & {\qquad + \frac {2 m - 3}{2 (m - 1) (q - p ^ {2} / 4)} \int \frac {\mathrm{d} x}{(x ^ {2} + p x + q) ^ {m - 1}}. \quad (8. 1 8 \mathrm{e})} \\ & {\blacksquare I = \int \frac {2 x ^ {2} + 2 x + 1 3}{(x - 2) (x ^ {2} + 1) ^ {2}} \mathrm{d} x: \frac {2 x ^ {2} + 2 x + 1 3}{(x - 2) (x ^ {2} + 1) ^ {2}} = \frac {A}{x - 2} + \frac {C _ {1} x + D _ {1}}{x ^ {2} + 1} + \frac {C _ {2} x + D _ {2}}{(x ^ {2} + 1) ^ {2}}.} \end{array}
$$

由待定系数法可得到如下方程组：

$$
\begin{array}{r l} & A + C _ {1} = 0, \quad - 2 C _ {1} + D _ {1} = 0, \quad 2 A + C _ {1} - 2 D _ {1} + C _ {2} = 2, \\ & \qquad - 2 C _ {1} + D _ {1} - 2 C _ {2} + D _ {2} = 2, \quad A - 2 D _ {1} - 2 D _ {2} = 1 3; \end{array}
$$

解得系数 $A = 1 , C _ { 1 } = - 1 , D _ { 1 } = - 2 , C _ { 2 } = - 3 , D _ { 2 } = - 4 ,$ ，故

$$
I = \int \left(\frac {1}{x - 2} - \frac {x + 2}{x ^ {2} + 1} - \frac {3 x + 4}{(x ^ {2} + 1) ^ {2}}\right) \mathrm{d} x.
$$

(8.18e) ，有

$$
\int {\frac {\mathrm{d} x}{(x ^ {2} + 1) ^ {2}}} = \frac {x}{2 (x ^ {2} + 1)} + \frac {1}{2} \int {\frac {\mathrm{d} x}{x ^ {2} + 1}} = \frac {x}{2 (x ^ {2} + 1)} + \frac {1}{2} \arctan x,
$$

最终结果

$$
I = \frac {3 - 4 x}{2 (x ^ {2} + 1)} + \frac {1}{2} \ln {\frac {(x - 2) ^ {2}}{x ^ {2} + 1}} - 4 \arctan {x} + C.
$$
