### 11.3 第一类弗雷德霍姆积分方程

#### 11.3.1 具有退化核的积分方程

1. 问题的叙述

考虑具有退化核的第一类弗雷德霍姆积分方程

$$
f (x) = \int_ {a} ^ {b} \left(\alpha_ {1} (x) \beta_ {1} (y) + \dots + \alpha_ {n} (x) \beta_ {n} (y)\right) \varphi (y) \mathrm{d} y \quad (c \leqslant x \leqslant d),\tag{11.38a}
$$

并引进类似千在第 818 11.2 中所用的记号

$$
A _ {j} = \int_ {a} ^ {b} \beta_ {j} (y) \varphi (y) \mathrm{d} y \quad (j = 1, 2, \dots , n).\tag{11.38b}
$$

(11.38a) 有形式

$$
f (x) = A _ {1} \alpha_ {1} (x) + \dots + A _ {n} \alpha_ {n} (x),\tag{11.38c}
$$

即，仅当 $f ( x )$ 是函数 $\alpha _ { 1 } ( x ) , \cdot \cdot \cdot , \alpha _ { n } ( x )$ 的线性组合时积分方程有解如果这个假设被满足，则可以求得系数 $A _ { 1 } , \cdots , A _ { n }$

2. 初步的途径

求形如

$$
\varphi (x) = c _ {1} \beta_ {1} (x) + \dots + c _ {n} \beta_ {n} (x)\tag{11.39a}
$$

的解，其中系数 $c _ { 1 } , \cdots , c _ { n }$ 是未知的，把 (11.39a) 代入 (11.38b) ，得到

$$
A _ {i} = c _ {1} \int_ {a} ^ {b} \beta_ {i} (y) \beta_ {1} (y) \mathrm{d} y + \dots + c _ {n} \int_ {a} ^ {b} \beta_ {i} (y) \beta_ {n} (y) \mathrm{d} y,\tag{11.39b}
$$

再引进记号

$$
K _ {i j} = \int_ {a} ^ {b} \beta_ {i} (y) \beta_ {j} (y) \mathrm{d} y,\tag{11.39c}
$$

则给出未知系数 $c _ { 1 } , \cdots , c _ { n }$ 的下述方程组：

$$
\begin{array}{c} K _ {1 1} c _ {1} + \dots + K _ {1 n} c _ {n} = A _ {1}, \\ \vdots \qquad \qquad \vdots \qquad \qquad \vdots \\ K _ {n 1} c _ {1} + \dots + K _ {n n} c _ {n} = A _ {n}. \end{array}\tag{11.39d}
$$

3.

如果函数 $\beta _ { 1 } ( x ) , \cdots , \beta _ { n } ( x )$ 是线性无关的，则系数矩阵是非奇异的（参见第 85812.1.3)．然而用 (11.39a) 所得到的解并非只有一个与具有退化核的第二类积分方程不同属千 (11.38a) 的齐次积分方程总有非平凡解假设 $\varphi ^ { h } ( x )$ 是齐次方程这样的一个解，并且 $\varphi ( x )$ 是方程 (11.38a) 的一个解．则 $\varphi ( x ) + \varphi ^ { h } ( x )$ 也是 (11.38a)的一个解

为了确定齐次方程所有的解，考虑 $f ( x ) = 0$ 的方程 (11.38c) ．如果函数 $\alpha _ { 1 } ( x )$ $\cdots , \alpha _ { n } ( x )$ 是线性无关的，则方程 (11.38c) 成立，当且仅当

$$
A _ {j} = \int_ {a} ^ {b} \beta_ {j} (y) \varphi (y) \mathrm{d} y = 0 \quad (j = 1, 2, \dots , n),\tag{11.40}
$$

即，正交千每个函数 $\beta _ { j } ( y )$ 的每个函数 $\varphi ^ { h } ( y )$ 是齐次积分方程的解

#### 11.3.2 分析的基础

1. 初步的途径

求解第一类弗雷德霍姆积分方程

$$
f (x) = \int_ {a} ^ {b} K (x, y) \varphi (y) \mathrm{d} y \quad (c \leqslant x \leqslant d)\tag{11.41}
$$

的几种方法把它的解确定为给定的一个函数系 $( \beta _ { n } ( y ) ) = \{ \beta _ { 1 } ( y ) , \beta _ { 2 } ( y ) , \cdot \cdot \cdot \}$ 的一个函数级数，即，寻求形如

$$
\varphi (y) = \sum_ {j = 1} ^ {\infty} c _ {j} \beta_ {j} (y)\tag{11.42}
$$

的解，要确定未知系数 $c _ { j }$ ．选取函数组，要考虑到函数系 $( \beta _ { n } ( y ) )$ 必须生成整个解空间，也要考虑到应该容易计算诸系数 $c _ { j }$

为了做一个简单的概述，在本节中只讨论实函数所有的陈述亦可适用千复值函数． 由千解的方法需要对核函数 $K ( x , y )$ 的性质提出某些要求（见 [11.3],[11.12]）．假定这些要求总是被满足的．其次需要讨论某些相关的信息．

2. 平方可积函数

一个函数 $\psi ( y )$ 在区间 $[ a , b ]$ 上是平方可积的 (quadratically integrable) ，如果成立

$$
\int_ {a} ^ {b} | \psi (y) | ^ {2} \mathrm{d} y <   \infty .\tag{11.43}
$$

例如， $[ a , b ]$ 上的每个连续函数是平方可积的用 $L ^ { 2 } [ a , b ]$ 表示 $[ a , b ]$ 上的平方可积函数的空间

3. 规范正交系

$[ a , b ]$ 上两个平方可积函数 $\beta _ { i } ( y ) , \beta _ { j } ( y )$ 被称为相互正交的，如果成立等式

$$
\int_ {a} ^ {b} \beta_ {i} (y) \beta_ {j} (y) \mathrm{d} y = 0.\tag{11.44a}
$$

空间 $L ^ { 2 } [ a , b ]$ 中的函数系 $\left( \beta _ { n } ( y ) \right)$ 被称为是一个规范正交系 (orthonormal system),如果下述等式为真：

$$
\int_ {a} ^ {b} \beta_ {i} (y) \beta_ {j} (y) \mathrm{d} y = \left\{ \begin{array}{l l} 1, & i = j, \\ 0, & i \neq j. \end{array} \right.\tag{11.44b}
$$

一个规范正交函数系是完全的 (complete) ，如果在 $L ^ { 2 } [ a , b ]$ 中不存在与这个系中每个函数都正交的函数 $\tilde { \boldsymbol { \beta } } ( y ) \neq \boldsymbol { 0 }$ 一个规范正交系包含可数无穷多个函数．这些函数形成空间 $L ^ { 2 } [ a , b ]$ 的一个基 (basis)．为了把一个函数系 $\left( \beta _ { n } ( y ) \right)$ ）变为一个规范正交系 $\left( \beta _ { n } ^ { * } ( y ) \right)$ ），可以用施密特正交化过程 (Schmidt orthogonalization procedure) ．这个过程逐次确定了系数 $b _ { n 1 } , b _ { n 2 } , \cdot \cdot \cdot \ , b _ { n n } ( n = 1 , 2 , \cdot \cdot \cdot )$ ，使得函数

$$
\beta_ {n} ^ {*} (y) = \sum_ {j = 1} ^ {n} b _ {n j} \beta_ {j} (y)\tag{11.44c}
$$

是规范化的，并且正交千每个函数 $\beta _ { 1 } ^ { * } ( y ) , \cdots , \beta _ { n - 1 } ^ { * } ( y )$

4. 傅里叶级数

如果 $\left( \beta _ { n } ( y ) \right)$ 是一个规范正交系，并且 $\psi ( y ) \in L ^ { 2 } [ a , b ]$ ，则把级数

$$
\sum_ {j = 1} ^ {\infty} d _ {j} \beta_ {j} (y) = \psi (y)\tag{11.45a}
$$

称为 $\psi ( y )$ 关千 $\left( \beta _ { n } ( y ) \right)$ 的傅里叶级数，诸数 $d _ { j }$ 是相应的傅里叶系数基千 (11.44b),成立

$$
\int_ {a} ^ {b} \beta_ {k} (y) \psi (y) \mathrm{d} y = \sum_ {j = 1} ^ {\infty} d _ {j} \int_ {a} ^ {b} \beta_ {j} (y) \beta_ {k} (y) \mathrm{d} y = d _ {k}.\tag{11.45b}
$$

如果 $\left( \beta _ { n } ( y ) \right)$ 是完全的，则帕塞 $\overline { { \mathtt { E L } } }$ 尔等式成立：

$$
\int_ {a} ^ {b} | \psi (y) | ^ {2} \mathrm{d} y = \sum_ {j = 1} ^ {\infty} | d _ {j} | ^ {2}.\tag{11.45c}
$$

#### 11.3.4 第一类齐次积分方程的解

如果 $\varphi ( y )$ 和 $\varphi ^ { h } ( y )$ 分别是非齐次和齐次积分方程的任意解，即

$$
f (x) = \int_ {a} ^ {b} K (x, y) \varphi (y) \mathrm{d} y,\tag{11.48a}
$$

$$
0 = \int_ {a} ^ {b} K (x, y) \varphi^ {h} (y) \mathrm{d} y,\tag{11.48b}
$$

则它们的和 $\varphi ( y ) + \varphi ^ { h } ( y )$ 是非齐次积分方程的一个解．因而，要确定齐次积分方程的所有解这个问题与确定线性方程组

$$
\sum_ {j = 1} ^ {\infty} K _ {i j} c _ {j} = 0 \quad (i = 1, 2, \dots)\tag{11.49}
$$

叩原文把 $K _ { i j }$ 式中的 sinjy 误为 sin iy. 译者注的所有非平凡解是一样的．有时，这个方程组不是那么容易就能解的，下述方法可用千计算如果存在一个完全规范正交系 $\left( \alpha _ { n } ( x ) \right)$ ），取函数

$$
K _ {i} (y) = \int_ {c} ^ {d} K (x, y) \alpha_ {i} (x) \mathrm{d} x \quad (i = 1, 2, \dots).\tag{11.50a}
$$

如果 $\varphi ^ { h } ( y )$ 是齐次方程的任一解，即成立

$$
\int_ {a} ^ {b} K (x, y) \varphi^ {h} (y) \mathrm{d} y = 0,\tag{11.50b}
$$

则用 $\alpha _ { i } ( x )$ 乘以这个方程并关千 积分，即给出

$$
0 = \int_ {a} ^ {b} \varphi^ {h} (y) \int_ {c} ^ {d} K (x, y) \alpha_ {i} (x) \mathrm{d} x \mathrm{d} y = \int_ {a} ^ {b} \varphi^ {h} (y) K _ {i} (y) \mathrm{d} y \quad (i = 1, 2, \dots),\tag{11.50c}
$$

即，齐次方程的每个解 $\varphi ^ { h } ( y )$ 都与每个函数 $K _ { i } ( y )$ 正交．用一个规范正交系 $\left( K _ { n } ^ { * } ( y ) \right)$ 代替 $\left( K _ { n } ( y ) \right)$ ），并利用一个正交化过程，替代 (11.50c) 而有

$$
\int_ {a} ^ {b} \varphi^ {h} (y) K _ {i} ^ {*} (y) \mathrm{d} y = 0.\tag{11.50d}
$$

把规范正交系 $\left( K _ { n } ^ { * } ( y ) \right)$ 拓广为一个完全规范正交系，那么 (11.50d) 显然对新函数的每个线性组合都成立．如果规范正交系 $\left( K _ { n } ^ { * } ( y ) \right)$ 已经是完全的，那么只存在平凡解 $\varphi ^ { h } ( y ) = 0$

$$

#### 11.3.5 对于一个给定核的两个特殊的规范正交系的构造

1. 预备知识

无限线性方程组的解（参见第 836 11.3.3) 通常并不比原始问题的解容易选取适当的规范正交系 $( \alpha _ { n } ( x ) )$ 和 $( \beta _ { n } ( y ) )$ 可以使得较容易地解方程组而改变核矩阵 的结构用下述方法可以构造两个规范正交系使得核矩阵的系数 $K _ { i j }$ 仅当$i = j$ 和 $i = j + 1$ 时是非零的．

利用前一节中所给的方法，首先要确定两个规范正交系 $( \beta _ { n } ^ { h } ( y ) )$ 和 $\textstyle ( \alpha _ { n } ^ { h } ( x ) )$ ），即分别是齐次积分方程和相应的伴随齐次积分方程的解组．这意味着，用函 $\beta _ { n } ^ { h } ( y )$ 和 $\alpha _ { n } ^ { h } ( x )$ 的线性组合可以给出这两个积分方程所有的解．这些规范正交系不是完全的．用下述方法这两个系被一步一步地完全为完全规范正交系 $\alpha _ { j } ( x ) , \beta _ { j } ( y ) ( j =$ $1 , 2 , \cdots )$

2. 过程

首先确定一个正规化函数 $\alpha _ { 1 } ( x )$ ，它正交千每个函数 $\alpha _ { n } ^ { h } ( x )$ 贮再对 $j = 1 , 2 , \cdots$ 施行以下步骤

(1) 由下述公式确定函数 $\beta _ { j } ( y )$ 和数 $\nu _ { j }$

$$
\nu_ {1} \beta_ {1} (y) = \int_ {c} ^ {d} K (x, y) \alpha_ {1} (x) \mathrm{d} x,\tag{11.51a}
$$

$$
\nu_ {j} \beta_ {j} (y) = \int_ {c} ^ {d} K (x, y) \alpha_ {j} (x) \mathrm{d} x - \mu_ {j - 1} \beta_ {j - 1} (y) \quad (j \neq 1),\tag{11.51b}
$$

因而 $\nu _ { j } \neq 0$ , 且 $\beta _ { j } ( y )$ 是正规化的．则 $\beta _ { j } ( y )$ 正交千所有函数 $\big ( ( \beta _ { n } ^ { h } ( y ) ) , \beta _ { 1 } ( y ) , \cdot \cdot \cdot$ $\beta _ { j - 1 } ( y ) )$

(2) 由公式

$$
\mu_ {j} \alpha_ {j + 1} (x) = \int_ {a} ^ {b} K (x, y) \beta_ {j} (y) \mathrm{d} y - \nu_ {j} \alpha_ {j} (x)\tag{11.51c}
$$

#### 11.3.6 迭代法

为了解积分方程

$$
f (x) = \int_ {a} ^ {b} K (x, y) \varphi (y) \mathrm{d} y \quad (c \leqslant x \leqslant d),\tag{11.54a}
$$

从 $\alpha _ { 0 } ( x ) = f ( x )$ 开始，对千 $n = 1 , 2 , \cdots$ 确定诸函数

$$
\begin{array}{l} \beta_ {n} (y) = \int_ {c} ^ {d} K (x, y) \alpha_ {n - 1} (x) \mathrm{d} x, \\ \alpha_ {n} (x) = \int_ {a} ^ {b} K (x, y) \beta_ {n} (y) \mathrm{d} y. \end{array}\tag{11.54b}
$$

(11.54c)

如果 (11.54a) 存在一个平方可积解 $\varphi ( y )$ ，则下列等式成立：

$$
\begin{array}{c} \int_ {a} ^ {b} \varphi (y) \beta_ {n} (y) \mathrm{d} y = \int_ {a} ^ {b} \int_ {c} ^ {d} \varphi (y) K (x, y) \alpha_ {n - 1} (x) \mathrm{d} x \mathrm{d} y \\ = \int_ {c} ^ {d} f (x) \alpha_ {n - 1} (x) \mathrm{d} x \quad (n = 1, 2, \dots). \end{array}\tag{11.54d}
$$

函数系 (11.54 b), (11. 54c) 的正交化和规范化给出了规范正交系 $( \alpha _ { n } ^ { * } ( x ) )$ 和 $\left( \beta _ { n } ^ { * } ( y ) \right)$ 利用施密特正交化方法则 $\beta _ { n } ^ { * } ( y )$ 有形式

$$
\beta_ {n} ^ {*} (y) = \sum_ {j = 1} ^ {n} b _ {n j} \beta_ {j} (y) \quad (n = 1, 2, \dots).\tag{11.54e}
$$

现在假设 (11.54a) 的解 $\varphi ( y )$ 有级数表达式心

$$
\varphi (y) = \sum_ {n = 1} ^ {\infty} c _ {n} \beta_ {n} ^ {*} (y).\tag{11.54f}
$$

注意到 (11.54d) ，对千系数 $c _ { n }$ 九即有

$$
c _ {n} = \int_ {a} ^ {b} \varphi (y) \beta_ {n} ^ {*} (y) \mathrm{d} y = \sum_ {j = 1} ^ {n} b _ {n j} \int_ {a} ^ {b} \varphi (y) \beta_ {j} (y) \mathrm{d} y = \sum_ {j = 1} ^ {n} b _ {n j} \int_ {c} ^ {d} f (x) \alpha_ {j - 1} (x) \mathrm{d} x.\tag{11.54g}
$$

为了有形如 (11.54f) 的解，下述两个条件都是充要条件：

$$
(1) \int_ {c} ^ {d} [ f (x) ] ^ {2} \mathrm{d} x = \sum_ {n = 1} ^ {\infty} \left| \int_ {c} ^ {d} f (x) \alpha_ {n} ^ {*} (x) \mathrm{d} x \right| ^ {2};\tag{11.55a}
$$

$$
(2) \sum_ {n = 1} ^ {\infty} | c _ {n} | ^ {2} <   \infty .\tag{11.55b}
$$
