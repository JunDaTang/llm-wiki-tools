### 4.6 矩阵特征值问题

#### 4.6.1 一般特征值问题

是两个 阶方阵它们的元素可以是实数或复数．一般特征值问题是确定满足方程

$$
A \underline {{x}} = \lambda B \underline {{x}}\tag{4.193}
$$

的数入及相应的向量 $\underline { { \boldsymbol { x } } } \neq \underline { { \mathbf { 0 } } } .$ ．数入称为特征值，向量竺称为对应千入的特征向量．因为若 $\underline { { \boldsymbol { x } } }$ 是一个对应千入的特征向量，则 $c { \underline { { { x } } } } ( c$ 是常数）也是一个特征向量，所以特征向量可以确定到不计常数因子．在 $B = I$ 的特殊情形（这里 阶单位矩阵），即

$$
A \underline {{{{x}}}} = \lambda \underline {{{{x}}}} \quad \text {或} \quad (A - \lambda) \underline {{{{x}}}} = \underline {{{{0}}}},\tag{4.194}
$$

相应问题称作特殊特征值问题．它经常出现在实际问题中，特别是 为对称矩阵的问题中，因而下面要详细讨论．关千一般特征值问题的更多的信息可在文献 [4.1]找到

#### 4.6.2 特殊特征值问题

4.6.2.1 特征多项式

特征值方程 (4.194) 产生一个齐次方程组，它仅当

$$
\det (\boldsymbol {A} - \lambda \boldsymbol {I}) = 0\tag{4.195a}
$$

时有非平凡解 $\underline { { \boldsymbol { x } } } \neq \underline { { \mathbf { 0 } } }$ 展开行列式 det(A -.XI) 得到

$$
\begin{array}{r l} & {\det (\boldsymbol {A} - \lambda \boldsymbol {I}) = \left| \begin{array}{c c c c c} a _ {1 1} - \lambda & a _ {1 2} & a _ {1 3} & \dots & a _ {1 n} \\ a _ {2 1} & a _ {2 2} - \lambda & a _ {2 3} & \dots & a _ {2 n} \\ \vdots & \vdots & \vdots & & \vdots \\ a _ {n 1} & a _ {n 2} & a _ {n 3} & \dots & a _ {n n} - \lambda \end{array} \right|} \\ & {= P _ {n} (\lambda) = (- 1) ^ {n} \lambda^ {n} + a _ {n - 1} \lambda^ {n - 1} + \dots + a _ {1} \lambda + a _ {0} = 0.} \end{array}\tag{4.195b}
$$

因此特征值行列式等价千一个多项式方程．这个方程称为特征方程，多项式凡 $P _ { n } ( \lambda )$ 称为特征多项式．它的根是矩阵 的特征值．对千任意 阶方阵 A, 下列命题成立

情形 1: 因为 次多项式有 个根（若考虑它们的重数），所以矩阵 $\boldsymbol { A } _ { ( n , n ) }$ ）恰个特征值 $\lambda _ { 1 } , \lambda _ { 2 } , \cdots , \lambda _ { n }$ ，入九．实对称矩阵的特征值都是实数，在其他情形特征值也可能是复数

情形 2: 如果所有 $n$ 个特征值互异，那么矩阵 $\boldsymbol { A } _ { ( n , n ) }$ 恰有 个线性无关的特征向量 $\underline { { \mathbf { x } } } _ { i }$ ，它们是方程组 (4.194) 当 $\lambda = \lambda _ { i }$ 的解．

2. 主轴变换、相似变换

对千每个实对称矩阵 ，存在正交矩阵 和对角矩阵 满足

$$
\boldsymbol {A} = \boldsymbol {U} \boldsymbol {D} \boldsymbol {U} ^ {\mathrm{T}}.\tag{4.198}
$$

的对角元素是 的特征值，且 的列是对应的规范化特征向量．由 (4.198)然有

$$
\pmb {D} = \pmb {U} ^ {\mathrm{T}} \pmb {A} \pmb {U}.\tag{4.199}
$$

(4.199) 称作主轴变换．这样将 归结为对角矩阵（还可参见第 362 4.1.2, 2.).

如果方阵 （不必对称）通过正则方阵 $\pmb { G }$ 被变换为

$$
\boldsymbol {G} ^ {- 1} \boldsymbol {A} \boldsymbol {G} = \widetilde {\boldsymbol {A}},\tag{4.200}
$$

那么称它是相似变换矩阵 $\widetilde { A }$ 称为相似，并且它们有下列性质

(1) 矩阵 和 $\widetilde { A }$ 有相同的特征值，即相似变换不影响特征值．

(2) 如果 对称且 $G$ 正交，那么 $\widetilde { A }$ 对称，还有

$$
\widetilde {A} = G ^ {\mathrm{T}} A G, \quad \text {以及} \quad G ^ {\mathrm{T}} G = I.\tag{4.201}
$$

关系式 (4.201) 称为正交相似变换在此术语下，（4.199) 表明实对称矩阵 可以被变换为与某个实对角矩阵 正交相似．

4.6.2.3 二次型的主轴变换

1. 实二次型定义

变量 $x _ { 1 } , x _ { 2 } , \cdots , x _ { n }$ 的实二次型有形式：

$$
Q = \sum_ {i = 1} ^ {n} \sum_ {j = 1} ^ {n} a _ {i j} x _ {i} x _ {j} = \underline {{\boldsymbol {x}}} ^ {\mathrm{T}} \boldsymbol {A} \underline {{\boldsymbol {x}}},\tag{4.202}
$$

其中 $\underline { { \pmb { x } } } = ( x _ { 1 } , x _ { 2 } , \cdots , x _ { n } ) ^ { \mathrm { T } }$ 是实变量向量，矩阵 是实对称矩阵

如果型 $Q$ 除当 $x _ { 1 } = x _ { 2 } = \cdot \cdot \cdot = x _ { n } = 0$ 情形取值零外只取正值或只取负值，那么它分别称为 $\ I ^ { \ E }$ 定的或负定的．

型 $Q$ 称为半正定的或半负定的，如果它所取的非零值仅是正的或仅是负的，并且当非零向量也可能取值零

实二次型称为不定的，如果它取正值也取负值．依据 $Q$ 的性状，与它相关的实对称矩阵称为正定的、负定的、半正定的或不定的．

2. 实正定二次型性质

(1) 在实正定二次型 $Q$ 中，对应的实对称矩阵 的主对角元都是正的，即有

$$
a _ {i i} > 0 \quad (i = 1, 2, \dots , n).\tag{4.203}
$$

(4.203) 表述了正定矩阵的一个很重要的性质．

(2) 实二次型 是正定的，当且仅当对应的实对称矩阵 的所有特征值是正的．

(3) 设对应千实二次型 $Q = \underline { { \boldsymbol { x } } } ^ { \mathrm { T } } A \underline { { \boldsymbol { x } } }$ 的矩阵 的秩等千 $r ,$ ，那么二次型可以通过线性变换

$$
\underline {{\boldsymbol {x}}} = C \widetilde {\underline {{\boldsymbol {x}}}}\tag{4.204}
$$

化为纯二次项之和，即所谓标准形

$$
Q = \widetilde {\underline {{\boldsymbol {x}}}} ^ {\mathrm{T}} \boldsymbol {K} \widetilde {\underline {{\boldsymbol {x}}}} = \sum_ {i = 1} ^ {r} p _ {i} \widetilde {x} _ {i} ^ {2},\tag{4.205}
$$

其中 $p _ { i } = ( \mathrm { s i g n } \lambda _ { i } ) k _ { i }$ ，并且 $k _ { 1 } , k _ { 2 } , \cdots , k _ { r }$ 是任意预先给定的正常数．

对千任何将秩为 的实二次型变换为标准形 (4.205) 的非奇异变换 (4.204),标准形中正系数个数 $p$ 和负系数个数 $q = r - p$ 是不变的（西尔维斯特惯性定理）．称为二次型的惯性指数．

3. 标准形的生成

应用变换 (4.205) 的一个实用方法是从主轴变换 (4.199) 得来的首先通过正交矩阵 实施坐标系的旋转，这里 的各列是 的特征向量（即新坐标系的轴的方向是特征向量的方向）．这给出型

$$
Q = \widetilde {\underline {{\boldsymbol {x}}}} ^ {\mathrm{T}} \boldsymbol {L} \widetilde {\underline {{\boldsymbol {x}}}} = \sum_ {i = 1} ^ {r} \lambda_ {i} \widetilde {x} _ {i} ^ {2}.\tag{4.206}
$$

这里 是对角元为 的特征值的对角矩阵然后通过对角矩阵 实施伸缩，这的对角元是 $d _ { i } = \sqrt { \frac { k _ { i } } { | \lambda _ { i } | } }$ 是整个变换由矩阵

$$
\boldsymbol {C} = \boldsymbol {U D}\tag{4.207}
$$

给出，并且我们得到

$$
\begin{array}{r l} & Q = \widetilde {\underline {{x}}} ^ {\mathrm{T}} A \widetilde {\underline {{x}}} = (U D \widetilde {\underline {{x}}}) ^ {\mathrm{T}} A (U D \widetilde {\underline {{x}}}) = \widetilde {\underline {{x}}} ^ {\mathrm{T}} (D ^ {\mathrm{T}} U ^ {\mathrm{T}} A U D) \widetilde {\underline {{x}}} \\ & \quad = \widetilde {\underline {{x}}} ^ {\mathrm{T}} D ^ {\mathrm{T}} L D \widetilde {\underline {{x}}} = \widetilde {\underline {{x}}} ^ {\mathrm{T}} K \widetilde {\underline {{x}}}. \end{array}\tag{4.208}
$$

二次型的主轴变换在二阶曲线和曲面的的分类中起着本质性作用（参见第 277 3.5.2.11 及第 306 3.5.3.14).

4. 若尔当标准形

是任意 阶实或复矩阵，那么存在非奇异矩阵 使得

$$
\boldsymbol {T} ^ {- 1} \boldsymbol {A} \boldsymbol {T} = \boldsymbol {J},\tag{4.209}
$$

其中 称为 的若尔当矩阵或若尔当标准形．若尔当矩阵有 (4.210) 形式的分块对角结构，其中 的元素 $\boldsymbol { J } _ { j }$ 称为若尔当块：

$$
J = \left( \begin{array}{c c c c c} J _ {1} & & & & \\ & J _ {2} & & & O \\ & & \ddots & & \\ O & & & J _ {k - 1} & \\ & & & & J _ {k} \end{array} \right).\tag{4.210}
$$

$$
\boldsymbol {J} = \left( \begin{array}{c c c c c} \lambda_ {1} & & & & \\ & \lambda_ {2} & & & O \\ & & \ddots & & \\ O & & & \lambda_ {n - 1} & \\ & & & & \lambda_ {n} \end{array} \right).\tag{4.211}
$$

它们有下列结构：

(1) 如果 只有单特征值 $\lambda _ { j }$ ，那么 $J _ { j } = \lambda _ { j }$ ，并且 $k = n$ 是对角矩阵(4.211).

(2) 如果 $\lambda _ { j }$ 是重数为 $p _ { j }$ 的特征值，那么存在一个或多个 (4.212) 形式的块：

$$
\boldsymbol {J} _ {j} = \left( \begin{array}{c c c c c} \lambda_ {j} & 1 & & & \\ & \lambda_ {j} & 1 & & \boldsymbol {O} \\ & & \ddots & \ddots & \\ \boldsymbol {O} & & & \lambda_ {j} & 1 \\ & & & & \lambda_ {j} \end{array} \right),\tag{4.212}
$$

这里所有这样的块的大小之和等千 $p _ { j }$ ，并且 $\textstyle \sum _ { j = 1 } ^ { k } p _ { j } = n$ ．若尔当块的精确结构取决千特征矩阵 －入 的初等因子的结构．

进一步的信息见 [4.18], [19.3] （第 卷）．

4.6.2.4 对于特征值的数值计算的建议

(1) 特征值可以作为特征方程 (4.195b) 的根计算．为了求出它们必须确定矩阵的特征多项式的系数 $a _ { i } ( i = 0 , 1 , 2 , \cdots , n - 1 )$ ．但是我们必须避开这些计算方法，因为这些方法是极不稳定的也就是说，多项式系数 $a _ { i }$ 的微小变化会导致根 $\lambda _ { j }$ 的大的变化

(2) 有许多解对称矩阵特征值问题的算法．它们可区分为两种类型（见 [4.7]):

a) 变换方法例如雅可比方法、豪斯霍尔德三对角化、 QR 算法

b) 迭代法例如，向量迭代、瑞利－里茨算法、逆迭代、兰乔斯方法、对分法作为例子我们在此讨论米泽斯乘幕法．

(3) 米泽斯乘幕法 是实对称矩阵，并且只有唯一主特征值．迭代法确定这个特征值及相应的特征向量．设主特征值记作 $\lambda _ { 1 }$ ，千是

$$
\left| \lambda_ {1} \right| > \left| \lambda_ {2} \right| \geqslant \left| \lambda_ {3} \right| \geqslant \dots \geqslant \left| \lambda_ {n} \right|.\tag{4.213}
$$

设 $\underline { { { \pmb x } } } _ { 1 } , \underline { { { \pmb x } } } _ { 2 } , \cdots , \underline { { { \pmb x } } } _ { n }$ 九是相应的线性无关的特征向量，那么

a) $A \underline { { { x } } } _ { i } = \lambda _ { i } \underline { { { x } } } _ { i } ( i = 1 , 2 , \cdot \cdot \cdot , n ) .$

(4.214)

b) 每个元素 $\underline { { \boldsymbol { x } } } \in \mathbb { R } ^ { n }$ 以表示为这些特征向量 $\underline { { \mathbf { x } } } _ { i }$ 的线性组合：

$$
\underline {{{{\boldsymbol {x}}}}} = c _ {1} \underline {{{{\boldsymbol {x}}}}} _ {1} + c _ {2} \underline {{{{\boldsymbol {x}}}}} _ {2} + \dots + c _ {n} \underline {{{{\boldsymbol {x}}}}} _ {n} \quad (c _ {i} \text {是常数}; i = 1, 2, \dots , n).\tag{4.215}
$$

(4.215) 两边用 次那么应用 (4.214) 得到

$$
\begin{array}{l} \boldsymbol {A} ^ {k} \underline {{\boldsymbol {x}}} = c _ {1} \lambda_ {1} ^ {k} \underline {{\boldsymbol {x}}} _ {1} + c _ {2} \lambda_ {2} ^ {k} \underline {{\boldsymbol {x}}} _ {2} + \dots + c _ {n} \lambda_ {n} ^ {k} \underline {{\boldsymbol {x}}} _ {n} \\ = \lambda_ {1} ^ {k} \left(c _ {1} \underline {{\boldsymbol {x}}} _ {1} + c _ {2} \left(\frac {\lambda_ {2}}{\lambda_ {1}}\right) ^ {k} \underline {{\boldsymbol {x}}} _ {2} + \dots + c _ {n} \left(\frac {\lambda_ {n}}{\lambda_ {1}}\right) ^ {k} \underline {{\boldsymbol {x}}} _ {n}\right). \end{array}\tag{4.216}
$$

由此关系式和 (4.213) 可见当 $k  \infty$ 时，

$$
\frac {\pmb {A} ^ {k} \underline {{{{\pmb {x}}}}}}{\lambda_ {1} ^ {k} c _ {1}} \rightarrow \underline {{{{\pmb {x}}}}} _ {1}, \quad \text {即} \quad \pmb {A} ^ {k} \underline {{{{\pmb {x}}}}} \approx c _ {1} \lambda_ {1} ^ {k} \underline {{{{\pmb {x}}}}} _ {1}.\tag{4.217}
$$

这是下列迭代程序的基础：

步骤 选择任意初始向量 $\underline { { \pmb x } } ^ { ( 0 ) } \in \mathbb { R } ^ { n }$

步骤 迭代计算

$$
\underline {{{{\pmb {x}}}}} ^ {(k + 1)} = \pmb {A} \underline {{{{\pmb {x}}}}} ^ {k} \quad (k = 0, 1, 2, \dots ; \underline {{{{\pmb {x}}}}} ^ {(0)} \text {给定}).\tag{4.218}
$$

(4.218) 并且注意 (4.217) 可得到

$$
\underline {{\boldsymbol {x}}} ^ {(k)} = \boldsymbol {A} ^ {k} \underline {{\boldsymbol {x}}} ^ {(0)} \approx c _ {1} \lambda_ {1} ^ {k} \underline {{\boldsymbol {x}}} _ {1}.\tag{4.219}
$$

步骤 (4.218) (4.219) 得到

$$
\begin{array}{r l} & {\underline {{\boldsymbol {x}}} ^ {(k + 1)} = \boldsymbol {A} \underline {{\boldsymbol {x}}} ^ {(k)} = \boldsymbol {A} (\boldsymbol {A} ^ {k} \underline {{\boldsymbol {x}}} ^ {(0)}),} \\ & {\boldsymbol {A} (\boldsymbol {A} ^ {k} \underline {{\boldsymbol {x}}} ^ {(0)}) \approx \boldsymbol {A} (c _ {1} \lambda_ {1} ^ {k} \underline {{\boldsymbol {x}}} _ {1}) = c _ {1} \lambda_ {1} ^ {k} (\boldsymbol {A} \underline {{\boldsymbol {x}}} _ {1}),} \\ & {c _ {1} (\lambda_ {1} ^ {k} \boldsymbol {A} \underline {{\boldsymbol {x}}} _ {1}) = \lambda_ {1} (c _ {1} \lambda_ {1} ^ {k} \underline {{\boldsymbol {x}}} _ {1}) \approx \lambda_ {1} \underline {{\boldsymbol {x}}} ^ {(k)},} \end{array}
$$

因此

$$
\underline {{\boldsymbol {x}}} ^ {(k + 1)} \approx \lambda_ {1} \underline {{\boldsymbol {x}}} ^ {(k)},\tag{4.220}
$$

这就是说，对千大的 值相继向量 $\pmb { x } ^ { ( k + 1 ) }$ 和 $\underline { { \boldsymbol { x } } } ^ { ( k ) }$ 近似地相差一个因子 $\lambda _ { 1 }$

$$

#### 4.6.3 奇异值分解

(1) 奇异值和奇异向量 是大小为 $( m , n )$ 的实矩阵，秩等千 $r .$ ．矩阵 $A A ^ { \mathrm { T } }$ 和 $A ^ { \mathrm { T } } A$ 个非零特征值 $\lambda _ { \nu }$ ，并且对千这两个矩阵它们是相同的．矩阵 $A ^ { \mathrm { T } } A$ 的特征值 $\lambda _ { \nu }$ 的正平方根 $d _ { \nu } = \sqrt { \lambda _ { \nu } } ( \nu = 1 , 2 , \cdot \cdot \cdot , r )$ 称为矩阵 的奇异值． $A ^ { \mathrm { T } } A$ 对应的特征向量 $\underline { { \boldsymbol { \ b u } } } _ { \nu }$ 称为矩阵 的右奇异向量， $A A ^ { \mathrm { T } }$ 对应的特征向量 $\underline { { v } } _ { \nu }$ 称为左奇异向量：

$$
\boldsymbol {A} ^ {\mathrm{T}} \boldsymbol {A} \underline {{\boldsymbol {u}}} _ {\nu} = \lambda_ {\nu} \underline {{\boldsymbol {u}}} _ {\nu}, \quad \boldsymbol {A} \boldsymbol {A} ^ {\mathrm{T}} \underline {{\boldsymbol {v}}} _ {\nu} = \lambda_ {\nu} \underline {{\boldsymbol {v}}} _ {\nu} \quad (\nu = 1, 2, \dots , r).\tag{4.222a}
$$

左右奇异向量间的关系是

$$
\boldsymbol {A} \underline {{\boldsymbol {u}}} _ {\nu} = d _ {\nu} \underline {{\boldsymbol {v}}} _ {\nu}, \quad \boldsymbol {A} ^ {\mathrm{T}} \underline {{\boldsymbol {v}}} _ {\nu} = d _ {\nu} \underline {{\boldsymbol {u}}} _ {\nu}.\tag{4.222b}
$$

秩为 的大小为 $( m , n )$ 的矩阵 个正奇异值 $d _ { \nu } ( \nu = 1 , 2 , \cdot \cdot \cdot , r )$ ，有 个正交规范化右奇异向 $\underline { { \mathbf { u } } } _ { \nu }$ 和 个正交规范化左奇异向量 $\underline { { v } } _ { \nu }$ ．此外，对千零奇异值存在 $n - r$ 个正交规范化右奇异向量 $\underline { { { u } } } _ { \nu } ( \nu = r + 1 , \cdot \cdot \cdot , n )$ 和 $m - r$ 个正交规范化左奇异向量 $\underline { { v } } _ { \nu } ( \nu = r + 1 , \cdot \cdot \cdot , m )$ ．因此大小为 $( m , n )$ 的矩阵有 个右奇异向量和$m$ 个左奇异向量，并且可由它们构成两个正交矩阵

$$
\boldsymbol {U} = (\underline {{\boldsymbol {u}}} _ {1}, \underline {{\boldsymbol {u}}} _ {2}, \dots , \underline {{\boldsymbol {u}}} _ {n}), \quad \boldsymbol {V} = (\underline {{\boldsymbol {v}}} _ {1}, \underline {{\boldsymbol {v}}} _ {2}, \dots , \underline {{\boldsymbol {v}}} _ {m})\tag{4.223}
$$

（参见第 368 4.1.4, 9.).

(2) 奇异值分解表达式

$$
\boldsymbol {A} = \boldsymbol {V} \hat {\boldsymbol {A}} \boldsymbol {U} ^ {\mathrm{T}}\tag{4.224a}
$$

称为矩阵 的奇异值分解，其中

$$
\hat {\boldsymbol {A}} = \left( \begin{array}{c c c c c c c c} d _ {1} & 0 & 0 & \dots & 0 & 0 & \dots & 0 \\ 0 & d _ {2} & & & 0 & 0 & & 0 \\ \vdots & & \ddots & & \vdots & \vdots & & \vdots \\ \vdots & & & \ddots & 0 & \vdots & & \vdots \\ 0 & \dots & \dots & 0 & d _ {r} & 0 & \dots & 0 \\ \hline 0 & 0 & \dots & \dots & 0 & 0 & \dots & 0 \\ 0 & & & & 0 & \vdots & & \vdots \\ \vdots & & & & \vdots & \vdots & & \vdots \\ 0 & 0 & \dots & \dots & 0 & 0 & \dots & 0 \\ \hline r \text {列} & n - r \text {列}. \end{array} \right) \left\{ \begin{array}{l l} r \text {行} \\ m - r \text {行} \end{array} \right.\tag{4.224b}
$$

矩阵 $\hat { \boldsymbol A }$ 与矩阵 的大小同为 $( m , n )$ ，并且除最初 个对角元 $\hat { a } _ { \nu \nu } = d _ { \nu } ( \nu =$ $1 , 2 , \cdots , r )$ 外，只有零元素数 $d _ { \nu }$ 是 的奇异值

注 用 $A ^ { \mathrm { H } }$ 代替 $A ^ { \mathrm { T } }$ ，并且代替正交矩阵考虑酉矩阵 ，那么关千奇异值分解的所有论述对千复元素矩阵也成立．
