否则，如果 表面上不是一个数，例如 $x = \pi ,$ ，则输出是 $O u t \left[ 3 \right] = \mathbf { F a l s e }$ 然而Num.ericQ ［兀］得出 True ．这里， True False 是表示布尔常数的符号． IntegerQ[x]检验 $x$ 是否是一个整数，因此

$$
\text { In } [ 4 ] := \text { IntegerQ } [ 2. ] \longrightarrow \text { Out } [ 4 ] = \text { False }
$$

对千具有头 EvenQ, OddQ PrimeQ 的数可以进行类似的检验．它们的意义是显然的．因此，我们有

$$
I n [ 5 ] := \text { PrimeQ } [ 1 0 7 5 6 4 3 ] \longrightarrow O u t [ 5 ] = \text { True }\tag{20.5b}
$$

而

$$
I n [ 6 ] := \text { PrimeQ } [ 1 0 7 5 6 4 1 ] \longrightarrow O u t [ 6 ] = \text { False }\tag{20.5c}
$$

上述检验属千一组检验算子，称为谓词或判据，它们都以 作为结尾并且总是在逻辑检验（包括类型检查）的意义上回答 True False.

20.2.2.2 特殊的数

Mathematica 中，常常需要一些特殊的数，它们能以任意精度被调入．这些数包括以符号 Pi 表示的 $\pi ,$ 以符号 表示的 e, 以常数 Degree 表示的从角度到弧度的变换因子 $\frac { \pi } { 1 8 0 ^ { \circ } }$ 表示符号 $\infty$ Infinity和虚单位 I.

20.2.2.3 数的表示与转换

数可以用不同形式表示，它们可以相互转换．因此，每个实数 可以表示成一个具有 位精确度的浮点数 $\mathbb { N } [ x , n ]$

$$
I N [ 1 ] := \mathbb {N} [ E, 2 0 ] \quad \longrightarrow \quad O u t [ 1 ] = 2. 7 1 8 2 8 1 8 2 8 4 5 9 0 4 5 2 3 5 4\tag{20.6a}
$$

使用 $\mathtt { R a t i o n a l i z e } [ x , \ d x ]$ ，具有精度为 $d x$ 的数 可以转换成一个有理数，即转换成两个整数作成的分数．

$$
I n [ 2 ] := \text { Rationalize } [ E, 1 0 ^ {\wedge} - 5 ] \longrightarrow O u t [ 2 ] = \frac {1 0 7 1}{3 9 4}\tag{20.6b}
$$

Mathematica 用一个具有 准确度的有理数，给出了数 可能的最佳逼近．

不同数制的数可以相互转换．使用 BaseForm[x, b]，以十进制给出的数 被转换成相应的具有数基 $b \leqslant 3 6$ 的数制中的数．如果 $b > 1 0$ 则字母表中依次出现的字母 $a , b , c , \cdots$ 就被进一步用千具有大千十含义的数位．

A:

$$
I n [ 1 ] := \mathrm{BaseForm} [ 2 5 5, 1 6 ] \longrightarrow O u t [ 1 ] = f f _ {1 6}\tag{20.7a}
$$

$$
I n [ 2 ] := \text {BaseForm} [ N [ E, 1 0 ], 8 ] \longrightarrow O u t [ 2 ] = 2. 5 5 7 6 0 5 2 1 3 _ {8}\tag{20.7b}
$$

反向的变换可以用 $b ^ { \wedge \wedge }$ Ammmm 来执行．

$$
I n [ 1 ] := 8 ^ {\wedge \wedge} 7 3 5 \longrightarrow O u t [ 1 ] = 4 7 7\tag{20.7c}
$$
