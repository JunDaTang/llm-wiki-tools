#### 1.1.8 无理式

任何无理式都可通过下述方式化为更简洁的形式: ① 化简指数; ② 把项从根号中开出来; ③ 分母有理化.

(1) 化简指数 若被开方式可因式分解, 且根式的指数和被开方式的指数有公共因子, 就可以化简指数; 根式的指数和被开方式的指数须除以其最大公约数.

$$
\sqrt [ 6 ]{1 6 (x ^ {1 2} - 2 x ^ {1 1} + x ^ {1 0})} = \sqrt [ 6 ]{4 ^ {2} \cdot x ^ {5} \cdot^ {2} (x - 1) ^ {2}} = \sqrt [ 3 ]{4 x ^ {5} (x - 1)}.
$$

(2) 移动无理式 有多种方式可移动无理式到分子上.

$$
{\bf \Delta} \mathrm {\bf A}: \sqrt {\frac {x}{2 y}} = \sqrt {\frac {2 x y}{4 y ^ {2}}} = \frac {\sqrt {2 x y}}{2 y}. \qquad {\bf B}: \sqrt [ 3 ]{\frac {x}{4 y z ^ {2}}} = \sqrt [ 3 ]{\frac {2 x y ^ {2} z}{8 y ^ {3} z ^ {3}}} = \frac {\sqrt [ 3 ]{2 x y ^ {2} z}}{2 y z}.
$$

$$
{\bf \Pi} {\bf C} \colon \frac {1}{x + \sqrt {y}} = \frac {x - \sqrt {y}}{(x + \sqrt {y}) (x - \sqrt {y})} = \frac {x - \sqrt {y}}{x ^ {2} - y}.
$$

$$
\text {■} \mathbf {D}: \frac {1}{x + \sqrt [ 3 ]{y}} = \frac {x ^ {2} - x \sqrt [ 3 ]{y} + \sqrt [ 3 ]{y ^ {2}}}{(x + \sqrt [ 3 ]{y}) (x ^ {2} - x \sqrt [ 3 ]{y} + \sqrt [ 3 ]{y ^ {2}})} = \frac {x ^ {2} - x \sqrt [ 3 ]{y} + \sqrt [ 3 ]{y ^ {2}}}{x ^ {3} + y}.
$$

(3) 幂和根式的最简形式 幂和根式也可以化为最简形式.

$$
A: \sqrt [ 4 ]{\frac {8 1 x ^ {6}}{(\sqrt {2} - \sqrt {x}) ^ {4}}} = \sqrt {\frac {9 x ^ {3}}{(\sqrt {2} - \sqrt {x}) ^ {2}}} = \frac {3 x \sqrt {x}}{\sqrt {2} - \sqrt {x}} = \frac {3 x \sqrt {x} (\sqrt {2} + \sqrt {x})}{2 - x}
$$

$$
\begin{array}{r l} & {= \frac {3 x \sqrt {2 x} + 3 x ^ {2}}{2 - x}.} \\ & {\blacksquare \textbf {B} \colon \left(\sqrt {x} + \sqrt [ 3 ]{x ^ {2}} + \sqrt [ 4 ]{x ^ {3}} + \sqrt [ 1 2 ]{x ^ {7}}\right) \left(\sqrt {x} - \sqrt [ 3 ]{x} + \sqrt [ 4 ]{x} - \sqrt [ 1 2 ]{x ^ {5}}\right)} \\ & {\qquad = \left(x ^ {1 / 2} + x ^ {2 / 3} + x ^ {3 / 4} + x ^ {7 / 1 2}\right) \left(x ^ {1 / 2} - x ^ {1 / 3} + x ^ {1 / 4} - x ^ {5 / 1 2}\right)} \\ & {\qquad = x + x ^ {7 / 6} + x ^ {5 / 4} + x ^ {1 3 / 1 2} - x ^ {5 / 6} - x - x ^ {1 3 / 1 2} - x ^ {1 1 / 1 2} + x ^ {3 / 4}} \\ & {\qquad + x ^ {1 1 / 1 2} + x + x ^ {5 / 6} - x ^ {1 1 / 1 2} - x ^ {1 3 / 1 2} - x ^ {7 / 6} - x} \\ & {\qquad = x ^ {5 / 4} - x ^ {1 3 / 1 2} - x ^ {1 1 / 1 2} + x ^ {3 / 4} = \sqrt [ 4 ]{x ^ {5}} - \sqrt [ 1 2 ]{x ^ {1 3}} - \sqrt [ 1 2 ]{x ^ {1 1}} + \sqrt [ 4 ]{x ^ {3}}} \\ & {\qquad = x ^ {3 / 4} \left(1 - x ^ {1 / 6} - x ^ {1 / 3} + x ^ {1 / 2}\right) = \sqrt [ 4 ]{x ^ {3}} \left(1 - \sqrt [ 6 ]{x} - \sqrt [ 3 ]{x} + \sqrt {x}\right).} \end{array}
$$
