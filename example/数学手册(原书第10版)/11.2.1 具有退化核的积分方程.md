#### 11.2.1 具有退化核的积分方程

如果一个积分方程的核 $K ( x , y ) ( \mathrm { k e r n e l } \ K ( x , y )$ of an integral equation) 是两个单变量函数积的有限和，即一个函数仅依赖千 $x ,$ ，而另一函数仅依赖千 $y ,$ ，那么它被称为一个退化核 (degenerate kernel) ，或积核 (product kernel).

1. 退化核情形的解

一个具有退化核的第二类弗雷德霍姆积分方程的解导致一个有限维方程组的解．考虑积分方程

$$
\varphi (x) = f (x) + \lambda \int_ {a} ^ {b} K (x, y) \varphi (y) \mathrm{d} y,\tag{11.4a}
$$

其中

$$
K (x, y) = \alpha_ {1} (x) \beta_ {1} (y) + \alpha_ {2} (x) \beta_ {2} (y) + \dots + \alpha_ {n} (x) \beta_ {n} (y).\tag{11.4b}
$$

诸函数 $\alpha _ { 1 } ( x ) , \cdot \cdot \cdot , \alpha _ { n } ( x )$ 和 $\beta _ { 1 } ( x ) , \cdots , \beta _ { n } ( x )$ 在区间 $[ a , b ]$ 上被给出，并被假设是连续的．其次假设函数 $\alpha _ { 1 } ( x ) , \cdot \cdot \cdot , \alpha _ { n } ( x )$ 是线性无关的，即，具有常系数 $c _ { k }$ 的等式

$$
\sum_ {k = 1} ^ {n} c _ {k} \alpha_ {k} (x) \equiv 0\tag{11.5}
$$

叩原文将下式中的 $f ( \xi , y ( \xi ) )$ 误为 $f ( \xi , \eta ( \xi ) )$ ． 译者注对每个 $x \in [ a , b ]$ 成立，仅当 $c _ { 1 } = c _ { 2 } = \cdot \cdot \cdot = c _ { n } = 0$ 时否则 $K ( x , y )$ 可以被表示成较小数目乘积的和．

(11.4a) (11.4b) 即得

$$
\varphi (x) = f (x) + \lambda \alpha_ {1} (x) \int_ {a} ^ {b} \beta_ {1} (y) \varphi (y) \mathrm{d} y + \dots + \lambda \alpha_ {n} (x) \int_ {a} ^ {b} \beta_ {n} (y) \varphi (y) \mathrm{d} y.\tag{11.6a}
$$

式中的这些积分不再是变量 的函数，它们是常数．用 $A _ { k }$ 表示它们：

$$
A _ {k} = \int_ {a} ^ {b} \beta_ {k} (y) \varphi (y) \mathrm{d} y, \quad k = 1, \dots , n.\tag{11.6b}
$$

解函数 $\varphi ( x )$ ，如果存在，是扰动函数 $f ( x )$ 和诸函数 $\alpha _ { 1 } ( x ) , \cdot \cdot \cdot , \alpha _ { n } ( x )$ 的一个线性组合之和

$$
\varphi (x) = f (x) + \lambda A _ {1} \alpha_ {1} (x) + \lambda A _ {2} \alpha_ {2} (x) + \dots + \lambda A _ {n} \alpha_ {n} (x).\tag{11.6c}
$$

2. 解的系数的计算

如下计算诸系数 $A _ { 1 } , \cdots , A _ { n }$ ．用 $\beta _ { k } ( x )$ 乘以方程 (11.6c)，并在区间 $[ a , b ]$ 上关于 $x$ 计算其积分：

$$
\begin{array}{c} \int_ {a} ^ {b} \beta_ {k} (x) \varphi (x) \mathrm{d} x = \int_ {a} ^ {b} \beta_ {k} (x) f (x) \mathrm{d} x + \lambda A _ {1} \int_ {a} ^ {b} \beta_ {k} (x) \alpha_ {1} (x) \mathrm{d} x + \dots \\ + \lambda A _ {n} \int_ {a} ^ {b} \beta_ {k} (x) \alpha_ {n} (x) \mathrm{d} x. \end{array}\tag{11.7a}
$$

根据 (11.6b)，这个方程的左端等千 $A _ { k }$ . 利用下述记号

$$
b _ {k} = \int_ {a} ^ {b} \beta_ {k} (x) f (x) \mathrm{d} x, \quad c _ {k j} = \int_ {a} ^ {b} \beta_ {k} (x) \alpha_ {j} (x) \mathrm{d} x,\tag{11.7b}
$$

则对千 $k = 1 , \cdots , n$ ，有

$$
A _ {k} = b _ {k} + \lambda c _ {k 1} A _ {1} + \lambda c _ {k 2} A _ {2} + \dots + \lambda c _ {k n} A _ {n}.\tag{11.7c}
$$

有可能不能计算 (11.7b) 中那些积分的精确值．一旦出现这种情形，必须用给出在1252 19.3 中的那些公式之一来计算它们的近似值．线性方程组 (11.7c) 对千未知值 $A _ { 1 } , \cdots , A _ { n }$ 包含 个方程：

$$
\begin{array}{c} (1 - \lambda c _ {1 1}) A _ {1} - \lambda c _ {1 2} A _ {2} - \dots - \lambda c _ {1 n} A _ {n} = b _ {1}, \\ - \lambda c _ {2 1} A _ {1} + (1 - \lambda c _ {2 2}) A _ {2} - \dots - \lambda c _ {2 n} A _ {n} = b _ {2}, \\ \dots \dots \\ - \lambda c _ {n 1} A _ {1} - \lambda c _ {n 2} A _ {2} - \dots + (1 - \lambda c _ {n n}) A _ {n} = b _ {n}. \end{array}\tag{11.7d}
$$

3. 解、本征值、本征函数的分析

从线性方程组的理论知道 (11.7d) 有且仅有一个解 $A _ { 1 } , \cdots , A _ { n }$ ，如果系数矩阵行列式不等千零，即

$$
D (\lambda) = \left| \begin{array}{c c c c} (1 - \lambda c _ {1 1}) & - \lambda c _ {1 2} & \dots & - \lambda c _ {1 n} \\ - \lambda c _ {2 1} & (1 - \lambda c _ {2 2}) & \dots & - \lambda c _ {2 n} \\ \vdots & \vdots & & \vdots \\ - \lambda c _ {n 1} & - \lambda c _ {n 2} & \dots & (1 - \lambda c _ {n n}) \end{array} \right| \neq 0.\tag{11.8}
$$

显然， $D ( \boldsymbol { \lambda } )$ ）不恒为零，因为有 $D ( 0 ) = 1$ . 因而存在一个数 $R > 0$ ，使得当 $| \lambda | < R$ 时 $D ( \boldsymbol { \lambda } ) \neq 0$ ．为了进一步的研究考虑两种不同的情形

情形 $D ( \boldsymbol { \lambda } ) \neq \mathbf { 0 }$

积分方程恰好有形如 (11.6c) 的一个解，并且诸系数 $A _ { 1 } , \cdots , A _ { n }$ 巾方程组(11.7d) 的解给出．如果 (11.4a) 是一个齐次积分方程，即 $f ( x ) \equiv 0 _ { : }$ 则 $b _ { 1 } = b _ { 2 } =$ $\cdots = b _ { n } = 0$ ．此时齐次方程组 (11.7d) 只有平凡解 $A _ { 1 } = A _ { 2 } = \cdots = A _ { n } = 0$ .这个情形只有函数 $\varphi ( x ) \equiv 0$ 满足积分方程

情形 $D ( \boldsymbol { \lambda } ) = \mathbf { 0 }$

$D ( \boldsymbol { \lambda } )$ ）是一个不高千 次的多项式，因而它至多有 个根．对千入的这些值，$b _ { 1 } = b _ { 2 } = \cdot \cdot \cdot = b _ { n } = 0$ 时的齐次方程组 (11.7d) 还有非平凡解，因而除了平凡解$\varphi ( x ) \equiv 0$ 外，齐次方程组有别的形如

$$
\varphi (x) = C \cdot \left(A _ {1} \alpha_ {1} (x) + A _ {2} \alpha_ {2} (x) + \dots + A _ {n} \alpha_ {n} (x)\right) \quad (C \text {是一个任意常数})
$$

的解．由千 $\alpha _ { 1 } ( x ) , \cdot \cdot \cdot , \alpha _ { n } ( x )$ 是线性无关的，因此 $\varphi ( x )$ 不恒等千零． （入）的根被称为积分方程的本征值(eigenvalues)．齐次积分方程相应的非零解被称为属千本征值入的本征函数 (eigenfunctions)．儿个线性无关的本征函数可以属千同一个本征值如果积分方程有一个一般的核，那么就要考虑齐次积分方程有非平凡解的所有那些本征值入．有些作者把满足 $D ( \boldsymbol { \lambda } ) = 0$ 的入称为特征数，把 $\mu = \frac { 1 } { \lambda }$ 称为相应千形如 $\mu \varphi ( x ) = \int _ { a } ^ { b } K ( x , y ) \varphi ( y ) \mathrm { d } y$ 方程的本征值

$$
\psi (x) = g (x) + \lambda \int_ {a} ^ {b} K (y, x) \psi (y) \mathrm{d} y.\tag{11.9a}
$$

令入是一个本征值， $\varphi ( x )$ 是齐次积分方程 (11.4a) 的一个解．容易证明入也是伴随积分方程的一个本征值．现在 (11.4a) 的两端乘以齐次伴随积分方程的任一解 $\psi ( x )$

$$
