1. 线性方程组

个含 个未知数 $x _ { 1 } , x _ { 2 } , \cdots , x _ { n }$ 的线性方程形成的组

$$

$$
a _ {m 1} x _ {1} + a _ {m 2} x _ {2} + \dots + a _ {m n} x _ {n} = a _ {m},
$$

或简明地记为

$$
\boldsymbol {A} \underline {{\boldsymbol {x}}} = \underline {{\boldsymbol {a}}},\tag{4.177a}
$$

$$

#### 4.5.3 超定线性方程组

4.5.3.1 超定线性方程组和线性最小二乘问题

1. 超定方程组

考虑具有长方系数矩阵 $A = ( a _ { i j } ) ( i = 1 , 2 , \cdot \cdot \cdot , m ; j = 1 , 2 , \cdot \cdot \cdot , n ; m > n )$ 的线性方程组

$$
A \underline {{x}} = \underline {{b}}.\tag{4.187}
$$

矩阵 和右边的向量 $\underline { { \boldsymbol { b } } } = ( b _ { 1 } , b _ { 2 } , \cdots , b _ { m } ) ^ { \mathrm { T } }$ 是给定的，向量 $\underline { { \pmb { x } } } = ( x _ { 1 } , x _ { 2 } , \cdots , x _ { n } ) ^ { \mathrm { T } }$ 是未知的因为 $m > n$ 所以这个方程组称为超定组我们可以讨论解的存在性和唯一性，并且有时还可用（例如）选主元法求解．

2. 线性最小二乘问题

如果 (4.187) 是表示实际问题的数学模型（即 A,h\_,\~ 是实的），那么因为测量或其他误差，不可能求出 (4.187) 满足所有方程的精确解如果代入任何向量竺 $\underline { { \mathbf { x } } } .$ 那么将产生由

$$
\underline {{r}} = A \underline {{x}} - \underline {{b}}, \quad \underline {{r}} \neq \underline {{0}}\tag{4.188}
$$

给出的残差向量 $\underline { { \boldsymbol { r } } } = ( r _ { 1 } , r _ { 2 } , \cdots , r _ { m } ) ^ { \mathrm { T } }$ ．在此情形要确定生使得残差向量的模尽可能小．现在设 A,h\_，竺是实的．如果考虑欧氏模，那么必须有

$$
\sum_ {i = 1} ^ {m} r _ {i} ^ {2} = \underline {{\textbf {r}}} ^ {\mathrm{T}} \underline {{\textbf {r}}} = (\boldsymbol {A} \underline {{\boldsymbol {x}}} - \underline {{\boldsymbol {b}}}) ^ {\mathrm{T}} (\boldsymbol {A} \underline {{\boldsymbol {x}}} - \underline {{\boldsymbol {b}}}) = \min,\tag{4.189}
$$

即残差平方和必须极小．高斯就已经有这样的思想．公式 (4.189) 称为线性最小二乘方问题残差向量 的模 $\| \underline { { \boldsymbol { r } } } \| = \sqrt { \underline { { \boldsymbol { r } } } ^ { \mathrm { T } } \underline { { \boldsymbol { r } } } }$ 称为残差．

3. 高斯变换

如果残差向量 的每个列正交，那么向量生是（4.189) 的解．这就是

$$
\pmb {A} ^ {\mathrm{T}} \underline {{{{\pmb {r}}}}} = \pmb {A} ^ {\mathrm{T}} (\pmb {A} \underline {{{{\pmb {x}}}}} - \underline {{{{\pmb {b}}}}}) = \underline {{{{\pmb {0}}}}} \quad \text {或} \quad \pmb {A} ^ {\mathrm{T}} \pmb {A} \underline {{{{\pmb {x}}}}} = \pmb {A} ^ {\mathrm{T}} \underline {{{{\pmb {b}}}}}.\tag{4.190}
$$

方程 (4.190) 实际上是系数矩阵是方阵的线性方程组将它称为正规方程组它的维数为 n. 由（4.187) (4.190) 的转化称作 $\frac { \dot { \pi } } { \vert \nabla \vert }$ 斯变换矩阵 $A ^ { \mathrm { T } } A$ 是对称的．

如果矩阵 的秩为 （因为 $m > n$ ，所以 的所有列是线性无关的），那么矩阵 $A ^ { \mathrm { T } } A$ 是正定的，因而是正则的，即如果 的秩等千未知数的个数，那么正规方程组有唯一解．

4.5.3.2 对最小二乘问题数值解的建议

1. 楚列斯基方法

因为矩阵 $A ^ { \mathrm { T } } A$ 是对称的，并且在 $\operatorname { r a n k } ( A ) = n$ 的情形是正定的，所以为解正规方程组我们可以应用楚列斯基方法（参见第 1245 19.2.1.2)．不幸的是，这个算法虽然在“大“残差 $\| \underline { { \boldsymbol { r } } } \|$ 和“小“解 $| | \underline { { \boldsymbol { x } } } | |$ 的情形实施得还算不错，但在数值上是相当不稳定的

2. 豪斯霍尔德方法

适用千解最小二乘问题的数值方法是正交化方法，它基千分解 $A = Q R$ .特别适用的是豪斯霍尔德方法，其中 $Q$ 是大小为 $( m , m )$ 的正交矩阵， 是大小为$( m , n )$ 的三角矩阵（参见第 364 4.1.2, 11.).

3. 正则化问题

在秩亏格情形，即如果 $\operatorname { r a n k } ( A ) < n$ ，那么正规方程组不再有唯一解，并且正交化方法给出无用的结果．千是代替 (4.189) 考虑所谓正则化问题：

$$
\underline {{\textbf {r}}} ^ {\mathrm{T}} \underline {{\textbf {r}}} + \alpha \underline {{\textbf {x}}} ^ {\mathrm{T}} \underline {{\textbf {x}}} = \min!,\tag{4.191}
$$

这里 $\alpha > 0$ 是正则化参数对千 (4.191) 的正规方程是

$$
(\boldsymbol {A} ^ {\mathrm{T}} \boldsymbol {A} + \alpha \boldsymbol {I}) \underline {{\boldsymbol {x}}} = \boldsymbol {A} ^ {\mathrm{T}} \underline {{\boldsymbol {b}}}.\tag{4.192}
$$

当 $\alpha > 0$ 时这个线性方程组的系数矩阵正定并且正则，但选取合适的正则化参数是一个困难的问题（见 [4.7]).
