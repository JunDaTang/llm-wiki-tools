#### 5.4.2 线性丢番图方程

1. 丢番图方程

方程 $f ( x _ { 1 } , x _ { 2 } , \cdot \cdot \cdot , x _ { n } ) = b$ 称作 个未知数的丢番图 (Diophantine) 方程，当且仅当 $f ( x _ { 1 } , x _ { 2 } , \cdots , x _ { n } )$ ）是 $x _ { 1 } , x _ { 2 } , \cdots , x _ { n }$ 的系数在整数集 中的多项式， 是一个整常数，并且仅考虑整数解命名“丢番图”是为纪念希腊数学家丢番图，他生活在公元 250 年前后．

在实际中，丢番图方程出现在，例如，数量之间关系的刻画中．迄今只有 个未知数并且至多两次的丢番图方程的一般解是已知的．仅在特殊情形才知道高次丢番图方程的解

2. 个未知数的线性丢番图方程

个未知数的线性丢番图方程是指形如

$$
a _ {1} x _ {1} + a _ {2} x _ {2} + \dots + a _ {n} x _ {n} = b \quad (a _ {i} \in \mathbb {Z}, b \in \mathbb {Z})\tag{5.240}
$$

的方程这里仅求整数解下面给出它的解法

5. $n > 2$ 时的归约方法

设给定可解的丢番图方程

$$
a _ {1} x _ {1} + a _ {2} x _ {2} + \dots + a _ {n} x _ {n} = b,\tag{5.242a}
$$

其中 $( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } ) \neq ( 0 , 0 , \cdots , 0 )$ ，并且 $\operatorname* { g c d } ( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } ) = 1$ ．如果 $\operatorname* { g c d } ( a _ { 1 }$ $a _ { 2 } , \cdots , a _ { n } ) \neq 1$ , 那么可用 $\operatorname* { g c d } ( a _ { 1 } , a _ { 2 } , \cdots , a _ { n } )$ ）除方程作变换

$$
a _ {1} x _ {1} + a _ {2} x _ {2} + \dots + a _ {n - 1} x _ {n - 1} = b - a _ {n} x _ {n}\tag{5.242b}
$$

后，将 $x _ { n }$ 看作一个整常数，得到一个含有 $n - 1$ 个变量的线性丢番图方程因而它当且仅当 $\operatorname* { g c d } ( a _ { 1 } , a _ { 2 } , \cdots , a _ { n - 1 } )$ 整除 $b - a _ { n } x _ { n }$ 时可解．

条件

$$
\operatorname * {g c d} (a _ {1}, a _ {2}, \dots , a _ {n - 1}) \mid b - a _ {n} x _ {n}\tag{5.242c}
$$

被满足，当且仅当存在整数 $\underline { { c } } , \underline { { c } } _ { n }$ 使得

$$
\operatorname * {g c d} (a _ {1}, a _ {2}, \dots , a _ {n - 1}) \cdot \underline {{c}} + a _ {n} \cdot \underline {{c}} _ {n} = b.\tag{5.242d}
$$

这是两个未知数的线性丢番图方程并且它可以如同第 503 5.4.2, 4. 那样求解如果确定了它的解，那么剩下要解只有 $n - 1$ 个未知数的丢番图方程．继续这个过程直到得到两个未知数的丢番图方程，这可用第 503 5.4.2, 4. 给出的方法求解．最后所给方程的解由这样得到的解集构造出来
