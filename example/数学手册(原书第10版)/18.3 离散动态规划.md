### 18.3 离散动态规划

#### 18.3.1 离散动态决策模型

很大一类优化问题可以用动态规划法求解．我们把这样的优化问题看作自然地或形式上按时间行进的过程，并且它由依赖时间的决策所控制．如果这一过程可以分解成有穷或可数无穷多步，则它称为离散动态规划．本节仅讨论 级离散过程

$$
\left. \begin{array}{l l} \mathbf {O F}: f (u _ {1}, \dots , u _ {n}) = \sum_ {j = 1} ^ {n} f _ {j} (u _ {j}) = \sum_ {j = 1} ^ {n} c _ {j} u _ {j} \longrightarrow \min! \\ \mathbf {C T}: x _ {j} = x _ {j - 1} + u _ {j} - v _ {j}, & j = 1 (1) n, \\ x _ {0} = x _ {a}, 0 \leqslant x _ {j} \leqslant K, & j = 1 (1) n, \\ U _ {j} (x _ {j - 1}) = \{u _ {j}: \max \{0, v _ {j} - x _ {j - 1} \} & \\ \leqslant u _ {j} \leqslant K - x _ {j - 1} \}, & j = 1 (1) n. \end{array} \right\}\tag{18.127a}

#### 18.3.3 贝尔曼泛函方程

18.3.3.1 费用函数的性质

为了叙述贝尔曼泛函方程费用函数必须满足两个性质．

1. 可分性

函数 $f ( f _ { 1 } ( { \underline { { \mathbf { x } } } } _ { 0 } , { \underline { { \mathbf { u } } } } _ { 1 } ) , \cdots , f _ { n } ( { \underline { { \mathbf { x } } } } _ { n - 1 } , { \underline { { \mathbf { u } } } } _ { n } ) )$ ）称作可分的，是指它可以由双参函数$H _ { 1 } , \cdots , H _ { n - 1 }$ 以及函数 $F _ { 1 } , \cdots , F _ { n }$ 按如下方式给出：

$$
\begin{array}{r l} & f (f _ {1} (\underline {{\boldsymbol {x}}} _ {0}, \underline {{\boldsymbol {u}}} _ {1}), \dots , f _ {n} (\underline {{\boldsymbol {x}}} _ {n - 1}, \underline {{\boldsymbol {u}}} _ {n})) \\ & = F _ {1} (f _ {1} (\underline {{\boldsymbol {x}}} _ {0}, \underline {{\boldsymbol {u}}} _ {1}), \dots , f _ {n} (\underline {{\boldsymbol {x}}} _ {n - 1}, \underline {{\boldsymbol {u}}} _ {n})), \\ & F _ {1} (f _ {1} (\underline {{\boldsymbol {x}}} _ {0}, \underline {{\boldsymbol {u}}} _ {1}), \dots , f _ {n} (\underline {{\boldsymbol {x}}} _ {n - 1}, \underline {{\boldsymbol {u}}} _ {n})) \\ & = H _ {1} (f _ {1} (\underline {{\boldsymbol {x}}} _ {0}, \underline {{\boldsymbol {u}}} _ {1}), F _ {2} (f _ {2} (\underline {{\boldsymbol {x}}} _ {1}, \underline {{\boldsymbol {u}}} _ {2}) \dots , f _ {n} (\underline {{\boldsymbol {x}}} _ {n - 1}, \underline {{\boldsymbol {u}}} _ {n}))), \\ & \dots \dots \\ & F _ {n - 1} (f _ {n - 1} (\underline {{\boldsymbol {x}}} _ {n - 2}, \underline {{\boldsymbol {u}}} _ {n - 1}), f _ {n} (\underline {{\boldsymbol {x}}} _ {n - 1}, \underline {{\boldsymbol {u}}} _ {n})) \\ & = H _ {n - 1} (f _ {n - 1} (\underline {{\boldsymbol {x}}} _ {n - 2}, \underline {{\boldsymbol {u}}} _ {n - 1}), F _ {n} (f _ {n} (\underline {{\boldsymbol {x}}} _ {n - 1}, \underline {{\boldsymbol {u}}} _ {n}))), \\ & F _ {n} (f _ {n} (\underline {{\boldsymbol {x}}} _ {n - 1}, \underline {{\boldsymbol {u}}} _ {n})) = f _ {n} (\underline {{\boldsymbol {x}}} _ {n - 1}, \underline {{\boldsymbol {u}}} _ {n}). \end{array}\tag{18.130}
$$

2. 极小可交换性

函数 $H ( \tilde { f } ( \underline { { \mathbf { a } } } ) , \tilde { F } ( \underline { { \mathbf { b } } } ) )$ 称作极小可交换的，是指它满足

$$
\min _ {(\underline {{\boldsymbol {a}}}, \underline {{\boldsymbol {b}}}) \in A \times B} H (\tilde {f} (\underline {{\boldsymbol {a}}}), \tilde {F} (\underline {{\boldsymbol {b}}})) = \min _ {\underline {{\boldsymbol {a}}} \in A} H \Big (\tilde {f} (\underline {{\boldsymbol {a}}}), \min _ {\underline {{\boldsymbol {b}}} \in B} \tilde {F} (\underline {{\boldsymbol {b}}}) \Big).\tag{18.131}
$$

例如如果 对千每个 $\underline { { \mathbf { \delta } } } \mathbf { a } \in A$ 相对千第二变元是单调递增的，即若对千每个 $\underline { { \mathbf { \Pi } } } \mathbf { a } \in A$

$$
H (\tilde {f} (\underline {{{{\boldsymbol {a}}}}}), \tilde {F} (\underline {{{{\boldsymbol {b}}}}} _ {1})) \leqslant H (\tilde {f} (\underline {{{{\boldsymbol {a}}}}}), \tilde {F} (\underline {{{{\boldsymbol {b}}}}} _ {2})), \quad \text {若} \tilde {F} (\underline {{{{\boldsymbol {b}}}}} _ {1}) \leqslant \tilde {F} (\underline {{{{\boldsymbol {b}}}}} _ {2}),\tag{18.132}
$$

则上述可交换性就满足现在对千动态规划问题的费用函数，则要求满足 的可分性以及所有函数 $H _ { j } , j = 1 ( 1 ) n - 1$ 的极小可交换性以下经常出现的费用函数类型就满足这两种要求：

$$
f ^ {\mathrm{sum}} = \sum_ {j = 1} ^ {n} f _ {j} (\underline {{{{\boldsymbol {x}}}}} _ {j - 1}, \underline {{{{\boldsymbol {u}}}}} _ {j}), \text {或者} f ^ {\mathrm{max}} = \max _ {j = 1 (1) n} f _ {j} (\underline {{{{\boldsymbol {x}}}}} _ {j - 1}, \underline {{{{\boldsymbol {u}}}}} _ {j}),\tag{18.133}
$$

而函数 $H _ { j }$ 分别是

$$
H _ {j} ^ {\mathrm{sum}} = f _ {j} (\underline {{\boldsymbol {x}}} _ {j - 1}, \underline {{\boldsymbol {u}}} _ {j}) + \sum_ {k = j + 1} ^ {n} f _ {k} (\underline {{\boldsymbol {x}}} _ {k - 1}, \underline {{\boldsymbol {u}}} _ {k}),\tag{18.134}
$$

以及

$$
H _ {j} ^ {\mathrm{max}} = \max \left\{f _ {j} (\underline {{\boldsymbol {x}}} _ {j - 1}, \underline {{\boldsymbol {u}}} _ {j}), \max _ {k = j + 1 (1) n} f _ {k} (\underline {{\boldsymbol {x}}} _ {k - 1}, \underline {{\boldsymbol {u}}} _ {k}) \right\}.\tag{18.135}
$$

#### 18.3.4 贝尔曼最优性原理

求解泛函方程

$$
\phi_ {j} (\underline {{\boldsymbol {x}}} _ {j - 1}) = \min _ {\underline {{\boldsymbol {u}}} _ {j} \in U _ {j} (\underline {{\boldsymbol {x}}} _ {j - 1})} H _ {j} \left(f _ {j} (\underline {{\boldsymbol {x}}} _ {j - 1}, \underline {{\boldsymbol {u}}} _ {j}), \phi_ {j + 1} (\underline {{\boldsymbol {x}}} _ {j})\right)\tag{18.139}
$$

相当千确定最优策略 $( \underline { { \boldsymbol { u } } } _ { j } ^ { * } , \cdots , \underline { { \boldsymbol { u } } } _ { n } ^ { * } )$ 妇），这一策略使得从状态 $\underline { { \boldsymbol { x } } } _ { j - 1 }$ 开始，由全过程 $P$ 的最后 $n - j + 1$ 级组成的子过程 $P _ { j }$ 的费用函数达到极小，即

$$
F _ {j} (f _ {j} (\underline {{\boldsymbol {x}}} _ {j - 1}, \underline {{\boldsymbol {u}}} _ {j}), \dots , f _ {n} (\underline {{\boldsymbol {x}}} _ {n - 1}, \underline {{\boldsymbol {u}}} _ {n})) \longrightarrow \min!\tag{18.140}
$$

初始状态为 $\underline { { \boldsymbol { x } } } _ { j - 1 }$ 的子过程 $P _ { j }$ 的最优策略与已经将 驱动至状态 $\underline { { \boldsymbol { x } } } _ { j - 1 }$ 的前$j - 1$ 级的决策 $( \underline { { \pmb u } } _ { j } , \cdots , \underline { { \pmb u } } _ { n } )$ 无关．为了确定 $\phi _ { j } ( \underline { { \pmb x } } _ { j - 1 } )$ ），需要知道值 $\phi _ { j + 1 } ( \underline { { \pmb x } } _ { j } )$ ．现在，如果 $( \underline { { \boldsymbol { u } } } _ { j } ^ { * } , \cdots , \underline { { \boldsymbol { u } } } _ { n } ^ { * } )$ ） $P _ { j }$ 的最优策略，则显然 $( \underline { { \pmb u } } _ { j + 1 } ^ { * } , \cdots , \underline { { \pmb u } } _ { n } ^ { * } )$ ）是初始状态为$\underline { { \pmb { x } } } _ { j } = g _ { j } ( \underline { { \pmb { x } } } _ { j - 1 } , \underline { { \pmb { u } } } _ { j } ^ { * } )$ ）的子过程 $P _ { j + 1 }$ 的最优策略这个命题在贝尔曼最优性原理中被进一步推广为贝尔曼原理．

贝尔曼原理 如果（ $( \underline { { \boldsymbol { u } } } _ { 1 } ^ { * } , \cdots , \underline { { \boldsymbol { u } } } _ { n } ^ { * } )$ ）是过程 的最优策略，而（ $( \underline { { \pmb x } } _ { 0 } ^ { * } , \cdots , \underline { { \pmb x } } _ { n } ^ { * } )$ 是相应的状态序列则对千每个子过程 $P _ { j } , ~ j = 1 ( 1 ) n$ 在初始状态 $\underline { { \boldsymbol { x } } } _ { j - 1 } ^ { * }$ 下，策略$( \underline { { \boldsymbol { u } } } _ { j } ^ { * } , \cdots , \underline { { \boldsymbol { u } } } _ { n } ^ { * } )$ ）也是最优的．

的递增顺序逐个确定 $\underline { { \boldsymbol { \ b u } } } _ { j }$ . 然后得到 $\underline { { \pmb x } } _ { j } ^ { * } = g _ { j } ( \underline { { \pmb x } } _ { j - 1 } ^ { * } , \underline { { \pmb u } } _ { j } ^ { * } )$ ）．在前向计算中，每一级都必须求解一个优化问题．

(3) 两种方式的比较 由千是前向计算，方式 计算的代价要小千方式要求的代价．然而，由千每一状态 $\underline { { \boldsymbol { x } } } _ { j - 1 }$ 下都要存储决策 $\underline { { \boldsymbol { \ b u } } } _ { j }$ ，从而在高维决策空间$U _ { j } ( \underline { { \mathbf { x } } } _ { j - 1 } )$ 情形下，这可能需要非常大的存储量，而在方式 中，仅需存储 $\phi _ { j } ( \underline { { \pmb x } } _ { j - 1 } )$ 因此常常在计算机上使用方式 2.
