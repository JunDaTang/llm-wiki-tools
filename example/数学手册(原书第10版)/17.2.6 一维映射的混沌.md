#### 17.2.6 一维映射的混沌

对紧区间到自身的连续映射，有儿个充分条件可以保证存在混沌的不变集合．下面考虑三个例子

赛奈 {Sinai) 定理 $\varphi : I  I$ 为紧区间 $I = [ 0 , 1 ]$ 到自身的连续映射，则上系统 $\{ \varphi ^ { t } \}$ 在德瓦尼意义下是混沌的当且仅当 $\varphi$ 在 上的拓扑嫡 $h ( \varphi )$ ）是正的．

沙可夫斯基 {Sharkovsky) 定理 考虑如下方式的正整数排列：

$$
3 \succ 5 \succ 7 \succ \dots \succ 2 \cdot 3 \succ 2 \cdot 5 \succ \dots \succ 2 ^ {2} \cdot 3 \succ 2 ^ {2} \cdot 5 \succ \dots \succ 2 ^ {3} \succ 2 ^ {2} \succ 2 \succ 1.\tag{17.60}
$$

设 $\varphi : I  I$ 为紧区间到自身的连续映射， $\{ \varphi ^ { k } \}$ 在 上有一个 周期轨道，则对$n \succ m , \{ \varphi ^ { k } \}$ 也有一个 周期轨道．

Block-Guckerheimer-Misiuriewicz 定理 $\varphi : I  I$ 为紧区间 到自身的连续映射，若 $\{ \varphi ^ { k } \}$ 有一个 $2 ^ { n } m$ 周期轨道 $( m > 1$ ，奇数），则 $h ( \varphi ) \geqslant { \frac { \ln 2 } { 2 ^ { n + 1 } } }$
