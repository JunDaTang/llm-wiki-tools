下面解释具有头 Rule Set 的表达式． Set 指派值给右手边的表达式 s,如一个数，给左手边的表达式 指派，例如一个变元．由此开始 表示这个值，直到该指派改变为止．这一改变，要么由一个新指派做出，要么由 $\mathrm { ~ x ~ } { = } .$ ．或 $\mathtt { C l e a r } [ x ]$ 做出，即去除到目前为止的所有指派结构 Rule应被看成一种变换规则它与替换算子／．一同出现

$\mathtt { R e p l a c e } [ t , u - > v ]$ 或 $t / . \ u - > v$ 意思是指表达式 的每个出现将被替换为表达式 V.

$$
\blacksquare I n [ 1 ] := x + y ^ {2} /. y \rightarrow a + b \longrightarrow O u t [ 1 ] = (a + b) ^ {2} + x
$$

对千这两个算子来说，典型的情况是在进行指派或运用变换规则后右手边即刻求出值来．因此，在后面每次调用时左手边将被这个算出值的右手边取代．

在此，还要提到具有延迟赋值的两个算子．

$$
u := v \text {的} \mathrm{FullForm} \text {是} \mathrm{SetDelayed} [ u, v ]\tag{20.8a}
$$

$$
u: - > v \text {的} \mathrm{FullForm} \text {是} \mathrm{RuleDelayed} [ u, v ]\tag{20.8b}
$$

指派或变换规则在此也有效，直到它被改变尽管左手边总是被右手边取代但是只是当调用左手边的那一刻右手边才第一次算出值来．
