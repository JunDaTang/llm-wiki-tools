12.9.5.1 分部积分公式

对千任意（开）区域 $\varOmega \subset \mathbb { R } ^ { n } , \mathscr { C } _ { 0 } ^ { \infty } ( \varOmega )$ 表示 上具有紧支集的任意多次可微函数 $\varphi$ 的集合，这里所谓紧支集是指集合 $\operatorname { s u p p } ( \varphi ) = { \overline { { \{ x \in \Omega : \varphi ( x ) \neq 0 \} } } }$ 在 $\mathbb { R } ^ { n }$ 中是紧的，并且位千 $\varOmega . \mathbb { R } ^ { n }$ 上所有相对千勒贝格测度局部可和的函数集记作 $L _ { \mathrm { l o c } } ^ { 1 } ( \varOmega )$ 即在 上使得对千任意有界区域 $\omega \subset { \mathcal { Q } }$ 有 $\int _ { \omega } | f | \mathrm { d } \lambda < \infty$ 的可测函数（等价类）的全体．这两个集都是向量空间（在自然的代数运算下）．

对千 $1 \leqslant p \leqslant \infty .$ 有 $L ^ { p } ( \Omega ) \subset L _ { \mathrm { l o c } } ^ { 1 } ( \Omega )$ ，而对千有界集 n, 则有 $L ^ { 1 } ( \varOmega ) =$ $L _ { \mathrm { l o c } } ^ { 1 } ( \varOmega )$ ．如果 $c ^ { k } ( { \overline { { \varOmega } } } )$ ）的元看作 $L ^ { p } ( \varOmega )$ 中对应元生成的等价类，那么对千有界集 n,有 $\mathcal { C } ^ { k } ( \overline { { \Omega } } ) \subset L ^ { p } ( \mathcal { Q } )$ ，这里 $c ^ { k } ( { \overline { { \varOmega } } } )$ ）同时也是稠的．如果 是无界的，那么 $\mathcal { C } _ { 0 } ^ { \infty } ( \varOmega )$ （在此意义下）在 $L ^ { p } ( \varOmega )$ 中是稠的．

对千给定的函数 $f \in \mathcal { C } ^ { k } ( \overline { { \varOmega } } )$ 和任意函数 $\varphi \in \mathcal { C } _ { 0 } ^ { \infty } ( \varOmega )$ ，分部积分公式具有如下形式：

$$
\int_ {\Omega} f (x) D ^ {\alpha} \varphi (x) \mathrm{d} \lambda = (- 1) ^ {| \alpha |} \int_ {\Omega} \varphi (x) D ^ {\alpha} f (x) \mathrm{d} \lambda , \forall \alpha , | \alpha | \leqslant k,\tag{12.222}
$$

这里使用了事实： $D ^ { \alpha } \varphi | _ { \partial \Omega } = 0$ . 这个公式将作为定义函数 $f \in L _ { \mathrm { l o c } } ^ { 1 } ( \varOmega )$ 的广义导数的出发点

12.9.5.2 广义导数

假定 $f \in L _ { \mathrm { l o c } } ^ { 1 } ( \varOmega )$ ．如果存在一函数 $g \in L _ { \mathrm { l o c } } ^ { 1 } ( \varOmega )$ ，使得 $\forall \ : \varphi \in \mathcal { C } _ { 0 } ^ { \infty } ( \varOmega )$ ，对千某个多重标号 $\alpha ,$ ，有

$$
\int_ {\Omega} f (x) D ^ {\alpha} \varphi (x) \mathrm{d} \lambda = (- 1) ^ {| \alpha |} \int_ {\Omega} g (x) \varphi (x) \mathrm{d} \lambda ,\tag{12.223}
$$

那么 $g$ 称作 阶广义导数（索伯列夫意义下导数，或分布导数），如同经典情形那样，记作 $g = D ^ { \alpha } f$

向量空间 $\mathcal { C } _ { 0 } ^ { \infty } ( \varOmega )$ 中的序列 $\{ \varphi _ { k } \} _ { k = 1 } ^ { \infty }$ 收敛千 $\varphi$ 定义为

$$
\varphi_ {k} \longrightarrow \varphi \text {当且仅当} \left\{ \begin{array}{l l} \mathrm{a)} & \exists \text {紧集} K \subset \Omega \text {使得} \operatorname{supp} (\varphi_ {k}) \subset K, \forall k \\ \mathrm{b)} & \text {对于每个多重标号} \alpha , \text {在} K \text {上一致} D ^ {\alpha} \varphi_ {k} \longrightarrow D ^ {\alpha} \varphi . \end{array} \right.\tag{12.224}
$$

集合 $\mathcal { C } _ { 0 } ^ { \infty } ( \varOmega )$ 赋以这样的序列收敛后称作基本空间，并记作 ${ \mathcal { D } } ( { \mathcal { Q } } )$ . 其中的元称作测试函数

12.9.5.3 分布

D(Q) 上的连续线性泛函 称作广义函数或分布，这里线性泛函 连续是指（参见第 873 12.2.3):

$$
\varphi , \varphi_ {n} \in \mathcal {D} (\Omega), \quad \varphi_ {n} \to \varphi \Longrightarrow \ell (\varphi_ {n}) \to \ell (\varphi).\tag{12.225}
$$

■ A: 如果 $f \in L _ { \mathrm { l o c } } ^ { 1 } ( \varOmega )$ ，那么

$$
\ell_ {f} (\varphi) = (f, \varphi) = \int_ {\Omega} f (x) \varphi (x) \mathrm{d} \lambda , \quad \varphi \in \mathcal {D} (\Omega)\tag{12.226}
$$

是一分布像 (12.226) 这样由局部可和函数定义的分布称作正则分布．两个正则分布相等，即 $\ell _ { f } ( \varphi ) = \ell _ { g } ( \varphi ) , \ \forall \ \varphi \in { \mathcal { D } } ( \varOmega )$ ，当且仅当相对千测度入， $f = g \mathrm { ~ a . e ~ }$

■ B: $a \in { \mathcal { Q } }$ 是任意固定点．那 $\ell _ { \delta _ { a } } ( \varphi ) = \varphi ( a ) , \varphi \in { \mathcal { D } } ( \varOmega )$ ，是 ${ \mathcal { D } } ( { \mathcal { Q } } )$ 上的连续线性泛函，从而是一分布，称作狄拉克分布、 分布或 函数

由千 $\delta _ { a }$ 不可能由任何局部可和函数产生（见 [12.12], [12.27]），因此这是非正则分布的一个例子．

所有分布的集合记作 $\mathcal { D } ^ { \prime } ( \varOmega )$ ．根据相比 890 12.5.4 中讨论的更一般的对偶理论， $\mathcal { D } ^ { \prime } ( \varOmega )$ 可以作为 ${ \mathcal { D } } ( { \mathcal { Q } } )$ 的对偶空间得到．因而在此意义下应该写 ${ \mathcal { D } } ^ { * } ( { \mathcal { Q } } )$ 代替$\mathcal { D } ^ { \prime } ( \varOmega )$ ．在空间 $\mathcal { D } ^ { \prime } ( \varOmega )$ 中，可以定义与其元有关的运算，以及与 ${ \mathcal { C } } ^ { \infty }$ 的函数有关的运算，例如分布的导数，或两个分布的卷积，从而使得 $\mathcal { D } ^ { \prime } ( \varOmega )$ 不仅在理论研究中，而且在电子工程、力学等实际应用中都起着十分重要的作用．

12.9.5.4 分布的导数

是一给定的分布．由公式

$$
(D ^ {\alpha} \ell) (\varphi) = (- 1) ^ {| \alpha |} \ell (D ^ {\alpha} \varphi), \varphi \in \mathcal {D} (\Omega)\tag{12.227}
$$

定义的分布 $D ^ { \alpha } \ell$ 称作 阶导数

是（比方说）厌上连续可微函数（故 在民上局部可和，并且可以看作是一个分布），设 $f ^ { \prime }$ 是其经典导数，而 $D ^ { 1 } f$ 是其一阶分布导数那么

$$
(D ^ {1} f, \varphi) = \int_ {\mathbb {R}} f ^ {\prime} (x) \varphi (x) \mathrm{d} x,\tag{12.228a}
$$

据此由分部积分可得

$$
(D ^ {1} f, \varphi) = - \int_ {\mathbb {R}} f (x) \varphi^ {\prime} (x) \mathrm{d} x = (f, \varphi^ {\prime}).\tag{12.228b}
$$

在正则分布 $\ell _ { f }$ 的情形下 $( f \in L _ { \mathrm { l o c } } ^ { 1 } ( \varOmega ) )$ ，利用 (12.226) 可得

$$
(D ^ {\alpha} \ell_ {f}) (\varphi) = (- 1) ^ {| \alpha |} \ell_ {f} (D ^ {\alpha} \varphi) = (- 1) ^ {| \alpha |} \int_ {\Omega} f (x) D ^ {\alpha} \varphi \mathrm{d} \lambda ,\tag{12.229}
$$

这是函数 在索伯列夫意义下的广义导数（见 (12.223)).
