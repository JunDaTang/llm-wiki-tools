## 第9章 微分方程

(1) 一个微分方程 是一个或多个变量，这些变量的一个或多个函数，以及这些函数关千所出现的这些变最的导数的一个方程．一个微分方程的阶 (order) 等千其中出现的导数最高的阶数．

(2) 常微分方程和偏微分方程 相互间的差别在千它们的自变量的数目；在第一种情形只有一个自变量，在第二种情形有几个自变量

A: $\left( { \frac { \mathrm { d } y } { \mathrm { d } x } } \right) ^ { 2 } - x y ^ { 5 } { \frac { \mathrm { d } y } { \mathrm { d } x } } + \sin y = 0 .$

■ B: $x \mathrm { d } ^ { 2 } y \mathrm { d } x - \mathrm { d } y ( \mathrm { d } x ) ^ { 2 } = \mathrm { e } ^ { y } ( \mathrm { d } y ) ^ { 3 }$

■ C: $\frac { \partial ^ { 2 } z } { \partial x \partial y } = x y z \frac { \partial z } { \partial x } \frac { \partial z } { \partial y } .$
