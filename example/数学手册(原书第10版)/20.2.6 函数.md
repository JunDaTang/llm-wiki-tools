20.2.6.3 纯函数

Mathematica 支持使用所谓的纯函数一个纯函数是一个无名函数，一个没有赋予名称的运算．它们被记作 Function[x, body]．第一个自变量指定形式参数，第二个自变量是函数主体，即主体 (body) 是变元 的函数的一个表达式．

$$
I n [ 1 ] := \operatorname{Function} \left[ x, x ^ {3} + x ^ {2} \right] \longrightarrow O u t [ 1 ] = \operatorname{Function} \left[ x, x ^ {3} + x ^ {2} \right]\tag{20.13}
$$

因此

$$
I n [ 2 ] := \operatorname{Function} [ x, x ^ {3} + x ^ {2} ] [ c ] \text {给出} O u t [ 2 ] = c ^ {2} + c ^ {3}\tag{20.14}
$$

我们可以使用该命令的简化形式．它的形式是 body&，其中变元表示为＃．代替前面的两行我们也可以写

$$
I n [ 3 ] := (\# ^ {3} + \# ^ {2}) \& [ c ] O u t [ 3 ] = c ^ {2} + c ^ {3}\tag{20.15}
$$

也可以定义具有多个变元的纯函数：

$\mathtt { F u n c t i o n [ \{ x _ { 1 } , \ x _ { 2 } , \ \cdot \cdot \cdot \} , \ b o d y ] }$ 或简化形式 body&，其中主体中的变元用元素＃1, #2,... 表示．用千结束表达式的符号＆非常重要，因为从这个符号可以看出前面的表达式应该被认作一个纯函数．要指出的是＃＆即恒等函数：对千任何自变量 它指派 X. 类似地＃ ＆相应千在第一个坐标轴上的投影
