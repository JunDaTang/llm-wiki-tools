#### 6.2.1 偏导数

6.2.1.1 函数的偏导数

元函数 $u = f \left( x _ { 1 } , x _ { 2 } , \cdot \cdot \cdot , x _ { i } , \cdot \cdot \cdot , x _ { n } \right)$ 的偏导数，比如关千 $x _ { 1 }$ 的偏导数定义为

$$
\frac {\partial u}{\partial x _ {1}} = \lim _ {\Delta x _ {1} \rightarrow 0} \frac {f (x _ {1} + \Delta x _ {1} , x _ {2} , x _ {3} , \cdots , x _ {n}) - f (x _ {1} , x _ {2} , x _ {3} , \cdots , x _ {n})}{\Delta x _ {1}},\tag{6.35}
$$

即认为 个变量中只有一个发生了改变，而其他 $n - 1$ 个是常数．偏导数的符号为$\frac { \partial u } { \partial x } , u _ { x } ^ { \prime } , \frac { \partial f } { \partial x } , f _ { x } ^ { \prime } . \ n$ 元函数有 个一阶偏导数 ${ \frac { \partial u } { \partial x _ { 1 } } } , { \frac { \partial u } { \partial x _ { 2 } } } , { \frac { \partial u } { \partial x _ { 3 } } } , \cdots , { \frac { \partial u } { \partial x _ { n } } }$ ，且可利用与一元函数相同的求导法则来计算偏导数．

$$
u = \frac {x ^ {2} y}{z}, \frac {\partial u}{\partial x} = \frac {2 x y}{z}, \frac {\partial u}{\partial y} = \frac {x ^ {2}}{z}, \frac {\partial u}{\partial z} = - \frac {x ^ {2} y}{z ^ {2}}.
$$

6.2.1.2 二元函数的几何意义

函数 $u = f \left( x , y \right)$ 在笛卡儿坐标系中表示一曲面，过曲面上一点 作平行千$u O x$ 而的平而与之相交（图 6.14)，则

$$
\frac {\partial u}{\partial x} = \tan \alpha ,\tag{6.36a}
$$

其中 $\alpha$ 为上述平面与曲面的交曲线在点 $P$ 的切线与 轴正半轴所成的角，它也等千切线在 $u O x$ 面的垂直投影与 轴正半轴所成的角， 的正方向为从 轴正半轴出发，朝 $y$ 轴正半轴方向看的逆时针方向．类似 $\alpha _ { \mathrm { { ; } } }$ ，可以用平行千 $y O u$ 的平面定义角 $\beta { \mathrm { : } }$ 1

$$
\frac {\partial u}{\partial y} = \tan \beta .\tag{6.36b}
$$

6.2.1.3 $f \left( x \right)$ 的微分

(1) 自变量 的微分 dx 等千增量 $\Delta x$ ，即

$$
\mathrm{d} x = \Delta x,\tag{6.37a}
$$

其中 $\Delta x$ 为任意量．

(2) 含一个变最 的函数 $y = f \left( x \right)$ 的微分 $\mathrm { d } y \mathbf { : }$ ：对给定的 dx, 定义

$$
\mathrm{d} y = f ^ {\prime} (x) \mathrm{d} x.\tag{6.37b}
$$

(3) $x + \Delta x .$ 函数 $y = f \left( x \right)$ 的增量是差

$$
\Delta y = f (x + \Delta x) - f (x).\tag{6.37c}
$$

(4) 微分的儿何意义：

在笛卡儿坐标系中把函数用一条曲线表示，则 $\mathrm { d } y$ 是当 改变 dx 时，切线纵坐标的增量（图 6.1)，而 $\Delta y$ 是曲线纵坐标的增量．

6.2.1.4 微分的基本性质

1. 不变性

不管 是自变量还是另一个变量 的函数，都有

$$
\mathrm{dy} = f ^ {\prime} (x) \mathrm{dx}.\tag{6.38}
$$

2. 量的阶

dx 为任意小量，则 $\mathrm { d } y$ 和 $\Delta y = y \left( x + \Delta x \right) - y \left( x \right)$ 也为任意小量，但它们等价，即 $\operatorname* { l i m } _ { \Delta x \to 0 } { \frac { \Delta y } { { \mathrm { d } } y } } = 1$ ．因此它们的差 $\mathrm { d } y - \Delta y$ 也为任意小量，而且是比 $\mathrm { d } x , \mathrm { d } y , \Delta x$ 高阶的任意小（除非 $\mathrm { d } y = 0 )$ ，故有

$$
\lim _ {\Delta x \to 0} \frac {\Delta y}{\mathrm{d} y} = 1, \quad \Delta y \approx \mathrm{d} y = f ^ {\prime} (x) \mathrm{d} x,\tag{6.39}
$$

千是可以把对小增量的计算简化到计算它的微分，这个公式常用千近似计算（参见593 6.1.4.4 1114 16.4.2.1, 2.).

6.2.1.5 偏微分

对多元函数 $u = f \left( x , y , \cdot \cdot \cdot \right)$ )，可计算其中一个变元的偏微分，例如关千 的偏微分可定义为

$$
\mathrm{d} _ {x} u = \mathrm{d} _ {x} f = \frac {\partial u}{\partial x} \mathrm{d} x.\tag{6.40}
$$
