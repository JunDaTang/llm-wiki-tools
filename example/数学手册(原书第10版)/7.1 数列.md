7.1.1.2 单调数列

数列 $a _ { 1 } , a _ { 2 } , \cdots , a _ { n } , \cdots$ ...称为单调递增数列，若

$$
a _ {1} \leqslant a _ {2} \leqslant a _ {3} \leqslant \dots \leqslant a _ {n} \leqslant \dots ;\tag{7.2}
$$

数列 $a _ { 1 } , a _ { 2 } , \cdots , a _ { n } , \cdots$ ·称为单调递减数列，若

$$
a _ {1} \geqslant a _ {2} \geqslant a _ {3} \geqslant \dots \geqslant a _ {n} \geqslant \dots .\tag{7.3}
$$

(7.2), (7.3) 中的等号恒不成立，则相应的数列称为严格单调递增数列或严格单调递减数列

#### 7.1.2 数列的极限

1. 数列的极限

若对无限增加的指标 n, 恒有 $a _ { n } - A$ 任意小，则称无穷数列 (7.1) 有极限 A.其精确定义为：若对千任意小的 $\varepsilon > 0$ 总存在指标 $n _ { 0 } \left( \varepsilon \right)$ ，使得对千 $n > n _ { 0 }$ 时的一切 $a _ { n }$ ，恒有

$$
\left| a _ {n} - A \right| <   \varepsilon .\tag{7.5a}
$$

若对千任意 $K > 0$ 总存在指标 $n _ { 0 } \left( K \right)$ ，使得对千 $n > n _ { 0 }$ 时的一切 $a _ { n }$ ，恒有

$$
a _ {n} > K \quad (a _ {n} <   - K),\tag{7.5b}
$$

则称数列 (7.1) 的极限为 $+ \infty ( - \infty )$

2. 收敛数列

若数列 $\left\{ a _ { n } \right\}$ 满足 (7.5a)，则称该数列收敛于 A, 记为

$$
\lim _ {n \to \infty} a _ {n} = A \quad {\text {或}} \quad a _ {n} \to A.\tag{7.6}
$$

·在 7.1.1.1 的数列 中，数列 收敛千 $A = 0 ,$ ，数列 收敛千 $A = 3$ 数列收敛千 $A = 3 \frac 1 3$ ，数列 收敛千 $A = 0$

3. 发散数列

不收敛的数列称为发散数列 (7.5b) 的情况称为真发散，即随着 的无限增加$a _ { n }$ 超过任意大的正数 $K ( K > 0 )$ ，且一直不会变小；或者若随着 的无限增加， $a _ { n }$ 小千任意小的负数 $- K ( K > 0 )$ ，且一直不会变大．若数列有极限 $\pm \infty$ ，记为

$$
\lim _ {n \rightarrow \infty} a _ {n} = \infty \quad (a _ {n} > K, \forall n > n _ {0}) \quad \text {或} \quad \lim _ {n \rightarrow \infty} a _ {n} = - \infty (a _ {n} <   - K, \forall n > n _ {0});\tag{7.7}
$$

否则数列称为假发散

4. 数列极限的定理

a) 若数列 $\left\{ a _ { n } \right\}$ ｝与 $\left\{ b _ { n } \right\}$ ｝均收敛，则

$$
\lim _ {n \to \infty} (a _ {n} + b _ {n}) = \lim _ {n \to \infty} a _ {n} + \lim _ {n \to \infty} b _ {n},\tag{7.8}
$$

$$
\lim _ {n \to \infty} (a _ {n} b _ {n}) = \left(\lim _ {n \to \infty} a _ {n}\right) \left(\lim _ {n \to \infty} b _ {n}\right).\tag{7.9}
$$

若对每个 $n , b _ { n } \neq 0$ ，且 $\operatorname* { l i m } _ { n \to \infty } b _ { n } \neq 0$ ，则

$$
\lim _ {n \to \infty} \frac {a _ {n}}{b _ {n}} = \frac {\lim _ {n \to \infty} a _ {n}}{\lim _ {n \to \infty} b _ {n}}.\tag{7.10}
$$

注若 $\operatorname* { l i m } _ { n \to \infty } b _ { n } = 0 , \{ a _ { n } \}$ ｝有界，即使 $\left\{ a _ { n } \right\}$ ｝没有有限极限，仍有 $\operatorname* { l i m } _ { n \to \infty } \left( a _ { n } b _ { n } \right) = 0$ b) $\operatorname* { l i m } _ { n \to \infty } a _ { n } = \operatorname* { l i m } _ { n \to \infty } b _ { n } = A$ 且至少从一个指标 $n _ { 1 }$ 之后，恒有不等式 $a _ { n } \leqslant$ $c _ { n }$ \~ $b _ { n }$ ，则有

$$
\lim _ {n \to \infty} c _ {n} = A.\tag{7.11}
$$
