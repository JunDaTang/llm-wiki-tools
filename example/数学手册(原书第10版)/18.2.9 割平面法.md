#### 18.2.9 割平面法

1. 问题的提法和求解原理

设考虑有界区域 $M \subset \mathbb { R } ^ { n }$ 上的问题

$$
f (\underline {{\boldsymbol {x}}}) = \underline {{\boldsymbol {c}}} ^ {\mathrm{T}} \underline {{\boldsymbol {x}}} = \min!, \quad \underline {{\boldsymbol {c}}} \in \mathbb {R} ^ {n},\tag{18.117}
$$

这里 由凸函数 $g _ { i } ( \underline { { { x } } } ) \ ( i = 1 , \cdots , m )$ 以约束形式 $g _ { i } ( \underline { { { \pmb x } } } ) \leqslant 0$ 给出相应千非线性但凸的目标函数 （\~)的规划问题就可以转换成这种形式，为此只要把

$$
f (\underline {{\boldsymbol {x}}}) - x _ {n + 1} \leqslant 0, \quad \underline {{\boldsymbol {x}}} _ {n + 1} \in \mathbb {R}\tag{18.118}
$$

看作另一个约束，并且在约束 $\overline { { g } } _ { i } ( \underline { { \pmb x } } ) = g _ { i } ( \underline { { \pmb x } } ) \leqslant 0$ 之下求解问题：

$$
\overline {{f}} (\underline {{\boldsymbol {x}}}) = x _ {n + 1} = \min!, \quad \forall \overline {{\boldsymbol {x}}} = (\underline {{\boldsymbol {x}}}, x _ {n + 1}) \in \mathbb {R} ^ {n + 1}.\tag{18.119}
$$

这个方法的基本想法是通过极小点 x\* $\underline { { \boldsymbol { x } } } ^ { * }$ 邻域中一凸多面体，迭代线性逼近 ，从而原规划问题转化成一列线性规划问题

首先，确定凸多面体

$$
P _ {1} = \{\underline {{\boldsymbol {x}}} \in \mathbb {R} ^ {n}: \underline {{\boldsymbol {a}}} _ {i} ^ {\mathrm{T}} \underline {{\boldsymbol {x}}} \leqslant b _ {i}, i = 1, \dots , s \}.\tag{18.120}
$$

由线性规划问题

$$
f (\underline {{\boldsymbol {x}}}) = \min!, \quad \underline {{\boldsymbol {x}}} \in P _ {1}\tag{18.121}
$$

相对千 $f ( { \underline { { \pmb x } } } )$ ）确定 $P _ { 1 }$ 的最优极端点 $\underline { { \boldsymbol { x } } } ^ { 1 }$ ．如果 ${ \pmb x } ^ { 1 } \in M$ ，则就找到原问题的最优解否则确定将点 $\underline { { \boldsymbol { x } } } ^ { 1 }$ 和 分离的一超平面： $H _ { 1 } = \{ \underline { { { \pmb x } } } : \underline { { { \pmb a } } } _ { s + 1 } ^ { \mathrm { \scriptscriptstyle T } } \underline { { { \pmb x } } } = b _ { s + 1 } , \underline { { { \pmb a } } } _ { s + 1 } ^ { \mathrm { \scriptscriptstyle T } } \underline { { { \pmb x } } } ^ { 1 } > b _ { s + 1 } \}$ 千是新的多面体包含

$$
P _ {2} = \{\underline {{\boldsymbol {x}}} \in P _ {1}: \underline {{\boldsymbol {a}}} _ {s + 1} ^ {\mathrm{T}} \underline {{\boldsymbol {x}}} \leqslant b _ {s + 1} \}.\tag{18.122}
$$

2. 凯利 (Kelley) 方法

不同方法之间的区别在千分离平面的选取．采用凯利方法， $H _ { k }$ 的选取方法如下：选择一标号 $j _ { k }$ 使得

$$
g _ {j _ {k}} (\underline {{\boldsymbol {x}}} ^ {k}) = \max \{g _ {i} (\underline {{\boldsymbol {x}}} ^ {k}): i = 1, \dots , m \}.\tag{18.123}
$$

函数 $g _ { j _ { k } } ( \underline { { \pmb x } } )$ ）在 $\underline { { \boldsymbol { x } } } = \underline { { \boldsymbol { x } } } ^ { k }$ 的切平面为

$$
T (\underline {{\boldsymbol {x}}}) = g _ {j _ {k}} (\underline {{\boldsymbol {x}}} ^ {k}) + (\underline {{\boldsymbol {x}}} - \underline {{\boldsymbol {x}}} ^ {k}) ^ {\mathrm{T}} \nabla g _ {j _ {k}} (\underline {{\boldsymbol {x}}} ^ {k}).\tag{18.124}
$$

超平面 $H _ { k } = \{ \underline { { \pmb { x } } } \in \mathbb { R } ^ { n } : T ( \underline { { \pmb { x } } } ) = 0 \}$ 把点 $\underline { { \boldsymbol { x } } } ^ { k }$ 与所有满足 $g _ { j _ { k } } ( \underline { { \pmb { x } } } ) \leqslant 0$ 的点竺分离开千是，对千第 $k + 1$ 个线性规划问题，增加一个约束条件 $T ( \underline { { \boldsymbol { x } } } ) \leqslant 0 .$ 序列 $\{ \underline { { \boldsymbol { x } } } ^ { k } \}$ 的每个聚点 $\underline { { \boldsymbol { x } } } ^ { * }$ 都是原问题的一个极小点实际应用表明这种方法的收敛速度较低此外，约束的数量总是不断增加
