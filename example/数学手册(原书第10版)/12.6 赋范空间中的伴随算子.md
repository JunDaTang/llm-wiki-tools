### 12.6 赋范空间中的伴随算子

#### 12.6.1 有界算子的伴随

设给定线性连续算子 $T : X \longrightarrow Y ( X , Y$ 为赋范空间），对千每个 $g \in Y ^ { * }$ ，通过$f ( x ) = g ( T x ) , \forall x \in X$ 定义出一新的泛函 $f \in X ^ { * }$ ．由此可得一个连续线性算子

$$
T ^ {*}: Y ^ {*} \longrightarrow X ^ {*}, (T ^ {*} g) (x) = g (T x), \forall g \in Y ^ {*}, \quad x \in X,\tag{12.177}
$$

它称作 $T$ 的伴随算子，并具有如下性质：

$$
(T + S) ^ {*} = T ^ {*} + S ^ {*}, \quad (S T) ^ {*} = T ^ {*} S ^ {*}, \quad \| T ^ {*} \| = \| T \|,
$$

这里对千线性算子 $T : X \longrightarrow Y , S : Y \longrightarrow Z ( X , Y , Z$ 为赋范空间），算子 $S T$ 以自然方式定义为 $( S T ) ( x ) = S ( T ( x ) )$ ）（参见第 878 $1 2 . 3 . 4 , \equiv \mathbf { C } )$ ．利用第 86012.1.5 和第 890 12.5.4.2 引入的记号，对千算子 $T \in { \cal B } ( X , Y )$ ，下列等式成立：

$$
\overline {{\operatorname{Im} (T)}} = \ker (T ^ {*}) ^ {\perp}, \overline {{\operatorname{Im} (T ^ {*})}} = \ker (T) ^ {\perp},\tag{12.178}
$$

这里 $\mathrm { I m } ( T )$ 的闭性蕴涵 $\mathrm { I m } ( T ^ { * } )$ 的闭性

从 $T ^ { * }$ 的伴随 $( T ^ { * } ) ^ { * }$ 得到的算子 $T ^ { * * } : X ^ { * * } \longrightarrow Y ^ { * * }$ 称作 的第二伴随．由千$( T ^ { * * } ( F _ { x } ) ) g = F _ { x } ( T ^ { * } g ) = ( T ^ { * } g ) ( x ) = g ( T x ) = F _ { T x } ( g )$ ，算子 $T ^ { * * }$ 具有如下性质：如果 $F _ { x } \in X ^ { * * }$ ＊，那么 $T ^ { * * } F _ { x } = F _ { T x } \in Y ^ { * * }$ ＊．因此 $T ^ { * * } : Y ^ { * * } \longrightarrow X ^ { * * }$ 是 $T$ 的一个延拓．

在希尔伯特空间 中，伴随算子也可以通过标量积来引入： $( T x , y ) = ( x , T ^ { * } y )$ $x , y \in H$ . 这是基千里斯表示定理，这里 $H ^ { * * }$ 的等同意味着 $\left( \lambda T \right) ^ { * } =$ $\overline { { { \lambda } } } T ^ { * } , I ^ { * } \ = \ I$ ，并且 $T ^ { * * } = T$ . 如果 $T$ 是双射，则 $T ^ { * }$ ＊也是双射，并且还有$( T ^ { * } ) ^ { - 1 } = ( T ^ { - 1 } ) ^ { * }$ ＊．对千 $T$ 和 $T ^ { * }$ ＊的预解式有

$$
[ R _ {\lambda} (T) ] ^ {*} = R _ {\overline {{\lambda}}} (T ^ {*}),\tag{12.179}
$$

由此可得伴随算 $T ^ { * }$ 的谱是 $\sigma ( T ^ { * } ) = \{ \overline { { \lambda } } : \lambda \in \sigma ( T ) \}$

A: $T$ 是空间 $L ^ { p } ( [ a , b ] ) ( 1 < p < \infty )$ 中的积分算子：

$$
(T x) (s) = \int_ {a} ^ {b} K (s, t) x (t) \mathrm{d} t,\tag{12.180}
$$

其中 $K ( s , t )$ 是连续核． 的伴随算子也是一个积分算子，即

$$
(T ^ {*} g) (t) = \int_ {a} ^ {b} K ^ {*} (t, s) y _ {g} (s) \mathrm{d} s,\tag{12.181}
$$

其中核 $K ^ { * } ( s , t ) = K ( t , s )$ ，而 $y _ { g }$ 是根据 (12.167) $g \in ( L ^ { p } ) ^ { * }$ 相关联的 $L ^ { q }$ 中的元

#### 12.6.2 无界算子的伴随

是实赋范空间， 是定义在（线性）区域 $D ( T ) \subset X$ 取值在 中的（不必有界的）线性算子．对千给定的 $g \in Y ^ { * }$ ，表达式 $g ( T x )$ 有意义并且显然关千$x$ 是线性的．现在的问题是：是否存在一个泛函 $f \in X ^ { * }$ 使得

$$
f (x) = g (T x), \forall x \in D (T).\tag{12.182}
$$

设 $D ^ { * } ~ \subset ~ Y ^ { * }$ 是使得表达式 (12.182) 对千某个 $f \in X ^ { * }$ 成立的所有元 $g \in Y ^ { * }$ 的集合如果 ${ \overline { { D ( T ) } } } = X$ 则对千给定的泛函 $g ,$ 泛函 是唯一确定的．因此借助 $f = T ^ { * } g$ 可以定义线性算子 $T ^ { * }$ ，其定义域为 $D ( T ^ { * } ) = D ^ { * }$ ．千是对千任意元$x \in D ( T ) , g \in D ( T ^ { * } )$ ），有

$$
g (T x) = (T ^ {*} g) (x).\tag{12.183}
$$

算子 $T ^ { * }$ 总是闭的，称作 的伴随上述伴随算子定义过程的合理性源于如下事实： $D ( T ^ { * } ) = Y ^ { * }$ 立当且仅当 $T$ 在 $D ( T )$ 上有界． 在这种情形下， $T ^ { * } \in$ $B ( Y ^ { * } , X ^ { * } )$ ，并且 $\| T ^ { * } \| = \| T \|$

#### 12.6.3 自伴算子

算子 $T \in B ( H ) ( H$ 是希尔伯特空间）称作自伴的，是指 $T ^ { * } = T$ 在这种情形下，有

$$
(T x, y) = (x, T y), \quad x, y \in H,\tag{12.184a}
$$

并且对千每一个 $x \in H , ( T x , x )$ 是实数．千是有等式

$$
\| T \| = \sup _ {\| x \| = 1} | (T x, x) |,\tag{12.184b}
$$

并且若记 $m = m ( T ) = \operatorname* { i n f } _ { \| x \| = 1 } ( T x , x ) , \ M = M ( T ) = \operatorname* { s u p } _ { \| x \| = 1 } ( T x , x )$ ，那么还成立

$$
m (T) \| x \| ^ {2} \leqslant (T x, x) \leqslant M (T) \| x \| ^ {2} \text {和} \| T \| = r (T) = \max \{m, M \}.\tag{12.185}
$$

等式 (12.184a) 刻画了自伴算子的特征．自伴（有界）算子的谱位千区间 $[ n , M ]$ ，并且 $m , M \in \sigma ( T )$

12.6.3.1 正定算子

在 $B ( H )$ 的所有自伴算子的集合中可以按如下方式引进偏序：

$$
T \geqslant 0    \text {当且仅当}    (T x, x) \geqslant 0,    \forall    x \in H.\tag{12.186}
$$

算子 T当 $T \geqslant 0$ 时称作正的（或更确切地说，称作正定的）®.对千任意自伴算子（根据第 879 12.4.1.1 (Hl) ），有 $( T ^ { 2 } x , x ) = ( T x , T x ) \geqslant 0$ 从而 $T ^ { 2 }$ 是正定算子．每个正定算子都有平方根，即存在唯一的正定算子 使得 $W ^ { 2 } = T$ 此外，所有自伴算子的向量空间是一个 空间（康托洛维奇空间，参见第 863 12.1.7.4),其中算子

$$
| T | = \sqrt {T ^ {2}}, T ^ {+} = \frac {1}{2} (| T | + T), T ^ {-} = \frac {1}{2} (| T | - T)\tag{12.187}
$$

是与 (12.37) 相对应的元在利用某些斯蒂尔切斯积分（参见第 673 8.2.3.1, 2.以及 [12.1], [12.12], [12.13], [12.15], [12.18], [12.21] ）研究自伴算子的谱分解、谱表示和积分表示时这些结果具有特别重要的作用．

12.6.3.2 希尔伯特空间中的投影

设 $H _ { 0 }$ 是希尔伯特空间 是子空间那么根据投影定理（参见第 881 12.4.2),每个元 $x \in H$ 在 $H _ { 0 }$ 上都有投影 $x ^ { \prime }$ ，因此利用 $P x = x ^ { \prime }$ ，可以定义 上取值千 $H _ { 0 }$ 的算子 P. 称作 $H _ { 0 }$ 上的投影算子．显然， 是线性连续的，并且 $\| \cal P \| = 1$ . H中连续线性算子是（某个子空间上）投影的充分必要条件是：

a) $P = P ^ { * }$ ，即 P 是自伴的，并且

b) $P ^ { 2 } = P$ ，即 是幕等的．
