是一集合，并假定在 $X \times X$ 上定义了一个实值非负函数 $\rho ( x , y ) ( x , y \in X )$ 如果函数 $\rho : X \times Y $ 股上对千任意元 $x , y , z \in X$ 满足性质 $( \mathrm { M 1 } ) { \sim } ( \mathrm { M 3 } )$ ，那么它就叫作 中一个度量或距离，而偶对 $X = ( X , \rho )$ 则叫作距离空间距离空间的公理是：

$$

$$
(\mathrm{M} 2) \rho (x, y) = \rho (y, x); \quad (\text {对称性})\tag{12.41}
$$

$$
(\mathrm{M} 3) \rho (x, y) \leqslant \rho (x, z) + \rho (z, y). \quad (\text {三角形不等式})\tag{12.42}

12.2.1.4 稠子集和可分距离空间

距离空间 的子集 称作几乎处处稠的，是指 ${ \overline { { A } } } = X$ 即每一点 $x \in X$ 都是集合 的极限点．这就是说，对千每一点 $x \in X$ 存在一序列｛ $\{ x _ { n } \} _ { n = 1 } ^ { \infty } , x _ { n } \in X$ 使得 $x _ { n } \longrightarrow x$

\sqrt {\sum_ {j , k = 1} ^ {n} \left| a _ {j k} \right| ^ {2}}, \quad \max _ {1 \leqslant j \leqslant n} \sum_ {k = 1} ^ {n} \left| a _ {j k} \right|, \quad \max _ {1 \leqslant k \leqslant n} \sum_ {j = 1} ^ {n} \left| a _ {j k} \right|\tag{12.65}

2. 弗雷德霍姆积分方程

考虑第二类弗雷德霍姆积分方程（也可参见第 817 11.2)

$$
\varphi (x) - \int_ {a} ^ {b} K (x, y) \varphi (y) \mathrm{d} y = f (x), \quad x \in [ a, b ],\tag{12.66}
$$

这里核函数 $K ( x , y )$ 和右端函数 $f ( x )$ 都是连续的这个方程可以用迭代法求解．为此，定义算子 $T : { \mathcal { C } } ( a , b ] ) \to { \mathcal { C } } ( a , b ] )$ ）为

$$
(T \varphi) (x) = \int_ {a} ^ {b} K (x, y) \varphi (y) \mathrm{d} y + f (x), \quad \forall \varphi \in \mathcal {C} ([ a, b ]),\tag{12.67}
$$

千是上述积分方程就变成距离空间 $\mathcal { C } ( [ a , b ] )$ 中不动点问题 $T \varphi ~ = ~ \varphi ($ (参见第 85712.1.2, ．中例A) ．如果 $\operatorname* { m a x } _ { a \leqslant x \leqslant b } \int _ { a } ^ { b } | K ( x , y ) | \mathrm { d } y < 1$ ，则 $T$ 是压缩算子，并且可以应用不动点定理千是其唯一解就是迭代序列 $\{ \varphi _ { n } \} _ { n = 1 } ^ { \infty }$ 的一致极限，这里迭代$\varphi _ { n } = T \varphi _ { n - 1 }$ 从任意元 $\varphi _ { 0 } \in { \mathcal { C } } ( [ a , b ] )$ 出发显然， $\varphi _ { n } = T ^ { n } \varphi _ { 0 }$ ，并且迭代序列是$\{ T ^ { n } \varphi _ { 0 } \} _ { n = 1 } ^ { \infty }$

3. 沃尔泰拉积分方程

考虑第二类沃尔泰拉积分方程（参见第 842 11.4)

$$
\varphi (x) - \int_ {a} ^ {x} K (x, y) \varphi (y) \mathrm{d} y = f (x), x \in [ a, b ],\tag{12.68}

这里核函数 $K ( x , y )$ 和右端函数 $f ( x )$ 都是连续的．定义沃尔泰拉积分算子

12.2.2.5 距离空间的完备化

每一个（不完备的）距离空间 都可以被完备；确切地说，存在一距离空间具有如下性质：

a) $\tilde { X }$ 包含一个与 等距的子空间 （参见第 874 12.2.3, 2.).

b) $\tilde { X }$ 中是儿乎处处稠的．

c) 是完备的距离空间

d) 如果 是任意一个具有性质 $\mathrm { a } ) { \sim } \mathrm { c } )$ 的距离空间，那么 和 $\tilde { X }$ 是等距的．

用这种方式在等距意义下唯一确定的这个完备距离空间称作空间 的完备化．
