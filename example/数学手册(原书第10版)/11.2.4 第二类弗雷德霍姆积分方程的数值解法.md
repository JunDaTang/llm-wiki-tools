#### 11.2.4 第二类弗雷德霍姆积分方程的数值解法

对千一个第二类弗雷德霍姆积分方程

$$
\varphi (x) = f (x) + \lambda \int_ {a} ^ {b} K (x, y) \varphi (y) \mathrm{d} y,\tag{11.23}
$$

为了获得其精确解，用第 817 页的 11.2.1, 821 页的 11.2.2, 以及用第 823 页的11.2.3 中给出的解法经常是不可能的，或者要做太多的工作．在一些这样的情形中，为了近似可以用某些数值方法．下面给出 种不同的方法来得到形如 (11.23) 积分方程的数值解

11.2.4.1 积分的近似

1. 半离散问题

在研究积分方程 (11.23) 时，经常用一个近似公式来代替其中的积分．这些近似公式被称为求积公式 (quadrature formulas) ．它们有形式

$$
\int_ {a} ^ {b} f (x) \mathrm{d} x \approx Q _ {[ a, b ]} (f) = \sum_ {k = 1} ^ {n} \omega_ {k} f (x _ {k}),\tag{11.24}
$$

即，代替积分，现在用被积函数在插值节 $x _ { k }$ 处赋以权值 $\omega _ { k }$ 的代换值之和．诸数$\omega _ { k }$ 要被适当地选取（以便与 无关）．用近似形式，方程 (11.23) 可以被写成

$$
\varphi (x) \approx f (x) + \lambda Q _ {[ a, b ]} (K (x, \cdot) \varphi (\cdot)) = f (x) + \lambda \sum_ {k = 1} ^ {n} \omega_ {k} K (x, y _ {k}) \varphi (y _ {k}).\tag{11.25a}
$$

求积公式 $Q _ { [ a , b ] } ( K ( x , \cdot ) \varphi ( \cdot ) )$ 还依赖千变量 X. 在函数变量位置上的点意味着求积公式是关千变量 所用的定义关系式

$$
\overline {{\varphi}} (x) = f (x) + \lambda \sum_ {k = 1} ^ {n} \omega_ {k} K (x, y _ {k}) \overline {{\varphi}} (y _ {k}).\tag{11.25b}
$$

$\overline { { \varphi } } ( x )$ 是精确解 $\varphi ( x )$ 的一个近似．把 (11.25b) 视为一个半离散问题(semi-discreteproblem)，因为变量 被转为离散值，而变量 仍可为任意的．

如果方程 (11.25b) 对一个函数 $\overline { { \varphi } } ( x )$ 在每个点 $x \in [ a , b ]$ 处成立，那么它必定在每个插值节点 $x = x _ { k }$ 处成立：

$$
\overline {{{{\varphi}}}} (x _ {k}) = f (x _ {k}) + \lambda \sum_ {j = 1} ^ {n} \omega_ {j} K (x _ {k}, y _ {j}) \overline {{{{\varphi}}}} (y _ {j}), \quad k = 1, 2, \dots , n.\tag{11.25c}
$$

这是一个关千 个未知值 $\overline { { \varphi } } ( \boldsymbol { x } _ { k } )$ 的 个方程的一个线性方程组． 把这些解代(11.25b)，产生了半离散问题的解．这个方法的精度和计算量依赖千所用的求积公式例如用左矩形公式（参见第 1253 19.3.2.1) 以及等距划分 $y _ { k } = x _ { k } =$ $a + h ( k - 1 ) , h = ( b - a ) / n ( k = 1 , \cdots , n )$ ，产生

$$
\int_ {a} ^ {b} K (x, y) \overline {{\varphi}} (y) \mathrm{d} y \approx \sum_ {k = 1} ^ {n} h K (x, y _ {k}) \overline {{\varphi}} (y _ {k}).\tag{11.26a}
$$

利用记号

$$
K _ {j k} = K (x _ {j}, y _ {k}), \quad f _ {k} = f (x _ {k}), \quad \varphi_ {k} = \overline {{\varphi}} (x _ {k}),\tag{11.26b}
$$

方程组 (11.25c) 有形式：

$$
\begin{array}{c} (1 - \lambda h K _ {1 1}) \varphi_ {1} - \lambda h K _ {1 2} \varphi_ {2} - \dots - \lambda h K _ {1 n} \varphi_ {n} = f _ {1}, \\ - \lambda h K _ {2 1} \varphi_ {1} + (1 - \lambda h K _ {2 2}) \varphi_ {2} - \dots - \lambda h K _ {2 n} \varphi_ {n} = f _ {2}, \\ \dots \dots \\ - \lambda h K _ {n 1} \varphi_ {1} - \lambda h K _ {n 2} \varphi_ {2} - \dots + (1 - \lambda h K _ {n n}) \varphi_ {n} = f _ {n}. \end{array}\tag{11.26c}
$$

相同的方程组被包含在弗雷德霍姆解法（参见第 823 11.2.3) 中．因为矩形公式并非足够精确因此为了更好地近似积分，可以增加插值节点的数目，但随之而来的是方程组维数的增加因而要寻找另外的求积公式

2. 尼斯特伦法

在所谓的尼斯特伦法(Nystrom method) 中，高斯求积公式被用千求积分的近似（参见第 1254 19.3.3,3.)．为了推导它考虑积分

$$
I = \int_ {a} ^ {b} f (x) \mathrm{d} x.\tag{11.27a}
$$

用一个多项式 $p ( x )$ ，即 $f ( x )$ 在插值节点 $x _ { k }$ 处的插值多项式来代替被积函数：

$$
p (x) = \sum_ {k = 1} ^ {n} L _ {k} (x) f (x _ {k}),
$$

其中

$$
L _ {k} (x) = \frac {(x - x _ {1}) \cdots (x - x _ {k - 1}) (x - x _ {k + 1}) \cdots (x - x _ {n})}{(x _ {k} - x _ {1}) \cdots (x _ {k} - x _ {k - 1}) (x _ {k} - x _ {k + 1}) \cdots (x _ {k} - x _ {n})}.\tag{11.27b}
$$

对千这个多项式有

$$
p (x _ {k}) = f (x _ {k}), \qquad k = 1, \dots , n.\tag{11.27c}
$$

用 $p ( x )$ 代替被积函数 $f ( x )$ 导致求积公式

$$
\int_ {a} ^ {b} f (x) \mathrm{d} x \approx \int_ {a} ^ {b} p (x) \mathrm{d} x = \sum_ {k = 1} ^ {n} f (x _ {k}) \int_ {a} ^ {b} L _ {k} (x) \mathrm{d} x = \sum_ {k = 1} ^ {n} \omega_ {k} f (x _ {k}),\tag{11.27d}
$$

其中 $\omega _ { k } = \int _ { a } ^ { b } L _ { k } ( x ) \mathrm { d } x$ 对千高斯求积公式不能任意选取插值节点它们必须用公式

$$
x _ {k} = \frac {a + b}{2} + \frac {b - a}{2} t _ {k}, \quad k = 1, 2, \dots , n\tag{11.28a}
$$

来选取这 个 $t _ { k }$ 值是第一类勒让德多项式（参见第 748 9.1.2.6, 3.)

$$
P _ {n} (t) = \frac {1}{2 ^ {n} \cdot n !} \frac {d ^ {n} [ (t ^ {2} - 1) ^ {n} ]}{d t ^ {n}}\tag{11.28b}
$$

个根这些根都在区间 [-1,+1] 中．由代换 $x - x _ { k } = \frac { b - a } { 2 } ( t - t _ { k } )$ 可以计算诸系数 $\omega _ { k }$ ，因而

$$
\begin{array}{l} \omega_ {k} = \int_ {a} ^ {b} L _ {k} (x) \mathrm{d} x = (b - a) \frac {1}{2} \int_ {- 1} ^ {1} \frac {(t - t _ {1}) \cdots (t - t _ {k - 1}) (t - t _ {k + 1}) \cdots (t - t _ {n})}{(t _ {k} - t _ {1}) \cdots (t _ {k} - t _ {k - 1}) (t _ {k} - t _ {k + 1}) \cdots (t _ {k} - t _ {n})} \mathrm{d} t \\ = (b - a) A _ {k}. \end{array} \tag {11.29}
$$

11.2.4.2 核近似

用一个核 $\overline { { K } } ( x , y )$ 代替核 $K ( x , y )$ ，使得对千 $a \leqslant x \leqslant b , a \leqslant y \leqslant b$ 有 $\overline { { K } } ( x , y ) \approx$ $K ( x , y )$ ．试图选取一个核，使得最容易获得积分方程

$$
\overline {{{{\varphi}}}} (x) = f (x) + \lambda \int_ {a} ^ {b} \overline {{{{K}}}} (x, y) \overline {{{{\varphi}}}} (y) \mathrm{d} y\tag{11.30}
$$

的解．

1. 张量积近似

经常用到的核的近似是形如

$$
K (x, y) \approx \overline {{K}} (x, y) = \sum_ {j = 0} ^ {n} \sum_ {k = 0} ^ {n} d _ {j k} \alpha_ {j} (x) \beta_ {k} (y)\tag{11.31a}
$$

的张量积近似 (tensor product approximation) ，其中 $\alpha _ { 0 } ( x ) , \cdot \cdot \cdot , \alpha _ { n } ( x )$ 和 $\beta _ { 0 } ( y )$ $\cdots , \beta _ { n } ( y )$ 是给定的线性无关的函数，它们的系数 $d _ { j k }$ 必须选取得使二重和在某种意义下充分地逼近核．用一个退化核重写 (11.31a)

$$
\begin{array}{c} \overline {{K}} (x, y) = \sum_ {j = 0} ^ {n} \alpha_ {j} (x) \bigg [ \sum_ {k = 0} ^ {n} d _ {j k} \beta_ {k} (y) \bigg ], \quad \delta_ {j} (y) = \sum_ {k = 0} ^ {n} d _ {j k} \beta_ {k} (y), \\ \overline {{K}} (x, y) = \sum_ {j = 0} ^ {n} \alpha_ {j} (x) \delta_ {j} (y). \end{array}\tag{11.31b}
$$

现在，可以把第 817 11.2.1 的解法用千积分方程

$$
\overline {{{{\varphi}}}} (x) = f (x) + \lambda \int_ {a} ^ {b} \biggl [ \sum_ {j = 0} ^ {n} \alpha_ {j} (x) \delta_ {j} (y) \biggr ] \overline {{{{\varphi}}}} (y) \mathrm{d} y.\tag{11.31c}
$$

应该选取诸函数 $\alpha _ { 0 } ( x ) , \cdot \cdot \cdot , \alpha _ { n } ( x )$ 和 $\beta _ { 0 } ( y ) , \cdots , \beta _ { n } ( y )$ ，使得可以容易地计算(11.31a) 中的系数 $d _ { j k }$ , 并且也使得计算 (11.31c) 的解不太困难．

叩原文把 (11.31b) 后两等式连在一起了： $\begin{array} { r c l } { { \delta _ { j } ( y ) } } & { { = } } & { { \sum _ { k = 0 } ^ { n } d _ { j k } \beta _ { k } ( y ) \overline { { { K } } } ( x , y ) } } \end{array} =$ $\textstyle \sum _ { j = 0 } ^ { n } \alpha _ { j } ( x ) \delta _ { j } ( y )$ 译者注

11.2.4.3 配置法

假设在区间 $[ a , b ]$ 中 $n$ 个函数 $\varphi _ { 1 } ( x ) , \cdots , \varphi _ { n } ( x )$ 是线性无关的．它们可以被用来构成解 $\varphi ( x )$ 的一个近似函数 $\overline { { \varphi } } ( x )$

$$
\varphi (x) \approx \overline {{{{\varphi}}}} (x) = a _ {1} \varphi_ {1} (x) + a _ {2} \varphi_ {2} (x) + \dots + a _ {n} \varphi_ {n} (x).\tag{11.37a}
$$

现在的问题是确定系数 $a _ { 1 } , \cdots , a _ { n }$ ．通常，不存在 $a _ { 1 } , \cdots , a _ { n }$ 知，使得以这种形式给出的函数 $\overline { { \varphi } } ( x )$ 表示积分方程 (11.23) 的精确解 $\varphi ( x ) = { \overline { { \varphi } } } ( x )$ ．因而，在积分区间中界定 $n$ 个插值点 $x _ { 1 } , \cdots , x _ { n }$ , 使得近似函数 (11.37a) 至少在这些点上满足积分方程：

$$
\begin{array}{r l} \overline {{{\varphi}}} (x _ {k}) & = a _ {1} \varphi_ {1} (x _ {k}) + \dots + a _ {n} \varphi_ {n} (x _ {k}) \\ & = f (x _ {k}) + \lambda \int_ {a} ^ {b} K (x _ {k}, y) [ a _ {1} \varphi_ {1} (y) + \dots + a _ {n} \varphi_ {n} (y) ] \mathrm{d} y \quad (k = 1, \dots , n) \end{array}\tag{11.37b}
$$

(11.37c)

在一些变换下，这个方程组取下述形式：

$$
\begin{array}{l} \left[ \varphi_ {1} (x _ {k}) - \lambda \int_ {a} ^ {b} K (x _ {k}, y) \varphi_ {1} (y) \mathrm{d} y \right] a _ {1} + \dots + \left[ \varphi_ {n} (x _ {k}) - \lambda \int_ {a} ^ {b} K (x _ {k}, y) \varphi_ {n} (y) \mathrm{d} y \right] a _ {n} \\ = f (x _ {k}) \quad (k = 1, \dots , n). \end{array} \tag {11.37d}
$$
