#### 20.2.1 Mathematica的基本结构要素

Mathematica 屯基本结构要素被称为表达式．它们的旬法是（再强调一下，目前的对象是由它们相应的符号和名称给定的）：

$$
\mathsf {o b j} _ {0} \bigl [ \mathsf {o b j} _ {1}, \mathsf {o b j} _ {2}, \dots , \mathsf {o b j} _ {n} \bigr ]\tag{20.4}
$$

objo 称为表达式的头；对它指派了数 0. ${ \mathsf { o b j } } _ { i } \ ( i = 1 , \cdots , n )$ 称为表达式的元素或自变量，可以用它们的数 1, · · ·, 指称它们．在许多情形中表达式的头是一个算子或函数，元素则是头作用千其上的运算对象或变元．

并且，头作为一个表达式的元素也可以是一个表达式． Mathematica 中的方括号专门用来表示一个表达式它们只能用千这种关系．

·在 Mathematica 中，项 $x ^ { \wedge } 2 + 2 * x + 1$ 也能以这种中缀形式（或以更漂亮也更可取的形式 $x ^ { 2 } + 2 x + 1 )$ 键入它的完整形式 (FullForm)

$$
\operatorname{Plus} [ 1, \text {Times} [ 2, x ], \operatorname{Power} [ x, 2 ] ]
$$

也是一个表达式． Plus, Power Times 表示相应的算术运算这个例子表明，所有单一的数学算子都存在用千在内部表示的前缀形式，而项表示法只是 Mathematica的一个方便功能

表达式的部分可以被分离．这可以用 $\mathsf { P a r t } [ e x p r , i ]$ 做到，其中 是对应元的数．特别 = 时得到的是该表达式的头

·在 Mathematica 中键入

$$
I n [ 1 ] := x ^ {2} + 2 x + 1
$$

则当 SHIFT ENTER 键一起按下时 Mathematica 的解答是

$$
O u t [ 1 ] = 1 + 2 x + x ^ {2}
$$

Mathematica 分析了输入后将其复原为数学标准形式．如果输入以分号结束，则输出将被禁止．

如果键入

$$
\text {In} [ 2 ] := \text {FullForm} [ \% ]
$$

则解答是

$$
O u t [ 2 ] = \operatorname{Plus} [ 1, \text {Times} [ 2, x ], \text {Power} [ x, 2 ] ]
$$

方括号中的符号％告诉 Mathematica 这次输入的自变量是上一次的输出．从这个表达式有可能得到比如第三个元素

$$
\text {In} [ 3 ] := \operatorname{Part} [ \%, 3 ] \quad \text {为} \quad \text {Out} [ 3 ] = x ^ {2}
$$

在该情形中仍然是一个表达式

Mathematica 中的符号是基本对象的表示法它们可以是任何一列字母和数字，但一定不能以数字开始．也允许使用专门记号＄．字母区分大写和小写．留作专用的符号要么以大写字母开始，要么以记号＄开始．而在复合词中，如果第二个词具有单独意义那么它也以大写字母开始建议用户创建他们自己的符号时以小写字母开始
