#### 18.2.5 无约束问题的解法

考虑一般的优化问题

$$
f (\underline {{\boldsymbol {x}}}) = \min!, \quad \underline {{\boldsymbol {x}}} \in \mathbb {R} ^ {n},\tag{18.72}
$$

这里 是连续可微函数．本节描述的每一种方法一般是构建一无穷序列 $\{ \underline { { { \pmb x } } } ^ { k } \} \subset \mathbb { R } ^ { n }$ 其聚点是一平稳点．这个点列将从 $\mathbf { x } ^ { 1 }$ 始，按照如下递推公式构建：

$$
\underline {{\boldsymbol {x}}} ^ {k + 1} = \underline {{\boldsymbol {x}}} ^ {k} + \alpha_ {k} \underline {{\boldsymbol {d}}} ^ {k} (k = 1, 2, \dots),\tag{18.73}
$$

即首先在 $\scriptstyle { \pmb { x } } ^ { k }$ 处确定一方向 $\underline { { \boldsymbol { d } } } ^ { k }$ ' 而步长 $\alpha _ { k }$ 表示在 $\underline { { \boldsymbol { x } } } ^ { k }$ 沿 $\underline { d } ^ { k }$ 方向离 $\underline { { \boldsymbol { x } } } ^ { k + 1 }$ 有多远．这样的方法称作下降法是指

$$
f (\underline {{\boldsymbol {x}}} ^ {k + 1}) <   f (\underline {{\boldsymbol {x}}} ^ {k}) \quad (k = 1, 2, \dots).\tag{18.74}
$$

等式\~ $\nabla f ( { \underline { { \pmb x } } } ) = 0$ 刻画平稳点并且可以用作迭代算法的停止规则其中 $\nabla$ 表示梯度算子（参见第 933 13.2.6.1).

18.2.5.1 最速下降法

从现时点 $\underline { { \boldsymbol { x } } } ^ { k }$ 发，函数下降最快速的方向是

$$
\underline {{\boldsymbol {d}}} ^ {k} = - \nabla f (\underline {{\boldsymbol {x}}} ^ {k}),\tag{18.75a}
$$

从而

$$
\underline {{\boldsymbol {x}}} ^ {k + 1} = \underline {{\boldsymbol {x}}} ^ {k} - \alpha_ {k} \nabla f (\underline {{\boldsymbol {x}}} ^ {k}).\tag{18.75b}
$$

最速下降法以 $f ( { \underline { { \mathbf { x } } } } ) = f ( { \underline { { \mathbf { x } } } } ^ { i } )$ ）为水平线的示意图见图 18.6.

$$
\underline {{\boldsymbol {x}}} ^ {k + 1} = \underline {{\boldsymbol {x}}} ^ {k} + \alpha_ {k} \underline {{\boldsymbol {d}}} ^ {k},\tag{18.77a}
$$

其中

$$
\underline {{{{\boldsymbol {d}}}}} ^ {k} = - \left(2 \boldsymbol {C} \underline {{{{\boldsymbol {x}}}}} ^ {k} + \underline {{{{\boldsymbol {p}}}}}\right), \quad \text {且} \quad \alpha_ {k} = \frac {\underline {{{{\boldsymbol {d}}}}} ^ {k ^ {\mathrm{T}}} \boldsymbol {d} ^ {k}}{2 \underline {{{{\boldsymbol {d}}}}} ^ {k ^ {\mathrm{T}}} \boldsymbol {C} \underline {{{{\boldsymbol {d}}}}} ^ {k}}.\tag{18.77b}
$$

18.2.5.2 牛顿法的应用

假定在当前的近似点 $\underline { { \boldsymbol { x } } } ^ { k }$ 处，函数 由如下二次函数逼近：

$$
q (\underline {{\boldsymbol {x}}}) = f (\underline {{\boldsymbol {x}}} ^ {k}) + (\underline {{\boldsymbol {x}}} - \underline {{\boldsymbol {x}}} ^ {k}) ^ {\mathrm{T}} \nabla f (\underline {{\boldsymbol {x}}} ^ {k}) + \frac {1}{2} (\underline {{\boldsymbol {x}}} - \underline {{\boldsymbol {x}}} ^ {k}) ^ {\mathrm{T}} \boldsymbol {H} (\underline {{\boldsymbol {x}}} ^ {k}) (\underline {{\boldsymbol {x}}} - \underline {{\boldsymbol {x}}} ^ {k}).\tag{18.78}
$$

这里 $H ( \underline { { { \boldsymbol { x } } } } ^ { k } )$ ）是黑塞矩阵，即 $f$ 在 $\underline { { \boldsymbol { x } } } ^ { k }$ 处的二阶偏导数矩阵．如果 $H ( \underline { { { \boldsymbol { x } } } } ^ { k } )$ ）是正定的，则 $q ( \underline { { \pmb x } } )$ )在 $\mathbf { x } ^ { k + 1 }$ 处达到绝对极小，且 $\nabla q ( \underline { { \pmb x } } ^ { k + 1 } ) = 0$ 从而得到牛顿方法

$$
\underline {{{{\boldsymbol {x}}}}} ^ {k + 1} = \underline {{{{\boldsymbol {x}}}}} ^ {k} - \boldsymbol {H} ^ {- 1} (\underline {{{{\boldsymbol {x}}}}} ^ {k}) \nabla f (\underline {{{{\boldsymbol {x}}}}} ^ {k}) \quad (k = 1, 2, \dots),\tag{18.79a}
$$

即

$$
\underline {{{{\pmb {d}}}}} ^ {k} = - \pmb {H} ^ {- 1} (\underline {{{{\pmb {x}}}}} ^ {k}) \nabla f (\underline {{{{\pmb {x}}}}} ^ {k}), \quad \text {且} \quad \alpha_ {k} \text {见} (1 8. 7 3).\tag{18.79b}
$$

牛顿法收敛速度快，但它也有如下缺点：

a) 矩阵 $H ( \underline { { { \boldsymbol { x } } } } ^ { k } )$ ）必须是正定的．

b) 该方法仅对充分好的初始点收敛．

c) 步长可能没有影响

d) 该方法并不是一种下降法．

e) 计算逆矩阵 $H ^ { - 1 } ( \underline { { { \boldsymbol x } } } ^ { k } )$ 的计算量相当大．

通过所谓的阻尼牛顿法可能会适当减少某些缺点（例如 1251 19.2.2.2):

$$
\underline {{\boldsymbol {x}}} ^ {k + 1} = \underline {{\boldsymbol {x}}} ^ {k} - \alpha_ {k} \boldsymbol {H} ^ {- 1} (\underline {{\boldsymbol {x}}} ^ {k}) \nabla f (\underline {{\boldsymbol {x}}} ^ {k}) \quad (k = 1, 2, \dots),\tag{18.80}
$$

其中的松弛因子 $\alpha _ { k }$ 比如可以通过前面给出的原则来确定（参见第 1210 18.2.5.1).

18.2.5.3 共扼梯度法

两个向量 $\underline { d } ^ { 1 } , \underline { d } ^ { 2 }$ 称作相对千对称正定矩阵 是共扼向量，是指它们满足

$$
\underline {{\boldsymbol {d}}} ^ {\mathrm{T}} \boldsymbol {C} \underline {{\boldsymbol {d}}} ^ {2} = 0.\tag{18.81}
$$

如果 $\underline { { d } } ^ { 1 } , \underline { { d } } ^ { 2 } , \cdots , \underline { { d } } ^ { n }$ 矿相对千矩阵 是两两共辄的，那么凸二次问题 $q ( \underline { { \mathbf { x } } } ) = \underline { { \mathbf { x } } } ^ { \mathrm { T } } C \underline { { \mathbf { x } } } +$ $\underline { { p } } ^ { \mathrm { T } } \underline { { x } } , \underline { { x } } \in \mathbb { R } ^ { n }$ 可以通过 $n$ 步求解，为此只要从 ${ \pmb x } ^ { 1 }$ 出发构建序列 $\underline { { \pmb x } } ^ { k + 1 } = \underline { { \pmb x } } ^ { k } + \alpha _ { k } \underline { d } ^ { k }$ 其中 $\alpha _ { k }$ 是最优步长．假设 $f ( { \underline { { \pmb x } } } )$ 拦） $\underline { { \boldsymbol { x } } } ^ { * }$ 矿的邻域内是近似二次函数，即 $C \approx \frac { 1 } { 2 } H ( \underline { { { x } } } ^ { * } )$ 则为二次目标函数研发的方法也可应用千更一般的函数 $f ( { \underline { { \pmb x } } } )$ ），而无须明着使用矩阵 $H ( \underline { { \boldsymbol { x } } } ^ { * } )$

共辄梯度法分如下几个步骤：

a) $\underline { { \pmb x } } ^ { 1 } \in \mathbb { R } ^ { n } , ~ \underline { { \pmb d } } ^ { 1 } = - \nabla f ( \underline { { \pmb x } } ^ { 1 } )$ ），其 $\mathbf { x } ^ { 1 }$ 矿 $\ b { x } ^ { * }$ 的一个适当的初始近似．（18.82)

b) $\underline { { { \pmb x } } } ^ { k + 1 } = \underline { { { \pmb x } } } ^ { k } + \alpha _ { k } \underline { { { \pmb d } } } ^ { k } \ ( k = 1 , \cdots , n )$ 切，其 $\alpha _ { k } \geqslant 0$ 使得 $f ( \underline { { \pmb { x } } } ^ { k } + \alpha \underline { { \pmb { d } } } ^ { k } )$ 达到极小． (18.83a)

$$
\underline {{\boldsymbol {d}}} ^ {k + 1} = - \nabla f (\underline {{\boldsymbol {x}}} ^ {k + 1}) + \mu_ {k} \underline {{\boldsymbol {d}}} ^ {k} \quad (k = 1, \dots , n - 1),\tag{18.83b}
$$

其中

$$
\mu_ {k} = \frac {\nabla f (\underline {{\boldsymbol {x}}} ^ {k + 1}) ^ {\mathrm{T}} \nabla f (\underline {{\boldsymbol {x}}} ^ {k + 1})}{\nabla f (\underline {{\boldsymbol {x}}} ^ {k}) ^ {\mathrm{T}} \nabla f (\underline {{\boldsymbol {x}}} ^ {k})}, \quad \underline {{\boldsymbol {d}}} ^ {n + 1} = - \nabla f (\underline {{\boldsymbol {x}}} ^ {n + 1}).\tag{18.83c}
$$

c) 用 $\underline { { \pmb x } } ^ { n + 1 }$ 和 $\underline { d } ^ { n + 1 }$ 代替 ${ \underline { { \boldsymbol { x } } } } ^ { 1 }$ 和矿 $\pmb { d } ^ { 1 }$ 重复步骤 b).

18.2.5.4 戴维顿 (Davidon) 、弗莱彻 (Fletcher) 和鲍威尔

$$
(\mathrm{Powell}) (\mathrm{DFP}) \text {方法}
$$

DFP 方法中，从 $\underline { { \boldsymbol { x } } } ^ { 1 }$ 出发的点列根据下列公式确定

$$
\underline {{\boldsymbol {x}}} ^ {k + 1} = \underline {{\boldsymbol {x}}} ^ {k} - \alpha_ {k} \boldsymbol {M} _ {k} \nabla f (\underline {{\boldsymbol {x}}} ^ {k}) (k = 1, 2, \dots),\tag{18.84}
$$

这里 $M _ { k }$ 是对称正定矩阵．在 为二次函数的情形下，这一方法的想法是逆黑塞矩阵由矩阵 $M _ { k }$ 逐步近似从对称正定矩阵 $M _ { 1 }$ 例如 $M _ { 1 } = I ( I$ 为单位矩阵）出发， $M _ { k }$ 由 $M _ { k - 1 }$ 加上一个 秩修正矩阵确定

$$
\boldsymbol {M} _ {k} = \boldsymbol {M} _ {k - 1} + \frac {\underline {{\boldsymbol {v}}} ^ {k} \underline {{\boldsymbol {v}}} ^ {k ^ {\mathrm{T}}}}{\underline {{\boldsymbol {v}}} ^ {k ^ {\mathrm{T}}} \underline {{\boldsymbol {v}}} ^ {k}} - \frac {(\boldsymbol {M} _ {k - 1} \underline {{\boldsymbol {w}}} ^ {k}) (\boldsymbol {M} _ {k - 1} \underline {{\boldsymbol {w}}} ^ {k}) ^ {\mathrm{T}}}{\underline {{\boldsymbol {w}}} ^ {k ^ {\mathrm{T}}} \boldsymbol {M} _ {k} \underline {{\boldsymbol {w}}} ^ {k}},\tag{18.85}
$$

其中 $\underline { { v } } ^ { k } = \underline { { x } } ^ { k } - \underline { { x } } ^ { k - 1 } , \underline { { w } } ^ { k } = \nabla f ( \underline { { x } } ^ { k } ) - \nabla f ( \underline { { x } } ^ { k - 1 } ) \ ( k = 2 , 3 , \cdots )$ )．步长 $\alpha _ { k }$ 从求解下列优化问题得到

$$
f (\underline {{{\boldsymbol {x}}}} ^ {k} - \alpha \boldsymbol {M} _ {k} \nabla f (\underline {{{\boldsymbol {x}}}} ^ {k})) = \min!, \quad \alpha \geqslant 0.\tag{18.86}
$$

如果 $f ( { \underline { { \pmb x } } } )$ ）是二次函数，则 DFP 方法变成共辄梯度法，相应的初始 $M _ { 1 } = I$
