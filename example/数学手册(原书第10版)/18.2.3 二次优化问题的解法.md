#### 18.2.3 二次优化问题的解法

18.2.3.1 沃尔夫方法

1. 问题的提法和求解原理

沃尔夫 (Wolfe) 方法用千求解如下特殊类型的二次问题：

$$
f (\underline {{{{\boldsymbol {x}}}}}) = \underline {{{{\boldsymbol {x}}}}} ^ {\mathrm{T}} \boldsymbol {C} \underline {{{{\boldsymbol {x}}}}} + \underline {{{{\boldsymbol {p}}}}} ^ {\mathrm{T}} \underline {{{{\boldsymbol {x}}}}} = \min!, \quad \text {约束为} \quad \boldsymbol {A} \underline {{{{\boldsymbol {x}}}}} = \underline {{{{\boldsymbol {b}}}}}, \underline {{{{\boldsymbol {x}}}}} \geqslant \underline {{{{\boldsymbol {0}}}}}.\tag{18.56}
$$

假定 是正定的．基本思想是确定与问题 (18.56) 相关的库恩—塔克条件组成的系统

$$
A \underline {{x}} = \underline {{b}},\tag{18.57a}
$$

$$
2 \boldsymbol {C} \underline {{\boldsymbol {x}}} - \underline {{\boldsymbol {v}}} + \boldsymbol {A} ^ {\mathrm{T}} \underline {{\boldsymbol {u}}} = - \underline {{\boldsymbol {p}}},\tag{18.57b}
$$

$$
\underline {{x}} \geqslant \underline {{0}}, \underline {{v}} \geqslant \underline {{0}};\tag{18.57c}
$$

$$
\underline {{\boldsymbol {x}}} ^ {\mathrm{T}} \underline {{\boldsymbol {v}}} = 0\tag{18.58}
$$

的解（ $( \underline { { \boldsymbol { x } } } ^ { * } , \underline { { \boldsymbol { u } } } ^ { * } , \underline { { \boldsymbol { v } } } ^ { * } )$ ）．关系式 (18.57a, 18.57b, 18.57c) 表示一个线性方程组，共有 $m { + } n$ 个方程和 $2 n + m$ 个变量．由千 (18.58)，必然有 $x _ { i } = 0$ 或者 $v _ { i } = 0 ~ ( i = 1 , \cdots , n )$

因此 (18.57a, 18.57b, 18.57c) (18.58) 的每个解至多有 $n + m$ 个非零分量．从而它必定是 (18.57a, 18.57b, 18.57c) 的基本解

2. 求解过程

首先，我们确定系统 $\mathbf { A } { \underline { { x } } } = { \underline { { b } } }$ 的一个可行基本解（顶点）2. 属千 $\underline { { \bar { \mathbf { x } } } }$ 的基变量的指标构成集合 $I _ { B }$ . 为了找出系统 (18.57a, 18.57b, 18.57c) 的同时也满足 (18.58)解，我们把问题表达成

$$
- \mu = \min! (\mu \in \mathbb {R});\tag{18.59}
$$

$$
A \underline {{x}} = \underline {{b}},\tag{18.60a}
$$

$$
2 C \underline {{\boldsymbol {x}}} - \underline {{\boldsymbol {v}}} + A ^ {\mathrm{T}} \underline {{\boldsymbol {u}}} - \mu \underline {{\boldsymbol {q}}} = - \underline {{\boldsymbol {p}}}, \quad \underline {{\boldsymbol {q}}} = 2 C \underline {{\bar {\boldsymbol {x}}}} + \underline {{\boldsymbol {p}}},\tag{18.60b}
$$

$$
\underline {{x}} \geqslant \underline {{0}}, \underline {{v}} \geqslant \underline {{0}}, \mu \geqslant 0;\tag{18.60c}
$$

$$
\underline {{\boldsymbol {x}}} ^ {\mathrm{T}} \underline {{\boldsymbol {v}}} = 0.\tag{18.61}
$$

如果（ $( \underline { { \pmb { x } } } , \underline { { \pmb { v } } } , \underline { { \pmb { u } } } , \mu )$ )是这个问题同时满足 (19.57a, 19.57b, 19.57c) (18.58) 的解，那么 $\mu = 0$ ．向量（ $( \underline { { { \pmb x } } } , \underline { { { \pmb v } } } , \underline { { { \pmb u } } } , \mu ) = ( \underline { { { \bar { \bf x } } } } , \underline { { { \bf 0 } } } , \underline { { { \bf 0 } } } , 1 )$ 是系统 (18.60a, 18.60b, 18.60c) 的已知可行解，并且它也满足 (18.61) ．与此基本解相关的基由系数矩阵

$$
\left( \begin{array}{c c c c} A & 0 & 0 & \underline {{0}} \\ 2 C & - I & A ^ {\mathrm{T}} & - \underline {{q}} \end{array} \right)\tag{18.62}
$$

（这里 1,0,Q 分别表示相应维数的单位矩阵、零矩阵、零向量）的某些列构成：

a) $m$ 个列属千 $x _ { i } , i \in I _ { B }$ 9

b) $n - m$ 个列属千 $v _ { i } , i \notin I _ { B }$

c) 所有 个列都属千如 $u _ { i }$

d) 先删最后一列然后删去 b) c) 中一适当的列

如果 $\underline { { \pmb { q } } } = \underline { { \bf 0 } } ,$ 则根据 d) 互换是不可能的．千是卫；已经是解了．现在第 张单纯形表就可以构建出来了．目标函数的极小将通过单纯形法求解，不过这里要加上一个附加的规则即保证满足关系 $\underline { { \boldsymbol { x } } } ^ { \mathrm { T } } \underline { { \boldsymbol { v } } } = 0 :$ 变量 $x _ { i }$ 和 $v _ { i } ( i = 1 , \cdots , n )$ 必须不能同时是基变量

在系数矩阵 正定的情形下，考虑到此附加规则单纯形法提供问题 (18.59),(18.60a, 18.60b, 18.60c), (18.61) 的一个满足 $\mu = 0$ 的解．在 为正半定矩阵情形下，巾千限制了主元的选择，有可能发生：尽管 $\mu > 0$ ，在无强加的附加规则下，不可能再有交换步骤在这种情形下， $\mu$ 再也无法进一步减少了．

18.2.3.2 希尔德雷思—戴索普 (Hildreth-cl'Esopo) 方法

1. 原理

严格凸优化问题

$$
f (\underline {{{x}}}) = \underline {{{x}}} ^ {\mathrm{T}} C \underline {{{x}}} + \underline {{{p}}} ^ {\mathrm{T}} \underline {{{x}}} = \min!, \quad A \underline {{{x}}} \leqslant \underline {{{b}}}\tag{18.63}
$$

的对偶问题（参见第 1202 1. ）是

$$
\psi (\underline {{{{\boldsymbol {u}}}}}) = \underline {{{{\boldsymbol {u}}}}} ^ {\mathrm{T}} \boldsymbol {E} \underline {{{{\boldsymbol {u}}}}} + \underline {{{{\boldsymbol {h}}}}} ^ {\mathrm{T}} \underline {{{{\boldsymbol {u}}}}} = \min!, \quad \underline {{{{\boldsymbol {u}}}}} \geqslant 0, \text {其中}\tag{18.64a}
$$

$$
\boldsymbol {E} = \frac {1}{4} \boldsymbol {A} \boldsymbol {C} ^ {- 1} \boldsymbol {A} ^ {\mathrm{T}}, \quad \underline {{\boldsymbol {h}}} = \frac {1}{2} \boldsymbol {A} \boldsymbol {C} ^ {- 1} \underline {{\boldsymbol {p}}} + \underline {{\boldsymbol {b}}}.\tag{18.64b}
$$

矩阵 是正定的并有正对角元 $e _ { i i } ( i = 1 , \cdots , m )$ ．变量尘和旦满足如下关系：

$$
\underline {{x}} = - \frac {1}{2} C ^ {- 1} (A ^ {\mathrm{T}} \underline {{u}} + \underline {{p}}).\tag{18.65}
$$

2. 迭代求解

对偶问题 (18.64a) 仅包含约束条件 $\underline { { \textbf { \em u } } } \geqslant \underline { { \textbf { \em 0 } } } .$ 可以通过如下简单的迭代方法求解：

a) 代入 ${ \underline { { \boldsymbol u } } } ^ { 1 } \geqslant \mathbf { 0 }$ （例如， $\mathbf { u ^ { 1 } } = \mathbf { \underline { { 0 } } } ) , k = 1$

b) 根据下列公式计算 $u _ { i } ^ { k + 1 } , ~ i = 1 , \cdots , m$

$$
w _ {i} ^ {k + 1} = - \frac {1}{e _ {i i}} \left(\sum_ {j = 1} ^ {i - 1} e _ {i j} u _ {j} ^ {k + 1} + \frac {h _ {i}}{2} + \sum_ {j = i + 1} ^ {m} e _ {i j} u _ {j} ^ {k}\right),\tag{18.66a}
$$

$$
u _ {i} ^ {k + 1} = \max \left\{0, w _ {i} ^ {k + 1} \right\}.\tag{18.66b}
$$
