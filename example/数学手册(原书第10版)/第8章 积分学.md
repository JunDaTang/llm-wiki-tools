## 第8章 积分学

(1) 积分与不定积分 在下述意义下积分是微分的逆运算：若微分计算的是给定函数 (x) 的导数 ${ f ^ { \prime } } \left( x \right)$ ，积分则是要确定一个函数，使其导数为前面给出的 ${ f ^ { \prime } } \left( x \right)$ 因积分结果不唯一，故要引出不定积分的概念．

(2) 定积分 从积分学的图形问题出发，要确定曲线 $y = f \left( x \right)$ 轴围成的图形面积，需要用一些小矩形来近似（图 8.1)，由此引出定积分的概念．
