#### 11.2.2 逐次逼近法、诺伊曼级数

1. 迭代法

类似千对千常微分方程解的皮卡迭代法(Picard iteration method) （参见第 7279.1.1.5,1.），需要给出一个迭代法来解第二类弗雷德霍姆积分方程．从方程

$$
\varphi (x) = f (x) + \lambda \int_ {a} ^ {b} K (x, y) \varphi (y) \mathrm{d} y,\tag{11.10}
$$

开始，定义一个函数序列 $\varphi _ { 0 } ( x ) , \varphi _ { 1 } ( x ) , \varphi _ { 2 } ( x ) , \cdot \cdot \cdot$ ．．．令第一个函数为 $\varphi _ { 0 } ( x ) = f ( x )$ 可以由下述公式得到后续 $\varphi _ { n } ( x )$

$$
\varphi_ {n} (x) = f (x) + \lambda \int_ {a} ^ {b} K (x, y) \varphi_ {n - 1} (y) \mathrm{d} y \quad (n = 1, 2, \dots ; \varphi_ {0} (x) = f (x)).\tag{11.11a}
$$

按照给定的方法，第一步是

$$
\varphi_ {1} (x) = f (x) + \lambda \int_ {a} ^ {b} K (x, y) f (y) \mathrm{d} y.\tag{11.11b}
$$

根据迭代公式把 $\varphi ( x )$ 的这个表达式代入 (11.10) 的右端为了避免积分变量的误解，在 (11.llb) 中用 表示 y.

$$
\begin{array}{l} \varphi_ {2} (x) = f (x) + \lambda \int_ {a} ^ {b} K (x, y) \bigg [ f (y) + \lambda \int_ {a} ^ {b} K (y, \eta) f (\eta) \mathrm{d} \eta \bigg ] \mathrm{d} y \\ = f (x) + \lambda \int_ {a} ^ {b} K (x, y) f (y) \mathrm{d} y + \lambda^ {2} \int_ {a} ^ {b} \int_ {a} ^ {b} K (x, y) K (y, \eta) f (\eta) \mathrm{d} y \mathrm{d} \eta . \end{array}\tag{11.11c}
$$

11.lld)

引进记号 $K _ { 1 } ( x , y ) = K ( x , y )$ 和 $K _ { 2 } ( x , y ) = \int _ { a } ^ { b } K ( x , \xi ) K ( \xi , y ) \mathrm { d } \xi$ ，并重新把 记为$y ,$ 则可以把 $\varphi _ { 2 } ( x )$ 写为

$$
\varphi_ {2} (x) = f (x) + \lambda \int_ {a} ^ {b} K _ {1} (x, y) f (y) \mathrm{d} y + \lambda^ {2} \int_ {a} ^ {b} K _ {2} (x, y) f (y) \mathrm{d} y.\tag{11.11e}
$$

记

$$
K _ {n} (x, y) = \int_ {a} ^ {b} K (x, \xi) K _ {n - 1} (\xi , y) \mathrm{d} \xi \quad (n = 2, 3, \dots),\tag{11.11f}
$$

次迭代函数 $\varphi _ { n } ( x )$ 有表达式

$$
\varphi_ {n} (x) = f (x) + \lambda \int_ {a} ^ {b} K _ {1} (x, y) f (y) \mathrm{d} y + \dots + \lambda^ {n} \int_ {a} ^ {b} K _ {n} (x, y) f (y) \mathrm{d} y.\tag{11.11g}
$$

其中 $K _ { n } ( x , y )$ 被称为 $K ( x , y )$ 次迭代核 (n-th iterated kernel).

2. 诺伊曼级数的收敛性

为了得到解 $\varphi ( x )$ ，需要讨论被称为诺伊曼级数的入的幕级数

$$
f (x) + \sum_ {n = 1} ^ {\infty} \lambda^ {n} \int_ {a} ^ {b} K _ {n} (x, y) f (y) \mathrm{d} y\tag{11.12}
$$

的收敛性．如果函数 $K ( x , y )$ 和 $f ( x )$ 是有界的，即成立不等式

$$
| K (x, y) | <   M (a \leqslant x \leqslant b, a \leqslant y \leqslant b) \quad \text {和} \quad | f (x) | <   N \quad (a \leqslant x \leqslant b),\tag{11.13a}
$$

则级数

$$
N \sum_ {n = 0} ^ {\infty} | \lambda M (b - a) | ^ {n}\tag{11.13b}
$$

是幕级数 (11.12) 的一个优级数．这个儿何级数对千所有

$$
| \lambda | <   \frac {1}{M (b - a)}\tag{11.13c}
$$

是收敛的．对千所有满足 (11.13c) 的入，该诺伊曼级数是绝对和一致收敛的．通过对诺伊曼级数项更精确的估计，可以给出更确切的收敛区间据此，对千

$$
| \lambda | <   \frac {1}{\sqrt {\int_ {a} ^ {b} \int_ {a} ^ {b} | K (x , y) | ^ {2} \mathrm{d} x \mathrm{d} y}},\tag{11.13d}
$$

诺伊曼级数是收敛的．对千入的这个限制并不意味着对任意在由 (11.13d) 所规定的有界集合外的入不存在解，而只是不能由该诺伊曼级数得到解．表达式

$$
\Gamma (x, y; \lambda) = \sum_ {n = 1} ^ {\infty} \lambda^ {n - 1} K _ {n} (x, y)\tag{11.14a}
$$

被称为积分方程的预解式 (resolvent) 或解核 (solving kernel) ．利用预解式得到形如

$$
\varphi (x) = f (x) + \lambda \int_ {a} ^ {b} \Gamma (x, y; \lambda) f (y) \mathrm{d} y\tag{11.14b}
$$

的解．

·对千第二类非齐次弗雷德霍姆积分方程 $\varphi ( x ) = x + \lambda \int _ { 0 } ^ { 1 } x y \varphi ( y ) \mathrm { d } y$ ，有 $K _ { 1 } ( x , y ) =$ $x y , K _ { 2 } ( x , y ) = \int _ { 0 } ^ { 1 } x \eta \eta y \mathrm { d } y = { \frac { 1 } { 3 } } x y , K _ { 3 } ( x , y ) = { \frac { 1 } { 9 } } x y , \cdots , K _ { n } ( x , y ) = { \frac { x y } { 3 ^ { n - 1 } } }$ ，并由此得到 ${ \cal { T } } ( x , y ; \lambda ) = x y \bigg ( \sum _ { n = 0 } ^ { \infty } \frac { \lambda ^ { n } } { 3 ^ { n } } \bigg )$ ．在限制 (11.13c) 下，因为 $| K ( x , y ) | \leqslant M = 1$ ，所以诺伊曼级数对千 $| \lambda | < 1$ 必定收敛预解式 $\begin{array} { l } { \displaystyle { T ( x , y ; \lambda ) = \frac { x y } { 1 - \frac { \lambda } { 3 } } } } \end{array}$ 是一个儿何级数，它甚至当 $| \lambda | < 3$ 时都是收敛的．这样，由（11.14b）即得 $\varphi ( x ) = x + \lambda \int _ { 0 } ^ { 1 } { \frac { x y ^ { 2 } } { 1 - { \frac { \lambda } { 3 } } } } \mathrm { d } y =$ ${ \frac { x } { 1 - { \frac { \lambda } { 3 } } } } ,$

如果对千一个给定的入，关系式 (11.13d) 不成立，此时任一连续核可以被分解为两个连续核之和 $K ( x , y ) = K ^ { 1 } ( x , y ) + K ^ { 2 } ( x , y )$ ，其中 $K ^ { 1 } ( x , y )$ 是一个退化核，而 $K ^ { 2 } ( x , y )$ 充分小，使得 (11.13d) 成立用这种方法对千不是本征值的任意入，也有一个明确的解法
