### 16.1 组合学

由已知集合的元素通常可构造新的集合、体系或序列．根据不同的构造方式，可得到全排列（排序）、组合（选元）以及部分排列或排列等概念．排列兼顾元素的顺序和选择，组合的基本问题是对千给定元素确定可能有多少种不同的选择或排列方式

#### 16.1.1 全排列

1. 定义

个元素的一个全排列是 个元素的一个排序．

2. 无重复全排列数

个互异元素的不同全排列数是

$$
\mathrm{P} _ {n} = n!.\tag{16.1}
$$

■ 16 个学生坐到教室的 16 个座位上，共有 16! 种不同的坐法．

．有重复全排列数

若 $n$ 个元素中有 $k ( k \leqslant n )$ 个元素相同则其不同的全排列数 $\mathrm { P } _ { n } ^ { ( k ) }$

$$
\mathrm{P} _ {n} ^ {(k)} = \frac {n !}{k !}.\tag{16.2}
$$

·把 16 个学生的书包放到教室的 16 把椅子上，其中 个书包是相同的，则书包的不同放置方式有 16!/4！种．

4. 推广

个元素中包含 类重数分别是 $k _ { 1 } , k _ { 2 } , \cdot \cdot \cdot , k _ { m } ( k _ { 1 } + k _ { 2 } + \cdot \cdot \cdot + k _ { m } = n )$ 的不同元素，则其不同的全排列数 $\mathrm { P } _ { n } ^ { ( k _ { 1 } , k _ { 2 } , \cdots , k _ { m } ) }$ 是

$$
\mathrm{P} _ {n} ^ {(k _ {1}, k _ {2}, \dots , k _ {m})} = \frac {n !}{k _ {1} ! k _ {2} ! \cdots k _ {m} !}.\tag{16.3}
$$

·假设我们用数字 4, 4, 5, 5, 构造五位数，可组成 $\mathrm { P _ { 5 } ^ { ( 2 , 3 ) } } = { \frac { 5 ! } { 2 ! 3 ! } } = 1 0$ 个不同的数

#### 16.1.2 组合

1. 定义

组合是从 个不同元素中任取 个元素，不管其顺序的取法，也称为 阶组合，我们将它分为有重复组合与无重复组合

2. 无重复组合数

个不同元素中取出 个，不考虑所取元素的顺序，若每个元素最多可取出次，则其可能的不同取法 $\mathrm { C } _ { n } ^ { ( k ) }$ 是

$$
\mathrm{C} _ {n} ^ {(k)} = \binom{n}{k}, \text {其中} 0 \leqslant k \leqslant n \quad (\text {参见第} 1 5 \text {页} 1. 1. 6. 4, 3.).\tag{16.4}
$$

它称为无重复组合

·从 30 位参会者中挑出 位组成选举委员会，共有 $\left( \begin{array} { c } { { 3 0 } } \\ { { 4 } } \end{array} \right) = 2 7 4 0 5$ 种可能的取法.

3. 有重复组合数

从n个不同元素中取出k个，每个元素可重复选取，且不考虑元素间的顺序则可能的取法是

$$
\mathrm{C} _ {n} ^ {(k)} = \binom{n + k - 1}{k}.\tag{16.5}
$$

换言之，即考虑从 个不同元素中任取 个元素的不同取法其中每个元素可重复选取

·掷 颗骰子，可能的不同结果是 $\mathrm { C } _ { 6 } ^ { ( k ) } = \left( \begin{array} { c } { { k + 6 - 1 } } \\ { { k } } \end{array} \right)$ ．故掷 颗骰子，有$\mathrm { C _ { 6 } ^ { ( 2 ) } = \left( \begin{array} { l } { 7 } \\ { 2 } \end{array} \right) = 2 1 }$ 种不同结果．

#### 16.1.3 排列

1. 定义

排列是从 个不同元素中任取 个元素并排序，即排列是考虑元素顺序的组合

．无重复排列数

个不同元素中选取 个不同元素，且依不同顺序进行排列，其排列数 $\mathrm { V } _ { n } ^ { ( k ) }$

是

$$
\mathrm{V} _ {n} ^ {(k)} = k! \left( \begin{array}{l} n \\ k \end{array} \right) = n (n - 1) (n - 2) \dots (n - k + 1) \quad (0 \leqslant k \leqslant n).\tag{16.6}
$$

·在一次选举会议上，要从 30 位候选人中选出一名主席、一名副主席，以及第一助理和第二助理各一名，共有多少种不同的选举方法？答案是 ${ \binom { 3 0 } { 4 } } 4 ! = 6 5 7 7 2 0$ 种．

3. 有重复排列数

个不同元素中选取 个元素，按照一定的顺序排成一列其中每个元素可取任意多次称为有重复排列其排列数是

$$
\mathrm{V} _ {n} ^ {(k)} = n ^ {k}.\tag{16.7}
$$

A: 一场有 12 支队伍的 Toto 杯足球赛，共有 $3 ^ { 1 2 }$ 种不同的比赛结果．

■ B: 使用 位数字单元也称为一个字节可表示 $2 ^ { 8 } = 2 5 6$ 个不同字符（例子可参见著名的 ASCII 表）．
