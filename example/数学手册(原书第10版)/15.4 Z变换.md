### 15.4 Z变换

在自然科学以及工程学中，人们经常需要区分连续过程和离散过程．连续过程可用微分方程描述，而离散过程主要由差分方程描述．求解微分方程主要使用傅里叶变换和拉普拉斯变换，但为求解差分方程，则必须使用其他运算方法．已知的最好方法是 变换，它与拉普拉斯变换密切相关．

#### 15.4.1 Z变换的性质

15.4.1.1 离散函数

若仅知函数 $f ( t ) \ ( 0 \leqslant t < \infty )$ 在自变量离散点 $t _ { n } = n T ( n = 0 , 1 , 2 , \cdot \cdot \cdot ; T > 0$ 是常数）处的取值，则可记作 $f ( n T ) = f _ { n }$ ，且构成序列 $\left\{ f _ { n } \right\}$ ．比如，在电工学中，在离散时间段 $t _ { n }$ 处＂浏览＇函数 f(t)，即可产生这样的序列．其表达式为阶梯函数（图 15.27).

只在自变量离散点处有定义的函数 $f ( n T )$ （称为离散函数）和序列 $\left\{ f _ { n } \right\}$ ，二者是等价的．

15.4.1.2 变换的定义

1. 原序列和变换

给定序列 $\left\{ f _ { n } \right\}$ ，可得到无穷级数

$$
F (z) = \sum_ {n = 0} ^ {\infty} f _ {n} \left(\frac {1}{z}\right) ^ {n}.\tag{15.105}
$$

若该级数收敛，则序列 $\left\{ f _ { n } \right\}$ 称为可 变换的，且可表示为

$$
F (z) = \mathcal {Z} \left\{f _ {n} \right\}.\tag{15.106}
$$

$\left\{ f _ { n } \right\}$ ｝称为原序列 $F ( z )$ 称为变换函数， 表示复变量， $F ( z )$ 是复值函数．■ $f _ { n } = 1 \quad ( n = 0 , 1 , 2 , \cdots )$ )．对应的无穷级数是

$$
F (z) = \sum_ {n = 0} ^ {\infty} \left(\frac {1}{z}\right) ^ {n}.\tag{15.107}
$$

它表示公比为 $1 / z$ 的儿何级数，当 $\left| \frac { 1 } { z } \right| < 1$ 时级数收敛，其和是 $F ( z ) = { \frac { z } { z - 1 } }$ 当 $\left| { \frac { 1 } { z } } \right| \geqslant 1$ 时，级数发散．因此，当 $\left| { \frac { 1 } { z } } \right| < 1$ 时，即对千 平面内单位圆 $| z | = 1$ 的任何外点序列 {1} 是可 变换的．

2. 性质

根据式 (15.105) ，变换 $F ( z )$ 是复变量 $1 / z$ 的幕级数，由复幕级数（参见第 97914.3.1.3) 的性质，可知如下结论：

a) 对千可 变换的序列｛ $\{ f _ { n } \}$ ，存在实数 ，使得当 $| z | > 1 / R$ 时，级数 (15.105)绝对收敛，当 $| z | < 1 / R$ 时级数发散当 $| z | \geqslant 1 / R _ { 0 } > 1 / R$ 时，级数一致收敛．是关千 $1 / z$ 的幕级数 (15.105) 的收敛半径．若对千任 $| z | > 0$ , 级数收敛，则$R = \infty$ ．对千不可 变换的序列，有 $R = 0$

b) 若当 $| z | > 1 / R$ 时， $\left\{ f _ { n } \right\}$ 是可 变换的，则 $| z | > 1 / R$ 时，对应的变换$F ( z )$ 是解析函数，且它是 $\{ f _ { n } \}$ 的唯一变换．反之，若 $| z | > 1 / R$ 时， $F ( z )$ 是解析函数，且在 $z = \infty$ 处， $F ( z )$ 是正则的，则对千 $F ( z )$ ，存在唯一的原序列｛ $\{ f _ { n } \}$ ．若$F ( z )$ 有形如 (15.105) 的幕级数展开式且 $F ( \infty ) = f _ { 0 }$ , 则称 $F ( z )$ 在 $z = \infty$ 处是正则的．

3. 极限定理

与拉普拉斯变换的极限性质类似（参见第 1006 (15.7b) ），对千 变换有下述极限定理成立

a) $F ( z ) = \mathcal { Z } \left\{ f _ { n } \right\}$ ｝存在，则

$$
f _ {0} = \lim _ {z \to \infty} F (z).\tag{15.108}
$$

此处， 可以沿着实轴或其他任何路径趋向千无穷大．由千级数

$$
z \left\{F (z) - f _ {0} \right\} = f _ {1} + f _ {2} \frac {1}{z} + f _ {3} \frac {1}{z ^ {2}} + \dots ,\tag{15.109}
$$

$$
z ^ {2} \left\{F (z) - f _ {0} - f _ {1} \frac {1}{z} \right\} = f _ {2} + f _ {3} \frac {1}{z} + f _ {4} \frac {1}{z ^ {2}} + \dots ,\tag{15.110}
$$

明显是 变换，类似千式 (15.108)，可得到

$$
f _ {1} = \lim _ {z \rightarrow \infty} z \left\{F (z) - f _ {0} \right\}, \quad f _ {2} = \lim _ {z \rightarrow \infty} z ^ {2} \left\{F (z) - f _ {0} - f _ {1} \frac {1}{z} \right\}, \dots .\tag{15.111}
$$

通过这种方式，原序列 $\{ f _ { n } \}$ 可根据其变换 $F ( z )$ 来确定．

b) $\operatorname* { l i m } _ { n \to \infty } f _ { n }$ 存在，则

$$
\lim _ {n \to \infty} f _ {n} = \lim _ {z \to 1 + 0} (z - 1) F (z).\tag{15.112}
$$

但由千上述命题不可逆，根据式 (15.112)，只有能保证 $\operatorname* { l i m } _ { n \to \infty } f _ { n }$ 存在时，才能确定其值

■ $f _ { n } = ( - 1 ) ^ { n } ( n = 0 , 1 , 2 , \cdot \cdot \cdot )$ ，则 ${ \mathcal { Z } } \left\{ f _ { n } \right\} = { \frac { z } { z + 1 } }$ ，且 $\operatorname* { l i m } _ { z  1 + 0 } ( z - 1 ) \frac { z } { z + 1 } = 0$ ，但$\operatorname* { l i m } _ { n \to \infty } ( - 1 ) ^ { n }$ 不存在．

15.4.1.3 计算法则

在运用 变换时，了解定义在原序列上的某些运算对变换的影响及其反过来的情况，是很重要的．此处为了简化，当 $| z | > 1 / R$ 时，将使用记号 $F ( z ) = \mathcal { Z } \left\{ f _ { n } \right\}$

1. 平移

需要区分向前平移和向后平移．

(1) 第一移位定理： ${ \mathcal { Z } } \left\{ f _ { n - k } \right\} = z ^ { - k } F ( z ) \left( k = 0 , 1 , 2 , \cdot \cdot \cdot \right)$

(15.113)

当 $n - k < 0$ 时定义 $f _ { n - k } = 0$

(2) 第二移位定理： ${ \mathcal { Z } } \left\{ f _ { n + k } \right\} = z ^ { k } \left[ F ( z ) - \sum _ { v = 0 } ^ { k - 1 } f _ { v } \left( { \frac { 1 } { z } } \right) ^ { v } \right] ( k = 1 , 2 , \cdots )$

(15.114)

2. 求和

当 $| z | > \operatorname* { m a x } { \left( 1 , \frac { 1 } { R } \right) }$ 时，有 $\mathcal { Z } \left\{ \sum _ { v = 0 } ^ { n - 1 } f _ { v } \right\} = \frac { 1 } { z - 1 } F ( z ) .$

3. 差分

(15.115)

对千差分

$$
\Delta f _ {n} = f _ {n + 1} - f _ {n}, \quad \Delta^ {m} f _ {n} = \Delta (\Delta^ {m - 1} f _ {n}) \quad (m = 1, 2, \dots ; \Delta^ {0} f _ {n} = f _ {n})\tag{15.116}
$$

有下述等式成立：

$$
\begin{array}{c} \mathcal {Z} \left\{\Delta f _ {n} \right\} = (z - 1) F (z) - z f _ {0}, \\ \mathcal {Z} \left\{\Delta^ {2} f _ {n} \right\} = (z - 1) ^ {2} F (z) - z (z - 1) f _ {0} - z f _ {0}, \\ \vdots \end{array}\tag{15.117}
$$

$$
\mathcal {Z} \left\{\Delta^ {k} f _ {n} \right\} = (z - 1) ^ {k} F (z) - z \sum_ {v = 0} ^ {k - 1} (z - 1) ^ {k - v - 1} \Delta^ {v} f _ {0}.
$$

4. 阻尼

对千任意复数 $\lambda \neq 0$ 和 $| z | > \frac { | \lambda | } { R }$ ，有

$$
\mathcal {Z} \left\{\lambda^ {n} f _ {n} \right\} = F \left(\frac {z}{\lambda}\right).\tag{15.118}
$$

5. 卷积

两个序列 $\left\{ f _ { n } \right\}$ 和 $\left\{ g _ { n } \right\}$ 的卷积是运算

$$
f _ {n} * g _ {n} = \sum_ {v = 0} ^ {n} f _ {v} g _ {n - v}.\tag{15.119}
$$

若当 $| z | > 1 / R _ { 1 }$ 时， 变换函数 ${ \mathcal { Z } } \left\{ f _ { n } \right\} = F ( z )$ ，以及 $| z | > 1 / R _ { 2 }$ 时，${ \mathcal { Z } } \left\{ g _ { n } \right\} = G ( z )$ 存在，则对千 $| z | > \operatorname* { m a x } \left( \frac { 1 } { R _ { 1 } } , \frac { 1 } { R _ { 2 } } \right)$ ，有

$$
\mathcal {Z} \left\{f _ {n} * g _ {n} \right\} = F (z) G (z).\tag{15.120}
$$

关系式 (15.120) 称为 变换的卷积定理．它相当千两个幕级数的乘法法则．6. 变换的微分

$$
\mathcal {Z} \left\{n f _ {n} \right\} = - z \frac {\mathrm{d} F (z)}{\mathrm{d} z}.\tag{15.121}
$$

重复运用 (15.121) ，可得到 $F ( z )$ 的高阶导数．

7. 变换的积分

当假定 $f _ { 0 } = 0$ 时有

$$
\mathcal {Z} \left\{\frac {f _ {n}}{n} \right\} = \int_ {z} ^ {\infty} \frac {F (\xi)}{\xi} \mathrm{d} \xi .\tag{15.122}
$$

15.4.1.4 与拉普拉斯变换的关系

把离散函数 f(t)（参见第 1038 15.4.1.1) 描述为阶梯函数，则

$f ( t ) = f ( n T ) = f _ { n }$ , 其中， $n T \leqslant t < ( n + 1 ) T \quad ( n = 0 , 1 , 2 , \cdot \cdot \cdot ; T > 0 , \ T$ 是常数），

(15.123)

对千该分段常数函数，求拉普拉斯变换（参见第 1006 15.2.1.1, 1.)，当 $T = 1$ 时，有

$$
\begin{array}{r l} & {\mathcal {L} \left\{f (t) \right\} = F (p) = \sum_ {n = 0} ^ {\infty} \int_ {n} ^ {n + 1} f _ {n} \mathrm{e} ^ {- p t} \mathrm{d} t} \\ & {\qquad = \sum_ {n = 0} ^ {\infty} f _ {n} \frac {\mathrm{e} ^ {- n p} - \mathrm{e} ^ {- (n + 1) p}}{p} = \frac {1 - \mathrm{e} ^ {- p}}{p} \sum_ {n = 0} ^ {\infty} f _ {n} \mathrm{e} ^ {- n p}.} \end{array}\tag{15.124}
$$

(15.124) 中的无穷级数称为离散拉普拉斯变换，用 表示：

$$
\mathcal {D} \left\{f (t) \right\} = \mathcal {D} \left\{f _ {n} \right\} = \sum_ {n = 0} ^ {\infty} f _ {n} \mathrm{e} ^ {- n p}.\tag{15.125}
$$

在式 (15.125) 中进行 $\mathrm { e } ^ { p } = z$ 的替换后 $\mathcal { D } \left\{ f _ { n } \right\}$ 表示关千 $1 / z$ 的幕级数，即所谓的洛朗级数（参见第 981 14.3.4) ．替换 $\mathrm { e } ^ { p } = z$ 启示了 变换的名称．根据该变换，由式 (15.124)，可最终得到在阶梯函数的情况下，拉普拉斯变换和 变换之间有下述关系：

$$
p F (p) = \left(1 - \frac {1}{z}\right) F (z)\tag{15.126a}
$$

或

$$
p \mathcal {L} \left\{f (t) \right\} = \left(1 - \frac {1}{z}\right) \mathcal {Z} \left\{f _ {n} \right\}.\tag{15.126b}
$$

通过这种方式阶梯函数的 变换（参见第 1454 页表 21.15) 可转化为阶梯函数的拉普拉斯变换（参见第 1431 页表 21.13)，反之亦然．

15.4.1.5 变换的逆变换

变换的逆变换是根据变换 $F ( z )$ ，探寻对应的唯一原序列｛ $\{ f _ { n } \}$

$$
\mathcal {Z} ^ {- 1} \left\{F (z) \right\} = \left\{f _ {n} \right\}.\tag{15.127}
$$

求逆变换有不同的方法．

1. 使用表格

若表格中没有给出函数 $F ( z )$ ，则我们可试着把 $F ( z )$ 转化为表 21.15 中已给出的函数．

2. $F ( z )$ 的洛朗级数

若关千 $1 / z$ 的 $F ( z )$ 的级数展开式已知或可求出，则使用第 1039 页定义 (15.105),可直接求其逆变换

3. $F \left( { \frac { 1 } { z } } \right)$ 的泰勒级数

由于 $F \left( { \frac { 1 } { z } } \right)$ 是关于z的幂递增的级数，根据(15.105)，使用泰勒公式，可推出

$$
f _ {n} = \left. \frac {1}{n !} \frac {\mathrm{d} ^ {n}}{\mathrm{d} z ^ {n}} F \left(\frac {1}{z}\right) \right| _ {z = 0} \quad (n = 0, 1, 2, \dots).\tag{15.128}
$$

使用第 1040 页的极限式 (15.108) (15.111) ，原序列 $\left\{ f _ { n } \right\}$ ｝可由其变换 $F ( z )$ 直接确定

#### 15.4.2 Z变换的应用

15.4.2.1 线性差分方程的一般解法

阶常系数线性差分方程形如

$$
a _ {k} y _ {n + k} + a _ {k - 1} y _ {n + k - 1} + \dots + a _ {2} y _ {n + 2} + a _ {1} y _ {n + 1} + a _ {0} y _ {n} = g _ {n} (n = 0, 1, 2, \dots),\tag{15.132}
$$

其中， 为自然数．系数 $a _ { i } ( i = 0 , 1 , \cdots , k )$ 是已知的实数或复数，且与 无关． $a _ { 0 }$ 和 $a _ { k }$ 是非零数．序列 $\left\{ g _ { n } \right\}$ 已知，序列｛ $\left\{ y _ { n } \right\}$ 待定．

为求 (15.132) 的特解，需要已知以前的值 $y _ { 0 } , y _ { 1 } , \cdots , y _ { k - 1 }$ ．此时，根据 (15.132),当 $n = 0$ 时可求出下一个值 $y _ { k }$ · 接下来，由 $y _ { 0 } , y _ { 1 } , \dotsb , y _ { k }$ (15.132) ，当 $n = 1$ 时，可得到 $y _ { k + 1 }$ ．按照这种方式可递归计算所有的值 $y _ { n }$ ．但对 (15.132) 运用第二移位定理 (15.114)，利用 变换，对千值 $y _ { n }$ 可给出一般解：

$$
\begin{array}{l} a _ {k} z ^ {k} \left[ Y (z) - y _ {0} - y _ {1} z ^ {- 1} - \dots - y _ {k - 1} z ^ {- (k - 1)} \right] + \dots \\ + a _ {1} z \left[ Y (z) - y _ {0} \right] + a _ {0} Y (z) = G (z). \end{array}\tag{15.133}
$$

其中， $Y ( z ) = { \mathcal { Z } } \left\{ y _ { n } \right\} , G ( z ) = { \mathcal { Z } } \left\{ g _ { n } \right\}$ ．令 $a _ { k } z ^ { k } + a _ { k - 1 } z ^ { k - 1 } + \cdot \cdot \cdot + a _ { 1 } z + a _ { 0 } = p ( z )$ 2则变换方程 (15.133) 的解为

$$
Y (z) = \frac {1}{p (z)} G (z) + \frac {1}{p (z)} \sum_ {i = 0} ^ {k - 1} y _ {i} \sum_ {j = i + 1} ^ {k} a _ {j} z ^ {j - i}.\tag{15.134}
$$

正如使用拉普拉斯变换求解线性微分方程的情况， 变换也有类似的优势，即初值可包含在变换方程中，故变换方程的解也自动包含了初值．由 (15.134)，通过第1042 15.4.1.5 中讨论的逆变换，可推出所求解 $\{ y _ { n } \} = \mathcal { Z } ^ { - 1 } \{ Y ( z ) \}$

15.4.2.2 二阶差分方程（初值问题）

二阶线性差分方程形如

$$
y _ {n + 2} + a _ {1} y _ {n + 1} + a _ {0} y _ {n} = g _ {n},\tag{15.135}
$$

其中， $y _ { 0 }$ 和 $y _ { 1 }$ 作为初值已给出．对 (15.135) 使用第二移位定理，变换方程是

$$
z ^ {2} \left[ Y (z) - y _ {0} - y _ {1} \frac {1}{z} \right] + a _ {1} z \left[ Y (z) - y _ {0} \right] + a _ {0} Y (z) = G (z).\tag{15.136}
$$

进行替换 $z ^ { 2 } + a _ { 1 } z + a _ { 0 } = p ( z )$ ，解得

$$
Y (z) = \frac {1}{p (z)} G (z) + y _ {0} \frac {z (z + a _ {1})}{p (z)} + y _ {1} \frac {z}{p (z)}.\tag{15.137}
$$

若多项式 $p ( z )$ 的根是 $\alpha _ { 1 }$ 和 $\alpha _ { 2 }$ ，则 $\alpha _ { 1 } \neq 0 , \alpha _ { 2 } \neq 0$ ，否则 $a _ { 0 } = 0$ ，差分方程降为一阶．通过部分分式分解和运用表 21.15 中的 $Z$ 变换，可得到

$$
\frac {z}{p (z)} = \left\{ \begin{array}{l l} \frac {1}{\alpha_ {1} - \alpha_ {2}} \left(\frac {z}{z - \alpha_ {1}} - \frac {z}{z - \alpha_ {2}}\right), & \alpha_ {1} \neq \alpha_ {2}, \\ \frac {z}{(z - \alpha_ {1}) ^ {2}}, & \alpha_ {1} = \alpha_ {2}, \end{array} \right.
$$

$$
\mathcal {Z} ^ {- 1} \left\{\frac {z}{p (z)} \right\} = \{p _ {n} \} = \left\{ \begin{array}{l l} \frac {\alpha_ {1} ^ {n} - \alpha_ {2} ^ {n}}{\alpha_ {1} - \alpha_ {2}}, & \alpha_ {1} \neq \alpha_ {2}, \\ n \alpha_ {1} ^ {n - 1}, & \alpha_ {1} = \alpha_ {2}. \end{array} \right.\tag{15.138a}
$$

由千 $p _ { 0 } = 0$ ，利用第二移位定理有

$$
\mathcal {Z} ^ {- 1} \left\{\frac {z ^ {2}}{p (z)} \right\} = \mathcal {Z} ^ {- 1} \left\{z \frac {z}{p (z)} \right\} = \left\{p _ {n + 1} \right\},\tag{15.138b}
$$

以及利用第一移位定理

$$
\mathcal {Z} ^ {- 1} \left\{\frac {1}{p (z)} \right\} = \mathcal {Z} ^ {- 1} \left\{\frac {1}{z} \frac {z}{p (z)} \right\} = \left\{p _ {n - 1} \right\},\tag{15.138c}
$$

进行替换 $p _ { - 1 } = 0$ ，基千卷积定理可得到原序列

$$
y _ {n} = \sum_ {v = 0} ^ {n} p _ {v - 1} g _ {n - v} + y _ {0} (p _ {n + 1} + a _ {1} p _ {n}) + y _ {1} p _ {n}.\tag{15.138d}
$$

由千 $p _ { - 1 } = p _ { 0 } = 0$ , 该关系式和 (15.138a) 表明当 $\alpha _ { 1 } \neq \alpha _ { 2 }$ 时可推出

$$
y _ {n} = \sum_ {v = 2} ^ {n} g _ {n - v} \frac {\alpha_ {1} ^ {v - 1} - \alpha_ {2} ^ {v - 1}}{\alpha_ {1} - \alpha_ {2}} + y _ {0} \left(\frac {\alpha_ {1} ^ {n + 1} - \alpha_ {2} ^ {n + 1}}{\alpha_ {1} - \alpha_ {2}} + a _ {1} \frac {\alpha_ {1} ^ {n} - \alpha_ {2} ^ {n}}{\alpha_ {1} - \alpha_ {2}}\right) + y _ {1} \frac {\alpha_ {1} ^ {n} - \alpha_ {2} ^ {n}}{\alpha_ {1} - \alpha_ {2}}.\tag{15.138e}
$$

该关系式可进一步简化由千 $\alpha _ { 1 } = - ( \alpha _ { 1 } \mathrm { + } \alpha _ { 2 } )$ 和 $\alpha _ { 0 } = \alpha _ { 1 } \alpha _ { 2 }$ （参见第 56 页， 1.6.3.1,3. 韦达定理），故

$$
y _ {n} = \sum_ {v = 2} ^ {n} g _ {n - v} \frac {\alpha_ {1} ^ {v - 1} - \alpha_ {2} ^ {v - 1}}{\alpha_ {1} - \alpha_ {2}} - y _ {0} a _ {0} \frac {\alpha_ {1} ^ {n - 1} - \alpha_ {2} ^ {n - 1}}{\alpha_ {1} - \alpha_ {2}} + y _ {1} \frac {\alpha_ {1} ^ {n} - \alpha_ {2} ^ {n}}{\alpha_ {1} - \alpha_ {2}}.\tag{15.138f}
$$

类似地当 $\alpha _ { 1 } = \alpha _ { 2 }$ 时有

$$
y _ {n} = \sum_ {v = 2} ^ {n} g _ {n - v} (v - 1) \alpha_ {1} ^ {v - 2} - y _ {0} a _ {0} (n - 1) \alpha_ {1} ^ {n - 2} + y _ {1} n \alpha_ {1} ^ {n - 1}.\tag{15.138g}
$$

在二阶差分方程的情况下，可以不进行部分分式分解，而使用一些对应关系，比如

$$
\mathcal {Z} ^ {- 1} \left\{\frac {z}{z ^ {2} - 2 a z \cosh b + a ^ {2}} \right\} = a ^ {n - 1} \frac {\sinh b n}{\sinh n},\tag{15.139}
$$

以及第二移位定理求变换 $Y ( z )$ 的逆变换．通过替换 $a _ { 1 } = - 2 a \cosh b$ 和 $a _ { 0 } = a ^ { 2 }$ (15.137) 的原序列成为

$$
y _ {n} = \frac {1}{\sinh b} \left[ \sum_ {v = 2} ^ {n} g _ {n - v} a ^ {v - 2} \sinh (v - 1) b - y _ {0} a ^ {n} \sinh (n - 1) b + y _ {1} a ^ {n - 1} \sinh n b \right].\tag{15.140}
$$

在数值计算中，尤其是当 $a _ { 0 }$ 和 $a _ { 1 }$ 是复数时，该公式非常有用．

注意对复变量也可以定义双曲线函数．

15.4.2.3 二阶差分方程（边值问题）

在应用中，经常出现只需对有限指数 $0 \leqslant n \leqslant N$ ，求差分方程的值 $y _ { n }$ 九．在二阶差分方程 (15.135) 的情况下，边值 $y _ { 0 }$ 和 $y _ { N }$ 通常是已知的．为求解边值问题，可从对应初值问题的解 (15.138£) 出发，其中利用 $y _ { N }$ 而不是未知的 $y _ { 1 }$ • 在（ 15.138£)中进行替换 $n = N$ 可得到 $y _ { 1 }$ , 它依赖千 $y _ { 0 }$ 和 $y _ { N }$ :

$$
y _ {1} = \frac {1}{\alpha_ {1} ^ {N} - \alpha_ {2} ^ {N}} \left[ y _ {0} a _ {0} (\alpha_ {1} ^ {N - 1} - \alpha_ {2} ^ {N - 1}) + y _ {N} (\alpha_ {1} - \alpha_ {2}) - \sum_ {v = 2} ^ {N} (\alpha_ {1} ^ {v - 1} - \alpha_ {2} ^ {v - 1}) g _ {N - v} \right].\tag{15.141}
$$

把该值替换到 (15.138£) 中，可得

$$
\begin{array}{l} y _ {n} = \frac {1}{\alpha_ {1} - \alpha_ {2}} \sum_ {v = 2} ^ {n} (\alpha_ {1} ^ {v - 1} - \alpha_ {2} ^ {v - 1}) g _ {n - v} - \frac {1}{\alpha_ {1} - \alpha_ {2}} \frac {\alpha_ {1} ^ {n} - \alpha_ {2} ^ {n}}{\alpha_ {1} ^ {N} - \alpha_ {2} ^ {N}} \sum_ {v = 2} ^ {N} (\alpha_ {1} ^ {v - 1} - \alpha_ {2} ^ {v - 1}) g _ {N - v} \\ + \frac {1}{\alpha_ {1} ^ {N} - \alpha_ {2} ^ {N}} \left[ y _ {0} (\alpha_ {1} ^ {N} \alpha_ {2} ^ {n} - \alpha_ {1} ^ {n} \alpha_ {2} ^ {N}) + y _ {N} (\alpha_ {1} ^ {n} - \alpha_ {2} ^ {n}) \right]. \end{array} \tag {15.142}
$$

只有当 $\alpha _ { 1 } ^ { N } - \alpha _ { 2 } ^ { N } \neq 0$ 时，解 (15.142) 才有意义．否则边值问题没有一般解，但与微分方程的边值问题类似，会出现特征值和特征向量．
