#### 18.2.2 特殊非线性优化问题

18.2.2.1 凸优化

1. 凸问题

如果函数 $g _ { i }$ 是 $\mu$ 函数，那么优化问题

$$
f (\underline {{{{\boldsymbol {x}}}}}) = \max!, \quad \text {其中} \underline {{{{\boldsymbol {x}}}}} \text {满足} g _ {i} (\underline {{{{\boldsymbol {x}}}}}) \leqslant 0 (i = 1, \dots , m)\tag{18.43}
$$

称作凸问题特别地 $g _ { i }$ 可以是线性函数对千凸问题，下列论断成立：

a) 上的局部极小也是全局极小．

b) 如果 非空且有界，则 (18.43) 至少有一个解

c) 如果 是严格凸的，则 (18.43) 至多有一个解．

．最优性条件

a) 如果 有连续偏导数， ${ \underline { { \pmb { x } } } } ^ { * } \in M$ ，并且满足

$$
(\underline {{\boldsymbol {x}}} - \underline {{\boldsymbol {x}}} ^ {*}) ^ {\mathrm{T}} \nabla f (\underline {{\boldsymbol {x}}} ^ {*}) \geqslant 0, \quad \forall \underline {{\boldsymbol {x}}} \in M,\tag{18.44}
$$

那么 $\underline { { \boldsymbol { x } } } ^ { * }$ 是 (18.43) 的解，

b) 斯莱特(Slater)条件是可行集 的正则性条件．如果存在 $\underline { { \boldsymbol { x } } } \in M$ 使得对千每个非放射线性函数 $g _ { i }$ 有 $g _ { i } ( \underline { { { \pmb x } } } ) < 0$ , 则斯莱特条件满足．

c) 如果斯莱特条件满足， $\underline { { \boldsymbol { x } } } ^ { * }$ 是 (18.43) 的极小点当且仅当存 $\underline { { \boldsymbol { u } } } ^ { * } \geqslant \underline { { \mathbf { 0 } } }$ 使得 $( \underline { { \boldsymbol { x } } } ^ { * } , \underline { { \boldsymbol { u } } } ^ { * } )$ ）是拉格朗日函数的鞍点．此外，如果函数 $f$ 和 $g _ { i }$ 可微， $\underline { { \boldsymbol { x } } } ^ { * }$ 是 (18.43)的解当且仅当存在 $\underline { { \boldsymbol { x } } } ^ { * }$ 满足局部库恩—塔克条件

d) 在凸规划问题中函数 $f$ 和 $g _ { i }$ 可微的情形下，对偶问题 (18.42a, 18.42b)以很容易表述为

$$
L (\underline {{\boldsymbol {x}}}, \underline {{\boldsymbol {u}}}) = \max!, \quad (\underline {{\boldsymbol {x}}}, \underline {{\boldsymbol {u}}}) \in M ^ {*},\tag{18.45a}
$$

$$
M ^ {*} = \left\{\left(\underline {{x}}, \underline {{u}}\right) \in \mathbb {R} ^ {n} \times \mathbb {R} _ {+} ^ {m}: \nabla_ {\underline {{x}}} L (\underline {{x}}, \underline {{u}}) = \underline {{0}} \right\}.\tag{18.45b}
$$

这里 的梯度只相对千竺进行计算．

e) 对千凸规划问题，还成立如下的强对偶性定理：

如果 满足斯莱特条件，并且 ${ \underline { { \boldsymbol { x } } } } ^ { * } \in M$ (18.43) 的解，那么存 $\underline { { \boldsymbol { u } } } ^ { * } \in \mathbb { R } _ { + } ^ { m }$ 使得 $( \underline { { \boldsymbol { x } } } ^ { * } , \underline { { \boldsymbol { u } } } ^ { * } )$ 是 (18.45a, 18.45b) 的解．并且

$$
f (\underline {{\boldsymbol {x}}} ^ {*}) = \min _ {\underline {{\boldsymbol {x}}} \in M} f (\underline {{\boldsymbol {x}}}) = \max _ {(\underline {{\boldsymbol {x}}}, \underline {{\boldsymbol {u}}}) \in M ^ {*}} L (\underline {{\boldsymbol {x}}}, \underline {{\boldsymbol {u}}}) = L (\underline {{\boldsymbol {x}}} ^ {*}, \underline {{\boldsymbol {u}}} ^ {*}).\tag{18.46}
$$

18.2.2.2 二次优化

1. 问题的提法

二次优化问题的形式如下：

$$
f (\underline {{\boldsymbol {x}}}) = \underline {{\boldsymbol {x}}} ^ {\mathrm{T}} \boldsymbol {C} \underline {{\boldsymbol {x}}} + \underline {{\boldsymbol {p}}} ^ {\mathrm{T}} \underline {{\boldsymbol {x}}} = \min!, \quad \underline {{\boldsymbol {x}}} \in M \subset \mathbb {R} ^ {n},\tag{18.47a}
$$

$$
M = M _ {\mathrm{I}}: M = \{\underline {{{\boldsymbol {x}}}} \in \mathbb {R} ^ {n}: A \underline {{{\boldsymbol {x}}}} \leqslant \underline {{{\boldsymbol {b}}}}, \underline {{{\boldsymbol {x}}}} \geqslant \underline {{{\boldsymbol {0}}}} \}.\tag{18.47b}
$$

这里 是对称 (n,n) 矩阵！ $\underline { { \boldsymbol { p } } } \in \mathbb { R } ^ { n }$ (m,n) 矩阵，而 $\underline { { b } } \in \mathbb { R } ^ { m }$ ．可行集可以写成下列形式

$$
M = M _ {\mathrm{II}}: M = \{\underline {{\boldsymbol {x}}} \in \mathbb {R} ^ {n}: A \underline {{\boldsymbol {x}}} = \underline {{\boldsymbol {b}}}, \underline {{\boldsymbol {x}}} \geqslant \underline {{\boldsymbol {0}}} \},\tag{18.48a}
$$

$$
M = M _ {\mathrm{III}}: M = \{\underline {{{\boldsymbol {x}}}} \in \mathbb {R} ^ {n}: \boldsymbol {A} \underline {{{\boldsymbol {x}}}} \leqslant \underline {{{\boldsymbol {b}}}} \}.\tag{18.48b}
$$

2. 拉格朗日函数和库恩—塔克条件

问题 (18.47a,18.47b) 的拉格朗日函数是

$$
L (\underline {{{\boldsymbol {x}}}}, \underline {{{\boldsymbol {u}}}}) = \underline {{{\boldsymbol {x}}}} ^ {\mathrm{T}} \boldsymbol {C} \underline {{{\boldsymbol {x}}}} + \underline {{{\boldsymbol {p}}}} ^ {\mathrm{T}} \underline {{{\boldsymbol {x}}}} + \underline {{{\boldsymbol {u}}}} ^ {\mathrm{T}} (\boldsymbol {A} \underline {{{\boldsymbol {x}}}} - \underline {{{\boldsymbol {b}}}}).\tag{18.49}

$$

3. 凸性

函数 （竺）是（严格）凸的，当且仅当矩阵 是半正定（正定）的．有关凸优化问题的每个结果都可用千带半正定矩阵 的二次问题；特别地，斯莱特条件总是成立的，从而点 $\underline { { \boldsymbol { x } } } ^ { * }$ 为最优点的必要且充分条件是，存在点（ $( \underline { { \boldsymbol { x } } } ^ { * } , \underline { { \boldsymbol { y } } } , \underline { { \boldsymbol { u } } } , \underline { { \boldsymbol { v } } } )$ 满足相应的局部库恩—塔克条件组

4. 对偶问题

如果 是正定的，那么 (18.47a,18.47b) 的对偶问题 (18.45a,18.45b) 可以表达为

$$
L (\underline {{\boldsymbol {x}}}, \underline {{\boldsymbol {u}}}) = \max!, \quad (\underline {{\boldsymbol {x}}}, \underline {{\boldsymbol {u}}}) \in M ^ {*},\tag{18.52a}
$$

其中

$$
M ^ {*} = \left\{(\underline {{\boldsymbol {x}}}, \underline {{\boldsymbol {u}}}) \in \mathbb {R} ^ {n} \times \mathbb {R} _ {+} ^ {m}: \underline {{\boldsymbol {x}}} = - \frac {1}{2} C ^ {- 1} (\boldsymbol {A} ^ {\mathrm{T}} \underline {{\boldsymbol {u}}} + \underline {{\boldsymbol {p}}}) \right\}.\tag{18.52b}
$$

如果表达式 $\underline { { { \pmb x } } } = - \frac 1 2 C ^ { - 1 } ( A ^ { \mathrm { T } } \underline { { { \pmb u } } } + \underline { { { \pmb p } } } )$ 代入对偶目标函数 $L ( { \underline { { \mathbf { x } } } } , { \underline { { \mathbf { u } } } } )$ , 千是得到等价的问题

$$
\varphi (\underline {{\boldsymbol {u}}}) = - \frac {1}{4} \underline {{\boldsymbol {u}}} ^ {\mathrm{T}} \boldsymbol {A} \boldsymbol {C} ^ {- 1} \boldsymbol {A} ^ {\mathrm{T}} \underline {{\boldsymbol {u}}} - \left(\frac {1}{2} \boldsymbol {A} \boldsymbol {C} ^ {- 1} \underline {{\boldsymbol {p}}} + \underline {{\boldsymbol {b}}}\right) ^ {\mathrm{T}} \underline {{\boldsymbol {u}}} - \frac {1}{4} \underline {{\boldsymbol {p}}} ^ {\mathrm{T}} \boldsymbol {C} ^ {- 1} \underline {{\boldsymbol {p}}} = \max!,\tag{\(\underline{u} \geqslant \underline{0}\).}
$$

(18.53)

因此如果 ${ \underline { { \boldsymbol { x } } } } ^ { * } \in M$ (18.47a, 18.47b) 的解，那么 (18.53) 有解 ${ \underline { { \boldsymbol { u } } } } ^ { * } \geqslant { \underline { { \mathbf { 0 } } } } .$ 并且

$$
f (\underline {{{\boldsymbol {x}}}} ^ {*}) = \varphi (\underline {{{\boldsymbol {u}}}} ^ {*}).\tag{18.54}
$$

问题 (18.53) 可以用如下等价的形式替代：

$$
\psi (\underline {{{{\boldsymbol {u}}}}}) = \underline {{{{\boldsymbol {u}}}}} ^ {\mathrm{T}} \boldsymbol {E} \underline {{{{\boldsymbol {u}}}}} + \underline {{{{\boldsymbol {h}}}}} ^ {\mathrm{T}} \underline {{{{\boldsymbol {u}}}}} = \min!, \quad \text {约束为} \underline {{{{\boldsymbol {u}}}}} \geqslant \underline {{{{\boldsymbol {0}}}}},\tag{18.55a}
$$

这里

$$
\boldsymbol {E} = \frac {1}{4} \boldsymbol {A} \boldsymbol {C} ^ {- 1} \boldsymbol {A} ^ {\mathrm{T}}, \quad \underline {{\boldsymbol {h}}} = \frac {1}{2} \boldsymbol {A} \boldsymbol {C} ^ {- 1} \underline {{\boldsymbol {p}}} + \underline {{\boldsymbol {b}}}.\tag{18.55b}
$$
