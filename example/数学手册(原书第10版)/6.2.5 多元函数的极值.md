#### 6.2.5 多元函数的极值

6.2.5.1 相对极值的定义

函数 $u = f \left( x _ { 1 } , x _ { 2 } , \cdot \cdot \cdot , x _ { i } , \cdot \cdot \cdot , x _ { n } \right)$ 吓）称为在点 $P _ { 0 } \left( x _ { 1 0 } , x _ { 2 0 } , \cdot \cdot \cdot , x _ { i 0 } , \cdot \cdot \cdot , x _ { n 0 } \right)$ 具有相对极值，若存在数 $\varepsilon ,$ ，满足对属千函数定义域区域 $x _ { 1 0 } - \varepsilon < x _ { 1 } < x _ { 1 0 } + \varepsilon , x _ { 2 0 } -$ $\varepsilon < x _ { 2 } < x _ { 2 0 } + \varepsilon , \cdot \cdot \cdot , x _ { n 0 } - \varepsilon < x _ { n } < x _ { n 0 } + \varepsilon$ 内的任意一点 $P \left( x _ { 1 } , x _ { 2 } , \cdots , x _ { n } \right)$ ，有不等式

$$
f (x _ {1}, x _ {2}, \dots , x _ {n}) <   f (x _ {1 0}, x _ {2 0}, \dots , x _ {n 0})\tag{6.68a}
$$

或

$$
f (x _ {1}, x _ {2}, \dots , x _ {n}) > f (x _ {1 0}, x _ {2 0}, \dots , x _ {n 0}).\tag{6.68b}
$$

利用多维空间的术语（参见第 153 2.18.1)，若函数在一点比它邻域内的任何点都大或都小，则称函数有相对极大值和相对极小值．

6.2.5.3 二元可微函数极值的确定

若已知 $u = f \left( x , y \right)$ ，可解方程组 $f _ { x } = 0 , \ f _ { y } = 0$ , 得点对 $\left( x _ { 1 } , y _ { 1 } \right) , \left( x _ { 2 } , y _ { 2 } \right) , \cdot \cdot \cdot$ 再将其代入二阶导数

$$
A = \frac {\partial^ {2} f}{\partial x ^ {2}}, \quad B = \frac {\partial^ {2} f}{\partial x \partial y}, \quad C = \frac {\partial^ {2} f}{\partial y ^ {2}}.\tag{6.69}
$$

利用表达式

$$
\Delta = \left| \begin{array}{l l} A & B \\ B & C \end{array} \right| = A C - B ^ {2} = [ f _ {x x} f _ {y y} - (f _ {x y}) ^ {2} ] _ {x = x _ {i}, y = y _ {i}} \quad (i = 1, 2, \dots)\tag{6.70}
$$

可以判断是否存在极值以及极值类型：

(1) $\varDelta > 0$ 时，函数 $f \left( x , y \right)$ 在点 $( x _ { i } , y _ { i } )$ 有极值，且若 $f _ { x x } < 0 , f \left( x , y \right)$ 有极大值，若 $f _ { x x } > 0 , f \left( x , y \right)$ 有极小值（充分条件）．

(2) $\varDelta < 0$ 时，函数 $f \left( x , y \right)$ 无极值．

(3) $\varDelta = 0$ 时，需要进一步判断函数是否存在极值．

6.2.5.4 元函数极值的确定

若已知 $u = f \left( x _ { 1 } , x _ { 2 } , \cdot \cdot \cdot , x _ { n } \right)$ ），首先可解由 个方程构成的方程组

$$
f _ {x _ {1}} = 0, f _ {x _ {2}} = 0, \dots , f _ {x _ {n}} = 0,\tag{6.71}
$$

得 $( x _ { 1 0 } , x _ { 2 0 } , \cdot \cdot \cdot , x _ { n 0 } )$ ，这是由千 (6.71) 是函数有极值的必要非充分条件．接下来建立一个由二阶偏导数构成的矩阵，满足 $a _ { i j } = { \frac { \partial ^ { 2 } f } { \partial x _ { i } \partial x _ { j } } }$ ．然后将方程组 (6.71) 的解代入到 $a _ { i j }$ 中，得到顺序主子式（左上角的子式 $\vec { \mathfrak { x } } \binom { } { } ( a _ { 1 1 } , a _ { 1 1 } a _ { 2 2 } - a _ { 1 2 } a _ { 2 1 } , \cdot \cdot \cdot )$ ，则存在如下情况：

(1) 若子式符号依次为— $- , + , - , + , \cdots$ ，则函数存在极大值

(2) 若子式符号依次为＋， $+ , + , + , + , \cdots$ ．，则函数存在极小值．

(3) 若其中一些子式为 ，但非零子式的符号与上述两种情况相应位置的符号一致，则需要进一步判断函数是否有极值：通常要检验 $( x _ { 1 0 } , x _ { 2 0 } , \cdot \cdot \cdot , x _ { n 0 } )$ 某一闭邻域内的函数值

(4) 若子式符号不满足情形 和情形 中的符号规则则函数在该点无极值．

当然，二元函数是 元函数情况的特例（参见 [6.3]).

6.2.5.6 带有约束条件的极值问题

对千满足约束条件

$$
\varphi (x _ {1}, x _ {2}, \dots , x _ {n}) = 0, \psi (x _ {1}, x _ {2}, \dots , x _ {n}) = 0, \dots , \chi (x _ {1}, x _ {2}, \dots , x _ {n}) = 0\tag{6.72a}
$$

元函数 $u = f \left( x _ { 1 } , x _ { 2 } , \cdot \cdot \cdot , x _ { n } \right)$ ，吓），巾千上述条件，变量不是相互独立的，若有个条件，显然必有 $k < n$ 为了确定 的极值，可能需要用条件方程组中的其他变量表示其中的 个变量，并将其代入原函数，由此可转化为含 $n - k$ 个变量的无条件极值问题．另一种方法是拉格朗日乘数法．引入 个未定乘数入， $\lambda , \mu , \cdots , \kappa ,$ ，得到含有 $n + k$ 个变量 $x _ { 1 } , x _ { 2 } , \cdot \cdot \cdot , x _ { n } , \lambda , \mu , \cdot \cdot \cdot , \kappa$ ·，尺的拉格朗日函数

$$
\begin{array}{l} \Phi (x _ {1}, x _ {2}, \dots , x _ {n}, \lambda , \mu , \dots , \kappa) \\ = f (x _ {1}, x _ {2}, \dots , x _ {n}) + \lambda \varphi (x _ {1}, x _ {2}, \dots , x _ {n}) + \mu \psi (x _ {1}, x _ {2}, \dots , x _ {n}) + \dots \\ \quad + \kappa \chi (x _ {1}, x _ {2}, \dots , x _ {n}). \end{array}\tag{6.72b}
$$

函数 $\phi$ 有极值的必要条件是关千变量 $x _ { 1 } , x _ { 2 } , \cdot \cdot \cdot , x _ { n } , \lambda , \mu , \cdot \cdot \cdot , \kappa$ 的 $n + k$ 个方程构成的方程组 (6.71) 满足

$$
\varphi = 0, \psi = 0, \dots , \chi = 0, \varPhi_ {x _ {1}} = 0, \varPhi_ {x _ {2}} = 0, \dots , \varPhi_ {x _ {n}} = 0.\tag{6.72c}
$$

由千满足约束条件 (6.72a) 的函数 在点 $P _ { 0 } \left( x _ { 1 0 } , x _ { 2 0 } , \cdot \cdot \cdot , x _ { n 0 } \right)$ 取得极值的必要条件是 $x _ { 1 0 } , x _ { 2 0 } , \cdots , x _ { n 0 }$ 满足方程 (6.72c)，因此可以在方程组 (6.72c) 的解 $x _ { 1 0 } ,$ $x _ { 2 0 } , \cdots , x _ { n 0 }$ 中寻找 $f$ 的极值点．为了判断在满足该必要条件的点中是否真有极值点还需要进一步的验证，其通用的方法相当复杂一般我们要据函数 $f$ 的特点采用一些恰当的、独特的计算方法来证明是否存在极值，比如往往利用近似计算，即对 $P _ { 0 }$ 邻域内的函数值进行对比

·满足约束条件 $\varphi \left( x , y \right) = 0$ 的函数 $u = f \left( x , y \right)$ 的极值可以通过以下含有三个未知量的三个方程来确定：

$$
\varphi (x, y) = 0, \quad \frac {\partial}{\partial x} [ f (x, y) + \lambda \varphi (x, y) ] = 0, \quad \frac {\partial}{\partial y} [ f (x, y) + \lambda \varphi (x, y) ] = 0.\tag{6.73}
$$

既然 (6.73) 中的三个方程仅为函数存在极值的必要非充分条件，因此还需要进一步判断函数在这个方程组的解处是否取得极值，其数学检验准则相当复杂（参见 [6.3],[6.12]）；通常要比较函数在这些点的闭邻域内的取值．
