#### 5.4.3 同余和剩余类

1. 同余

是正整数， $m > 1$ ．如果当除以 时两个整数 有相同的余数，那称为模 同余，并记作 $a \equiv b { \mathrm { ~ m o d } } m$ 或 $a \equiv b ( m )$

■ 3 = 13 mod5,38 = 13 mod5,3 = -2 mod 5.

显然， $a \equiv b { \bmod { m } }$ 成立，当且仅当 是差 $a - b$ 的因子模 同余是整数集合间的等价关系（参见第 447 5.2.4, 1.）．注意下列性质

$$
a \equiv a \bmod m, \quad \text {对每个} a \in \mathbb {Z},\tag{5.244a}
$$

$$
a \equiv b \bmod {m} \Rightarrow b \equiv a \bmod {m},\tag{5.244b}
$$

$$
a \equiv b \bmod m \land b \equiv c \bmod m \Rightarrow a \equiv c \bmod m.\tag{5.244c}
$$

2. 计算法则

$$
a \equiv b \bmod m \land c \equiv d \bmod m \Rightarrow a + c \equiv b + d \bmod m,\tag{5.245a}
$$

$$
a \equiv b \bmod {m} \land c \equiv d \bmod {m} \Rightarrow a \cdot c \equiv b \cdot d \bmod {m},\tag{5.245b}
$$

$$
a \cdot c \equiv b \cdot c \bmod m \land \operatorname * {g c d} (c, m) = 1 \Rightarrow a \equiv b \bmod m,\tag{5.245c}
$$

$$
a \cdot c \equiv b \cdot c \bmod m \land c \neq 0 \Rightarrow a \equiv b \bmod \frac {m}{\operatorname* {g c d} (c , m)}.\tag{5.245d}
$$

3. 剩余类、剩余类环

因为模 同余是 $\mathbb { Z }$ 中的等价关系，所以这个关系导致将 分拆为模 剩余类：

$$
[ a ] _ {m} = \{x \mid x \in \mathbb {Z} \land x \equiv a \bmod m \}.\tag{5.246}
$$

剩余类 $^ { 6 6 } a$ 模 $m ^ { \prime \prime }$ 由所有用 除时有相等的余数的整数组成．千是当且仅当 $a =$ bmodm $[ a ] _ { m } = [ b ] _ { m }$

$$
[ 0 ] _ {m}, [ 1 ] _ {m}, \dots , [ m - 1 ] _ {m}.\tag{5.247}
$$

在模 $m$ 剩余类的集合 $\mathbb { Z } _ { m }$ 中，剩余类加法和剩余类乘法定义为

$$
[ a ] _ {m} \oplus [ b ] _ {m} = [ a + b ] _ {m},\tag{5.248}
$$

$$
[ a ] _ {m} \otimes [ b ] _ {m} = [ a \cdot b ] _ {m}.\tag{5.249}
$$

这些剩余类运算与代表元的选取无关，即 $[ a ] _ { m } = [ a ^ { \prime } ] _ { m }$ 和 $[ b ] _ { m } = [ b ^ { \prime } ] _ { m }$ 蕴涵

$$
[ a ] _ {m} \oplus [ b ] _ {m} = [ a ^ {\prime} ] _ {m} \oplus [ b ^ {\prime} ] _ {m} \quad \text {及} \quad [ a ] _ {m} \otimes [ b ] _ {m} = [ a ^ {\prime} ] _ {m} \otimes [ b ^ {\prime} ] _ {m}.\tag{5.250}
$$

剩余类关千剩余类加法和剩余类乘法形成一个有单位元的环（参见第 5045.4.3, 1.），即模 剩余类环．如果 $p$ 是一个素数，那么模 $p$ 剩余类环是一个域（参见第 484 5.3.7.1, 2.).

4. 互素的剩余类

满足 $\operatorname* { g c d } ( a , m ) = 1$ 的剩余类称为与 互素的剩余类．如果 $p$ 是素数，那么所 有不等千 $[ 0 ] _ { p }$ 的剩余类与 $p$ 互素．

互素的剩余类对千剩余类乘法形成一个阿贝尔群（参见第 451 5.3.3.1,1.），称作与 互素的剩余类群．这个群的阶是 $\varphi ( m )$ ，这里 $\varphi$ 是欧拉函数（参见第509 5.4.4, 1.).

■ B: $[ 1 ] _ { 5 } , [ 2 ] _ { 5 } , [ 3 ] _ { 5 } , [ 4 ] _ { 5 }$ 是与 互素的剩余类．

5. 本原剩余类

一个与 互素的剩余类 $[ a ] _ { m }$ 称作本原剩余类，如果它在与 互素的剩余类群中有阶 $\varphi ( m )$

■ A: $[ 2 ] _ { 5 }$ 是模 本原剩余类，因为 $( [ 2 ] _ { 5 } ) ^ { 2 } = [ 4 ] _ { 5 } , ( [ 2 ] _ { 5 } ) ^ { 3 } = [ 3 ] _ { 5 } , ( [ 2 ] _ { 5 } ) ^ { 4 } = [ 1 ] _ { 5 }$

■ B: 因为在与 互素的剩余类群中 $[ 1 ] _ { 8 }$ 有阶 1, 并且 $[ 3 ] _ { 8 } , [ 5 ] _ { 8 } , [ 7 ] _ { 8 }$ 有阶 ，所以存在模 非本原剩余类．

如果存在模 本原剩余类，那么与 互素的剩余类群形成循环群．

$$
