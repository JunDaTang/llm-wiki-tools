#### 20.2.8 函数运算

函数对千数和表达式做运算． Mathematica 也可以对函数进行运算，因为函数的名称是作为表达式来处理的，所以它们也可以当作表达式来处理．

(1) 反函数、级数反演 确定一个已知函数 的反函数可以通过函数运算InverseFunction InverseSeries 来进行

(2) 微分 Mathematica 依据的是函数的微分可以看成函数空间中的一个映射Mathematica 中，微分算子是 $\mathtt { D e r i v a t i v e } [ 1 ] [ f ]$ 或简记为 $\mathbf { f ^ { \prime } }$ ．如果定义了函数，则其导数可以由 f'得到

· $ I n [ 1 ] : = \mathbf { f } [ x _ { - } ] : = { \mathsf { S i n } } [ x ] { \mathsf { C o s } } [ x ]$ 由

$$
I n [ 2 ] := \mathbf {f} ^ {\prime} \quad \text {得} \quad O u t [ 2 ] = \mathrm{Cos} [ \# 1 ] ^ {2} - \mathrm{Sin} [ \# 1 ] ^ {2} \&
$$

因此 $\mathtt { f ^ { \prime } }$ 被表示成一个纯函数，千是

$$
I n [ 3 ] := \% [ x ] \longrightarrow O u t [ 3 ] = \cos [ x ] ^ {2} - \sin [ x ] ^ {2}
$$

(3) Nest 命令 $\mathtt { N e s t } [ f , \ x , \ n ]$ 的意思是函数 作用千 后被嵌套进自身次结果是 $\mathbf { f } \left[ \mathbf { f } \left[ \cdot \cdot \cdot \ \mathbf { f } \left[ x \right] \cdot \cdot \cdot \ \right] \right]$

(4) N estList 应用 $\mathtt { N e s t L i s t } [ f , \ x , \ n ]$ 将显示列表 $\{ x , \ \mathbf { f } [ x ] , \ \mathbf { f } [ \mathbf { f } [ x ] ] , \ \cdots \}$ }，最终的 被嵌套 次． $\mathtt { F o l d L i s t } [ f , \ x , \ l i s t ]$ 则是对两个变元的函数做迭代．

(5) FixedPoint 对千 $\mathtt { F i x e d P o i n t } [ f , x ]$ 而言是指重复应用该函数直到结果不再改变

(6) FixedPointList 函数运算 FixedPointList [f, x] 显示的是应用 后结果的连续列表，直到这个值不再改变

·作为这种类型的函数运算的一个例子，我们将使用 NestList 运算根据牛顿法（参见第 1234 19.1.1.2) 对方程 $\boldsymbol { f } ^ { \mathrm { ~ } } \left( \boldsymbol { x } \right) = 0$ 的根作逼近．在 $3 \pi / 2$ 的邻域中求方程$x \mathrm { c o s } x = \mathrm { s i n } x$ 的一个根：

$$
\begin{array}{r l} & I n [ 1 ] := \mathbf {f} [ x _ {-} ] := x - \operatorname{Tan} [ x ] \\ & I n [ 2 ] := \mathbf {f} ^ {\prime} [ x ] \longrightarrow O u t [ 2 ] = 1 - \operatorname{Sec} [ x ] ^ {2} \\ & I n [ 3 ] = \mathbf {g} [ x _ {-} ] := x - \mathbf {f} [ x ] / \mathbf {f} ^ {\prime} [ x ] \\ & I n [ 4 ] := \operatorname{NestList} [ g, 4. 6, 4 ] \longrightarrow O u t [ 4 ] \end{array}
$$

$$
= \{4. 6, 4. 5 4 5 7 3, 4. 5 0 6 1 5, 4. 4 9 4 1 7, 4. 4 9 3 4 1 \}
$$

$$
I n [ 5 ] := \text { FixedPoint } [ g, 4. 6 ] \longrightarrow O u t [ 5 ] = 4. 4 9 3 4 1
$$

该结果还可以达到更高的精度．

(7) Apply 是一个函数，它与列表 $\{ a , b , c , \cdots \}$ }有关．则

$$
\mathsf {A p p l y} [ f, \{a, b, c, \dots \} ] \longrightarrow f [ a, b, c, \dots ]\tag{20.22}
$$

$$
I n [ 1 ] := \text {Apply} [ \text {Plus}, \{u, v, w \} ] \longrightarrow O u t [ 1 ] = u + v + w
$$

$$
I n [ 2 ] := \text { Apply } [ \text { List }, a + b + c ] \longrightarrow O u t [ 2 ] = \{a, b, c \}
$$

在此我们可以容易地看出 Mathematica 如何处理表达式的表达式之一般流程．最后运算的完整形式是

$$
I n [ 3 ] := \text { FullForm } [ \text { Apply } [ \text { List }, \text { Plus } [ a, b, c ] ] ] \longrightarrow O u t [ 3 ] = \text { List } [ a, b, c ]
$$

显然，函数运算 Apply 以所求的 List 来代替所考虑的表达式 Plus 的头

(8) Map 对千一个有定义的函数 $f ,$ 运算 Map 给出

$$
\operatorname{Map} [ f, \{a, b, c, \dots \} ] \longrightarrow \{f [ a ], f [ b ], f [ c ], \dots \}\tag{20.23}
$$

Map 生成一个列表，其元素是当把 应用千原来列表时的值．

·设 是函数 $f \ ( x ) = x ^ { 2 }$ 它被定义为

$I n [ 1 ] : = \mathbf { f } [ x \_ ] : = \ x ^ { 2 }$ 对千这个 我们得到

$$
I n [ 2 ] := \operatorname{Map} [ f, \{u, v, w \} ] \longrightarrow O u t [ 2 ] = \left\{u ^ {2}, v ^ {2}, w ^ {2} \right\}
$$

Map 可以被应用千更一般的表达式：

$$
I n [ 3 ] := \operatorname{Map} [ f, \text {Plus} [ a, b, c ] ] \longrightarrow O u t [ 3 ] = a ^ {2} + b ^ {2} + c ^ {2}
$$
