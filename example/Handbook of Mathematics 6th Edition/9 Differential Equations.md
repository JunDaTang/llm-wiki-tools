## 9 Differential Equations

1. A Diferential Equation is an equation, in which one or more variables, one or more functions of these variables, and also the derivatives of these functions with respect to these variables occur. The order of a diferential equation is equal to the order of the highest occurring derivative.

2. Ordinary and Partial Diferential Equations difer from each other in the number of their independent variables; in the first case there is only one, in the second case there are several.

$$
\textbf { A : } \left( \frac { d y } { d x } \right) ^ { 2 } - x y ^ { 5 } \frac { d y } { d x } + \sin y = 0 . \quad \textbf { B : } x d ^ { 2 } y d x - d y ( d x ) ^ { 2 } = e ^ { y } ( d y ) ^ { 3 } . \quad \textbf { U C : } \frac { \partial ^ { 2 } z } { \partial x \partial y } = x y z \frac { \partial z } { \partial x } \frac { \partial z } { \partial y } .
$$
