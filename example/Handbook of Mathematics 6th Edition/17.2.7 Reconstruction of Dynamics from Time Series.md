#### 17.2.7 Reconstruction of Dynamics from Time Series

##### 17.2.7.1 Foundations, Reconstruction with Basic Properties

1. Measuring Function, Time Series

Considered is a dynamic system $\{ \varphi ^ { t } \} _ { t \in T }$ with $T \in \{ \mathbb { Z } _ { + } , \mathbb { R } _ { + } \}$ , generated by a mapping $\varphi \in \mathrm { D i f f } _ { + } ^ { 1 } ( U )$

(see 17.1.4.2, p. 874) or a vector field $f \in \mathbf { X } _ { + } ^ { 1 } ( U )$ (see 17.1.4.1. p. 873). A C<sup>1</sup>-function $h \colon U \to \mathbb { R }$ the so called measuring function is needed to reconstruct the dynamics from measurements. Since in practice only discrete time measurements can be obtained, this will be done in time periods $\{ k \tau , k =$ $\mathrm { i } , 2 , \ldots \} \subset T$ , where $\tau > 0$ is a fixed interval of time. For $m \in \mathbb { N }$ and $\kappa \in \{ - 1 , 1 \}$ the time sequence of order m measured with fixed time step $\tau > 0$

$$
\left\{ \left( h \left( \varphi ^ { \kappa \tau } ( p ) \right) , h \left( \varphi ^ { ( k + \kappa ) \tau } ( p ) \right) , \ldots , h \left( \varphi ^ { ( k + ( m - 1 ) \kappa ) \tau } ( p ) \right) \right) \right\} _ { k = m - 1 } ^ { \infty }\tag{17.61}
$$

is called the backward $( \kappa = - 1 )$ or forward $( \kappa = 1 )$ coordinates of the orbit $\{ \varphi ^ { t } ( p ) \} _ { t \in T }$ with $p \in U$ based on the measuring function h.

2. Immersion, Embedding, Theorem of Whitney

Let $U \subset \mathbb { R } ^ { n }$ be an open set. The C<sup>1</sup>-mapping Φ : $U \to \mathbb { R } ^ { m }$ is called an immersion if the Jacobian matrix $D \varPhi ( u )$ has rank n for every $u \in U$ . The immersion $\varPhi \colon U  \mathbb { R } ^ { m }$ is called embedding if $\varPhi$ is a homeomorphism of U into $\varPhi ( U ) \left( \bar { \phi } ( U ) \right)$ is considered with the subspace topology of $\mathbb { R } ^ { m } )$

Whitney’s theorem states that with respect to the open and bounded set $U \subset \mathbb { R } ^ { n }$ for every $m \geq 2 n + 1$ the set of all embeddings $\varPhi \colon U  \mathbb { R } ^ { m }$ form an open and dense subset of C<sup>1</sup>-mappings $U \to \mathbb { R } ^ { m }$ . Hence, for $m \geq 2 n + 1$ is $\varPhi$ generically an embedding.

Let the diferential equation ${ \dot { x } } = - x \equiv f ( x )$ be given in an interval $( - 1 - \varepsilon , 1 + \varepsilon ) \left( \varepsilon > 0 \right.$ , for a suficiently small ε). ##### 17.2.7.2 Reconstructions with Prevalent Properties

1. Prevalence as a Generic Metric

Prevalence or generic metric is an extension to infinite dimension of the wellknown concept ”almost everywhere in Lebesgue-measure” (see 12.9.1,2., p. 694) known in finite dimensions, so it difers from the corresponding notions for the sets of the second Baire category. A Borel set S in a Banach space B is prevalent (see [17.13]) if there is a finite Borel measure $\mu$ with support K (see 17.2.1.1,1., p. 876), such that $\mu ( S + x ) { \overset { } { = } } \mu ( S ) = \mu ( K )$ for all $x \in B$

A: Every Borel set of a finite dimensional vector space with measure zero complement is prevalent.

B: The union and intersection of finitely many prevalent sets are also prevalent.

C: Let $C ^ { k } ( { \overline { { U } } } , \mathbb { R } ) , U \subset \mathbb { R } ^ { n }$ be the Banach space of all scalar valued functions from $C ^ { k } ( { \overline { { U } } } , \mathbb { R } )$ whose partial derivatives up to order k are continuous on $\overline { { U } } .$ . If $U \in \mathbb { R } ^ { n }$ is open and connected, then the prevalent subsets of $\mathcal { C } ^ { k } ( U , \mathbb { R } )$ , are dense in this space.
