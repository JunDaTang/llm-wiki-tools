#### 18.3.4 Bellman Optimality Principle

The evaluation of the functional equation

$$
\phi _ { j } ( \underline { { \mathbf { x } } } _ { j - 1 } ) = \operatorname* { m i n } _ { \underline { { \mathbf { u } } } _ { j } \in U _ { j } ( \underline { { \mathbf { x } } } _ { j - 1 } ) } H _ { j } \left( f _ { j } ( \underline { { \mathbf { x } } } _ { j - 1 } , \underline { { \mathbf { u } } } _ { j } ) , \phi _ { j + 1 } ( \underline { { \mathbf { x } } } _ { j } ) \right)\tag{18.139}
$$

corresponds to the determination of an optimal policy $( \underline { { \mathbf { u } } } _ { i } ^ { * } , \dots , \underline { { \mathbf { u } } } _ { n } ^ { * } )$ for which the subprocess $P _ { j }$ starting at state $\underline { { \mathbf { X } } } _ { j - 1 }$ and consisting of the last $n - j + 1$ stages of the total process $P$ minimizes the cost function, $\mathrm { i . e . }$

$$
F _ { j } ( f _ { j } ( \underline { { \mathbf { x } } } _ { j - 1 } , \underline { { \mathbf { u } } } _ { j } ) , \dots , f _ { n } ( \underline { { \mathbf { x } } } _ { n - 1 } , \underline { { \mathbf { u } } } _ { n } ) ) \longrightarrow \mathrm { m i n ! } .\tag{18.140}
$$

The optimal policy of the process $P _ { j }$ with the initial state $\underline { { \mathbf { X } } } _ { j - 1 }$ is independent of the decisions $\underline { { \mathbf { u } } } _ { 1 } , \dots ,$ $\underline { { \mathbf { u } } } _ { j - 1 }$ of the first $j - 1$ stages of $P$ which have driven $P$ to the state $\underline { { \mathbf { X } } } _ { j - 1 }$ . To determine $\phi _ { j } ( \underline { { \mathbf { x } } } _ { j - 1 } )$ the value $\phi _ { j + 1 } ( \underline { { \mathbf { x } } } _ { j } )$ is needed to know. Now, if $( \underline { { \mathbf { u } } } _ { j } ^ { * } , \dots , \underline { { \mathbf { u } } } _ { n } ^ { * } )$ is an optimal policy for $P _ { j }$ , then, obviously, $( \underline { { \mathbf { u } } } _ { j + 1 } ^ { * } , \ldots , \underline { { \mathbf { u } } } _ { n } ^ { * } )$ is an optimal policy for the subprocess $P _ { j + 1 }$ starting at $\underline { { \mathbf { x } } } _ { j } = g _ { j } ( \underline { { \mathbf { x } } } _ { j - 1 } , \underline { { \mathbf { u } } } _ { j } ^ { * } )$ . This statement is generalized in the Bellman optimality principle.

Bellman Principle: $\operatorname { I f } \left( \underline { { \mathbf { u } } } _ { 1 } ^ { * } , \ldots , \underline { { \mathbf { u } } } _ { n } ^ { * } \right)$ is an optimal policy of the process $P$ and $\left( \underline { { \mathbf { x } } } _ { 0 } ^ { * } , \ldots , \underline { { \mathbf { x } } } _ { n } ^ { * } \right)$ is the corresponding sequence of states, then for every subprocess $\bar { P } _ { j } , j = \bar { 1 } ( 1 ) n$ , with initial state $\underline { { \mathbf { X } } } _ { j - 1 } ^ { * }$ the policy $( \underline { { \mathbf { u } } } _ { j } ^ { * } , \dots , \underline { { \mathbf { u } } } _ { n } ^ { * } )$ is also optimal.
