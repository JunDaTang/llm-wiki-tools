##### 16.4.2.1 Gauss Error Propagation Law

1. Problem Formulation

Suppose it is to determine the numerical value and the error of a quantity z given by the function ${ \boldsymbol { z } } = f ( x _ { 1 } , x _ { 2 } , \dots , x _ { k } )$ of the independent variables $x _ { j } ~ ( j = 1 , 2 , \ldots , \bar { k } )$ . The mean value $\overline { { x } } _ { j }$ obtained from $n _ { j }$ measured values is considered as realizations of the random variable $x _ { j }$ , with variance ${ \sigma _ { j } } ^ { 2 }$ . The question is how the errors of the variables afect the function value $f ( x _ { 1 } , x _ { 2 } , \ldots , x _ { k } )$ . It is assumed that the function $f ( x _ { 1 } , x _ { 2 } , \ldots , x _ { k } )$ is diferentiable and its variables are stochastically independent. However they may follow any type of distribution with diferent variances ${ \sigma _ { j } } ^ { 2 }$

2. Taylor Expansion

Since the error represents relatively small changes of the independent variables, the function $f ( x _ { 1 } , x _ { 2 } , \dots ,$ $x _ { k } )$ can be approximated in the neighborhood of the mean $\overline { { x } } _ { j }$ by the linear part of its Taylor expansion with the coeficients $~ a _ { j } ,$ so its error $\Delta f$ is:

$$
\Delta f = f ( x _ { 1 } , x _ { 2 } , \ldots , x _ { k } ) - f ( { \overline { { x } } } _ { 1 } , { \overline { { x } } } _ { 2 } , \ldots , { \overline { { x } } } _ { k } ) ,\tag{16.216a}
$$

$$
\Delta f \approx d f = \frac { \partial f } { \partial x _ { 1 } } d x _ { 1 } + \frac { \partial f } { \partial x _ { 2 } } d x _ { 2 } + \cdot \cdot \cdot + \frac { \partial f } { \partial x _ { k } } d x _ { k } = \sum _ { j = 1 } ^ { k } \frac { \partial f } { \partial x _ { j } } d x _ { j } = \sum _ { j = 1 } ^ { k } a _ { j } d x _ { j } ,\tag{16.216b}
$$

where the partial derivatives $\partial f / \partial x _ { j }$ are taken at $( \overline { { x } } _ { 1 } , \overline { { x } } _ { 2 } , \ldots , \overline { { x } } _ { k } )$ The variance of the function is

$$
\sigma _ { f } { } ^ { 2 } = a _ { 1 } { } ^ { 2 } \sigma _ { x _ { 1 } } { } ^ { 2 } + a _ { 2 } { } ^ { 2 } \sigma _ { x _ { 2 } } { } ^ { 2 } + \cdot \cdot \cdot + a _ { k } { } ^ { 2 } \sigma _ { x _ { k } } { } ^ { 2 } = \sum _ { j = 1 } ^ { k } a _ { j } { } ^ { 2 } \sigma _ { x _ { j } } { } ^ { 2 } .\tag{16.217}
$$

3. Approximation of the Variance $\sigma _ { f } ^ { 2 }$

Since the variances of the independent variables $x _ { j }$ are unknown, they can be approximated by the variance of their mean, which is determined from the measured values $x _ { j l } \left( l = 1 , 2 , \ldots , n _ { l } \right)$ of the single variables as follows:

$$
\tilde { \sigma } _ { \overline { { x } } _ { j } } ^ { 2 } = \frac { \displaystyle \sum _ { l = 1 } ^ { n _ { j } } ( x _ { j l } - \overline { { x } } _ { j } ) ^ { 2 } } { n _ { j } ( n _ { j } - 1 ) } .\tag{16.218}
$$

Using these values one can form an approximation of $\sigma { _ f } ^ { 2 }$

$$
\tilde { \sigma } _ { f } ^ { 2 } = \sum _ { j = 1 } ^ { k } { a _ { j } } ^ { 2 } \tilde { \sigma } _ { \overline { { x } } _ { j } } ^ { 2 } .\tag{16.219}
$$

The formula (16.219) is called the Gauss error propagation law.

4. Special Cases

1. Linear Case An often occurring case is the summation of the values of the errors of linearly occurring error quantities with $a _ { j } = 1$

$$
\tilde { \sigma } _ { f } = \sqrt { \tilde { \sigma } _ { 1 } ^ { 2 } + \tilde { \sigma } _ { 2 } ^ { 2 } + \cdot \cdot \cdot + \tilde { \sigma } _ { k } ^ { 2 } } .\tag{16.220}
$$

The pulse length is to be measured at the output of a pulse amplifier of a detector channel for spectrometry of radiation, whose error can be deduced for three components:

1. statistical energy distribution of the radiation of the part passing through the spectometer with an energy $E _ { 0 }$ , which is characterized by $\tilde { \sigma } _ { \mathrm { S t r } }$

2. statistical interference processes in the detector with $\tilde { \sigma } _ { \mathrm { D e t } }$

3. electronic noice of the amplifier of the detector impulse $\tilde { \sigma } _ { \mathrm { e l } }$

The total pulse length has the error

$$
\tilde { \sigma } _ { f } = \sqrt { \tilde { \sigma } _ { \mathrm { S t r } } ^ { 2 } + \tilde { \sigma } _ { \mathrm { D e t } } ^ { 2 } + \tilde { \sigma } _ { \mathrm { e l } } ^ { 2 } } .\tag{16.221}
$$

2. Power Rule The variables $x _ { j }$ often occur in the following form:

$$
z = f ( x _ { 1 } , x _ { 2 } , \ldots x _ { k } ) = a x _ { 1 } { } ^ { b _ { 1 } } \cdot x _ { 2 } { } ^ { b _ { 2 } } \cdot \ldots x _ { k } { } ^ { b _ { k } } .\tag{16.222}
$$

By logarithmic diferentiation the relative error is

$$
{ \frac { d f } { f } } = b _ { 1 } { \frac { d x _ { 1 } } { x _ { 1 } } } + b _ { 2 } { \frac { d x _ { 2 } } { x _ { 2 } } } + \cdots + b _ { k } { \frac { d x _ { k } } { x _ { k } } } ,\tag{16.223}
$$

from which by the error propagation law follows for the mean relative error:

$$
\frac { \tilde { \sigma } _ { f } } { f } = \sqrt { \sum _ { j = 1 } ^ { k } { \left( b _ { j } \frac { \tilde { \sigma } _ { \overline { { x } } _ { j } } } { \overline { { x } } _ { j } } \right) ^ { 2 } } } .\tag{16.224}
$$

Suppose the function $f ( x _ { 1 } , x _ { 2 } , x _ { 3 } )$ has the form $f ( x _ { 1 } , x _ { 2 } , x _ { 3 } ) = { \sqrt { x _ { 1 } } } { x _ { 2 } } ^ { 2 } { x _ { 3 } } ^ { 3 }$ , and the standard deviations are $\sigma _ { x _ { 1 } } , \sigma _ { x _ { 2 } }$ and $\sigma _ { x _ { 3 } }$ . The relative error is then

$$
\delta z = \frac { \tilde { \sigma } _ { f } } { f } = \sqrt { \left( \frac { 1 } { 2 } \frac { \tilde { \sigma } _ { \overline { { x } } _ { 1 } } } { \overline { { x } } _ { 1 } } \right) ^ { 2 } + \left( 2 \frac { \tilde { \sigma } _ { \overline { { x } } _ { 2 } } } { \overline { { x } } _ { 2 } } \right) ^ { 2 } + \left( 3 \frac { \tilde { \sigma } _ { \overline { { x } } _ { 3 } } } { \overline { { x } } _ { 3 } } \right) ^ { 2 } } .
$$

5. Diference to the Maximum Error

Declaring the absolute or relative maximal error (16.207), (16.208) means that no smoothing for the values of the measurement is been made. For the determination of the relative or absolute error with the error propagation laws (16.219) or (16.222), smoothing between the measurement values $x _ { j }$ means that a confidence interval for a previously given level is to be determined. This procedure is given in 16.4.1.4, p. 853.

##### 16.4.2.2 Error Analysis

The general analysis of error propagation in the calculations of a function $\varphi ( x _ { i } )$ , when quantities of higher order are neglected, is called error analysis. In the framework of the theory of error analysis one investigates using an algorithm, how an input error $\Delta x _ { i }$ afects the value of $\varphi ( x _ { i } )$ . In this context one also talks about diferential error analysis.

In numerical mathematics, error analysis means the investigation of the afect of errors of methods, of rounding, and of input errors to the final result (see [19.24]).
