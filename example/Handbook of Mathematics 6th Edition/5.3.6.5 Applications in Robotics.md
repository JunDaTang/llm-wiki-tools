##### 5.3.6.5 Applications in Robotics

1. Rigid Body Motion

The special Euclidean group $S E ( 3 )$ , which describes the rigid-body motions in $\mathbb { R } ^ { 3 }$ , is the semidirect product of group SO(3) (rotation about the origin) and $\mathbb { R } ^ { 3 }$ (translations):

$$
S E ( 3 ) = S O ( 3 ) \times \mathbb { R } ^ { 3 } .\tag{5.160}
$$

In a direct product the factors have no interaction, but this is a semidirect product since rotations act on translations as it is clear from matrix multiplication:

$$
\left( \begin{array} { c } { \mathbf { R } _ { 2 } \vec { \mathbf { t } } _ { 2 } } \\ { 0 1 } \end{array} \right) \left( \begin{array} { c } { \mathbf { R } _ { 1 } \vec { \mathbf { t } } _ { 1 } } \\ { 0 1 } \end{array} \right) = \left( \begin{array} { c c } { \mathbf { R } _ { 2 } \mathbf { R } _ { 1 } } & { \mathbf { R } _ { 2 } \vec { \mathbf { t } } _ { 1 } + \vec { \mathbf { t } } _ { 2 } } \\ { 0 } & { 1 } \end{array} \right) ,\tag{5.161}
$$

i.e. the first translation vector is rotated before the second translation vector is added.

2. Theorem of Chasles

This theorem tells that every rigid-body motion which is not a pure translation can be described as a (finite) screw motion. A (finite) screwing motion along an axis through the origin has the form

$$
A ( \theta ) = \left( { \bf R } \begin{array} { c } { { \displaystyle { \frac { \theta p } { 2 \pi } } \vec { \bf x } } } \\ { { 0 } } \end{array} \right) ,\tag{5.162a}
$$

where x is a unit vector in the direction of the axis of rotation, $\theta$ is the angle of rotation and $p$ is the angular coeficient. Since x is the axis of rotation $\mathbf { R } \vec { \mathbf { x } } = \vec { \mathbf { x } } , \mathrm { i . e }$ . x is an eigenvector of matrix R belonging to unit eigenvalue 1 .

When the axis of rotation does not go through the origin, then a point u of the axis of rotation is chosen which is shifted into the origin, then after the screwing it is shifted back:

$$
\left( { \bf \frac { I } { 0 } } { \bf \frac { \vec { u } } { 1 } } \right) \left( { \bf R } { \bf \frac { \nabla } { 2 \pi } } { \bf \frac { \theta \rho } { 1 } } { \bf \vec { x } } \right) \left( { \bf \frac { I } { 0 } } - { \bf \vec { u } } \right) = \left( { \bf R } { \bf \frac { \nabla } { 2 \pi } } { \bf \vec { x } } + ( { \bf I } - { \bf R } ) { \bf \vec { u } } \right) .\tag{5.162b}
$$

The theorem of Chasles tells that an arbitrary rigid-body motion can be given in the above form, i.e.

$$
{ \biggl ( } { \mathbf { R } } { \begin{array} { c c } { { \vec { \mathbf { t } } } } \\ { { \boldsymbol { 0 } } } \end{array} } { \biggr . } { \biggr ) } = { \biggl ( } { \mathbf { R } } { \begin{array} { c c } { { \frac { \theta p } { 2 \pi } } { \vec { \mathbf { x } } } + ( { \mathbf { I } } - { \mathbf { R } } ) { \vec { \mathbf { u } } } } \\ { { \boldsymbol { 0 } } } \end{array} } { \biggr ) }\tag{5.163}
$$

for given R , $\vec { \mathbf { t } }$ and appropriate $p$ and u . Assuming that the angle of rotation $\theta$ and the axis of rotation $\vec { \bf x }$ are already known from R

$$
\frac { \theta p } { 2 \pi } = \vec { \bf x } \cdot \vec { \bf t }\tag{5.164}
$$

is valid, so the angular coeficient p can be calculated. Then the solution of a linear system of equations gives u:

$$
( \mathbf { I } - \mathbf { R } ) { \vec { \mathbf { u } } } = { \frac { \theta p } { 2 \pi } } { \vec { \mathbf { x } } } - { \vec { \mathbf { t } } } .\tag{5.165}
$$

This is a singular system of equations, where x is in its kernel. Therefore the solution u is unique except to a manyfold of $\check { \mathbf { x } } .$ . In order to determine u it is reasonable to require that u is perpendicular to $\vec { \bf x } .$ When the rigid body motion is a pure rotation, then it is not possible to determine an appropriate vector u.

3. Mechanical Joints

Joints with one degree of freedom can be represented by a one-parameter subgroup of the group SE(3). For the general case of screw joints the corresponding subgroup is

$$
A ( \theta ) = \left( \begin{array} { c c } { { { \bf R } } } & { { \frac { \theta p } { 2 \pi } \vec { \bf x } + ( { \bf I } - { \bf R } ) \vec { \bf u } } } \\ { { 0 } } & { { 1 } } \end{array} \right) ,\tag{5.166}
$$

where $\vec { \bf x }$ is the axis of rotation, $\theta$ is the angle of rotation, p gives the angular coeficient and u is an arbitrary point on the axis of rotation.

The most often occurring types ofjoints are the rotational joints which can be described by the following subgroup:

$$
A ( \theta ) = \left( { \begin{array} { c c } { \mathbf { R } } & { ( \mathbf { I } - \mathbf { R } ) { \vec { \mathbf { u } } } } \\ { 0 } & { 1 } \end{array} } \right) .\tag{5.167}
$$

The subgroup corresponding the shift joints is

$$
A ( \theta ) = \left( \begin{array} { c c } { { { \bf I } } } & { { \theta \vec { \bf t } } } \\ { { 0 } } & { { 1 } } \end{array} \right) ,\tag{5.168}
$$

where <sup></sup>t describes the direction of the shifting.

4. Forward Kinematics

The goal in the case of industrial robots is the moving and control of the end efectors, which is done by joints in a kinematic chain. If all joints are of one parameter and the robot consists e.g. of 6 joints, then every position of the robot can be described by the joint-variables $\vec { \theta } ^ { \mathrm { T } } = ( \theta _ { 1 } , \theta _ { 2 } , \theta _ { 3 } , \theta _ { 4 } , \theta _ { 5 } , \theta _ { 6 } )$ The output state of the robot is described by the null vector. Then the motions of the robot can be described so that first the farest joint together the end efector are moved and this motion is given by the matrix $A ( \theta _ { 6 } )$ . Then the 5-th joint is moved. Since the axis of this joint should not be influenced by the motion of the last joint, this motion is given by the matrix $A ( \theta _ { 5 } )$ . In this way all the joints are moved, and the complete motion of the end efector is given by

$$
{ \cal K } ( \vec { \theta } ) = A _ { 1 } ( \theta _ { 1 } ) A _ { 2 } ( \theta _ { 2 } ) A _ { 3 } ( \theta _ { 3 } ) A _ { 4 } ( \theta _ { 4 } ) A _ { 5 } ( \theta _ { 5 } ) A _ { 6 } ( \theta _ { 6 } ) .\tag{5.169}
$$

5. Vector Product and Lie Algebra

A screw is given by

$$
A ( \theta ) = \left( \begin{array} { c c } { { { \bf R } } } & { { \frac { \theta p } { 2 \pi } \vec { \bf x } + ( { \bf I } - { \bf R } ) \vec { \bf u } } } \\ { { 0 } } & { { 1 } } \end{array} \right) ;\tag{5.170}
$$

and it represents rigid body motions parameterized by the angle θ. Obviously, $\theta = 0$ gives the identity transformation. If the derivative is calculated at $\theta = 0$ , i.e. the derivative at the identity, then the general element of the Lie algebra is the following:

$$
S = \left. \frac { d A } { d \theta } \right| _ { \theta = 0 } = \left. \left( \begin{array} { c c } { \frac { d { \bf R } } { d \theta } } & { \frac { p } { 2 \pi } \vec { \bf x } - \frac { d { \bf R } } { d \theta } \vec { \bf u } } \\ { 0 } & { 0 } \end{array} \right) \right| _ { \theta = 0 } = \left( \begin{array} { c c } { \Omega } & { \frac { p } { 2 \pi } \vec { \bf x } - \Omega \vec { \bf u } } \\ { 0 } & { 0 } \end{array} \right) ,\tag{5.171a}
$$

where $\Omega = \frac { d \mathbf { R } } { d \theta } ( 0 )$ is a skew symmetric matrix. It can be shown that R is an orthogonal matrix, so ${ \bf R R } ^ { \mathrm { T } } = { \bf I }$ and ${ \bf R } { \bf R } ^ { \mathrm { T } } = { \bf I }$ holds and therefore

$$
{ \frac { d } { d \theta } } ( \mathbf { R } \mathbf { R } ^ { \mathrm { T } } ) = { \frac { d \mathbf { R } } { d \theta } } \mathbf { R } ^ { \mathrm { T } } + \mathbf { R } { \frac { d \mathbf { R } ^ { \mathrm { T } } } { d \theta } } = { \frac { d \mathbf { I } } { d \theta } } = 0 .\tag{5.171b}
$$

Since R = I for $\theta = 0$

$$
\frac { d \mathbf R } { d \theta } ( 0 ) + \frac { d \mathbf R ^ { \mathrm T } } { d \theta } ( 0 ) = 0 .\tag{5.171c}
$$

So every skew symmetric matrix

$$
\Omega = \left( \begin{array} { c c c } { 0 } & { - \omega _ { z } } & { \omega _ { y } } \\ { \omega _ { z } } & { 0 } & { - \omega _ { x } } \\ { - \omega _ { y } } & { \omega _ { x } } & { 0 } \end{array} \right)\tag{5.171d}
$$

can be identified with a vector $\vec { \omega } ^ { \mathrm { T } } = \left( \omega _ { x } , \omega _ { y } , \omega _ { z } \right)$ . In this way the multiplication of any three dimensional vector $\vec { \bf p }$ by matrix Ω corresponds to the vector product with vector :

$$
\Omega \vec { \bf p } = \vec { \pmb { \omega } } \times \vec { \bf p } .\tag{5.171e}
$$

Consequently is the angular velocity of the rigid body with an amplitude ω. Hence a general element of the Lie algebra se(3) has the form

$$
\mathbf { \Omega } = \left( \begin{array} { c c } { \Omega \vec { \mathbf { v } } } \\ { 0 0 } \end{array} \right) .\tag{5.171f}
$$

These matrices form a 6-dimensional vector space which is often identified with the 6-dimensional vectors of the form

$$
\begin{array} { r } { \vec { \bf s } = \left( \begin{array} { c } { \vec { \omega } } \\ { \vec { \bf v } } \end{array} \right) . } \end{array}\tag{5.172}
$$
