### 11.4 Volterra Integral Equations

#### 11.4.1 Theoretical Foundations

A Volterra integral equation of the second kind has the form

$$
\varphi ( x ) = f ( x ) + \int _ { a } ^ { x } K ( x , y ) \varphi ( y ) d y .\tag{11.56}
$$

The solution function $\varphi ( x )$ with the independent variable x from the closed interval $I = [ a , b ]$ or from the semi-open interval $I = [ a , \infty )$ is required. There is the following theorem about the solution of a Volterra integral equation of the second kind: If the functions $f ( x )$ for $x \in I$ and $K ( x , y )$ on the triangular region $x \in I$ and $y \in [ a , x ]$ are continuous, then there exists a unique solution $\varphi ( x )$ of the integral equation such that it is continuous for $x \in I$ . For this solution

$$
\varphi ( a ) = f ( a )\tag{11.57}
$$

holds. In many cases, the Volterra integral equation of the first kind can be transformed into an equation of the second kind. Hence, theorems about existence and uniqueness of the solution are valid with some modifications.

1. Transformation by Diferentiation

Assuming $\varphi ( x ) , K ( x , y )$ , and $K _ { x } ( x , y )$ are continuous functions, the integral equation of the first kind

$$
f ( x ) = \int _ { a } ^ { x } K ( x , y ) \varphi ( y ) d y\tag{11.58a}
$$

can be transformed into the form

$$
f ^ { \prime } ( x ) = K ( x , x ) \varphi ( x ) + \int _ { a } ^ { x } { \frac { \partial } { \partial x } } K ( x , y ) \varphi ( y ) d y\tag{11.58b}
$$

by diferentiation with respect to x. If $K ( x , x ) \neq 0$ for all $x \in I$ , then dividing the equation by $K ( x , x )$ gives an integral equation of the second kind.

2. Transformation by Partial Integration

Assuming that $\varphi ( x ) , K ( x , y )$ and $K _ { y } ( x , y )$ are continuous, one can evaluate the integral in (11.58a) by partial integration. Substituting

$$
\int _ { a } ^ { x } \varphi ( y ) d y = \psi ( x )\tag{11.59a}
$$

gives

$$
\begin{array} { r l } { f ( x ) = [ K ( x , y ) \psi ( y ) ] _ { y = a } ^ { y = x } - \displaystyle \int _ { a } ^ { x } \left( \frac { \partial } { \partial y } K ( x , y ) \right) \psi ( y ) d y } \\ { = } & { K ( x , x ) \psi ( x ) - \displaystyle \int _ { a } ^ { x } \left( \frac { \partial } { \partial y } K ( x , y ) \right) \psi ( y ) d y . } \end{array}\tag{11.59b}
$$

If $K ( x , x ) \neq 0$ for $x \in I$ , then dividing by $K ( x , x )$ gives an integral equation of the second kind:

$$
\psi ( x ) = { \frac { f ( x ) } { K ( x , x ) } } + { \frac { 1 } { K ( x , x ) } } \int _ { a } ^ { x } \left( { \frac { \partial } { \partial y } } K ( x , y ) \right) \psi ( y ) d y .\tag{11.59c}
$$

Diferentiating the solution $\psi ( x )$ yields the solution $\varphi ( x )$ of (11.58a).

#### 11.4.3 Solution of the Volterra Integral Equation of the Second Kind by Neumann Series

The solution of the Volterra integral equations of the second kind can be represented by using a Neumann series (see 11.2.3, p. 627). If the equation has the form

$$
\varphi ( x ) = f ( x ) + \lambda \int _ { a } ^ { x } K ( x , y ) \varphi ( y ) d y ,\tag{11.61}
$$

so one formally substitutes

$$
\begin{array} { r } { \overline { { K } } ( x , y ) = \left\{ \begin{array} { l l } { K ( x , y ) } & { \mathrm { ~ f o r } y \leq x , } \\ { 0 } & { \mathrm { ~ f o r } y > x . } \end{array} \right. } \end{array}\tag{11.62a}
$$

With this transformation (11.61) is identically to a Fredholm integral equation

$$
\varphi ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } { \overline { { K } } } ( x , y ) \varphi ( y ) d y ,\tag{11.62b}
$$

allowing $b = \infty$ as well. The solution has the representation

$$
\varphi ( x ) = f ( x ) + \sum _ { n = 1 } ^ { \infty } \lambda ^ { n } \int _ { a } ^ { b } K _ { n } ( x , y ) f ( y ) d y .\tag{11.62c}
$$

The iterated kernels $K _ { 1 } , K _ { 2 } , \ldots$ . are defined by the following equalities:

$$
K _ { 1 } ( x , y ) = { \overline { { K } } } ( x , y ) , \quad K _ { 2 } ( x , y ) = \int _ { a } ^ { b } { \overline { { K } } } ( x , \eta ) { \overline { { K } } } ( \eta , y ) d \eta = \int _ { y } ^ { x } K ( x , \eta ) K ( \eta , y ) d \eta , \dots\tag{11.62d}
$$

and in general:

$$
K _ { n } ( x , y ) = \intop _ { y } ^ { x } K ( x , \eta ) K _ { n - 1 } ( \eta , y ) d \eta .\tag{11.62e}
$$

The equalities $K _ { j } ( x , y ) \equiv 0$ for $y > x ( j = 1 , 2 , . . . )$ are also valid for iterated kernels. Contrary to Fredholm integral equations if (11.61) has any solution, the Neumann series converges to it regardless of the value of λ.

$$

$$

Consequently the resolvent is: $T ( x , y ; \lambda ) = \mathrm { { e } } ^ { x - y } \sum _ { n = 0 } ^ { \infty } \frac { \lambda ^ { n } } { n ! } ( x - y ) ^ { n } = { { e } } ^ { ( x - y ) ( \lambda + 1 ) }$ . It is well-known that this series is convergent for any value of the parameter λ.

One gets $\varphi ( x ) = 1 + \lambda \int _ { 0 } ^ { x } \mathrm { e } ^ { ( x - y ) ( \lambda + 1 ) } d y = 1 + \lambda \mathrm { e } ^ { ( \lambda + 1 ) x } \int _ { 0 } ^ { x } \mathrm { e } ^ { - ( \lambda + 1 ) y } d y ,$ , in particular if $\lambda = - 1 \colon \varphi ( x ) =$

$$
1 - x , \ \lambda \neq - 1 \colon \varphi ( x ) = { \frac { 1 } { \lambda + 1 } } \left( 1 + \lambda \mathrm { e } ^ { ( \lambda + 1 ) x } \right) .
$$

#### 11.4.4 Convolution Type Volterra Integral Equations

If the kernel of a Volterra integral equation has the special form

$$
K ( x , y ) = { \left\{ \begin{array} { l l } { k ( x - y ) } & { { \mathrm { ~ f o r ~ } } 0 \leq y \leq x , } \\ { 0 } & { { \mathrm { ~ f o r ~ } } 0 \leq x < y , } \end{array} \right. }\tag{11.63a}
$$

can be used the Laplace transformation to solve the equations

$$
\int _ { 0 } ^ { x } k ( x - y ) \varphi ( y ) d y = f ( x ) \quad ( 1 1 . 6 3 \mathrm { b } ) \qquad { \mathrm { o r } } \quad \varphi ( x ) = f ( x ) + \int _ { 0 } ^ { x } k ( x - y ) \varphi ( y ) d y .\tag{11.63c}
$$

If the Laplace transforms ${ \mathcal { L } } \{ \varphi ( x ) \} = \phi ( p ) , { \mathcal { L } } \{ f ( x ) \} = F ( p )$ , and ${ \mathcal { L } } \{ k ( x ) \} = K ( p )$ exist, then the transformed equations have the form (see 15.2.1.2, 11., p. 773)

$$
K ( p ) \Phi ( p ) = F ( p ) \qquad \mathrm { ( 1 1 . 6 4 a ) ~ o r } \qquad \Phi ( p ) = F ( p ) + K ( p ) \Phi ( p ) \mathrm { ~ r e s p . }\tag{11.64b}
$$

From these follows

$$
\varPhi ( p ) = \frac { F ( p ) } { K ( p ) }
$$

$$
( 1 1 . 6 4 \mathrm { c } ) \mathrm { o r } \qquad \varPhi ( p ) = \frac { F ( p ) } { 1 - K ( p ) } \mathrm { r e s p . }\tag{11.64d}
$$

The inverse transformation gives the solution $\varphi ( x )$ of the original problem. Rewriting the formula for the Laplace transform of the solution of the integral equation of the second kind yields

$$
\Phi ( p ) = \frac { F ( p ) } { 1 - K ( p ) } = F ( p ) + \frac { K ( p ) } { 1 - K ( p ) } F ( p ) .\tag{11.64e}

The formula

\varphi ( x ) = f ( x ) + \intop _ { 0 } ^ { x } h ( x - y ) f ( y ) d y .\tag{11.64g}
$$

The function $h ( x - y )$ is the resolvent kernel of the integral equation.

#### 11.4.5 Numerical Methods for Volterra Integral Equation of the Second Kind

The problem is to find the solution for the integral equation

$$
\varphi ( x ) = f ( x ) + \int _ { a } ^ { x } K ( x , y ) \varphi ( y ) d y\tag{11.65}
$$

for x from the interval $I = [ a , b ]$ . The purpose of numerical methods is somehow to approximate the integral by a quadrature formula:

$$
\int _ { a } ^ { x } K ( x , y ) \varphi ( y ) d y \approx Q _ { [ a , x ] } ( K ( x , . ) \varphi ( . ) ) .\tag{11.66a}
$$

Both the interval of integration and the quadrature formula depend on x. This fact is emphasized by the index $[ a , x ]$ of $Q _ { [ a , x ] } ( . . . )$ . One gets the following equation as an approximation of (11.65):

$$
\overline { { { \varphi } } } ( x ) = f ( x ) + Q _ { [ a , x ] } ( K ( x , . ) \overline { { { \varphi } } } ( . ) ) .\tag{11.66b}
$$

The function $\overline { { \varphi } } ( x )$ is an approximation of the solution of (11.65). The number and the arrangement of the interpolation nodes of the quadrature formula depend on x, so as to allow little choice. If $\xi$ is an interpolation node of $Q _ { [ a , x ] } ( K ( \bar { x } , . ) \overline { { \varphi } } ( . ) )$ , then $( K ( x , \bar { \xi } ) \overline { { \varphi } } ( \xi ) )$ and especially $\overline { { \varphi } } ( \xi )$ must be known. For this purpose, the right-hand side of (11.66b) should be evaluated first for $x = \xi$ , which is equivalent to a quadrature over the interval $[ a , \xi ]$ . As a consequence, the use of the popular Gauss quadrature formula is not possible.

The problem is to be solved by choosing the interpolation nodes as $a = x _ { 0 } < x _ { 1 } < \ldots < x _ { k } < \ldots .$ and using a quadrature formula $Q _ { [ a , x _ { n } ] }$ with the interpolation nodes $x _ { 0 } , x _ { 1 } , \ldots , x _ { n }$ . The values of the function at the interpolation nodes are denoted by the brief notation $\varphi _ { k } = \overline { { \varphi } } ( x _ { k } ) \quad ( k = 0 , 1 , 2 , . . . )$ For $\varphi _ { 0 }$ follows (see 11.3.1, p. 635)

$$
\varphi _ { 0 } = f ( x _ { 0 } ) = f ( a ) , \mathrm { ~ \quad ( 1 1 . 6 6 c ) ~ } \mathrm { a n d ~ w i t h ~ t h i s . } \mathrm { ~ } \varphi _ { 1 } = f ( x _ { 1 } ) + Q _ { [ a , x _ { 1 } ] } ( K ( x _ { 1 } , . ) { \overline { { \varphi } } } ( . ) ) .\tag{11.66d}
$$

$Q _ { [ a , x _ { 1 } ] }$ has the interpolation points $x _ { 0 }$ and $x _ { 1 }$ and consequently it has the form

$$
Q _ { [ a , x _ { 1 } ] } ( K ( x _ { 1 } , . ) \overline { { { \varphi } } } ( . ) = w _ { 0 } K ( x _ { 1 } , x _ { 0 } ) \varphi _ { 0 } + w _ { 1 } K ( x _ { 1 } , x _ { 1 } ) \varphi _ { 1 }\tag{11.66e}
$$

with suitable coeficients $w _ { 0 }$ and $w _ { 1 }$ . Continuing this procedure, the values $\varphi _ { k }$ are successively determined from the general relation:

$$
\varphi _ { k } = f ( x _ { k } ) + Q _ { [ a , x _ { k } ] } ( K ( x _ { k } , . ) { \overline { { \varphi } } } ( . ) ) , \quad k = 1 , 2 , 3 , \dots .\tag{11.66f}
$$

The quadrature formulas $Q _ { [ a , x _ { k } ] }$ have the following form:

$$
Q _ { [ a , x _ { k } ] } ( K ( x _ { k } , . ) \overline { { \varphi } } ( . ) = \sum _ { j = 0 } ^ { k } w _ { j k } K ( x _ { k } , x _ { j } ) \varphi _ { j } .\tag{11.66g}
$$

Hence, (11.66f) takes the form:

$$
\varphi _ { k } = f ( x _ { k } ) + \sum _ { j = 0 } ^ { k } w _ { j k } K ( x _ { k } , x _ { j } ) \varphi _ { j } .\tag{11.66h}
$$

The simplest quadrature formula is the left-hand rectangular formula (see 19.3.2.1, p. 964). For this the coeficients are

$$
w _ { j k } = x _ { j + 1 } - x _ { j } \quad { \mathrm { f o r ~ } } j < k \quad { \mathrm { a n d } } \quad w _ { k k } = 0 .\tag{11.66i}
$$

With this follows the system

$$
\begin{array} { r l } & { \varphi _ { 0 } = f ( a ) , } \\ & { \varphi _ { 1 } = f ( x _ { 1 } ) + ( x _ { 1 } - x _ { 0 } ) K ( x _ { 1 } , x _ { 0 } ) \varphi _ { 0 } , } \\ & { \varphi _ { 2 } = f ( x _ { 2 } ) + ( x _ { 1 } - x _ { 0 } ) K ( x _ { 2 } , x _ { 0 } ) \varphi _ { 0 } + ( x _ { 2 } - x _ { 1 } ) K ( x _ { 2 } , x _ { 1 } ) \varphi _ { 1 } } \end{array}\tag{11.67a}
$$

and generally

$$
\varphi _ { k } = f ( x _ { k } ) + \sum _ { j = 0 } ^ { k - 1 } ( x _ { j + 1 } - x _ { j } ) K ( x _ { k } , x _ { j } ) \varphi _ { j } .\tag{11.67b}
$$

More accurate approximations of the integral can be obtained by using the trapezoidal formula (see $1 9 . 3 . 2 . 2 , \mathrm { p . 9 6 4 } )$ . To make it simple, one chooses equidistant interpolation nodes $x _ { k } = a + k h$ $k =$ $0 , 1 , 2 , \ldots :$

$$
\int _ { a } ^ { b } g ( x ) d x \approx { \frac { h } { 2 } } \left[ g ( x _ { 0 } ) + 2 \sum _ { j = 1 } ^ { k - 1 } g ( x _ { j } ) + g ( x _ { k } ) \right] .\tag{11.67c}
$$

Using this approximation for (11.66f) one gets:

$$
\varphi _ { 0 } = f ( a ) ,\tag{11.67d}
$$

$$
\varphi _ { k } = f ( x _ { k } ) + { \frac { h } { 2 } } \left[ K ( x _ { k } , x _ { 0 } ) \varphi _ { 0 } + K ( x _ { k } , x _ { k } ) \varphi _ { k } + 2 \sum _ { j = 1 } ^ { k - 1 } K ( x _ { k } , x _ { j } ) \varphi _ { j } \right] .\tag{11.67e}
$$

Although the unknown values also appear on the right-hand side of the equation, they are easy to express.
