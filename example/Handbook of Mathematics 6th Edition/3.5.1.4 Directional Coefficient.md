##### 3.5.1.4 Directional Coefficient

The directional coeficient of a vector a along a vector $\vec { \mathbf { b } }$ is the scalar product

$$
a _ { b } = \vec { \mathbf { a } } \vec { \mathbf { b } } ^ { 0 } = | \vec { \mathbf { a } } | \cos \varphi ,\tag{3.247}
$$

where $\vec { \mathbf { b ^ { 0 } } } = \frac { b } { | \vec { \mathbf { b } } | }$ is the unit vector in the direction of $\vec { \mathbf { b } }$ and $\varphi$ is the angle between $\vec { \mathbf { a } }$ and $\vec { \mathbf { b } } .$

The directional coeficient represents the projection of $\vec { \mathbf { a } }$ on $\vec { \mathbf { b } } .$

In the Cartesian coordinate system the directional coeficients of the vector $\vec { \mathbf { a } }$ along the x, y, z axes are the coordinates $a _ { x } , a _ { y } , a _ { z }$ . This statement is usually not true in a non-orthonormal coordinate system.
