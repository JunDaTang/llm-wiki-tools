#### 18.2.3 Solution Methods for Quadratic Optimization Problems

##### 18.2.3.1 Wolfe’s Method

1. Formulation of the Problem and Solution Principle

The method of Wolfe is to solve quadratic problems of the special form:

$$
f ( { \underline { { \mathbf { x } } } } ) = { \underline { { \mathbf { x } } } } ^ { \mathrm { T } } { \mathbf { C } } { \underline { { \mathbf { x } } } } + { \underline { { \mathbf { p } } } } ^ { \mathrm { T } } { \underline { { \mathbf { x } } } } = \operatorname* { m i n } ! , \quad { \mathrm { s u b j e c t ~ t o } } \quad { \mathbf { A } } { \underline { { \mathbf { x } } } } = { \underline { { \mathbf { b } } } } , \quad { \underline { { \mathbf { x } } } } \geq { \underline { { \mathbf { 0 } } } } .\tag{18.56}
$$

C is supposed to be positive definite. The basic idea is the determination of a solution $\left( \underline { { \mathbf { x } } } ^ { * } , \underline { { \mathbf { u } } } ^ { * } , \underline { { \mathbf { v } } } ^ { * } \right)$ of the corresponding system of Kuhn-Tucker conditions, associated to problem (18.56):

$$
\mathbf { A } \mathbf { \underline { { x } } } = \mathbf { \underline { { b } } } ,\tag{18.57a}
$$

$$
2 \mathbf { C } \underline { { \mathbf { x } } } - \underline { { \mathbf { v } } } + \mathbf { A } ^ { \mathrm { T } } \underline { { \mathbf { u } } } = - \underline { { \mathbf { p } } } ,\tag{18.57b}
$$

$$
\underline { { \mathbf { x } } } \geq \underline { { \mathbf { 0 } } } , \quad \underline { { \mathbf { v } } } { \geq } \underline { { \mathbf { 0 } } } ;\tag{18.57c}
$$

$$
\begin{array} { r } { \mathbf { x } ^ { \mathrm { T } } \mathbf { y } = 0 . } \end{array}\tag{18.58}
$$

Relations $( 1 8 . 5 7 \mathrm { a } , \mathrm { b } , \mathrm { c } )$ represent a linear equation system with $m + n$ equations and $2 n + m$ variables. Because of relation (18.58), either $x _ { i } = 0 \operatorname { o r } v _ { i } = 0 ( i = 1 , 2 , \ldots , n )$ must hold. Therefore, every solution of $\left( 1 8 . 5 7 \mathrm { a } , \mathrm { b } , \mathrm { c } \right)$ , (18.58) contains at most m+n non-zero components. Hence, it must be a basic solution of (18.57a,b,c).

2. Solution by Iteration

The dual problem (18.64a), which contains only the condition $\underline { { \mathbf { u } } } \geq \underline { { \mathbf { 0 } } }$ , can be solved by the following simple iteration method:

a) Substitute $\underline { { \mathbf { u } } } ^ { 1 } \geq \underline { { \mathbf { 0 } } } , ( \mathrm { e . g . , } \underline { { \mathbf { u } } } ^ { 1 } = \underline { { \mathbf { 0 } } } ) , k = 1$

b) Calculate $u _ { i } ^ { k + 1 }$ for $i = 1 , 2 , \dots , m$ according to

$$
w _ { i } ^ { k + 1 } = - \frac { 1 } { e _ { i i } } \left( \sum _ { j = 1 } ^ { i - 1 } e _ { i j } u _ { j } ^ { k + 1 } + \frac { h _ { i } } { 2 } + \sum _ { j = i + 1 } ^ { m } e _ { i j } u _ { j } ^ { k } \right) , \left( 1 8 . 6 6 \mathrm { a } \right) \qquad u _ { i } ^ { k + 1 } = \operatorname* { m a x } \left\{ 0 , w _ { i } ^ { k + 1 } \right\} .\tag{18.66b}
$$

c) Repeat step b) with $k + 1$ instead of k until a stopping rule is satisfied, $\mathrm { e . g . } , \left| \psi ( \underline { { \mathbf { u } } } ^ { k + 1 } ) - \psi ( \underline { { \mathbf { u } } } ^ { k } ) \right| < \varepsilon$ $\varepsilon > 0$

Under the assumption that there is an x such that $\mathbf { A } \underline { { \mathbf { x } } } < \underline { { \mathbf { b } } }$ , the sequence $\{ \psi ( \underline { { \mathbf { u } } } ^ { k } ) \}$ converges to the minimum value $\psi _ { \mathrm { m i n } }$ and sequence $\{ \underline { { \mathbf { x } } } ^ { k } \}$ given by (18.65) converges to the solution $\underline { { \mathbf { x } } } ^ { * }$ of the original problem. The sequence $\{ \underline { { \mathbf { u } } } ^ { k } \}$ is not always convergent.
