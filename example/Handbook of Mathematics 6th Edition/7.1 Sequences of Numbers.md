#### 7.1.2 Limits of Sequences ofNumbers

1. Limit of a Sequence of Numbers

An infinite sequence of numbers (7.1) has a limit A if for an unlimited increase of the index n the diference $a _ { n } - A$ becomes arbitrarily small. Precisely defined this means: For an arbitrarily small $\varepsilon >$ 0 there exists an index $n _ { 0 } ( \varepsilon )$ such that for every $n > n _ { 0 }$

$$
\left| a _ { n } - A \right| < \varepsilon .\tag{7.5a}
$$

The sequence of numbers has the limit $+ \infty \left( - \infty \right)$ , if for arbitrary $K > 0$ there exists an index $n _ { 0 } ( K )$ such that for every n $> n _ { 0 }$

$$
a _ { n } > K \qquad ( a _ { n } < - K ) .\tag{7.5b}

2. Convergence of a Sequence of Numbers

If a sequence of numbers $\left\{ a _ { n } \right\}$ satisfies (7.5a), then one says it converges to A. This is denoted by

$$
\operatorname* { l i m } _ { n \to \infty } a _ { n } = A \quad { \mathrm { o r } } \quad a _ { n } \to A .\tag{7.6}

3. Divergence of a Sequence of Numbers

Non-convergent sequences of numbers are called divergent. One talks about proper divergence in the case of (7.5b), i.e., if as n exceeds any value, $a _ { n }$ exceeds any large positive number K $( K > 0 )$ so that it never goes below, or if as n exceeds any value, $a _ { n }$ goes below any negative number $- K \ ( K > 0 )$ with arbitrarily large magnitude and never increases above it, i.e., if it has the limit . $$

Otherwise the sequence of numbers is called improperly divergent.
