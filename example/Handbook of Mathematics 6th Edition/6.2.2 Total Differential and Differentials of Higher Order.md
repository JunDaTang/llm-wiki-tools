#### 6.2.2 Total Differential and Differentials of Higher Order

##### 6.2.2.1 Notion of Total Differential of a Function of Several Variables (Complete Differential)

1. Diferentiability

The function of several variable $u \ = \ f ( x _ { 1 } , x _ { 2 } , \ldots , x _ { i } , \ldots , x _ { n } )$ is called diferentiable at the point $P _ { 0 } ( x _ { 1 0 } , x _ { 2 0 } , \ldots , x _ { i 0 } , \ldots , x _ { n 0 } )$ if at a transition to an arbitrarily close point $P ( x _ { 1 0 } + \Delta x _ { 1 } , x _ { 2 0 } + \Delta x _ { 2 } , . . . , x _ { i 0 }$ $+ \Delta x _ { i } , \ldots , x _ { n 0 } + \Delta x _ { n } )$ with the arbitrarily small quantities $\Delta x _ { 1 } , \Delta x _ { 2 } , \ldots , \Delta x _ { i } , \ldots , \Delta x _ { n }$ the complete increment

$$
\begin{array} { c } { \Delta u = f ( x _ { 1 0 } + \Delta x _ { 1 } , x _ { 2 0 } + \Delta x _ { 2 } , \dots , x _ { i 0 } + \Delta x _ { i } , \dots , x _ { n 0 } + \Delta x _ { n } ) } \\ { - f ( x _ { 1 0 } , x _ { 2 0 } , \dots , x _ { i 0 } , \dots , x _ { n 0 } ) } \end{array}\tag{6.41a}
$$

of the function difers from the sum of the partial diferentials of all variables

$$
( \frac { \partial u } { \partial x _ { 1 } } d x _ { 1 } + \frac { \partial u } { \partial x _ { 2 } } d x _ { 2 } + \ldots + \frac { \partial u } { \partial x _ { n } } d x _ { n } ) _ { x _ { 1 0 } , x _ { 2 0 } , \ldots , x _ { n 0 } }\tag{6.41b}
$$

by an arbitrarily small amount in higher order than the distance

$$
\overline { { P _ { 0 } P } } = \sqrt { \Delta x _ { 1 } ^ { 2 } + \Delta x _ { 2 } ^ { 2 } + . . . + \Delta x _ { n } ^ { 2 } } = \sqrt { d x _ { 1 } ^ { 2 } + d x _ { 2 } ^ { 2 } + . . . + d x _ { n } ^ { 2 } } .\tag{6.41c}
$$

A continuous function of several variables is diferentiable at a point if its partial derivatives, as functions of several variables, are continuous in a neighborhood of this point. This is a suficient but not a

necessary condition, while the simple existence of the partial derivatives at the considered point is not suficient even for the continuity of the function.

2. Total Diferential

If u is a diferentiable function, then the sum (6.41b)

$$
d u = { \frac { \partial u } { \partial x _ { 1 } } } d x _ { 1 } + { \frac { \partial u } { \partial x _ { 2 } } } d x _ { 2 } + \ldots + { \frac { \partial u } { \partial x _ { n } } } d x _ { n }\tag{6.42a}
$$

is called the total diferential of the function. With the n-dimensional vectors

$$
\underline { { \mathbf { g r a d } } } \mathbf { u } = \left( \frac { \partial u } { \partial x _ { 1 } } , \frac { \partial u } { \partial x _ { 2 } } , \ldots , \frac { \partial u } { \partial x _ { n } } \right) ^ { \mathrm { T } } , \quad \mathrm { ( 6 . 4 2 b ) } \qquad \underline { { \mathbf { d r } } } = ( d x _ { 1 } , d x _ { 2 } , \ldots , d x _ { n } ) ^ { \mathrm { T } }\tag{6.42c}
$$

the total diferential can be expressed as the scalar product

$$
d u = ( \underline { { \bf g r a d u } } ) ^ { \mathrm { T } } \cdot \underline { { \bf d r } } .\tag{6.42d}
$$

In (6.42b), there is the gradient, defined in 13.2.2, p. 710, for n independent variables.

3. Geometrical Representation

The geometrical meaning of the total diferential of a function of two variables $u = f ( x , y )$ , represented in a Cartesian coordinate system as a surface (Fig. 6.15), is that du is the same as the increment of the applicate (see 3.5.3.1, 3., p. 210) of the tangent plane (at the same point) if dx and dy are the increments of x and $y .$

From the Taylor formula (see 6.2.2.3, 1., p. 449) it follows for functions of two variables that

$$
f ( x , y ) = f ( x _ { 0 } , y _ { 0 } ) + { \frac { \partial f } { \partial x } } ( x _ { 0 } , y _ { 0 } ) ( x - x _ { 0 } ) + { \frac { \partial f } { \partial y } } ( x _ { 0 } , y _ { 0 } ) ( y - y _ { 0 } ) + R _ { 1 } .\tag{6.43a}
$$

Ignoring the remainder $R _ { 1 }$ , holds that

$$
u = f ( x _ { 0 } , y _ { 0 } ) + \frac { \partial f } { \partial x } ( x _ { 0 } , y _ { 0 } ) ( x - x _ { 0 } ) + \frac { \partial f } { \partial y } ( x _ { 0 } , y _ { 0 } ) ( y - y _ { 0 } )\tag{6.43b}
$$

gives the equation of the tangent plane of the surface $u = f ( x , y )$ at the point $P _ { 0 } ( x _ { 0 } , y _ { 0 } , u _ { 0 } )$

4. The Fundamental Property of the Total Diferential

is the invariance with respect to the variables as formulated in (6.38) for the one-variable case.

5. Application in Error Calculations

In error calculations one uses the total diferential du for an estimation of the error $\Delta u$ (see (6.41a)) (see, e.g., 16.4.1.3, 5., p. 852). From the Taylor formula (see 6.2.2.3, 1., p. 449) follows

$$
| \Delta u | = | d u + R _ { 1 } | \leq | d u | + | R _ { 1 } | \approx | d u | ,\tag{6.44}
$$

i.e., the absolute error $| \Delta u |$ can be replaced by du as a first approximation. It follows that du is a linear approximation for $\Delta u$

##### 6.2.2.2 Derivatives and Differentials of Higher Order

1. Partial Derivatives of Second Order, Schwarz’s Exchange Theorem

The second-order partial derivative of a function $u = f ( x _ { 1 } , x _ { 2 } , . . . , x _ { i } , . . . , x _ { n } )$ can be calculated with respect to the same variable as the first one was, i.e., ${ \frac { \partial ^ { 2 } u } { \partial x _ { 1 } ^ { 2 } } } , { \frac { \partial ^ { 2 } u } { \partial x _ { 2 } ^ { 2 } } } , \dots ,$ or with respect to another variable, i.e. ${ \frac { \partial ^ { 2 } u } { \partial x _ { 1 } \partial x _ { 2 } } } , { \frac { \partial ^ { 2 } u } { \partial x _ { 2 } \partial x _ { 3 } } } , { \frac { \partial ^ { 2 } u } { \partial x _ { 3 } \partial x _ { 1 } } } , \ldots .$ . In this second case one talks about mixed derivatives. If

If at the considered point the mixed derivatives are continuous, then

$$
{ \frac { \partial ^ { 2 } u } { \partial x _ { 1 } \partial x _ { 2 } } } = { \frac { \partial ^ { 2 } u } { \partial x _ { 2 } \partial x _ { 1 } } }\tag{6.45}
$$

holds for given $x _ { 1 }$ and $x _ { 2 }$ independently of the order of sequence of the diferentiation (Schwarz’s exchange theorem).

Partial derivatives of higher order such as, $\mathrm { e . g . , } \frac { \partial ^ { 3 } u } { \partial x ^ { 3 } } , \frac { \partial ^ { 3 } u } { \partial x \partial y ^ { 2 } } , . .$ . are defined analogously.

2. Second-Order Diferential of a Function of One Variable $y = f ( x )$

The second-order diferential of a function $y = f ( x )$ of one variable, denoted by the symbols $d ^ { 2 } y , d ^ { 2 } f ( x )$ is the diferential of the first diferential: $d ^ { 2 } y = \dot { d } ( \dot { d } y ) = f ^ { \prime \prime } ( x ) d x ^ { 2 }$ . These symbols are appropriate only if x is an independent variable, and they are not appropriate if x is ${ \mathrm { g i v e n , e . g . } }$ , in the form $x = z ( v )$ . Differentials of higher order are defined analogously. If the variables $x _ { 1 } , x _ { 2 } , \ldots , x _ { i } , \ldots , x _ { n }$ are themselves functions of other variables, then one gets more complicated formulas (see 6.2.4, p. 452).

3. Total Diferential of Second Order of a Function of Two Variables $\pmb { u } = f ( \pmb { x } , \pmb { y } )$

$$
d ^ { 2 } u = d ( d u ) = { \frac { \partial ^ { 2 } u } { \partial x ^ { 2 } } } d x ^ { 2 } + 2 { \frac { \partial ^ { 2 } u } { \partial x \partial y } } d x d y + { \frac { \partial ^ { 2 } u } { \partial y ^ { 2 } } } d y ^ { 2 }\tag{6.46a}
$$

or symbolically

$$
d ^ { 2 } u = \left( { \frac { \partial } { \partial x } } d x + { \frac { \partial } { \partial y } } d y \right) ^ { 2 } u .\tag{6.46b}
$$

4. Total Diferential of n-th Order of a Function of Two Variables

$$
d ^ { n } u = \left( { \frac { \partial } { \partial x } } d x + { \frac { \partial } { \partial y } } d y \right) ^ { n } u .\tag{6.47}
$$

$$
d ^ { n } u = \left( { \frac { \partial } { \partial x _ { 1 } } } d x _ { 1 } + { \frac { \partial } { \partial x _ { 2 } } } d x _ { 2 } + \ldots + { \frac { \partial } { \partial x _ { m } } } d x _ { m } \right) ^ { n } u .\tag{6.48}
$$
