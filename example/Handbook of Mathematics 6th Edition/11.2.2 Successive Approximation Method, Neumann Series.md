#### 11.2.2 Successive Approximation Method, Neumann Series

1. Iteration Method

Similarly to the Picard iteration method (see 9.1.1.5, 1., p. 549) for the solution of ordinary diferential equations, an iterative method needs to be given to solve Fredholm integral equations of the second kind. Starting with the equation

$$
\varphi ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } K ( x , y ) \varphi ( y ) d y ,\tag{11.10}
$$

one defines a sequence of functions $\varphi _ { 0 } ( x ) , \varphi _ { 1 } ( x ) , \varphi _ { 2 } ( x ) , . . . .$ . Let the first be $\varphi _ { 0 } ( x ) = f ( x )$ . The subsequent $\varphi _ { n } ( x )$ can be get by the formula

$$
\varphi _ { n } ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } K ( x , y ) \varphi _ { n - 1 } ( y ) d y \quad ( n = 1 , 2 , \ldots ; \quad \varphi _ { 0 } ( x ) = f ( x ) ) .\tag{11.11a}
$$

Following the given method the first step is

$$
\varphi _ { 1 } ( x ) = f ( x ) + \lambda \intop _ { a } ^ { b } K ( x , y ) f ( y ) d y .\tag{11.11b}
$$

According to the iteration formula this expression of $\varphi ( y )$ is substituted into the right-hand side of (11.10). To avoid the accidental confusion of the integral variables, y is denoted by η in (11.11b).

$$
\begin{array} { l } { \displaystyle \varphi _ { 2 } ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } K ( x , y ) \left[ f ( y ) + \lambda \int _ { a } ^ { b } K ( y , \eta ) f ( \eta ) d \eta \right] d y } \\ { \displaystyle = f ( x ) + \lambda \int _ { a } ^ { b } K ( x , y ) f ( y ) d y + \lambda ^ { 2 } \int _ { a } ^ { b } K ( x , y ) K ( y , \eta ) f ( \eta ) d y d \eta . } \end{array}\tag{11.11c}
$$

(11.11d)

Introducing the notation of $K _ { 1 } ( x , y ) = K ( x , y )$ and $K _ { 2 } ( x , y ) = \int _ { a } ^ { b } K ( x , \xi ) K ( \xi , y ) d \xi$ , and renaming η as y, one can write $\varphi _ { 2 } ( x )$ in the form

$$
\varphi _ { 2 } ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } K _ { 1 } ( x , y ) f ( y ) d y + \lambda ^ { 2 } \intop _ { a } ^ { b } K _ { 2 } ( x , y ) f ( y ) d y .\tag{11.11e}
$$

Denoting

$$
K _ { n } ( x , y ) = \int _ { a } ^ { b } K ( x , \xi ) K _ { n - 1 } ( \xi , y ) d \xi \quad ( n = 2 , 3 , . . . )\tag{11.11f}
$$

then there is the representation of the n-th iterated $\varphi _ { n } ( x )$

$$
\varphi _ { n } ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } K _ { 1 } ( x , y ) f ( y ) d y + . . . + \lambda ^ { n } \int _ { a } ^ { b } K _ { n } ( x , y ) f ( y ) d y .\tag{11.11g}
$$

$K _ { n } ( x , y )$ is called the n-th iterated kernel of $K ( x , y )$

2. Convergence of the Neumann Series

To get the solution $\varphi ( x )$ , it is to be discussed the convergence of the power series of λ

$$
f ( x ) + \sum _ { n = 1 } ^ { \infty } \lambda ^ { n } \int _ { a } ^ { b } K _ { n } ( x , y ) f ( y ) d y ,\tag{11.12}
$$

which is called the Neumann series. If the functions $K ( x , y )$ and $f ( x )$ are bounded, i.e., the inequalities

$$
| K ( x , y ) | < M ~ ( a \leq x \leq b , ~ a \leq y \leq b ) ~ \mathrm { a n d } ~ | f ( x ) | < N ~ ( a \leq x \leq b ) ,\tag{11.13a}
$$

hold, then the series

$$
N \sum _ { n = 0 } ^ { \infty } | \lambda M ( b - a ) | ^ { n }\tag{11.13b}
$$

is a majorant series for the power series (11.12). This geometric series is convergent for all

$$
\vert \lambda \vert < { \frac { 1 } { M ( b - a ) } } .\tag{11.13c}
$$

The Neumann series is absolutely and uniformly convergent for all values of λ satisfying (11.13c). By a sharper estimation of the terms of the Neumann series one can give the convergence interval more precisely. According to this, the Neumann series is convergent for

$$
| \lambda | < { \frac { 1 } { \sqrt { \int _ { a \ a } ^ { b \ b } | K ( x , y ) | ^ { 2 } d x d y } } } .\tag{11.13d}
$$

This restriction for the parameter λ does not mean that there are no solutions for any $| \lambda |$ outside the bounds set by (11.13d), but only that one cannot get it by the Neumann series. The expression

$$
T ( x , y ; \lambda ) = \sum _ { n = 1 } ^ { \infty } \lambda ^ { n - 1 } K _ { n } ( x , y )\tag{11.14a}
$$

is called the resolvent or solving kernel of the integral equation. Using the resolvent one gets the solution in the form

$$
\varphi ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } { \Gamma ( x , y ; \lambda ) f ( y ) d y } .\tag{11.14b}
$$

For the inhomogeneous Fredholm integral equation of the second kind $\varphi ( x ) = x + \lambda \int _ { 0 } ^ { 1 } x y \varphi ( y )$ dy follows $K _ { 1 } ( x , y ) = x y , K _ { 2 } ( x , y ) = \int _ { 0 } ^ { 1 } x \eta \eta y d y = { \frac { 1 } { 3 } } x y , K _ { 3 } ( x , y ) = { \frac { 1 } { 9 } } x y , . . . , K _ { n } ( x , y ) = { \frac { x y } { 3 ^ { n - 1 } } }$ and from this ${ \cal { T } } ( x , y ; \lambda ) = x y \left( \sum _ { n = 0 } ^ { \infty } \frac { \lambda ^ { n } } { 3 ^ { n } } \right)$ . With the limit (11.13c) the series is definitely convergent for $| \lambda | < 1$ , because $| K ( x , y ) | \leq M = 1$ holds. The resolvent $r ( x , y ; \lambda ) = { \frac { x y } { \left( 1 - { \frac { \lambda } { 3 } } \right) } }$ is a geometric series which is convergent even for $| \lambda | < 3$ . Thus from (11.14b) follows $\varphi ( x ) = x + \lambda \int _ { 0 } ^ { 1 } { \frac { x y ^ { 2 } } { \left( 1 - { \frac { \lambda } { 3 } } \right) } } d y = { \frac { x } { 1 - { \frac { \lambda } { 3 } } } } .$

Remark: If for a given λ the relation (11.13d) does not hold, then any continuous kernel can be decomposed into the sum of two continuous kernels $K ( x , y ) = K ^ { 1 } ( x , y ) + K ^ { 2 } ( x , y )$ , where $K ^ { 1 } ( x , y )$ is a degenerate kernel, and $K ^ { 2 } ( x , y )$ is so small that for this kernel (11.13d) holds. In this way one has an exact solution method for any λ which is not an eigenvalue.
