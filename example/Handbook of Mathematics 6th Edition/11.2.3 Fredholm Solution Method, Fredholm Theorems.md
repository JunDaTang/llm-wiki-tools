#### 11.2.3 Fredholm Solution Method, Fredholm Theorems

##### 11.2.3.1 Fredholm Solution Method

1. Approximate Solution by Discretization

A Fredholm integral equation of the second kind

$$
\varphi ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } K ( x , y ) \varphi ( y ) d y\tag{11.15}
$$

can be approximately represented by a linear system of equations. It should be assumed that the functions $K ( x , y )$ and $f ( \boldsymbol { x } )$ are continuous for $a \leq x \leq b , a \leq y \leq b .$

The integral in (11.15) should be approximated by the so-called left-hand rectangular formula (see 19.3.2.1, p. 964). It is also possible to use any other quadrature formula (see 19.3.1, p. 963). An equidistant partition

$$
y _ { k } = a + ( k - 1 ) h { \quad } ( k = 1 , 2 , \cdots , n ; \ h = { \frac { b - a } { n } } )\tag{11.16a}
$$

yields the approximation

$$
\varphi ( x ) \approx f ( x ) + \lambda h \left[ K ( x , y _ { 1 } ) \varphi ( y _ { 1 } ) + \ldots + K ( x , y _ { n } ) \varphi ( y _ { n } ) \right] .\tag{11.16b}
$$

Replacing $\varphi ( x )$ in this expression by a function $\overline { { \varphi } } ( x )$ exactly satisfying (11.16b) yields:

$$
\overline { { \varphi } } ( x ) = f ( x ) + \lambda h \left[ K ( x , y _ { 1 } ) \overline { { \varphi } } ( y _ { 1 } ) + \ldots + K ( x , y _ { n } ) \overline { { \varphi } } ( y _ { n } ) \right] .\tag{11.16c}
$$

To determine this approximate solution, it is necessary to know the substitution values of $\overline { { \varphi } } ( x )$ at the interpolation nodes $\overset { \cdot } { x } _ { k } = a + ( k - 1 ) h .$ Substituting $x = x _ { 1 } , x = x _ { 2 } , . . . , x = x _ { n }$ into (11.16c), yields a linear system of equations for the required n substitution values of $\overline { { \varphi } } ( \boldsymbol { x } _ { k } )$ . $$

$$

##### 11.2.3.2 Fredholm Theorems

For the Fredholm integral equation of the second kind

$$
\varphi ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } K ( x , y ) \varphi ( y ) d y\tag{11.21a}
$$

the correspondent transposed integral equation is given by

$$
\psi ( x ) = g ( x ) + \lambda \intop _ { a } ^ { b } K ( y , x ) \psi ( y ) d y .\tag{11.21b}
$$

For this pair of integral equations the following statements are valid (see also 11.2.1, p. 622).

1. A Fredholm integral equation of the second kind can only have finite or countably infinite eigenvalues. The eigenvalues cannot accumulate in any finite interval, i.e., for any positive R there are only a finite number of λ for which $| \lambda | < R$

2. If λ is not an eigenvalue of (11.21a), then both of the inhomogeneous integral equations have a unique solution for any perturbation function $f ( x )$ or $g ( x )$ , and the corresponding homogeneous integral equations have only trivial solutions.

3. If λ is an eigenvalue of (11.21a), then λ is also an eigenvalue of the transposed equation (11.21b). Both homogeneous integral equations have non-vanishing solutions, and the number of linearly independent solutions are the same for both equations.

4. For an eigenvalue λ the homogeneous integral equation can be solved if and only if the perturbation function is orthogonal to every solution of the homogeneous transposed integral equation, i.e., for every solution of the integral equation

$$
\psi ( x ) = \lambda \intop _ { a } ^ { b } K ( y , x ) \psi ( y ) d y ,
$$

$$
( 1 1 . 2 2 \mathrm { a } ) \qquad \int _ { a } ^ { b } f ( x ) \psi ( x ) d x = 0 \quad \mathrm { h o l d s } .\tag{11.22b}
$$

The Fredholm alternative theorem follows from these statements: Either the inhomogeneous integral equation can be solved for any perturbation function $f ( x )$ or the corresponding homogeneous equation

has non-trivial solutions.
