#### 18.2.2 Special Non-linear Optimization Problems

##### 18.2.2.1 Convex Optimization

1. Convex Problem

The optimization problem

$$
f ( \underline { { \mathbf { x } } } ) = \operatorname* { m i n } ! \quad \mathrm { s u b j e c t ~ t o } \quad g _ { i } ( \underline { { \mathbf { x } } } ) \leq 0 \quad ( i = 1 , \dots , m )\tag{18.43}
$$

is called a convex problem if the functions f and $g _ { i }$ are convex. In particular, f and $g _ { i }$ can be linear functions. The following statements are valid for convex problems:

a) Every local minimum of f over M is also a global minimum.

b) If M is not empty and bounded, then there exists at least one solution of (18.43).

c) If f is strictly convex, then there is at most one solution of (18.43).

1. Optimality Conditions

a) If f has continuous partial derivatives, then $\underline { { \mathbf { x } } } ^ { * } \in M$ is a solution of (18.43), if

$$
( \underline { { \mathbf { x } } } - \underline { { \mathbf { x } } } ^ { * } ) ^ { \mathrm { T } } \nabla f ( \underline { { \mathbf { x } } } ^ { * } ) \geq 0 \quad \mathrm { f o r ~ e v e r y } \quad \underline { { \mathbf { x } } } \in M .\tag{18.44}
$$

b) The Slater condition is a regularity condition for the feasible set M. It is satisfied if there exists an $\underline { { \mathbf { x } } } \in M$ such that $g _ { i } ( \underline { { \mathbf { x } } } ) < 0$ for every non-afine linear functions $g _ { i } .$

c) If the Slater condition is satisfied, then $\underline { { \mathbf { x } } } ^ { * }$ is a minimum point of (18.43) if and only if there exists a $\mathbf { u } ^ { * } \geq 0$ such that $\left( \underline { { \mathbf { x } } } ^ { * } , \underline { { \mathbf { u } } } ^ { * } \right)$ is a saddle point of the Lagrangian. Moreover, if functions f and $g _ { i }$ are differentiable, then $\mathbf { x } ^ { * }$ is a solution of (18.43) if and only if $\mathbf { x } ^ { * }$ satisfies the local Kuhn-Tucker conditions. d) The dual problem (18.42a,b) can be formulated easily for a convex optimization problem with differentiable functions f and g :

$$
L ( \underline { { \mathbf { x } } } , \underline { { \mathbf { u } } } ) = \mathrm { m a x ! } , \quad \mathrm { s u b j e c t ~ t o } \quad ( \underline { { \mathbf { x } } } , \underline { { \mathbf { u } } } ) \in M ^ { * } \quad \mathrm { w i t h }\tag{18.45a}
$$

$$
M ^ { * } = \{ ( \underline { { \mathbf { x } } } , \underline { { \mathbf { u } } } ) \in \mathbb { R } ^ { n } \times \mathbb { R } _ { + } ^ { m } : \nabla _ { \underline { { \mathbf { x } } } } L ( \underline { { \mathbf { x } } } , \underline { { \mathbf { u } } } ) = \underline { { \mathbf { 0 } } } \} .\tag{18.45b}
$$

The gradient of $L$ is calculated here only with respect to x.

e) For convex optimization problems, the strong duality theorem also holds:

If M satisfies the Slater condition and if $\underline { { \mathbf { x } } } ^ { * } \in M$ is a solution of (18.43), then there exists a $\mathbf { u } ^ { * } \in \mathbb { R } _ { + } ^ { m }$ such that $\left( \underline { { \mathbf { x } } } ^ { * } , \underline { { \mathbf { u } } } ^ { * } \right)$ is a solution of the dual problem (18.45a,b), and

$$
f ( \underline { { \mathbf { x } } } ^ { * } ) = \operatorname* { m i n } _ { \underline { { \mathbf { x } } } \in M } f ( \underline { { \mathbf { x } } } ) = \operatorname* { m a x } _ { ( \underline { { \mathbf { x } } } , \underline { { \mathbf { u } } } ) \in M ^ { * } } L ( \underline { { \mathbf { x } } } , \underline { { \mathbf { u } } } ) = L ( \underline { { \mathbf { x } } } ^ { * } , \underline { { \mathbf { u } } } ^ { * } ) .\tag{18.46}
$$

##### 18.2.2.2 Quadratic Optimization

1. Formulation of the Problem

Quadratic optimization problems have the form

$$
f ( \mathbf { \underline { { x } } } ) = \mathbf { \underline { { x } } } ^ { \mathrm { T } } \mathbf { C } \underline { { \mathbf { x } } } + \mathbf { \underline { { p } } } ^ { \mathrm { T } } \mathbf { \underline { { x } } } = \operatorname* { m i n } ! , \quad \mathrm { s u b j e c t ~ t o } \quad \underline { { \mathbf { x } } } \in M \subset \mathbf { R } ^ { n } \quad \mathrm { w i t h } \quad\tag{18.47a}
$$

$$
M = M _ { I } { \mathrm { : } } \quad M = \{ \underline { { \mathbf { x } } } \in \mathbb { R } ^ { n } : \mathbf { A } \underline { { \mathbf { x } } } \leq \underline { { \mathbf { b } } } , \ \underline { { \mathbf { x } } } \geq \underline { { \mathbf { 0 } } } \} .\tag{18.47b}
$$

Here, C is a symmetric $( n , n )$ matrix, $\mathbf { p } \in \mathbb { R } ^ { n }$ , A is an $( m , n )$ matrix, and $\mathbf { \underline { { b } } } \in \mathbb { R } ^ { m }$

The feasible set M can be written alternatively in the following way:

$$
M = M _ { I I } : ~ \ M = \{ \underline { { \mathbf { x } } } \ : \ \mathbf { A } \underline { { \mathbf { x } } } = \underline { { \mathbf { b } } } , \ \underline { { \mathbf { x } } } \geq \underline { { \mathbf { 0 } } } \} ,\tag{18.48a}

3. Convexity

The function $f ( \underline { { \mathbf { x } } } )$ is convex (strictly convex) if and only if the matrix C is positive semidefinite (positive definite). Every result on convex optimization problems can be used for quadratic problems with a positive semidefinite matrix C; in particular, the Slater condition always holds, so it is necessary and suficient for the optimality of a point $\underline { { \mathbf { x } } } ^ { * }$ that there exists a point $\left( \underline { { \mathbf { x } } } ^ { * } , \underline { { \mathbf { y } } } , \underline { { \mathbf { u } } } , \underline { { \mathbf { v } } } \right)$ , which satisfies the corresponding system of local Kuhn-Tucker conditions.
