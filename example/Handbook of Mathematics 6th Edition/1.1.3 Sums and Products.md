#### 1.1.3 Sums and Products

##### 1.1.3.1 Sums

1. Definition

To briefly denote a sum the summation sign $\scriptstyle \sum$ is used:

$$
a _ { 1 } + a _ { 2 } + \ldots + a _ { n } = \sum _ { k = 1 } ^ { n } a _ { k } .\tag{1.8}
$$

With this notation the sum of n summands $a _ { k } \ ( k = 1 , 2 , \ldots , n )$ is denoted, k is called the running index or summation variable.

2. Rules of Calculation

1. Sum of Summands Equal to Each Other , $\mathrm { i . e . , } a _ { k } = a \mathrm { f o r } k = 1 , 2 , . . . , n \mathrm { : }$

$$
\sum _ { k = 1 } ^ { n } a _ { k } = n a .\tag{1.9a}
$$

2. Multiplication by a Constant Factor

$$
\sum _ { k = 1 } ^ { n } c a _ { k } = c \sum _ { k = 1 } ^ { n } a _ { k } .\tag{1.9b}
$$

3. Separating a Sum

$$
\sum _ { k = 1 } ^ { n } a _ { k } = \sum _ { k = 1 } ^ { m } a _ { k } + \sum _ { k = m + 1 } ^ { n } a _ { k } \quad ( 1 < m < n ) .\tag{1.9c}
$$

4. Addition of Sums with the Same Length

$$
\sum _ { k = 1 } ^ { n } ( a _ { k } + b _ { k } + c _ { k } + \ldots ) = \sum _ { k = 1 } ^ { n } a _ { k } + \sum _ { k = 1 } ^ { n } b _ { k } + \sum _ { k = 1 } ^ { n } c _ { k } + \ldots .\tag{1.9d}
$$

5. Renumbering

$$
\sum _ { k = 1 } ^ { n } a _ { k } = \sum _ { k = m } ^ { m + n - 1 } a _ { k - m + 1 } , ~ \sum _ { k = m } ^ { n } a _ { k } = \sum _ { k = l } ^ { n - m + l } a _ { k + m - l } .\tag{1.9e}
$$

6. Exchange the Order of Summation in Double Sums

$$
\sum _ { i = 1 } ^ { n } \left( \sum _ { k = 1 } ^ { m } a _ { i k } \right) = \sum _ { k = 1 } ^ { m } \left( \sum _ { i = 1 } ^ { n } a _ { i k } \right) .\tag{1.9f}
$$

##### 1.1.3.2 Products

1. Definition

The abbreviated notation for a product is the product sign :

$$
a _ { 1 } a _ { 2 } \ldots a _ { n } = \prod _ { k = 1 } ^ { n } a _ { k } .\tag{1.10}
$$

With this notation a product of n factors $a _ { k } \ ( k = 1 , 2 , \ldots , n )$ is denoted, where k is called the running index.

2. Rules of Calculation

1. Product of Coincident Factors , i.e., $a _ { k } = a$ for k = 1, 2, . . . , n:

$$
\prod _ { k = 1 } ^ { n } a _ { k } = a ^ { n } .\tag{1.11a}
$$

2. Factoring out a Constant Factor

$$
\prod _ { k = 1 } ^ { n } ( c a _ { k } ) = c ^ { n } \prod _ { k = 1 } ^ { n } a _ { k } .\tag{1.11b}
$$

3. Separating into Partial Products

$$
\prod _ { k = 1 } ^ { n } a _ { k } = \left( \prod _ { k = 1 } ^ { m } a _ { k } \right) \left( \prod _ { k = m + 1 } ^ { n } a _ { k } \right) \quad ( 1 < m < n ) .\tag{1.11c}
$$

4. Product of Products

$$
\prod _ { k = 1 } ^ { n } a _ { k } b _ { k } c _ { k } \ldots = \left( \prod _ { k = 1 } ^ { n } a _ { k } \right) \left( \prod _ { k = 1 } ^ { n } b _ { k } \right) \left( \prod _ { k = 1 } ^ { n } c _ { k } \right) \ldots . . .\tag{1.11d}
$$

5. Renumbering

$$
\prod _ { k = 1 } ^ { n } a _ { k } = \prod _ { k = m } ^ { m + n - 1 } a _ { k - m + 1 } , \quad \prod _ { k = m } ^ { n } a _ { k } = \prod _ { k = l } ^ { n - m + l } a _ { k + m - l } .\tag{1.11e}
$$

6. Exchange the Order of Multiplication in Double Products

$$
\prod _ { i = 1 } ^ { n } \left( \prod _ { k = 1 } ^ { m } a _ { i k } \right) = \prod _ { k = 1 } ^ { m } \left( \prod _ { i = 1 } ^ { n } a _ { i k } \right) .\tag{1.11f}
$$
