#### 4.1.3 Vectors

Matrices of size $( n , 1 )$ are one-column matrices or column vectors of dimension n. Matrices of size $( 1 , n )$ are one-row matrices or row vectors of dimension n:

$$
\underline { { \underline { { \mathbf { a } } } } } = \left( \begin{array} { l } { a _ { 1 } } \\ { a _ { 2 } } \\ { \vdots } \\ { a _ { n } } \end{array} \right) , ( 4 . 1 9 \mathrm { a } )
$$

Column Vector:

$$
\mathbf { R o w V e c t o r : \boldsymbol { \underline { { a } } } ^ { \mathrm { T } } } = ( a _ { 1 } , a _ { 2 } , \ldots , a _ { n } ) .\tag{4.19b}
$$

By transposing, a column vector is changed into a row vector and conversely. A row or column vector

of dimension n can determine a point in the n dimensional Euclidean space $\mathbb { R } ^ { n }$ The zero vector is denoted by 0 or $\underline { { \mathbf { 0 } } } ^ { \mathrm { T } }$ respectively.
