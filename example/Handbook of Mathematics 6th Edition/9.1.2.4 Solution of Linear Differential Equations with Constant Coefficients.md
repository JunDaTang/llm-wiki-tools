##### 9.1.2.4 Solution of Linear Differential Equations with Constant Coefficients

1. Operational Notation

The diferential equation (9.32) can be written symbolically in the form

$$
P _ { n } ( D ) y \equiv \left( D ^ { n } + a _ { 1 } D ^ { n - 1 } + a _ { 2 } D ^ { n - 2 } + \cdots + a _ { n - 1 } D + a _ { n } \right) y = F ,\tag{9.39a}
$$

where D is a diferential operator:

$$
D y = { \frac { d y } { d x } } , \quad D ^ { k } y = { \frac { d ^ { k } y } { d x ^ { k } } } .\tag{9.39b}
$$

If the coeficients $a _ { i }$ are constants, then $P _ { n } ( D )$ is a usual polynomial in the operator D of degree n.

$$

$$
P _ { n } ( r ) = r ^ { n } + a _ { 1 } r ^ { n - 1 } + a _ { 2 } r ^ { n - 2 } + \cdots + a _ { n - 1 } r + a _ { n } = 0 .\tag{9.40b}
$$

If a root $r _ { i }$ has a higher multiplicity $k ,$ , then $x e ^ { r _ { i } x } , x ^ { 2 } e ^ { r _ { i } x } , \ldots , x ^ { k - 1 } e ^ { r _ { i } x }$ are also solutions. $$

In this case, for $r _ { 1 } = \alpha + \mathrm { i } \beta$ and $r _ { 2 } = \alpha - \mathrm { i } \beta$ one can replace the corresponding complex solution functions $e ^ { r _ { 1 } x }$ and $e ^ { r _ { 2 } x }$ by the real functions αx $e ^ { \alpha x }$ cos βx and $e ^ { \bar { \alpha } x }$ sin $_ { \beta x }$ The resulting expression $C _ { 1 } \cos \beta x + C _ { 2 }$ sin βx can be written in the form $A \cos ( \beta x + \varphi )$ with some constants A and $\varphi .$

3. Hurwitz Theorem

In diferent applications, e.g., in vibration theory, it is important to know whether a solution of a given homogeneous diferential equation with constant coeficients tend to zero for $x \to + \infty$ or not. It tends to zero, obviously, if the real parts of the roots of the characteristic equation (9.40b) are negative. According to the Hurwitz theorem an equation

$$
a _ { n } x ^ { n } + a _ { n - 1 } x ^ { n - 1 } + \dots + a _ { 1 } x + a _ { 0 } = 0\tag{9.41a}
$$

has only roots with negative real part if and only if all the determinants

$$
D _ { 1 } = a _ { 1 } , \quad D _ { 2 } = { \left| \begin{array} { l l } { a _ { 1 } \ a _ { 0 } } \\ { a _ { 3 } \ a _ { 2 } } \end{array} \right| } , \quad D _ { 3 } = { \left| \begin{array} { l l } { a _ { 1 } \ a _ { 0 } \ 0 } \\ { a _ { 3 } \ a _ { 2 } \ a _ { 1 } } \\ { a _ { 5 } \ a _ { 4 } \ a _ { 3 } } \end{array} \right| } , \ldots , \quad D _ { n } = { \left| \begin{array} { l l l l } { a _ { 1 } \ a _ { 0 } \ 0 } & { \ldots \ 0 } \\ { a _ { 3 } \ a _ { 2 } \ a _ { 1 } \ \ldots \ 0 } \\ { \ldots \ldots \ldots \ldots \ldots } \\ { 0 \ 0 } & { 0 } & { \ldots \ a _ { n } } \end{array} \right| }
$$

$$
( \mathrm { w i t h } \ a _ { m } = 0 \quad \mathrm { f o r } \quad m > n )\tag{9.41b}
$$

are positive. The determinants $D _ { k }$ have on their diagonal the coeficients $a _ { 1 } , a _ { 2 } , \ldots , a _ { k } \ ( k = 1 , 2 , \ldots , n )$ and the coeficient-indices are decreasing from left to right. Coeficients with negative indices and also with indices larger than n are all put to 0.

For a cubic polynomial the determinants have in accordance to (9.41b) the following form:

3. Euler Diferential Equation

The Euler diferential equation

$$
\sum _ { k = 0 } ^ { n } a _ { k } ( c x + d ) ^ { k } y ^ { ( k ) } = F ( x )\tag{9.44a}
$$

can be transformed with the substitution

$$
c x + d = e ^ { t }\tag{9.44b}
$$

into a linear diferential equation with constant coeficients.

The diferential equation $x ^ { 2 } y ^ { \prime \prime } - 5 x y ^ { \prime } + 8 y = x ^ { 2 }$ is a special case of the Euler diferential equation for $n = 2$ .
