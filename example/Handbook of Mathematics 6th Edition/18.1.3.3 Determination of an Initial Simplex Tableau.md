##### 18.1.3.3 Determination of an Initial Simplex Tableau

1. Secondary Program, Artificial Variables

If there are equalities among the original constraints (18.1b) or inequalities with negative $b _ { i } .$ then it is not easy to find a feasible solution to start the simplex method. In this case, one starts with a secondary program to produce a feasible solution, which can be a starting point for a simplex procedure for the original problem. The system $\mathbf { A } \mathbf { \underline { { x } } } = \mathbf { \underline { { b } } }$ is modified by multiplying some of the equations with $( - 1 )$ in order to satisfy the condition $\mathbf { b } \geq \mathbf { 0 }$ . Now, an artificial variable $y _ { k } \ge 0 ( k = 1 , 2 , \ldots , m )$ is added to every left-hand side of $\mathbf { A } \underline { { \mathbf { x } } } = \underline { { \mathbf { b } } } \mathrm { w i t h } \underline { { \mathbf { b } } } \geq \underline { { \mathbf { 0 } } }$ , and the secondary program is considered:

$$
\mathbf { O F ^ { * } } \colon g ( \underline { { \mathbf { x } } } , \underline { { \mathbf { y } } } ) = - y _ { 1 } - \cdot \cdot \cdot - y _ { m } = \operatorname* { m a x } !\tag{18.18a}
$$

CT∗:

$$
\left. { \begin{array} { l c c } { a _ { 1 , 1 } x _ { 1 } + \cdot \cdot \cdot + \ a _ { 1 , n } x _ { n } + y _ { 1 } } & { = b _ { 1 } , } \\ { \vdots } & { \vdots } & { \ddots } \\ { a _ { m , 1 } x _ { 1 } + \cdot \cdot \cdot + a _ { m , n } x _ { n } } & { + y _ { m } = b _ { m } , } \\ { x _ { 1 , \cdot \cdot \cdot , } x _ { n } \geq 0 ; \ y _ { 1 } , \ldots , y _ { m } \geq 0 . } \end{array} } \right\}\tag{18.18b}
$$

For this problem, the variables $y _ { 1 } , \ldots , y _ { m }$ are basic variables, and one can start the first simplex tableau (Scheme 18.5). The last row of the tableau contains the sums of the coeficients of the non-basic variables , and these sums are the coeficients of the new secondary objective function $\mathbf { O F ^ { * } }$ . Obviously, $g ( \underline { { \mathbf { x } } } , \underline { { \mathbf { y } } } ) ~ \leq ~ 0$ always. If $g ( \underline { { \mathbf { x } } } ^ { * } , \mathbf { y } ^ { * } ) = \ 0$ for a maximal point $\left( \underline { { \mathbf { x } } } ^ { * } , \mathbf { y } ^ { * } \right)$ of the secondary problem, then obviously $\mathbf { y } ^ { * } = 0 ,$ , and consequently $\underline { { \mathbf { x } } } ^ { * }$ is a solution of $\mathbf { A } \mathbf { x } = \mathbf { b }$ . If $g ( \underline { { \mathbf { x } } } ^ { * } , \underline { { \mathbf { y } } } ^ { * } ) < 0$ , then $\mathbf { A } \mathbf { x } = \mathbf { \underline { { b } } }$ does not have any solution.

2. Solution of the Secondary Program

Our goal is to eliminate the artificial variables from the basis. A scheme is prepared not only for the secondary program separately. The original tableau is completed by columns of the artificial variables and the row of the secondary objective function. The secondary objective function now contains the sums of the corresponding coeficients from the rows corresponding to the equalities, as shown below. If an artificial variable becomes a non-basic variable, its column can be omitted, since it will be never chosen again as a basis variable. If a maximal point $\left( \underline { { \mathbf { x } } } ^ { * } , \underline { { \mathbf { y } } } ^ { * } \right)$ is determined, then two cases are distin guished:

1. $g ( \underline { { \mathbf { x } } } ^ { * } , \mathbf { y } ^ { * } ) < 0 \mathrm { : }$ The system $\mathbf { A } \mathbf { \underline { { x } } } = \mathbf { \underline { { b } } }$ has no solution, the linear programming problem does not have any feasible solution.

2. $g ( \underline { { \mathbf { x } } } ^ { * } , \mathbf { y } ^ { * } ) = 0 \ :$ : If there are no artificial variables among the basic variables, this tableau is an initial tableau for the original problem. Otherwise all artificial variables among the basic variables are removed by additional steps of the simplex method.

By introducing the artificial variables, the size of the problem can be increased considerably. It is not necessary to introduce artificial variables for every equation. If the system of constraints before introducing the slack and surplus variables (see Remark in 18.1.2, 3., p. 913) has the form $\mathbf { A } _ { 1 } \underline { { \mathbf { x } } } \geq \underline { { \mathbf { b } } } _ { 1 }$ $\mathbf { A } _ { 2 } \mathbf { \underline { { x } } } = \mathbf { \underline { { b } } } _ { 2 } , \mathbf { A } _ { 3 } \mathbf { \underline { { x } } } \leq \mathbf { \underline { { b } } } _ { 3 }$ with $\underline { { \mathbf { b } } } _ { 1 } , \underline { { \mathbf { b } } } _ { 2 } , \underline { { \mathbf { b } } } _ { 3 } \geq 0$ , then artificial variables must be introduced only for the first two systems. For the third system the slack variables can be chosen as basic variables.

In the example of 18.1.2, p. 912, only the first equation requires an artificial variable:

$$
\begin{array} { r l r } { { \bf O } { \bf F } ^ { * } \colon } & { g ( { \bf x } , { \bf \underline { { y } } } ) = } & { - y _ { 1 } \qquad = \mathrm { m a x l } } \\ { { \bf C } { \bf T } ^ { * } \colon } & { x _ { 1 } + } & { x _ { 2 } + } & { x _ { 3 } - x _ { 4 } + y _ { 1 } \qquad = 1 , } \\ & { } & { x _ { 2 } \qquad \quad + x _ { 5 } \qquad = 2 , } \\ & { } & { - x _ { 1 } \qquad + 2 x _ { 3 } \qquad \quad + x _ { 6 } \qquad = 2 , } \\ & { } & { 2 x _ { 1 } - 3 x _ { 2 } + 2 x _ { 3 } \qquad \quad + x _ { 7 } = 2 . } \end{array}
$$

The tableau (Scheme 18.6b) is optimal with $g ( \underline { { \mathbf { x } } } ^ { * } , \mathbf { y } ^ { * } ) = 0$ . After omitting the second column the first tableau of the original problem is obtained.
