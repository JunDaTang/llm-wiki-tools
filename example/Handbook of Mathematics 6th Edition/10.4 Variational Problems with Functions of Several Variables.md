### 10.4 Variational Problems with Functions of Several Variables

One of the simplest problems with a function of several variables is the following variational problem for a double integral:

$$
I [ u ] = \int \int _ { ( G ) } F ( x , y , u ( x , y ) , u _ { x } , u _ { y } ) d x d y = { \mathrm { e x t r e m e l } } .\tag{10.44}
$$

The unknown function $u \ : = \ : u ( x , y )$ should take given values on the boundary Γ of the domain G. Analogously to 10.3.2, p. 612, a comparable function is to be introduced in the form

$$
u ( x , y ) = u _ { 0 } ( x , y ) + \epsilon \eta ( x , y ) ,\tag{10.45}
$$

where $u _ { 0 } ( x , y )$ is a solution of the variational problem (10.44), which takes the given boundary values, while $\eta ( x , y )$ satisfies the condition

$$
\eta ( x , y ) = 0 \quad \mathrm { o n t h e b o u n d a r y } \ : { \cal T } .\tag{10.46}
$$

$\eta ( x , y )$ together with $u _ { 0 } ( x , y )$ both are diferentiable as many times as needed. The quantity  is a parameter.

Next, a surface is to be determined by $u = u ( x , y )$ , which is close to the solution surface $u _ { 0 } ( x , y ) . ~ I [ u ]$ becomes $I ( \epsilon )$ with (10.45), i.e., the variational problem (10.44) becomes an extreme value problem which must satisfy the necessary conditions

$$
\frac { d I } { d \epsilon } = 0 \qquad \mathrm { f o r } \quad \epsilon = 0 .\tag{10.47}
$$

From this follows the Euler diferential equation

$$
\frac { \partial F } { \partial u } - \frac { \partial } { \partial x } \left( \frac { \partial F } { \partial u _ { x } } \right) - \frac { \partial } { \partial y } \left( \frac { \partial F } { \partial u _ { y } } \right) = 0\tag{10.48}
$$

as a necessary condition for the solution of the variational problem (10.44).

A free membrane, fixed at the perimeter Γ of a domain G in the x, y plane, covers a surface with area

$$
I _ { 1 } = \iint _ { ( G ) } d x d y .\tag{10.49a}
$$

If the membrane is deformed by a load so that every point has an elongation $u \ : = \ : u ( x , y )$ in the $z -$ direction, then its area is calculated by the formula

$$
I _ { 2 } = \iint _ { ( G ) } \sqrt { 1 + u _ { x } ^ { 2 } + u _ { y } ^ { 2 } } d x d y .\tag{10.49b}
$$

Linearizing the integrand in (10.49b) and using Taylor series (see 6.2.2.3, p. 449), one gets the relation

$$
I _ { 2 } \approx I _ { 1 } + \frac { 1 } { 2 } \int _ { ( G ) } \int _ { } \left( u _ { x } ^ { 2 } + u _ { y } ^ { 2 } \right) d x d y .\tag{10.49c}
$$

For the potential energy U of the deformed membrane holds

$$
U = \sigma ( I _ { 2 } - I _ { 1 } ) = \frac { \sigma } { 2 } \iint _ { ( G ) } \left( u _ { x } ^ { 2 } + u _ { y } ^ { 2 } \right) d x d y ,\tag{10.49d}
$$

where the constant $\sigma$ denotes the tension of the membrane. In this way arises the so-called Dirichlet variational problem: The function $u = u ( x , y )$ is to be determined so that the functional

$$
I [ u ] = \iint _ { ( G ) } \left( u _ { x } ^ { 2 } + u _ { y } ^ { 2 } \right) d x d y\tag{10.49e}
$$

should have an extremum, and u vanishes on the boundary Γ of the plane domain G. The corresponding Euler diferential equation is

$$
{ \frac { \partial ^ { 2 } u } { \partial x ^ { 2 } } } + { \frac { \partial ^ { 2 } u } { \partial y ^ { 2 } } } = 0 .\tag{10.49f}
$$

It is the Laplace diferential equation for functions of two variables (see 13.5.1, p. 729).
