##### 9.1.2.3 Linear n-th Order Differential Equations

1. Classification

A diferential equation of the form

$$
y ^ { ( n ) } + a _ { 1 } y ^ { ( n - 1 ) } + a _ { 2 } y ^ { ( n - 2 ) } + \cdot \cdot \cdot + a _ { n - 1 } y ^ { \prime } + a _ { n } y = F\tag{9.32}
$$

is called an n-th order linear diferential equation. Here $F$ and the coeficients $a _ { i }$ are functions of $x ,$ which are supposed to be continuous in a certain interval. If $a _ { 1 } , a _ { 2 } , \ldots , a _ { n }$ are constants, it is called a diferential equation with constant coeficients. If $F \equiv 0$ , then the linear diferential equation is homogeneous, and if $F \neq 0$ , then it is inhomogeneous.

2. Fundamental System of Solutions

A system of n solutions $y _ { 1 } , y _ { 2 } , \ldots , y _ { n }$ of a homogeneous linear diferential equation is called a fundamental system if these functions are linearly independent on the considered interval, i.e., their linear combination $C _ { 1 } y _ { 1 } + C _ { 2 } y _ { 2 } + \cdot \cdot \cdot + C _ { n } y _ { n }$ is not identically zero for any system of values $C _ { 1 } , C _ { 2 } , \ldots , C _ { n } .$ except for the values $C _ { 1 } = C _ { 2 } = \cdot \cdot \cdot = C _ { n } = 0$ . The solutions $y _ { 1 } , y _ { 2 } , \ldots , y _ { n }$ of a linear homogeneous differential equation form a fundamental system on the considered interval if and only if their Wronskian determinant

$$
W = { \left| \begin{array} { l l l l } { y _ { 1 } } & { y _ { 2 } } & { \cdot \cdot \cdot y _ { n } } \\ { { y _ { 1 } } ^ { \prime } } & { { y _ { 2 } } ^ { \prime } } & { \cdot \cdot \cdot y _ { n } { \mathrm { ' } } } \\ { \cdot \ \cdot \ \cdot \ \cdot \ \ \cdot \ \ \ \cdot \ \ \ \cdot \ \ \ \ \cdot \ \ \ \ \cdot \ \ \ \ \ \cdot \ \ \ \ \ \cdot \ \ \ \ \ \cdot } \\ { { y _ { 1 } } ^ { ( n - 1 ) } \ { y _ { 2 } } ^ { ( n - 1 ) } \ \cdot \cdot \cdot \ \cdot \ y _ { n } { ( n - 1 ) } } \end{array} \right| }\tag{9.33}
$$

is non-zero. For every solution system of a homogeneous linear diferential equation the formula of Liouville

$$
W ( x ) = W ( x _ { 0 } ) \exp \left( - \intop _ { x _ { 0 } } ^ { x } a _ { n - 1 } ( x ) d x \right) .\tag{9.34}
$$

It follows from (9.34) that if the Wronskian determinant is zero somewhere in the solution interval, then it can be only identically zero. This means: The n solutions $y _ { 1 } , y _ { 2 } , \ldots , y _ { n }$ of the homogeneous linear diferential equation are linearly dependent if even for a single point $x _ { 0 }$ of the considered interval $W ( x _ { 0 } ) = 0$ . If the solutions $y _ { 1 } , y _ { 2 } , \ldots , y _ { n }$ form a fundamental system of the diferential equation, then the general solution of the linear homogeneous diferential equation (9.32) is given as

$$
y = C _ { 1 } y _ { 1 } + C _ { 2 } y _ { 2 } + \cdot \cdot \cdot + C _ { n } y _ { n } .\tag{9.35}
$$

A linear n-th order homogeneous diferential equation has exactly n linearly independent solutions on an interval, where the coeficient functions $a _ { i } ( x )$ are continuous.

3. Lowering the Order

If a particular solution $y _ { 1 }$ of a homogeneous diferential equation is known, by assuming

$$
y = y _ { 1 } ( x ) u ( x )\tag{9.36}
$$

one can determine further solutions from a homogeneous linear diferential equation of order $n - 1$ for $u ^ { \prime } ( x )$

4. Superposition Principle

If $y _ { 1 }$ and $y _ { 2 }$ are two solutions of the diferential equation (9.32) for diferent right-hand sides $F _ { 1 }$ and $F _ { 2 }$ , then their sum $y = y _ { 1 } + y _ { 2 }$ is a solution of the same diferential equation with the right-hand side $F = F _ { 1 } + F _ { 2 }$ . From this observation it follows that to get the general solution of an inhomogeneous diferential equation it is suficient to add any particular solution of the inhomogeneous diferential equation to the general solution of the corresponding homogeneous diferential equation.

5. Decomposition Theorem

If an inhomogeneous diferential equation (9.32) has real coeficients and its right-hand side is complex in the form $\bar { F } = F _ { 1 } + \mathrm { i } F _ { 2 }$ with some real functions $F _ { 1 }$ and $F _ { 2 }$ , then the solution $y = y _ { 1 } + \mathrm { i } y _ { 2 }$ is also complex, where $y _ { 1 }$ and $y _ { 2 }$ are the two solutions of the two inhomogeneous diferential equations (9.32) with the corresponding right-hand sides $F _ { 1 }$ and $F _ { 2 }$

6. Solution of Inhomogeneous Diferential Equations (9.32) by Means of Quadratures

If the fundamental system of the corresponding homogeneous diferential equation is already known, there are the following two solution methods to continue the calculations:

$$

$$

$$

$$
