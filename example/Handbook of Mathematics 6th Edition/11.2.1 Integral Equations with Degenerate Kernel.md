#### 11.2.1 Integral Equations with Degenerate Kernel

If the kernel $K ( x , y )$ ofan integral equation is the finite sum of products of two functions of one variable, i.e., one depends only on x and the other one only on $y ,$ , it is called a degenerate kernel or a product kernel.

1. Solution in the Case of a Degenerate Kernel

The solution of a Fredholm integral equation of the second kind with a degenerate kernel leads to the solution of a finite-dimensional system of equations. Consider the integral equation

$$
\varphi ( x ) = f ( x ) + \lambda \int _ { a } ^ { b } K ( x , y ) \varphi ( y ) d y \quad { \mathrm { w i t h } } \quad\tag{11.4a}
$$

$$
K ( x , y ) = \alpha _ { 1 } ( x ) \beta _ { 1 } ( y ) + \alpha _ { 2 } ( x ) \beta _ { 2 } ( y ) + . . . + \alpha _ { n } ( x ) \beta _ { n } ( y ) .\tag{11.4b}
$$

The functions $\alpha _ { 1 } ( x ) , \ldots , \alpha _ { n } ( x )$ and $\beta _ { 1 } ( x ) , \ldots , \beta _ { n } ( x )$ are given on the interval $[ a , b ]$ and are supposed to be continuous. Furthermore, the functions $\alpha _ { 1 } ( x ) , \ldots , \alpha _ { n } ( x )$ are supposed to be linearly independent of one another, i.e., the equality

$$
\sum _ { k = 1 } ^ { n } c _ { k } \alpha _ { k } ( x ) \equiv 0\tag{11.5}
$$

with constant coeficients $c _ { k }$ holds for every x in $[ a , b ]$ only if $c _ { 1 } = c _ { 2 } = . . . = c _ { n } = 0$ . Otherwise, $K ( x , y )$ can be expressed as the sum of a smaller number of products.   
From (11.4a) and (11.4b) follows:

$$
\varphi ( x ) = f ( x ) + \lambda \alpha _ { 1 } ( x ) \int _ { a } ^ { b } \beta _ { 1 } ( y ) \varphi ( y ) d y + . . . + \lambda \alpha _ { n } ( x ) \int _ { a } ^ { b } \beta _ { n } ( y ) \varphi ( y ) d y .\tag{11.6a}
$$

The integrals are no longer functions of the variable x, they are constant values. Let’s denote them by $A _ { k } { \mathrm { : } }$

$$
A _ { k } = \int _ { a } ^ { b } \beta _ { k } ( y ) \varphi ( y ) d y , \quad k = 1 , \ldots , n .\tag{11.6b}
$$

The solution function $\varphi ( x )$ , if any exists, is the sum of the perturbation function $f ( x )$ and a linear combination of the function $\alpha _ { 1 } ( x ) , \ldots , \alpha _ { n } ( x )$

$$
\varphi ( x ) = f ( x ) + \lambda A _ { 1 } \alpha _ { 1 } ( x ) + \lambda A _ { 2 } \alpha _ { 2 } ( x ) + . . . + \lambda A _ { n } \alpha _ { n } ( x ) .\tag{11.6c}
$$

2. Calculation of the Coeficients of the Solution

The coeficients $A _ { 1 } , \ldots , A _ { n }$ are calculated as follows. Equation (11.6c) is multiplied by $\beta _ { k } ( x )$ and its integral is calculated with respect to x with the limits a and $b \colon$

$$
\int _ { a } ^ { b } \beta _ { k } ( x ) \varphi ( x ) d x = \int _ { a } ^ { b } \beta _ { k } ( x ) f ( x ) d x + \lambda A _ { 1 } \int _ { a } ^ { b } \beta _ { k } ( x ) \alpha _ { 1 } ( x ) d x + . . . + \lambda A _ { n } \int _ { a } ^ { b } \beta _ { k } ( x ) \alpha _ { n } ( x ) d x .\tag{11.7a}
$$

The left-hand side of this equation is equal to $A _ { k }$ according to (11.6b). Using the following notation

$$
b _ { k } = \int _ { a } ^ { b } \beta _ { k } ( x ) f ( x ) d x \quad { \mathrm { a n d } } \quad c _ { k j } = \int _ { a } ^ { b } \beta _ { k } ( x ) \alpha _ { j } ( x ) d x\tag{11.7b}
$$

there is for $k = 1 , \dots , n \colon$

$$
A _ { k } = b _ { k } + \lambda c _ { k 1 } A _ { 1 } + \lambda c _ { k 2 } A _ { 2 } + . . . + \lambda c _ { k n } A _ { n } .\tag{11.7c}
$$

It is possible that the exact values of the integrals in (11.7b) cannot be calculated. When this is the case, their approximate values must be calculated by one of the formulas given in 19.3, p. 963. The linear system of equations (11.7c) contains n equations for the unknown values $A _ { 1 } , \ldots , A _ { n } ;$

$$
\begin{array} { r l r } {  { ( 1 - \lambda c _ { 1 1 } ) A _ { 1 } } } & { - \lambda c _ { 1 2 } A _ { 2 } - \ldots } & { - \lambda c _ { 1 n } A _ { n } = b _ { 1 } , } \\ & { } & { - \lambda c _ { 2 1 } A _ { 1 } + ( 1 - \lambda c _ { 2 2 } ) A _ { 2 } - \ldots } & { - \lambda c _ { 2 n } A _ { n } = b _ { 2 } , } \\ & { } & { \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots } \\ & { } & { - \lambda c _ { n 1 } A _ { 1 } } & { - \lambda c _ { n 2 } A _ { 2 } - \ldots \ldots + ( 1 - \lambda c _ { n n } ) A _ { n } = b _ { n } . } \end{array}\tag{11.7d}
$$

3. Analyzing the Solution, Eigenvalues and Eigenfunctions

It is known from the theory of linear systems of equations that (11.7d) has one and only one solution for $A _ { 1 } , \ldots , A _ { n }$ if the determinant of the matrix of the coeficients is not equal to zero, i.e.,

$$
\begin{array} { r } { \mathrm { D } ( \lambda ) = \left| \begin{array} { c c c c c } { ( 1 - \lambda c _ { 1 1 } ) } & { - \lambda c _ { 1 2 } } & { . . . } & { - \lambda c _ { 1 n } } \\ { - \lambda c _ { 2 1 } } & { ( 1 - \lambda c _ { 2 2 } ) } & { . . . } & { - \lambda c _ { 2 n } } \\ { . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . } \\ { - \lambda c _ { n 1 } } & { - \lambda c _ { n 2 } } & { . . . } & { ( 1 - \lambda c _ { n n } ) } \end{array} \right| \ne 0 . } \end{array}\tag{11.8}
$$

So there is a number $R > 0$ such that $D ( \boldsymbol { \lambda } ) \neq \tilde { 0 } \mathrm { i f } | \dot { \boldsymbol { \lambda } } | ^ { \prime } < R$ . For further investigation two diferent cases are considered.

$$
\mathbf { D } ( \boldsymbol { \lambda } ) \neq \mathbf { 0 } \colon
$$

The integral equation has exactly one solution in the form (11.6c), and the coeficients $A _ { 1 } , \ldots , A _ { n }$ are given by the solution of the system of equations (11.7d). If (11.4a) is a homogeneous integral equation, $\operatorname { i . e . , } f ( x ) \equiv 0$ , then $b _ { 1 } = b _ { 2 } = \ldots = b _ { n } = 0$ . Then the homogeneous system of equations (11.7d) has only the trivial solution $A _ { 1 } = A _ { 2 } = \ldots = A _ { n } = 0$ . In this case only the function $\varphi ( x ) \equiv 0$ satisfies the integral equation.

Case D(λ) = 0:

D(λ) is a polynomial of no higher than n-th degree, so it can have at most n roots. For these values of λ the homogeneous system of equations (11.7d) with $b _ { 1 } = b _ { 2 } = \ldots = b _ { n } = 0$ also has non-trivial solutions, so besides the trivial solution $\varphi ( \dot { x } ) \equiv 0$ the homogeneous system of equations has other solutions of the form

$$
\varphi ( x ) = C \cdot ( A _ { 1 } \alpha _ { 1 } ( x ) + A _ { 2 } \alpha _ { 2 } ( x ) + \ldots + A _ { n } \alpha _ { n } ( x ) ) \quad ( C { \mathrm { ~ i s ~ a n ~ a r b i t r a r y ~ c o n s t a n t . } } )
$$

Because $\alpha _ { 1 } ( x ) , \ldots , \alpha _ { n } ( x )$ are linearly independent, $\varphi ( x )$ is not identically zero. The roots of D(λ) are called the eigenvalues of the integral equation. The corresponding non-vanishing solutions of the homogeneous integral equation are called the eigenfunctions belonging to the eigenvalue λ. Several linearly independent eigenfunctions can belong to the same eigenvalue. If the integral equation has a general kernel, then are be to considered all values of λ eigenvalues, for which the homogeneous integral equation has non-trivial solutions. Some authors call the λ with $\dot { \mathrm { D } } ( \lambda ) = 0$ the characteristic number, and $\mu = \frac { 1 } { \lambda }$ is called the eigenvalue corresponding to an equation form $\mu \varphi ( x ) = \int _ { a } ^ { b } K ( x , y ) \varphi ( y ) d y .$

4. Transposed Integral Equation

Now it is necessary to investigate the conditions under which the inhomogeneous integral equation will have solutions if $\dot { \mathrm { D } } ( \lambda ) = 0$ . For this purpose the transposed integral equation (or adjoint in the complex case) of (11.4a) is introduced:

$$
\psi ( x ) = g ( x ) + \lambda \intop _ { a } ^ { b } K ( y , x ) \psi ( y ) d y .\tag{11.9a}
$$

Let λ be an eigenvalue and $\varphi ( x )$ a solution of the inhomogeneous integral equation (11.4a). It is easy to show that λ is also an eigenvalue of the adjoint equation. Now multiply both sides of (11.4a) by any

solution $\psi ( x )$ of the homogeneous adjoint integral equation and evaluate the integral with respect to x between the limits a and b:

$$
\int _ { a } ^ { b } \varphi ( x ) \psi ( x ) d x = \int _ { a } ^ { b } f ( x ) \psi ( x ) d x + \int _ { a } ^ { b } \left( \lambda \int _ { a } ^ { b } K ( x , y ) \psi ( x ) d x \right) \varphi ( y ) d y .\tag{11.9b}
$$

That is: The inhomogeneous integral equation (11.4a) has a solution for some eigenvalue λ if and only if the perturbation function $f ( x )$ is orthogonal to every non-vanishing solution of the homogeneous adjoint integral equation belonging to the same λ.
