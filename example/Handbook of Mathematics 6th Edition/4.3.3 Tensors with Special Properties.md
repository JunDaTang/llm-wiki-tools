#### 4.3.3 Tensors with Special Properties

##### 4.3.3.1 Tensors of Rank 2

1. Rules of Calculation

For tensors of rank 2 the same rules are valid as for matrices. In particular, every tensor T can be decomposed into the sum of a symmetric and a skew-symmetric tensor:

$$
{ \pmb T } = \frac { 1 } { 2 } \left( { \pmb T } + { \pmb T } ^ { \mathrm { T } } \right) + \frac { 1 } { 2 } \left( { \pmb T } - { \pmb T } ^ { \mathrm { T } } \right) .\tag{4.77a}
$$

A tensor $\textbf { \textit { T } } = ( t _ { i j } )$ is called symmetric if

$$
t _ { i j } = t _ { j i } \qquad { \mathrm { f o r ~ a l l ~ } } i { \mathrm { ~ a n d ~ } } j\tag{4.77b}
$$

holds. In the case

$$
t _ { i j } = - t _ { j i } \qquad { \mathrm { f o r ~ a l l ~ } } i { \mathrm { ~ a n d ~ } } j\tag{4.77c}
$$

it is called skew- or antisymmetric. Obviously the elements $t _ { 1 1 } , t _ { 2 2 }$ and $t _ { 3 3 }$ of a skew-symmetric tensor are equal to zero. The notion of symmetry and antisymmetry can be extended for tensors of higher rank if refering to certain pairs of elements.

2. Transformation of Principal Axes

For a symmetric tensor T, i.e., if $t _ { \mu \nu } = t _ { \nu \mu }$ holds, there is always an orthogonal transformation D such that after the transformation the tensor has a diagonal form:

$$
\tilde { T } = \left( \begin{array} { c c c } { { \tilde { t } _ { 1 1 } } } & { { 0 } } & { { 0 } } \\ { { 0 } } & { { \tilde { t } _ { 2 2 } } } & { { 0 } } \\ { { 0 } } & { { 0 } } & { { \tilde { t } _ { 3 3 } } } \end{array} \right) .\tag{4.78a}
$$

The elements $\tilde { t } _ { 1 1 } , \tilde { t } _ { 2 2 }$ and $\tilde { t } _ { 3 3 }$ are called the eigenvalues ofthe tensor T. They are equal to the roots $\lambda _ { 1 }$ $\lambda _ { 2 }$ and $\lambda _ { 3 }$ of the algebraic equation of third degree in λ:

$$
\left| \begin{array} { c c c } { t _ { 1 1 } - \lambda } & { t _ { 1 2 } } & { t _ { 1 3 } } \\ { t _ { 2 1 } } & { t _ { 2 2 } - \lambda } & { t _ { 2 3 } } \\ { t _ { 3 1 } } & { t _ { 3 2 } } & { t _ { 3 3 } - \lambda } \end{array} \right| = 0 .\tag{4.78b}
$$

<sub>The column vectors</sub> $\underline { { \mathbf { d } } } _ { 1 } , \underline { { \mathbf { d } } } _ { 2 }$ <sub>and</sub> $\mathbf { d } _ { 3 }$ of the transformation matrix D are called the eigenvectors corresponding to the eigenvalues, and they satisfy the equations

$$
T \underline { { { \bf d } } } _ { \nu } = \lambda _ { \nu } \underline { { { \bf d } } } _ { \nu } \qquad ( \nu = 1 , 2 , 3 ) .\tag{4.78c}
$$

Their directions are called the directions of the principal axes, and the transformation T to diagona form is called the transformation ofthe principal axes.

##### 4.3.3.2 Invariant Tensors

1. Definition

A Cartesian tensor is called invariant if its components are the same in all Cartesian coordinate systems. Physical quantities such as scalars and vectors, which are special tensors, do not depend on the coordinate system in which they are determined; they must not change their value either under translation of the origin or rotation of a coordinate system K. One talks about translation invariance and about rotation invariance or in general about transformation invariance.

2. Generalized Kronecker Delta or Delta Tensor

If the elements $t _ { i j }$ of a tensor of rank 2 are the Kronecker symbols, i.e.,

$$
t _ { i j } = \delta _ { i j } = \left\{ \begin{array} { l l } { \begin{array} { r l } { 1 } & { { } \mathrm { ~ f o r ~ } i = j , } \\ { 0 } & { { } \mathrm { ~ o t h e r w i s e } , } \end{array} } \end{array} \right.\tag{4.79a}
$$

then from the transformation law (4.71b) in the case of a rotation of the coordinate system considering (4.68c) follows

$$
\tilde { t } _ { \mu \nu } = d _ { \mu i } d _ { \nu j } = \delta _ { \mu \nu } ,\tag{4.79b}
$$

i.e., the elements are rotation invariant. Putting them into a coordinate system so that they are independent of the choice of the origin, i.e., they will be translation invariant, then the numbers $\delta _ { i j }$ form a tensor of rank 2, the so-called generalized Kronecker delta or delta tensor.

3. Alternating Tensor

If $\vec { e _ { i } } , \vec { e _ { j } }$ and $\vec { e } _ { k }$ are unit vectors in the directions of the axes of a right-angle coordinate system, then for the mixed product (see 3.5.1.6, 2., p. 185) holds

$$
\epsilon _ { i j k } = \vec { e } _ { i } \left( \vec { e } _ { j } \times \vec { e } _ { k } \right) = \left\{ \begin{array} { r l } { 1 , } & { \mathrm { ~ i f ~ } i , j , k \mathrm { ~ c y c l i c ~ ( r i g h t \mathrm { - } h a n d ~ r u l e ) } , } \\ { - 1 , } & { \mathrm { ~ i f ~ } i , j , k \mathrm { ~ a n t i c y c l i c } , } \\ { 0 , } & { \mathrm { ~ o t h e r w i s e } . } \end{array} \right.\tag{4.80a}
$$

Altogether there are $3 ^ { 3 } = 2 7$ elements, which are the elements of a tensor of rank 3. In the case of a rotation of the coordinate system from the transformation law (4.69) it follows that

$$
\tilde { t } _ { \mu \nu \rho } = d _ { \mu i } d _ { \nu j } d _ { \rho k } \epsilon _ { i j k } = { \left| \begin{array} { l l } { d _ { \mu 1 } \ d _ { \nu 1 } \ d _ { \rho 1 } } \\ { d _ { \mu 2 } \ d _ { \nu 2 } \ d _ { \rho 2 } } \\ { d _ { \mu 3 } \ d _ { \nu 3 } \ d _ { \rho 3 } } \end{array} \right| } = \epsilon _ { \mu \nu \rho } ,\tag{4.80b}
$$

i.e., the elements are rotation invariant. Putting them into a coordinate system so that they are independent of the choice of the origin, i.e., they are translation invariant, then the numbers $\epsilon _ { i j k }$ form a tensor of rank 3, the so-called alternating tensor.

4. Tensor Invariants

There must not be a confusion between tensor invariants and invariant tensors. Tensor invariants are functions of the components of tensors whose forms and values do not change during the rotation of the coordinate system.

A: If for instance the tensor $\mathbf { \nabla } T = \left( t _ { i j } \right)$ is transformed in $\tilde { \pmb { T } } = ( \tilde { t } _ { i j } )$ by a rotation, then the trace (spur) of it does not change:

$$
\mathrm { T r } ( { \pmb T } ) = t _ { 1 1 } + t _ { 2 2 } + t _ { 3 3 } = \tilde { t } _ { 1 1 } + \tilde { t } _ { 2 2 } + \tilde { t } _ { 3 3 } .\tag{4.81}
$$

The trace of the tensor T is equal to the sum of the eigenvalues (see 4.1.2, 4., p. 270).

B: For the determinant of the tensor $\mathbf { \nabla } T = ( t _ { i j } )$

$$
\left| \begin{array} { l } { t _ { 1 1 } \ t _ { 1 2 } \ t _ { 1 3 } } \\ { t _ { 2 1 } \ t _ { 2 2 } \ t _ { 2 3 } } \\ { t _ { 3 1 } \ t _ { 3 2 } \ t _ { 3 3 } } \end{array} \right| = \left| \begin{array} { l } { \tilde { t } _ { 1 1 } \ \tilde { t } _ { 1 2 } \ \tilde { t } _ { 1 3 } } \\ { \tilde { t } _ { 2 1 } \ \tilde { t } _ { 2 2 } \ \tilde { t } _ { 2 3 } } \\ { \tilde { t } _ { 3 1 } \ \tilde { t } _ { 3 2 } \ \tilde { t } _ { 3 3 } } \end{array} \right|\tag{4.82}
$$

is valid. The determinant of the tensor is equal to the product of the eigenvalues.
