#### 20.2.2 Types of Numbers in Mathematica

##### 20.2.2.1 Basic Types ofNumbers

Mathematica knows four types of numbers represented in Table 20.1.

Table 20.1 Types of numbers in Mathematica
<table><tr><td>Type of number</td><td>Head</td><td>Characteristic</td><td>Input</td></tr><tr><td>Integers Rational numbers Real numbers</td><td>Integer Rational Real</td><td>exact integer, arbitrarily long fraction of coprimes in form Integer/Integer floating-point number, arbitrary given precision</td><td>nnnnn pppp/qqqq nnnn.mmmm</td></tr></table>

Real numbers, i.e., floating-point numbers, can be arbitrarily long. If an integer nnn is written in the form nnn., then Mathematica considers it as a floating-point number, that is, of type Real. The type of a number x can be determined with the command Head[x]. Hence, In[1] := Head[51] results in Out[1] = Integer, while In[2] := Head[51.] Out[2] = Real. The real and imaginary components of a complex number can belong to any type of numbers. A number such as 5.731 + 0 I is considered as a Real type by Mathematica, while 5.731 + 0. I is of type Complex, since 0. is considered as a floating-point approximation of 0.

There are some further operations, which give information about numbers. So,

$$
\mathtt { I n } [ 3 ] : = \mathtt { N u m b e r Q [ 5 1 ] } \mathrm { ~ r e s u l t s ~ i n ~ } O u t \ : [ 3 ] = \mathtt { T r u e } ,\tag{20.5a}
$$

Otherwise, if x is manifestly not a number, as $\mathrm { e . g . ~ } x = \pi$ , then the output is Out[3] =False. However, NumericQ[π] gives True. Here, True and False are the symbols for Boolean constants.

IntegerQ[x] tests if x is an integer, or not, so

$$
{ \cal I } n [ 4 ] : = \mathrm { I n t e g e r Q [ 2 . ] } \longrightarrow { \cal O } u t [ 4 ] = \mathrm { F a l s e }\tag{20.5b}
$$

Similar tests can be performed for numbers with heads EvenQ, OddQ and PrimeQ. Their meanings are obvious. So, one gets

$$
\begin{array} { r } { I n [ 5 J : = { \mathrm { P r i m e Q } } [ 1 0 7 5 6 4 3 ] \quad \longrightarrow \quad { \cal O } u t [ 5 J = { \mathrm { T r u e } } } \end{array}\tag{20.5c}
$$

while

$$
I n [ 6 ] : = { \mathrm { P r i m e Q } } [ 1 0 7 5 6 4 1 ] \quad \longrightarrow \quad 0 u t [ 6 ] = { \mathrm { F a l s e } }\tag{20.5d}
$$

These last tests belong to a group of test operators, called predicates or criteria, which all end by Q and always answer True or False in the sense of a logical test (including a type check).

##### 20.2.2.2 Special Numbers

In Mathematica, there are some special numbers which are often needed, and they can be called with arbitrary accuracy. They include π with the symbol Pi, e with the symbol E, $\frac { \pi } { 1 8 0 ^ { \circ } }$ as the transformation factor from degree measure into radian measure with the constant Degree, Infinity as the symbol for and the imaginary unit I.

##### 20.2.2.3 Representation and Conversion of Numbers

Numbers can be represented in diferent forms which can be converted into each other. So, every real number x can be represented by a floating-point number $\mathbb { N } [ x , n ]$ with an n-digit precision.

$$
T N [ t ] : = \mathbb { N } [ E , 2 0 ] \quad { \mathrm { y i e l d s } } \quad \longrightarrow \quad O u t \underbrace { [ t ] } _ { = 2 } . 7 1 8 2 8 1 8 2 8 4 5 9 0 4 5 2 3 5 4\tag{20.6a}
$$

With Rationalize[x, dx], the number x with an accuracy dx can be converted into a rational number, i.e., into the fraction of two integers.

$$
I n [ 2 ] : = { \mathrm { R a t i o n a l i z e } } [ \% , 1 0 ^ { - } 5 ] \longrightarrow \ { \cal O } u t [ 2 ] = { \frac { 1 0 7 1 } { 3 9 4 } }\tag{20.6b}
$$

With 0 accuracy, Mathematica gives the possible best approximation of the number x by a rational number.

Numbers of diferent number systems can be converted into each other. With BaseForm[x, b], the number x given in the decimal system is converted into the corresponding number in the number system with base $b \leq 3 6 . { \mathrm { ~ I f ~ } } b > 1 0$ , then the consecutive letters of the alphabet $a , b , c , \ldots$ . are used for the further digits having a meaning greater than ten.

$$
\begin{array} { r } { \begin{array} { c c c } { \boxed { \mathrm { A } : I n \left[ { \cal { I } } { \cal { I } } \right] : = \mathrm { B a s e F o r m } [ 2 5 5 , ~ 1 6 ] } } & { } & { \longrightarrow \ { \cal { O } } u t \left[ { \cal { I } } { \cal { I } } \right] = f f _ { 1 } } \end{array} } \end{array}\tag{20.7a}
$$

$$
{ \cal I } n [ 2 { \cal J } : = \mathrm { B a s e F o r m } [ \mathrm { N } [ E , ~ 1 0 ] , ~ 8 ] \longrightarrow { \cal O } u t [ 2 { \cal J } = 2 . 5 5 7 6 0 5 2 1 3 1 _ { 8 }\tag{20.7b}
$$

The reversed transformation can be performed by $b ^ { \wedge \wedge }$ mmmm.

$$
\begin{array} { r } { \textbf { B : } T n \left[ { 1 } \bar { \lambda } \right] : = 8 ^ { \wedge \wedge } 7 3 5 \longrightarrow \ { \cal { O } } u t \left[ { 1 } \bar { \lambda } \right] = 4 7 7 } \end{array}\tag{20.7c}
$$

Numbers can be represented with arbitrary precision (the default here is the hardware precision), and for large numbers so-called scientific form is used, i.e., the form n.mmmm $\boldsymbol { \mathrm { 1 0 ^ { \wedge } \pm q q } }$
