##### 17.1.2.2 Linear Differential Equations

1. General Statements

Let $A ( t ) = [ a _ { i j } ( t ) ] _ { i , j = 1 } ^ { n }$ be a matrix function on IR , where every component $a _ { i j } \colon \mathbb { R } \to \mathbb { R }$ is a continuous function, and let $ { b \colon }  { \mathbb { R } } \to  { \mathbb { R } } ^ { n }$ be a continuous vector function on IR . Then

$$
{ \dot { x } } = A ( t ) x + b ( t )\tag{17.13a}
$$

is called an inhomogeneous linear first-order diferential equation in $\mathbb { R } ^ { n }$ , and

$$
{ \dot { x } } = A ( t ) x\tag{17.13b}
$$

is the corresponding homogeneous linear first-order diferential equation.

1. Fundamental Theorem for Homogeneous Linear Diferential Equations Every solution of (17.13a) exists on the whole of IR. The set of all solutions of (17.13b) forms an n-dimensional vector subspace $L _ { H }$ of the $C ^ { 1 }$ -smooth vector functions over IR .

2. Fundamental Theorem for Inhomogeneous Linear Diferential Equations The set of all solutions $L _ { I }$ of (17.13a) is an n-dimensional afine vector subspace of the $C ^ { 1 }$ -smooth vector functions over IR of the form $L _ { I } = \varphi _ { 0 } + L _ { H }$ , where $\varphi _ { 0 }$ is an arbitrary solution of (17.13a).

Let $\varphi _ { 1 } , \ldots , \varphi _ { n }$ be arbitrary solutions of (17.13b) and $\varPhi = [ \varphi _ { 1 } , \dots , \varphi _ { n } ]$ the corresponding solution matrix. Then $\varPhi$ satisfies the matrix diferential equation $\dot { Z } ( t ) = A ( t ) Z ( t )$ on $\mathbb { R } ,$ where $Z \in \mathbb { R } ^ { n \cdot n }$ . If the solutions $\varphi _ { 1 } , \ldots , \varphi _ { n }$ form a basis of $L _ { H }$ , then $\varPhi = [ \varphi _ { 1 } , \dots \dots , \varphi _ { n } ]$ is called the fundamental matrix of (17.13b). $\dot { W } ( t ) = \dot { \operatorname* { d e t } } \varPhi ( t )$ is the Wronskian determinant with respect to the solution matrix $\varPhi$ of (17.13b). The formula ofLiouville states that:

$$
\dot { W } ( t ) = \operatorname { r a n k } A ( t ) W ( t ) \quad ( t \in \mathbb { R } ) .\tag{17.13c}
$$

For a solution matrix, either $W ( t ) \equiv 0$ on IR or $W ( t ) \neq 0$ for all $t \in \mathbb { R }$ . The system $\varphi _ { 1 } , \ldots , \varphi _ { n }$ is a basis of $L _ { H }$ , if and only if de $[ \varphi _ { 1 } ( t ) , \ldots , \varphi _ { n } ( t ) ] \neq 0$ for a t (and so for all t).

3. Theorem (Variation of Constants Formula) Let $\varPhi$ be an arbitrary fundamental matrix of (17.13b). Then the solution $\varphi$ of (17.13a) with initial point $p$ at time $t = \tau$ can be represented in the form

$$

3. Linear Diferential Equations with Periodic Coeficients

Considered is the homogeneous linear diferential equation (17.13b), where $A ( t ) = [ a _ { i j } ( t ) ] _ { i , j = 1 } ^ { n }$ is a $T _ { - }$ periodic matrix function, i.e., $a _ { i j } ( t ) = a _ { i j } ( t + T ) \quad ( \forall t \in \mathbb { R } , \ i , j = 1 , \dots , n )$ . In this case (17.13b) is called a linear T-periodic diferential equation. Then every fundamental matrix $\varPhi$ of (17.13b) can be written in the form $\varPhi ( t ) = \tilde { G } ( t ) e ^ { t R }$ , where $G ( t )$ is a smooth, regular T-periodic matrix function and R is a constant matrix of type $( n , n )$ (Floquet’s theorem).

Let $\varPhi ( t )$ be the fundamental matrix of the T-periodic diferential equation (17.13b), normed at $t = 0$ i.e., $\varPhi ( 0 ) = E _ { n }$ , and let $\varPhi ( t ) = G ( t ) e ^ { t R }$ be a representation of it according to Floquet’s theorem. The matrix $\begin{array} { r } { \dot { \phi } ( T ) = e ^ { R T } } \end{array}$ is called the monodromy matrix of (17.13b); the eigenvalues $\rho _ { j }$ of $\varPhi ( T )$ are the multipliers of (17.13b). A number $\boldsymbol \rho \in { \bf C }$ is a multiplier of (17.13b) if and only if there exists a solution $\varphi \not \equiv 0$ of (17.13b) such that $\varphi ( t + \dot { T } ) = \rho \varphi ( t ) \quad ( t \in \mathbb { R } )$ holds.
