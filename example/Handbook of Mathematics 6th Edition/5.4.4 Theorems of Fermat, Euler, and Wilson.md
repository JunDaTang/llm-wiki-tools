#### 5.4.4 Theorems of Fermat, Euler, and Wilson

1. Euler Function

For every positive integer m with $m > 0$ one can determine the number of coprimes x with respect to m for $1 \leq x \leq m$ . The corresponding function $\varphi$ is called the Euler function. The value of the function $\varphi ( m )$ is the number of residue classes relatively prime to m $( \mathrm { s . ~ 5 . 4 . 3 , 4 . , p . 3 7 8 } )$

For instance, $\varphi ( 1 ) = 1 , \ \varphi ( 2 ) = 1 , \ \varphi ( 3 ) = 2 , \ \varphi ( 4 ) = 2 , \ \varphi ( 5 ) = 4 , \ \varphi ( 6 ) = 2 , \ \varphi ( 7 ) = 6 , \ \varphi ( 8 ) = 4 , \ \varphi ( 7 ) = 1 2 , \ \varphi ( 8 ) = 2 .$ etc. In general, $\varphi ( p ) = p - 1$ holds for every prime number p and $\varphi ( p ^ { \alpha } ) = p ^ { \alpha } - p ^ { \alpha - 1 }$ for every prime number power $p ^ { \alpha }$ . If m is an arbitrary positive integer, then $\varphi ( m )$ can be determined in the following way:

$$
\varphi ( m ) = m \prod _ { p \mid m } \left( 1 - { \frac { 1 } { p } } \right) ,\tag{5.261a}
$$

where the product applies to all prime divisors p of $m$

$$
\textstyle \varphi ( 3 6 0 ) = \varphi ( 2 ^ { 3 } \cdot 3 ^ { 2 } \cdot 5 ) = 3 6 0 \cdot ( 1 - { \frac { 1 } { 2 } } ) \cdot ( 1 - { \frac { 1 } { 3 } } ) \cdot ( 1 - { \frac { 1 } { 5 } } ) = 9 6 .
$$

Furthermore

$$
\sum _ { d \mid m } \varphi ( d ) = m\tag{5.261b}
$$

is valid. If $\operatorname* { g c d } ( m , n ) = 1$ holds, then we get $\varphi ( m n ) = \varphi ( m ) \varphi ( n )$

$$
\varphi ( 3 6 0 ) = \varphi ( 2 ^ { 3 } \cdot 3 ^ { 2 } \cdot 5 ) = \varphi ( 2 ^ { 3 } ) \cdot \varphi ( 3 ^ { 2 } ) \cdot \varphi ( 5 ) = 4 \cdot 6 \cdot 4 = 9 6 .
$$

2. Fermat-Euler Theorem

The Fermat-Euler theorem is one of the most important theorems of elementary number theory. If a and m are coprime positive numbers, then

$$
a ^ { \varphi ( m ) } \equiv 1 ( m ) .\tag{5.262}
$$

3. Wilson’s Theorem

There is a further prime number criterion, called the Wilson theorem:

Every prime number p satisfies $( p - 1 ) ! \equiv - 1 ( p )$

The inverse proposition is also true; and therefore:

The number p is a prime number if $( p - 1 ) ! \equiv - 1 ( p )$
