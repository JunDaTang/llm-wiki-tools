##### 3.5.3.4 Rotations with Direction Cosines

1. Rotation of the Coordinate Axis

If the direction cosines of the new axes are given as in Table 3.23, see also (Fig. 3.176), then for the new and old coordinates

$$
\begin{array} { r } { x ^ { \prime } = l _ { 1 } x + m _ { 1 } y + n _ { 1 } z , } \\ { y ^ { \prime } = l _ { 2 } x + m _ { 2 } y + n _ { 2 } z , } \\ { z ^ { \prime } = l _ { 3 } x + m _ { 3 } y + n _ { 3 } z ; } \end{array}\tag{3.362a}
$$

$$
\begin{array} { l } { x = l _ { 1 } x ^ { \prime } + l _ { 2 } y ^ { \prime } + l _ { 3 } z ^ { \prime } , } \\ { y = m _ { 1 } x ^ { \prime } + m _ { 2 } y ^ { \prime } + m _ { 3 } z ^ { \prime } , } \\ { z = n _ { 1 } x ^ { \prime } + n _ { 2 } y ^ { \prime } + n _ { 3 } z ^ { \prime } } \end{array}\tag{3.362b}
$$

$$

$$

$$
\mathrm { d e t } { \bf D } = \Delta = \left| \begin{array} { c } { { l _ { 1 } l _ { 2 } l _ { 3 } } } \\ { { m _ { 1 } m _ { 2 } m _ { 3 } } } \\ { { n _ { 1 } n _ { 2 } n _ { 3 } } } \end{array} \right| .\tag{3.362d}

2. Properties of the Transformation Determinant

a) $\Delta = \pm 1$ , with a positive sign if it remains left- or right-handed, as it was, and with negative sign if it changes its orientation.

b) The sum of the squares of the elements of a row or column is always equal to one.

c) The sum of the products of the corresponding elements of two diferent rows or columns is equal to zero (see 4.1.4, 9., p. 275).

d) Every element can be written as the product of $\Delta = \pm 1$ and its adjoint (see 4.2.1, p. 278).

3. Scalar Invariant

This is a scalar which keeps its value during translation and rotation. The scalar product of two vectors is a scalar invariant (see 3.5.1.5, 3., p. 185).

A: The components of a vector $\vec { \bf a } = \{ a _ { 1 } , a _ { 2 } , a _ { 3 } \}$ are not scalar invariants, because they change their values during translation and rotation.

B: The length of a vector $\vec { \bf a } = \{ a _ { 1 } , a _ { 2 } , a _ { 3 } \}$ , i.e., the quantity $\sqrt { a _ { 1 } ^ { 2 } + a _ { 2 } ^ { 2 } + a _ { 3 } ^ { 2 } }$ , is a scalar invariant.

C: The scalar product of a vector with itself is a scalar invariant:

$\vec { \bf a } \vec { \bf a } = \vec { \bf a } ^ { 2 } = | \vec { \bf a } | ^ { 2 } \cos \varphi = | \vec { \bf a } ^ { 2 } |$ , because $\varphi = 0$
