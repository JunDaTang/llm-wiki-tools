##### 8.1.4.2 Integration of Binomial Integrands

An expression of the form

$$
x ^ { m } ( a + b x ^ { n } ) ^ { p }\tag{8.20}
$$

is called a binomial integrand, where a and b are arbitrary real numbers, and $m , n , p$ are arbitrary positive or negative rational numbers. The theorem ofChebyshev tells that the integral

$$
\int x ^ { m } ( a + b x ^ { n } ) ^ { p } d x\tag{8.21}
$$

can be expressed by elementary functions only in the following three cases:

Case 1: If p is an integer, then the expression $( a + b x ^ { n } ) ^ { p }$ can be expanded by the binomial theorem, so the integrand after eliminating the parentheses will be a sum of terms in the form $c x ^ { k }$ , which are easy to integrate.

Case 2: If $\frac { m + 1 } { n }$ is an integer, then the integral (8.21) can be reduced to the integral of a rational function by substituting $t = { \sqrt [ { r a + b x ^ { n } } }$ , where r is the denominator of the fraction $p .$

function by substituting $t = { \sqrt { \frac { a + b x ^ { n } } { x ^ { n } } } }$ , where r is the denominator of the fraction $p .$

##### 8.1.4.3 Elliptic Integrals

1. Indefinite Elliptic Integrals

Elliptic integrals are integrals of the form

$$
\int R \left( x , { \sqrt { a x ^ { 3 } + b x ^ { 2 } + c x + e } } \right) d x , \quad \int R \left( x , { \sqrt { a x ^ { 4 } + b x ^ { 3 } + c x ^ { 2 } + e x + f } } \right) d x .\tag{8.22}
$$

Usually they cannot be expressed by elementary functions; if it is still possible, the integral is called pseudoelliptic. The name of this type of integral originates from the fact that the first application of them was to calculate the perimeter of the ellipse (see 8.2.2.2, 2., p. 502). The inverses of elliptic integrals are the elliptic functions (see 14.6.1, p. 762). Integrals of the types (8.22), which are not integrable in elementary terms, can be reduced by a sequence of transformations into elementary functions and integrals of the following three types (see [21.1], [21.2], [21.7]):

$$
\int { \frac { d t } { \sqrt { ( 1 - t ^ { 2 } ) ( 1 - k ^ { 2 } t ^ { 2 } ) } } } \quad ( 0 < k < 1 ) , \ : \ : \ : \ : ( 8 . 2 3 \mathrm { a } ) \quad \int { \frac { ( 1 - k ^ { 2 } t ^ { 2 } ) d t } { \sqrt { ( 1 - t ^ { 2 } ) ( 1 - k ^ { 2 } t ^ { 2 } ) } } } \quad ( 0 < k < 1 ) ,\tag{8.23b}
$$

$$
\int { \frac { d t } { ( 1 + n t ^ { 2 } ) { \sqrt { ( 1 - t ^ { 2 } ) ( 1 - k ^ { 2 } t ^ { 2 } ) } } } } \quad ( 0 < k < 1 ) .\tag{8.23c}
$$

Concerning the parameter n in (8.23c) one has to distinguish certain cases (see [14.1]).

By the substitution $t \ = \ \sin \varphi \left( 0 < \varphi < { \frac { \pi } { 2 } } \right)$ the integrals (8.23a,b,c) can be transformed into the Legendre form:

Elliptic Integral of the First Kind:

$$
\int { \frac { d \varphi } { \sqrt { 1 - k ^ { 2 } \sin ^ { 2 } \varphi } } } .\tag{8.24a}
$$

Elliptic Integral of the Second Kind:

$$
\int { \sqrt { 1 - k ^ { 2 } \sin ^ { 2 } \varphi } } d \varphi .\tag{8.24b}
$$

Elliptic Integral of the Third Kind:

$$
\int { \frac { d \varphi } { ( 1 + n \sin ^ { 2 } \varphi ) { \sqrt { 1 - k ^ { 2 } \sin ^ { 2 } \varphi } } } } .\tag{8.24c}
$$
