### 4.2 Determinants

#### 4.2.1 Definitions

1. Determinants

Determinants are real or complex numbers uniquely associated with square matrices. The determinant of order n associated with the $( n , n )$ matrix $\mathbf { A } = \left( a _ { \mu \nu } \right)$

$$
{ \mathrm { D } } = \operatorname* { d e t } \mathbf { A } = \operatorname* { d e t } \left( a _ { \mu \nu } \right) = { \left| \begin{array} { l l l } { a _ { 1 1 } \ a _ { 1 2 } \cdot \cdot \cdot \ a _ { 1 n } } \\ { a _ { 2 1 } \ a _ { 2 2 } \cdot \cdot \cdot \ a _ { 2 n } } \\ { \vdots \quad \vdots \quad \vdots \quad \vdots } \\ { a _ { n 1 } \ a _ { n 2 } \cdot \cdot \cdot \ a _ { n n } } \end{array} \right| } ,\tag{4.55}
$$

<sub>is calculated in a recursive way using the</sub> La<sub>p</sub>lace ex<sub>p</sub>ansion rule<sub>:</sub>

$$
\operatorname* { d e t } \mathbf { A } = \sum _ { \nu = 1 } ^ { n } a _ { \mu \nu } A _ { \mu \nu } \qquad ( \mu \operatorname { f i x e d } , \operatorname { e x p a n s i o n } \mathrm { a l o n g } \operatorname { t h e } \mu \operatorname { f o r h } \operatorname { r o w } ) ,\tag{4.56a}
$$

$$
\operatorname* { d e t } \mathbf { A } = \sum _ { \mu = 1 } ^ { n } a _ { \mu \nu } A _ { \mu \nu }
$$

$$
( \nu \mathrm { ~ f i x e d , } \mathrm { e x p a n s i o n ~ a l o n g ~ t h e } \nu \mathrm { - t h } \mathrm { c o l u m n } ) .\tag{4.56b}
$$

Here $A _ { \mu \nu }$ is the subdeterminant belonging to the element $a _ { \mu \nu }$ multiplied by the sign factor $( - 1 ) ^ { \mu + \nu }$ $A _ { \mu \nu }$ is called the cofactor or algebraic complement.

2. Subdeterminants

The subdeterminant of order $( n - 1 )$ belonging to the element $a _ { \mu \nu }$ of a determinant of order n is the determinant obtained by deleting the μ-th row and the ν-th column.

Expansion of a determinant of order four along the third row:

$$
{ \left| \begin{array} { l } { a _ { 1 1 } \ a _ { 1 2 } \ a _ { 1 3 } \ a _ { 1 4 } } \\ { a _ { 2 1 } \ a _ { 2 2 } \ a _ { 2 3 } \ a _ { 2 4 } } \\ { a _ { 3 1 } \ a _ { 3 2 } \ a _ { 3 3 } \ a _ { 3 4 } } \\ { a _ { 4 1 } \ a _ { 4 2 } \ a _ { 4 3 } \ a _ { 4 4 } } \end{array} \right| } = a _ { 3 1 } { \left| \begin{array} { l l } { a _ { 1 2 } \ a _ { 1 3 } \ a _ { 1 4 } } \\ { a _ { 2 2 } \ a _ { 2 3 } \ a _ { 2 4 } } \\ { a _ { 4 2 } \ a _ { 4 3 } \ a _ { 4 4 } } \end{array} \right| } - a _ { 3 2 } { \left| \begin{array} { l l } { a _ { 1 1 } \ a _ { 1 3 } \ a _ { 1 4 } } \\ { a _ { 2 1 } \ a _ { 2 3 } \ a _ { 2 4 } } \\ { a _ { 4 1 } \ a _ { 4 3 } \ a _ { 4 4 } } \end{array} \right| } + a _ { 3 3 } { \left| \begin{array} { l } { a _ { 1 1 } \ a _ { 1 2 } \ a _ { 1 4 } } \\ { a _ { 2 1 } \ a _ { 2 2 } \ a _ { 2 4 } } \\ { a _ { 4 1 } \ a _ { 4 2 } \ a _ { 4 4 } } \end{array} \right| } - a _ { 3 4 } { \left| \begin{array} { l l } { a _ { 1 1 } \ a _ { 1 2 } \ a _ { 1 3 } } \\ { a _ { 2 1 } \ a _ { 2 2 } \ a _ { 2 3 } } \\ { a _ { 4 1 } \ a _ { 4 2 } \ a _ { 4 3 } } \end{array} \right| } .
$$

#### 4.2.2 Rules of Calculation for Determinants

Because of the Laplace expansion the following statements about rows are valid also for columns.

1. Independence of the Value of a Determinant

The value of a determinant does not depend on which row was chosen.

2. Substitution of Cofactors

If during the expansion of a determinant the cofactors of a row are replaced by the cofactors of another one, then one gets zero:

$$
\sum _ { \nu = 1 } ^ { n } a _ { \mu \nu } A _ { \lambda \nu } = 0 \qquad ( \mu , \lambda \mathrm { f i x e d } ; \lambda \ne \mu ) .\tag{4.57}
$$

This relation and the Laplace expansion result in

$$
\mathbf { A } _ { \mathrm { a d j } } \mathbf { A } = \mathbf { A } \mathbf { A } _ { \mathrm { a d j } } = ( \operatorname* { d e t } \mathbf { A } ) \mathbf { I } .\tag{4.58}
$$

The adjoint matrix of A, which is the transpose of the matrix made from the cofactors of A, is denoted by $\mathbf { A } _ { \mathrm { a d j } }$ . There must not be a confusion of this adjoint matrix with the transposed conjugate of a complex matrix ${ \bf A } ^ { \mathrm { H } }$ (see (4.4), p. 269). From the previous equality one gets the inverse matrix

$$
\mathbf { A } ^ { - 1 } = { \frac { 1 } { \operatorname* { d e t } \mathbf { A } } } \mathbf { A } _ { \mathrm { a d j } } ,\tag{4.59}
$$

3. Zero Value of a Determinant

A determinant is equal to zero if

a) a row contains zero elements only, or

b) two rows are equal to each other, or

c) a row is a linear combination of the others.

4. Changes and Additions

The value of the determinant does not change if

a) its rows are exchanged for its columns, i.e., reflection in the main diagonal does not afect the value of it:

$$
\operatorname* { d e t } \mathbf { A } = \operatorname* { d e t } \mathbf { A } ^ { \mathrm { T } } ,\tag{4.60}
$$

b) any row is added to or subtracted from another one, or

c) a multiple of any row is added to or subtracted from another one, or

d) a linear combination of other rows is added to any row.

5. Sign on Changing Rows

If two rows are interchanged in a determinant, then the sign of the determinant changes.

6. Multiplication of a Determinant by a Number

The value of a determinant will be multiplied by α if the elements of a row are multiplied by this number. The next formula shows the diference between this and the multiplication of a matrix A of size (n, n) by a number α

$$
\operatorname* { d e t } \left( \alpha \mathbf { A } \right) = \alpha ^ { n } \operatorname* { d e t } \mathbf { A } .\tag{4.61}
$$

7. Multiplication of Two Determinants

The multiplication of two determinants can be reduced to the multiplication of their matrices:

$$
( \operatorname* { d e t } \mathbf { A } ) ( \operatorname* { d e t } \mathbf { B } ) = \operatorname* { d e t } { ( \mathbf { A } \mathbf { B } ) } .\tag{4.62}
$$

Since det A = det A<sup>T</sup> (see (4.60)), we have the equalities

$$
( \operatorname* { d e t } \mathbf { A } ) ( \operatorname* { d e t } \mathbf { B } ) = \operatorname* { d e t } \left( \mathbf { A } \mathbf { B } \right) = \operatorname* { d e t } \left( \mathbf { A } \mathbf { B } ^ { \mathrm { T } } \right) = \operatorname* { d e t } \left( \mathbf { A } ^ { \mathrm { T } } \mathbf { B } \right) = \operatorname* { d e t } \left( \mathbf { A } ^ { \mathrm { T } } \mathbf { B } ^ { \mathrm { T } } \right) ,\tag{4.63}
$$

i.e., it is permissible to take the scalar product of rows with columns, rows with rows, columns with rows or columns with columns.

8. Diferentiation of a Determinant

Suppose the elements of a determinant of order n are diferentiable functions of a parameter t, i.e., $a _ { \mu \nu } = a _ { \mu \nu } ( t )$ . In order to diferentiate the determinant with respect to t, one diferentiates one row at one time and finally one adds the n determinants.

For a determinant of size (3, 3) follows:

$$
\frac { d } { d t } \left| \begin{array} { l } { a _ { 1 1 } ~ a _ { 1 2 } ~ a _ { 1 3 } } \\ { a _ { 2 1 } ~ a _ { 2 2 } ~ a _ { 2 3 } } \\ { a _ { 3 1 } ~ a _ { 3 2 } ~ a _ { 3 3 } } \end{array} \right| = \left| \begin{array} { l } { a _ { 1 1 } ^ { \prime } ~ a _ { 1 2 } ^ { \prime } ~ a _ { 1 3 } ^ { \prime } } \\ { a _ { 2 1 } ~ a _ { 2 2 } ~ a _ { 2 3 } } \\ { a _ { 3 1 } ~ a _ { 3 2 } ~ a _ { 3 3 } } \end{array} \right| + \left| \begin{array} { l } { a _ { 1 1 } ~ a _ { 1 2 } ~ a _ { 1 3 } } \\ { a _ { 2 1 } ^ { \prime } ~ a _ { 2 2 } ^ { \prime } ~ a _ { 2 3 } ^ { \prime } } \\ { a _ { 3 1 } ~ a _ { 3 2 } ~ a _ { 3 3 } } \end{array} \right| + \left| \begin{array} { l } { a _ { 1 1 } ~ a _ { 1 2 } ~ a _ { 1 3 } } \\ { a _ { 2 1 } ~ a _ { 2 2 } ~ a _ { 2 3 } } \\ { a _ { 3 1 } ^ { \prime } ~ a _ { 3 2 } ~ a _ { 3 3 } ^ { \prime } } \end{array} \right| .
$$

#### 4.2.3 Evaluation of Determinants

1. Value of a Determinant of Second Order

$$
\left| \begin{array} { c } { { a _ { 1 1 } \ a _ { 1 2 } } } \\ { { a _ { 2 1 } \ a _ { 2 2 } } } \end{array} \right| = a _ { 1 1 } a _ { 2 2 } - a _ { 2 1 } a _ { 1 2 } .\tag{4.64}
$$

2. Value of a Determinant of Third Order

The Sarrus rule gives a convenient scheme for the calculations, but it is valid only for determinants of order three. It is the following:

$$
\begin{array} { r l } &  \left| \begin{array} { l } { a _ { 1 1 } { \sim } a _ { 1 2 } { \sim } a _ { 1 3 } { \diamond } a _ { 1 1 } . . . . a _ { 1 2 } } \\ { a _ { 2 1 } . . . . a _ { 2 2 } { \sim } a _ { 2 3 } { \diamond } a _ { 2 1 } . . . a _ { 2 2 } } \\ { a _ { 3 1 } \quad a _ { 3 2 } \quad a _ { 3 3 } \end{array} \right. } \\ &  \left| \begin{array} { l } { a _ { 3 1 } a _ { 2 2 } a _ { 3 3 } + a _ { 1 1 } a _ { 2 2 } a _ { 3 3 } + a _ { 1 2 } a _ { 2 3 } a _ { 3 1 } + a _ { 1 3 } a _ { 2 1 } a _ { 3 2 } } \\ { a _ { 3 1 } \quad a _ { 3 2 } \quad a _ { 3 3 } \end{array} \right. } \\ & { \qquad \quad - ( a _ { 3 1 } a _ { 2 2 } a _ { 1 3 } + a _ { 3 2 } a _ { 2 3 } a _ { 1 1 } + a _ { 3 3 } a _ { 2 1 } a _ { 1 2 } ) . } \end{array}\tag{4.65}
$$

The first two columns are copied after the determinant, then the sum of the products of the elements along the redrawn declining segments is calculated, then the sum of the products of the elements along the dotted inclining segments is subtracted.

3. Value of a Determinant of n-th Order

By the expansion rule the calculation of the value of a determinant of order n is reduced to the evaluation of n determinants of order (n 1). But for practical reasons (to reduce the number of required operations), first one transforms the determinant with the help of the rules discussed above into a form such that it contains as many zeros as possible.

$$
{ \begin{array} { r l } & { \left| { \begin{array} { c c c c } { 2 } & { 9 } & { 9 } & { 4 } \\ { 2 - 3 } & { 1 2 } & { 8 } \\ { 4 } & { 8 } & { 3 } & { - 5 } \\ { 1 } & { 2 } & { 6 } & { 4 } \end{array} } \right| = \left| { \begin{array} { c c c c } { 2 } & { 5 } & { 9 } & { 4 } \\ { 2 } & { 7 } & { 1 2 } & { 8 } \\ { 4 } & { 0 } & { 3 } & { - 5 } \\ { 1 } & { 0 } & { 6 } & { 4 } \end{array} } \right| = 3 \left| { \begin{array} { c c c c } { 2 } & { 5 } & { 3 } & { 4 } \\ { 2 } & { 7 4 } & { 8 } \\ { 4 } & { 0 1 } & { - 5 } \\ { 1 } & { 0 2 } & { 4 } \end{array} } \right| = 3 \left( - 5 \left| { \begin{array} { c c c c } { 2 } & { 4 } & { 8 } \\ { 4 } & { - 5 } \\ { 1 } & { 2 } & { 4 } \end{array} } \right| - 7 \left| { \begin{array} { c c c } { 2 } & { 3 } & { 4 } \\ { 4 } & { - 5 } \\ { 1 } & { 2 } & { 4 } \end{array} } \right| \right) } \\ & { \qquad { \mathrm { ( r u l e ~ 4 ) } } \qquad \qquad { \mathrm { ( r u l e ~ 6 ) } } } \\ & { = - 2 1 \left| { \begin{array} { c c c } { 1 1 } & { 0 } & { } \\ { 4 1 } & { - 5 } \\ { 1 } & { 2 } & { 4 } \end{array} } \right| = - 2 1 \left( { \left| { \begin{array} { l l } { 1 } & { - 5 } \\ { 2 } & { 4 } \end{array} } \right| } - { \left| { \begin{array} { l l } { 4 } & { - 5 } \\ { 1 } & { 4 } \end{array} } \right| } \right) = 1 4 7 . } \end{array} }
$$

Remark: An especially eficient method to determine the value of a determinant of order n can be obtained by transforming it in the same way as it is done in order to determine the rank of a matrix (see 4.1.4, 7., p. 274), i.e., all the elements under the diagonal $a _ { 1 1 } , a _ { 2 2 } , \dotsc , a _ { n n }$ are equal to zero. Then the value of the determinant is the product of the diagonal elements of the transformed determinant.
