#### 19.6.2 Approximation in Mean

The principle of approximation in mean is known as the Gauss least squares method. In calculations continuous and discrete cases are distinguished.

##### 19.6.2.1 Continuous Problems, Normal Equations

The function $f ( x )$ is approximated by a function $g ( x )$ on the interval $[ a , b ]$ so that the expression

$$
F = \int _ { a } ^ { b } \omega ( x ) [ f ( x ) - g ( x ) ] ^ { 2 } d x ,\tag{19.169}
$$

depending on the parameters contained by $g ( x )$ , should be minimal. $\omega ( x )$ denotes a given weight function, such that $\omega ( x ) > 0$ in the integration interval.

If the best approximation $g ( x )$ is supposed to have the form

$$
g ( x ) = \sum _ { i = 0 } ^ { n } a _ { i } g _ { i } ( x )\tag{19.170}
$$

with suitable linearly independent functions $g _ { 0 } ( x ) , g _ { 1 } ( x ) , \ldots , g _ { n } ( x )$ , then the necessary conditions

$$
\frac { \partial F } { \partial a _ { i } } = 0 \quad ( i = 0 , 1 , \ldots , n )\tag{19.171}
$$

for an extreme value of (19.169) result in the so-called normal system ofequations

$$
\sum _ { i = 0 } ^ { n } a _ { i } ( g _ { i } , g _ { k } ) = ( f , g _ { k } ) \quad ( k = 0 , 1 , \ldots , n )\tag{19.172}
$$

to determine the unknown coeficients $a _ { i }$ . Here the brief notations

$$
\begin{array} { l } { { ( g _ { i } , g _ { k } ) = \displaystyle \int _ { a } ^ { b } \omega ( x ) g _ { i } ( x ) g _ { k } ( x ) d x , } } \\ { { ( f , g _ { k } ) = \displaystyle \int _ { a } ^ { b } \omega ( x ) f ( x ) g _ { k } ( x ) d x \quad ( i , k = 0 , 1 , . . . , n ) } } \end{array}\tag{19.173a}
$$

(19.173b)

are used, which are considered as the scalar products of the two indicated functions.

The system of normal equations can be solved uniquely, since the functions $g _ { 0 } ( x ) , g _ { 1 } ( x ) , . . . , g _ { n } ( x )$ are linearly independent. The coeficient matrix of the system (19.172) is symmetric, so the Cholesky method (see 19.2.1.2, p. 958) can be applied. The coeficients $a _ { i }$ can be determined directly, without solving the system of equations, if the system of functions $g _ { i } ( x )$ is orthogonal, that is, if

$$
( g _ { i } , g _ { k } ) = 0 \mathrm { f o r } i \ne k .\tag{19.174}
$$

It is called an orthonormal system, if

$$
( g _ { i } , g _ { k } ) = \left\{ \begin{array} { l l } { { 0 } } & { { \mathrm { f o r } i \neq k , } } \\ { { 1 } } & { { \mathrm { f o r } i = k } } \end{array} \right. \quad ( i , k = 0 , 1 , \ldots , n ) .\tag{19.175}
$$

With (19.175), the normal equations (19.172) are reduced to

$$
a _ { i } = ( f , g _ { i } ) \quad ( i = 0 , 1 , \ldots , n ) .\tag{19.176}
$$

Linearly independent function systems can be orthogonalized. From the power functions $g _ { i } ( x ) = x ^ { i }$ $( i = 0 , \bar { 1 } , \ldots , \bar { n } )$ , depending on the weight function and on the interval, the orthogonal polynomials in Table 19.2 can be obtained.

19.6.2.2 Discrete Problems, Normal Equations, Householder’s Method Let N pairs of values $( x _ { \nu } , y _ { \nu } )$ be given, e.g., by measured values. A function $g ( x )$ has to be determined, whose values $g ( x _ { \nu } )$ difer from the given values $y _ { \nu }$ in such a way that the quadratic expression

$$
F = \sum _ { \nu = 1 } ^ { N } [ y _ { \nu } - g ( x _ { \nu } ) ] ^ { 2 }\tag{19.179}
$$

is minimal. The value of F depends on the parameters contained in the function $g ( x )$ . Formula (19.179) represents the classical sum ofresidual squares. The minimization of the sum of residual squares is called the least squares method. From the assumption (19.170) and the necessary conditions $\frac { \partial F } { \partial a _ { i } } = 0 \ ( i =$ $0 , 1 , \ldots , n )$ for a relative minimum of (19.179) for the coeficients the normal system of equations is obtained:

$$
\sum _ { i = 0 } ^ { n } a _ { i } [ g _ { i } g _ { k } ] = [ y g _ { k } ] \quad ( k = 0 , 1 , \ldots , n ) .\tag{19.180}
$$

Here the Gaussean sum symbols are used in the following notation:

$$
\left[ g _ { i } g _ { k } \right] = \sum _ { \nu = 1 } ^ { N } g _ { i } ( x _ { \nu } ) g _ { k } ( x _ { \nu } ) ,\tag{19.181a}
$$

$$
[ y g _ { k } ] = \sum _ { \nu = 1 } ^ { N } y _ { \nu } g _ { k } ( x _ { \nu } ) \quad ( i , k = 0 , 1 , \dots , n ) .\tag{19.181b}
$$

Usually, $n \ll N$

For the polynomial $g ( x ) = a _ { 0 } + a _ { 1 } x + \cdot \cdot \cdot + a _ { n } x ^ { n }$ , the normal equations are $a _ { 0 } [ x ^ { k } ] + a _ { 1 } [ x ^ { k + 1 } ] + \cdot \cdot \cdot +$ $a _ { n } [ x ^ { k + n } ] = [ x ^ { k } y ] \ ( k = 0 , 1 , \ldots , n )$ with $\begin{array} { r } { [ { \boldsymbol { x } } ^ { k } ] = \sum _ { \nu = 1 } ^ { N } { \boldsymbol { x } } _ { \nu } { } ^ { k } , \quad [ { \boldsymbol { x } } ^ { 0 } ] = N , [ { \boldsymbol { x } } ^ { k } { \boldsymbol { y } } ] = \sum _ { \nu = 1 } ^ { N } { \boldsymbol { x } } _ { \nu } { } ^ { k } { \boldsymbol { y } } _ { \nu } , [ { \boldsymbol { y } } ] = } \end{array}$ $\scriptstyle \sum _ { \nu = 1 } ^ { N } y _ { \nu }$ . The coeficient matrix of the normal system of equations (19.180) is symmetric, so for the numerical solution the Cholesky method can be applied.

The normal equations (19.180) and the residue sum square (19.179) have the following compact form:

$$
\mathbf { G } ^ { \mathrm { T } } \mathbf { G } \underline { { \mathbf { a } } } = \mathbf { G } ^ { \mathrm { T } } \underline { { \mathbf { y } } } , \quad F = ( \underline { { \mathbf { y } } } - \mathbf { G } \underline { { \mathbf { a } } } ) ^ { \mathrm { T } } ( \underline { { \mathbf { y } } } - \mathbf { G } \underline { { \mathbf { a } } } ) \quad \mathrm { w i t h }\tag{19.182a}
$$

$$
\mathbf G = \left( \begin{array} { c c c c c c } { g _ { 0 } ( x _ { 1 } ) } & { g _ { 1 } ( x _ { 1 } ) } & { g _ { 2 } ( x _ { 1 } ) } & { \ldots } & { g _ { n } ( x _ { 1 } ) } \\ { g _ { 0 } ( x _ { 2 } ) } & { g _ { 1 } ( x _ { 2 } ) } & { g _ { 2 } ( x _ { 2 } ) } & { \ldots } & { g _ { n } ( x _ { 2 } ) } \\ { g _ { 0 } ( x _ { 3 } ) } & { g _ { 1 } ( x _ { 3 } ) } & { g _ { 2 } ( x _ { 3 } ) } & { \ldots } & { g _ { n } ( x _ { 3 } ) } \\ { \vdots } & & & & & \\ { \vdots } & & & & & { \vdots } \end{array} \right) , \quad \underline { { \mathbf { y } } } = \left( \begin{array} { c } { y _ { 1 } } \\ { y _ { 2 } } \\ { y _ { 3 } } \\ { \vdots } \\ { y _ { N } } \end{array} \right) , \quad \underline { { \mathbf { a } } } = \left( \begin{array} { c } { a _ { 0 } } \\ { a _ { 1 } } \\ { a _ { 2 } } \\ { \vdots } \\ { a _ { n } } \end{array} \right) .\tag{19.182b}
$$

If, instead of the minimalization of the sum of residual squares, one wants to solve the interpolation problem for the N points $\left( x _ { \nu } , y _ { \nu } \right)$ , then the following system of equations should be solved:

$$
\mathbf { G a } = \mathbf { y } .\tag{19.183}
$$

This system of equations is over-determined in the case of $n < N - 1$ , and usually it does not have any solution. The equations (19.180) or (19.182a) are obtained by multiplying (19.183) by $\mathbf { G } ^ { \mathrm { T } }$

From a numerical viewpoint, the Householder method (see 4.5.3.2, 2., p. 314) is recommended to solve equation (19.183), and this solution results in the minimal sum of residual squares (19.179).

##### 19.6.2.3 Multidimensional Problems

1. Computation of Adjustments

Suppose that there is a function $f ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } )$ of n independent variables $x _ { 1 } , x _ { 2 } , \ldots , x _ { n }$ . Its explicit form is not known; only N substitution values $f _ { \nu }$ are given, which are, in general, measured values. These data can be written in a table (see (19.184)).

The formulation of the adjustment problem is clearer by introducing the following vectors:

$$
\begin{array} { r } { x _ { 1 } ~ \left. ~ x _ { 1 } ^ { ( 1 ) } ~ x _ { 1 } ^ { ( 2 ) } \ldots ~ x _ { 1 } ^ { ( N ) } \right. } \\ { x _ { 2 } ~ \left. ~ x _ { 2 } ^ { ( 1 ) } ~ x _ { 2 } ^ { ( 2 ) } \ldots ~ x _ { 2 } ^ { ( N ) } \right. } \\ { \vdots ~ \vdots ~ \vdots ~ \qquad \vdots } \\ { \left. \frac { x _ { n } } { f ~ \left. ~ x _ { n } ^ { ( 1 ) } ~ x _ { n } ^ { ( 2 ) } \ldots ~ x _ { n } ^ { ( N ) } \right. } \right. } \end{array}\tag{19.184}
$$

$\begin{array} { r l } { \mathbf { \underline { { x } } } } & { { } = ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ) ^ { \mathrm { T } } } \end{array}$ : Vector of n independent variables,

$\underline { { \mathbf { x } } } ^ { ( \nu ) } = ( x _ { 1 } ^ { ( \nu ) } , x _ { 2 } ^ { ( \nu ) } , \dots , x _ { n } ^ { ( \nu ) } ) ^ { \mathrm { T } }$ : Vector of the ν-th interpolation node $( \nu = 1 , \ldots , N )$

$\begin{array} { r l } { \underline { { \mathbf { f } } } } & { { } = ( f _ { 1 } , f _ { 2 } , \dots f _ { N } ) ^ { \mathrm { T } } } \end{array}$ : Vector of the N function values at the N interpolation nodes.

$f ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ) = f ( \underline { { \mathbf { x } } } )$ is approximated by a function of the form

$$
g ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ) = \sum _ { i = 0 } ^ { m } a _ { i } g _ { i } ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ) .\tag{19.185}
$$

Here, the $m + 1$ functions $g _ { i } ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ) = g _ { i } ( \underline { { \mathbf { x } } } )$ are suitable, selected functions.

A: Linear approximation by n variables: $g ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ) = a _ { 0 } + a _ { 1 } x _ { 1 } + a _ { 2 } x _ { 2 } + \cdots + a _ { n } x _ { n } .$

B: Complete quadratic approximation with three variables:

$$
g ( x _ { 1 } , x _ { 2 } , x _ { 3 } ) = a _ { 0 } + a _ { 1 } x _ { 1 } + a _ { 2 } x _ { 2 } + a _ { 3 } x _ { 3 } + a _ { 4 } { x _ { 1 } } ^ { 2 } + a _ { 5 } { x _ { 2 } } ^ { 2 } + a _ { 6 } { x _ { 3 } } ^ { 2 } + a _ { 7 } x _ { 1 } x _ { 2 } + a _ { 8 } x _ { 1 } x _ { 3 } + a _ { 9 } { x _ { 2 } } x _ { 3 } .
$$

The coeficients are chosen to minimize ${ \textstyle \sum _ { \nu = 1 } ^ { N } } \left[ f _ { \nu } - g \left( x _ { 1 } ^ { ( \nu ) } , x _ { 2 } ^ { ( \nu ) } , \dots , x _ { n } ^ { ( \nu ) } \right) \right] ^ { 2 } .$

##### 19.6.2.4 Non-Linear Least Squares Problems

The main idea is discussed for a one-dimensional discrete case. The approximation function $g ( x )$ depends non-linearly on certain parameters.

A: $g ( x ) = a _ { 0 } e ^ { a _ { 1 } x } + a _ { 2 } e ^ { a _ { 3 } x }$ . This expression does not depend linearly on the parameters $a _ { 1 }$ and $a _ { 3 }$

B: $g ( x ) = a _ { 0 } e ^ { a _ { 1 } x } \cos a _ { 2 } x$ . This function does not depend linearly on the parameters $a _ { 1 }$ and $a _ { 2 }$

The fact that the approximation function $g ( x )$ depends on a parameter vector $\mathbf { a } = ( a _ { 0 } , a _ { 1 } , \ldots , a _ { n } ) ^ { \mathrm { T } }$ is indicated by the notation

$$
g = g ( x , \underline { { { \mathbf a } } } ) = g ( x ; a _ { 0 } , a _ { 1 } , \dots , a _ { n } ) .\tag{19.188}
$$

Suppose, N pairs of values $( x _ { \nu } , y _ { \nu } ) \ ( \nu = 1 , 2 , \ldots , N )$ are given. To minimize the sum of residual squares

$$
\sum _ { \nu = 1 } ^ { N } [ y _ { \nu } - g ( x _ { \nu } ; a _ { 0 } , a _ { 1 } , \ldots , a _ { n } ) ] ^ { 2 } = F ( a _ { 0 } , a _ { 1 } , \ldots , a _ { n } )\tag{19.189}
$$

the necessary conditions ${ \frac { \partial F } { \partial a _ { i } } } = 0 ( i = 0 , 1 , \ldots , n )$ lead to a non-linear normal equation system which must be solved by an iterative method, $\mathrm { e . g . }$ , by the Newton method (see 19.2.2.2, p. 962).

Another way to solve the problem, which is usually used in practical problems, is the application of the Gauss-Newton method (see 19.2.2.3, p. 962) given for the solution of the non-linear least squares problem (19.24). The following steps are needed to apply it for this non-linear approximation problem (19.189):

1. Linearization of the approximating function $g ( x , \underline { { \mathbf { a } } } )$ with the help of the Taylor formula with respect to $a _ { i }$ . To do this, the approximation values $a _ { i } ^ { ( 0 ) } ( i = 0 , 1 , \dots , n )$ are needed:

$$
g ( x , \underline { { \mathbf { a } } } ) \approx \tilde { g } ( x , \underline { { \mathbf { a } } } ) = g ( x , \underline { { \mathbf { a } } } ^ { ( 0 ) } ) + \sum _ { i = 0 } ^ { n } \frac { \partial g } { \partial a _ { i } } ( x , \underline { { \mathbf { a } } } ^ { ( 0 ) } ) ( a _ { i } - a _ { i } ^ { ( 0 ) } ) .\tag{19.190}
$$

2. Solution of the linear minimum problem

$$
\sum _ { \nu = 1 } ^ { N } [ y _ { \nu } - \tilde { g } ( x _ { \nu } , \underline { { { \mathbf { a } } } } ) ] ^ { 2 } = \operatorname* { m i n } !\tag{19.191}
$$

with the help of the normal equation system

$$
\tilde { \mathbf { G } } ^ { \mathrm { T } } \tilde { \mathbf { G } } \underline { { \Delta \mathbf { a } } } = \tilde { \mathbf { G } } ^ { \mathrm { T } } \underline { { \Delta \mathbf { y } } }\tag{19.192}
$$

or by the Householder method. In (19.192) the components of the vectors $\Delta \mathbf { a }$ and $\Delta \mathbf { y }$ are given as

$$
\Delta a _ { i } = a _ { i } - a _ { i } ^ { ( 0 ) } \qquad ( i = 0 , 1 , 2 , \ldots , n ) \mathrm { ~ a n d }\tag{19.193a}
$$

$$
\Delta y _ { \nu } = y _ { \nu } - g ( x _ { \nu } , \underline { { { \bf a } } } ^ { ( 0 ) } ) \quad ( \nu = 1 , 2 , \dots , N ) .\tag{19.193b}
$$

The matrix $\tilde { G }$ can be determined analogously to $G$ in (19.182b), where $g _ { i } ( x _ { \nu } )$ are replaced by $\frac { \partial g } { \partial a _ { i } } ( x _ { \nu } , \underline { { { \bf a } } } _ { 1 } ^ { ( 0 ) } ) ( i = 0 , 1 , \dots , n ; \nu = 1 , 2 , \dots , N ) .$

3. Calculation of a new approximation

$$
a _ { i } ^ { ( 1 ) } = a _ { i } ^ { ( 0 ) } + \Delta a _ { i } { \mathrm { ~ o r ~ } } a _ { i } ^ { ( 1 ) } = a _ { i } ^ { ( 0 ) } + \gamma \Delta a _ { i } \quad ( i = 0 , 1 , 2 , \ldots , n ) ,\tag{19.194}
$$

where $\gamma > 0$ is a step length parameter.

By repeating steps 2 and 3 with $a _ { i } ^ { ( 1 ) }$ instead of $a _ { i } ^ { ( 0 ) }$ , etc. a sequence of approximation values is obtained for the required parameters, whose convergence strongly depends on the accuracy of the initial approximations.
