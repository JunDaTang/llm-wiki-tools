#### 8.1.5 Integration of Trigonometric Functions

##### 8.1.5.1 Substitution

With the substitution

$$
t = \tan { \frac { x } { 2 } } , \quad \mathrm { i . e . , } \quad d x = { \frac { 2 d t } { 1 + t ^ { 2 } } } , \quad \sin x = { \frac { 2 t } { 1 + t ^ { 2 } } } , \quad \cos x = { \frac { 1 - t ^ { 2 } } { 1 + t ^ { 2 } } } ,\tag{8.27}
$$

an integral of the form

$$
\int R \left( \sin x , \cos x \right) d x\tag{8.28}
$$

can be transformed into an integral of a rational function, where R denotes a rational function of its arguments.

$$
= \int { \frac { 1 + \sin x } { \sin x ( 1 + \cos x ) } } d x = \int { \frac { \left( 1 + { \frac { 2 t } { 1 + t ^ { 2 } } } \right) { \frac { 2 } { 1 + t ^ { 2 } } } } { \frac { 2 t } { 1 + t ^ { 2 } } \left( 1 + { \frac { 1 - t ^ { 2 } } { 1 + t ^ { 2 } } } \right) } } d t = { \frac { 1 } { 2 } } \int \left( t + 2 + { \frac { 1 } { t } } \right) d t = { \frac { t ^ { 2 } } { 4 } } + t + { \frac { 1 } { 2 } } \ln | t | + C \left( t + { \frac { 1 } { t } } \right) d t .
$$

$= { \frac { \tan ^ { 2 } { \frac { x } { 2 } } } { 4 } } + \tan { \frac { x } { 2 } } + { \frac { 1 } { 2 } } \ln \left| \tan { \frac { x } { 2 } } \right| + C .$ . In some special cases more simple substitutions can be applied. If the integrand in (8.28) contains only odd powers of the functions sin x and cos x, then by the substitution t = tan x a rational function can be obtained in a simpler way.

##### 8.1.5.2 Simplified Methods

$$
\mathrm { C a s e 1 : } \int R \left( \sin x \right) \cos x d x . \qquad \mathrm { S u b s t i t u t i o n } \quad t = \sin x , \quad \cos x d x = d t .\tag{8.29}
$$

$$
\mathrm { C a s e 2 : } \quad \int R \left( \cos x \right) \sin x d x . \qquad \mathrm { S u b s t i t u t i o n } \quad t = \cos x , \quad \sin x d x = - d t .\tag{8.30}
$$

Case 3: $\int \sin ^ { n } x d x \colon$

(8.31a)

a) n = 2m + 1, odd:

$$
\int \sin ^ { n } x d x = \int ( 1 - \cos ^ { 2 } x ) ^ { m } \sin x d x = - \int ( 1 - t ^ { 2 } ) ^ { m } d t \qquad { \mathrm { w i t h } } \quad t = \cos x .\tag{8.31b}
$$

b) $n = 2 m , { \mathrm { e v e n } } ;$

$$
\int \sin ^ { n } x d x = \int \left[ { \frac { 1 } { 2 } } ( 1 - \cos 2 x ) \right] ^ { m } d x = { \frac { 1 } { 2 ^ { m + 1 } } } \int ( 1 - \cos t ) ^ { m } d t \qquad { \mathrm { w i t h } } \quad t = 2 x .\tag{8.31c}
$$

The power is halved in this way. After removing the parentheses in $( 1 - \cos t ) ^ { m }$ follows integration term-by-term.

Case 4: $\int \cos ^ { n } x d x .$

(8.32a)

a) $n = 2 m + 1$ , odd:

$$
\int \cos ^ { n } x d x = \int ( 1 - \sin ^ { 2 } x ) ^ { m } \cos x d x = \int ( 1 - t ^ { 2 } ) ^ { m } d t \qquad { \mathrm { w i t h } } \quad t = \sin x .\tag{8.32b}
$$

b) $n = 2 m$ , even:

$$
\int \cos ^ { n } x d x = \int \left[ { \frac { 1 } { 2 } } ( 1 + \cos 2 x ) \right] ^ { m } d x = { \frac { 1 } { 2 ^ { m + 1 } } } \int ( 1 + \cos t ) ^ { m } d t \qquad { \mathrm { w i t h } } \quad t = 2 x .\tag{8.32c}
$$

The power is halved in this way. After removing the parentheses follows integration term-by-term.

Case 5: $\int \sin ^ { n } x \cos ^ { m } x d x .$

(8.33a)

a) One of the numbers m or n is odd: Reducing it to the cases 1 or 2.

$$
\mathbf { A } \colon \ \int \sin ^ { 2 } x \cos ^ { 5 } x d x = \int \sin ^ { 2 } x ( 1 - \sin ^ { 2 } x ) ^ { 2 } \cos x d x = \int t ^ { 2 } ( 1 - t ^ { 2 } ) ^ { 2 } d t + C \quad { \mathrm { w i t h } } \quad t = \sin x .
$$

B: $\int { \frac { \sin { x } } { \sqrt { \cos { x } } } } d x = - \int { \frac { d t } { \sqrt { t } } } + C \quad { \mathrm { w i t h } } \quad t = \cos { x } .$

b) The numbers m and n are both even: Reducing it to the cases 3 or 4 by halving the powers using the trigonometric formulas

$$
\sin x \cos x = { \frac { \sin 2 x } { 2 } } , \qquad \sin ^ { 2 } x = { \frac { 1 - \cos 2 x } { 2 } } , \qquad \cos ^ { 2 } x = { \frac { 1 + \cos 2 x } { 2 } } .\tag{8.33b}
$$

$$
 \int \sin ^ { 2 } x \cos ^ { 4 } x d x = \int ( \sin x \cos x ) ^ { 2 } \cos ^ { 2 } x d x = { \frac { 1 } { 8 } } \int \sin ^ { 2 } 2 x ( 1 + \cos 2 x ) d x = { \frac { 1 } { 8 } } \int \sin ^ { 2 } 2 x \cos 2 x d x + \cdots
$$

$$
{ \frac { 1 } { 1 6 } } \int ( 1 - \cos 4 x ) d x = { \frac { 1 } { 4 8 } } \sin ^ { 3 } 2 x + { \frac { 1 } { 1 6 } } x - { \frac { 1 } { 6 4 } } \sin 4 x + C .
$$

$$
{ \begin{array} { r l } & { { \mathrm { C a s e ~ } } \mathbf { 6 } \colon \ \int \tan ^ { n } x d x = \int \tan ^ { n - 2 } x ( \sec ^ { 2 } x - 1 ) d x = \int \tan ^ { n - 2 } x ( \tan x ) ^ { \prime } d x - \int \tan ^ { n - 2 } x d x } \\ & { \qquad = { \frac { \tan ^ { n - 1 } x } { n - 1 } } - \int \tan ^ { n - 2 } x d x . } \end{array} }\tag{8.34a}
$$

By repeating this process one decreases the power and depending on whether n is even or odd one finally gets the integral

$$
\int d x = x \qquad { \mathrm { o r } } \qquad \int \tan x d x = - \ln | \cos x |\tag{8.34b}
$$

respectively.
