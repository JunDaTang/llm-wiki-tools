#### 18.1.4 Special Linear Programming Problems

##### 18.1.4.1 Transportation Problem

1. Modeling

A certain product, produced by m producers $E _ { 1 } , E _ { 2 } , \dots , E _ { m }$ in quantities $a _ { 1 } , a _ { 2 } , \ldots , a _ { m } .$ , is to be transported to n consumers $V _ { 1 } , V _ { 2 } , \ldots , \bar { V _ { n } }$ with demands $b _ { 1 } , b _ { 2 } , \ldots , b _ { n }$ . Transportation cost of a unit product of producer $E _ { i }$ to consumer $V _ { j }$ is $c _ { i j }$ . The amount of the product transported from $E _ { i }$ to $V _ { j }$ is $x _ { i j }$ units. An optimal transportation plan is to be determined with minimum total transportation cost. The system is supposed to be balanced, i.e., supply equals demand:

$$
\sum _ { i = 1 } ^ { m } a _ { i } = \sum _ { j = 1 } ^ { n } b _ { j } .\tag{18.24}
$$

The matrix of costs C and the distribution matrix X are constructed:

$$

In order to determine an optimal program, the following programming problem should be solved:

$$
\mathbf { O F } \colon \ f ( \mathbf { X } ) = \sum _ { i = 1 } ^ { m } \sum _ { j = 1 } ^ { n } c _ { i j } x _ { i j } = \operatorname* { m i n } !\tag{18.26a}

$$
\mathbf { C T : } \quad \sum _ { j = 1 } ^ { n } x _ { i j } = a _ { i } ( i = 1 , \ldots , m ) , \quad \sum _ { i = 1 } ^ { m } x _ { i j } = b _ { j } ( j = 1 , \ldots , n ) , x _ { i j } \geq 0 ) .\tag{18.26b}

The minimum of the problem occurs at a vertex of the feasible set. There are $m + n - 1$ linearly independent constraints among the $m + n$ original constraints, so, in the non-degenerate case, the solution contains $m + n - 1$ positive components $x _ { i j }$ . To determine an optimal solution the following algorithm is used, which is called the transportation algorithm.

##### 18.1.4.2 Assignment Problem

The representation is made by an example.

n shipping contracts should be given to n shipping companies so that each company receives exactly one contract. The assignment has to be determined which minimizes the total costs, if the i-th company charges $c _ { i j }$ for the j-th contract.

An assignment problem is a special transportation problem with $m = n$ and $a _ { i } = b _ { j } = 1$ for all $i , j \colon$

$$
f ( \underline { { \mathbf { x } } } ) = \sum _ { i = 1 } ^ { n } \sum _ { j = 1 } ^ { n } c _ { i j } x _ { i j } = \operatorname* { m i n } !\tag{18.29a}
$$

$$
\mathbf { C T } \colon \ \sum _ { j = 1 } ^ { n } x _ { i j } = 1 \ ( i = 1 , \ldots , n ) , \qquad \sum _ { i = 1 } ^ { n } x _ { i j } = 1 \ ( j = 1 , \ldots , n ) , \qquad x _ { i j } \in \{ 0 , 1 \} .\tag{18.29b}
$$

Every feasible distribution matrix contains exactly one 1 in every row and every column, all other elements are equal to zero. In a general transportation problem of this dimension, however, a nondegenerate basic solution would have $2 n - 1$ positive variables. Thus, basic feasible solutions to the assignment problem are highly degenerate, with $n - 1$ basic variables equal to zero. Starting with a feasible distribution matrix $\mathbf { \dot { X } } ,$ , the assignment problem can be solved by the general transportation algorithm. It is time consuming to do so. However, because of the highly degenerate nature of the basic feasible solutions, the assignment problem can be solved with the highly eficient Hungarian method (see [18.9]).

##### 18.1.4.3 Distribution Problem

The problem is represented by an example.

m products $E _ { 1 } , E _ { 2 } , \dots , E _ { m }$ should be produced in quantities $a _ { 1 } , a _ { 2 } , \ldots , a _ { m }$ . Every product can be produced on any of n machines $M _ { 1 } , M _ { 2 } , \ldots , M _ { n }$ . The production of a unit of product $E _ { i }$ on machine ${ \bf \bar { \boldsymbol { M } } } _ { j }$ needs processing time $b _ { i j }$ and cost $c _ { i j } .$ The time capacity of machine $M _ { j }$ is $b _ { j }$ . Denote the quantity produced by machine $M _ { j }$ from product $E _ { i }$ by $x _ { i j }$ . The total production costs should be minimized. This distribution problem has the following general model:

$$
f ( \underline { { \mathbf { x } } } ) = \sum _ { i = 1 } ^ { m } \sum _ { j = 1 } ^ { n } c _ { i j } x _ { i j } = \operatorname* { m i n } !\tag{18.30a}
$$

$$
\mathbf { C T } \colon \ \sum _ { j = 1 } ^ { m } x _ { i j } = a _ { i } \ ( i = 1 , \ldots , m ) , \quad \sum _ { i = 1 } ^ { n } b _ { i j } x _ { i j } \leq b _ { j } \ ( j = 1 , \ldots , n ) , \quad x _ { i j } \geq 0 \ \mathrm { f o r \ a l l } \ i , j .\tag{18.30b}
$$

The distribution problem is a generalization of the transportation problem and it can be solved by the simplex method. If all $b _ { i j } = 1$ , then the more efective transportation algorithm can be used (see 18.1.4.1, p. 921) after introducing a fictitious product $E _ { m + 1 }$ (see 18.1.4.1, p. 920).

##### 18.1.4.4 Travelling Salesman

Suppose there are n places $O _ { 1 } , O _ { 2 } , \ldots , O _ { n }$ . The travelling time from $O _ { i }$ to $O _ { j }$ is $c _ { i j }$ . Here, $c _ { i j } \neq c _ { j i }$ possible.

One wants to determine the shortest route such that the traveller passes through every place exactly once, and returns to the starting point.

Similarly to the assignment problem, exactly one element is chosen in every row and column of the time

matrix C so that the sum of the chosen elements is minimal. The dificulty of the numerical solution of this problem is the restriction that the marked elements $c _ { i j }$ should be arranged in order of the following form:

$$
c _ { i _ { 1 } , i _ { 2 } } , c _ { i _ { 2 } , i _ { 3 } } , \ldots , c _ { i _ { n } , i _ { n + 1 } } \quad { \mathrm { w i t h ~ } } i _ { k } \neq i _ { l } { \mathrm { ~ f o r ~ } } k \neq l { \mathrm { ~ a n d ~ } } i _ { n + 1 } = i _ { 1 } .\tag{18.31}
$$

The travelling salesman problem can be solved by the branch and bound methods.

##### 18.1.4.5 Scheduling Problem

n diferent products are processed on m diferent machines in a product-dependent order. At any time only one product can be processed on a machine. The processing time of each product on each machine is assumed to be known. Waiting times, when a given product is not in process, and machine idle times are also possible.

An optimal scheduling of the processing jobs is determined where the objective function is selected as the time when all jobs are finished, or the total waiting time of jobs, or total machine idle time. Sometimes the sum of the finishing times for all jobs is chosen as the objective function when no waiting time or idle time is allowed.
