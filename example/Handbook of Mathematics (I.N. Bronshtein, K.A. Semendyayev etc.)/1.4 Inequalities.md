### 1.4 Inequalities

#### 1.4.1 Pure Inequalities

##### 1.4.1.1 Definitions

1. Inequalities

Inequalities are comparisons of two real algebraic expressions represented by one of the following signs:

$$
\begin{array} { r l r } { \mathrm { T y p e I } } & { { } > } & { \left( \mathrm { " g r e a t e r " } \right) } \end{array}
$$

$$
\mathrm { T y p e I I I } \ne \quad \left( \mathrm { ^ { \cdot } n o t e q u a l ^ { \cdot \cdot } } \right)
$$

$$
\begin{array} { r l r } { \mathrm { T y p e \ I V } } & { { } \ge } & { \left( \mathrm { ^ { \mathfrak { c } } g r e a t e r \ o r \ e q u a l " } \right) } \end{array}
$$

$$
\begin{array} { r l r } { \mathrm { T y p e V } } & { { } \le } & { \left( \mathrm { \cdots m a l l e r ~ o r ~ e q u a l " } \right) } \end{array}
$$

$$
\mathrm { T y } \mathrm { \bar { p e } V a } \mathrm { \quad ~ \nsim ~ \quad ~ } \mathrm { ( ^ { \cdot \cdot } n o t ~ g r e a t e r " ) }
$$

The notation III and IIIa, IV and IVa, and V and Va have the same meaning, so they can be replaced by each other. The notation III can also be used for those types of quantities for which the notions of “greater” or “smaller” cannot be defined, for instance for complex numbers or vectors, but in this case it cannot be replaced by IIIa.

2. Identical Inequalities, Inequalities of the Same and of the Opposite Sense, Equivalent Inequalities

1. Identical Inequalities are valid for arbitrary values of the letters contained in them.

2. Inequalities of the Same Sense belong to the same type from the first two, i.e., both belong to type I or both belong to type II.

3. Inequalities of the Opposite Sense belong to diferent types of the first two, i.e., one to type I, the other to type II.

4. Equivalent Inequalities are inequalities if they are valid exactly for the same values of the unknowns contained in them.

3. Solution of Inequalities

Similarly to equalities, inequalities can contain unknown quantities which are usually denoted by the last letters of the alphabet. The solution ofan inequality or a system of inequalities means the determination of the limits for the unknowns between which they can change, keeping the inequality or system

of inequalities true.

Solutions can be looked for any kind of inequality; mostly pure inequalities of type I and II are to be solved.

##### 1.4.1.2 Properties of Inequalities of Type I and II

1. Change the Sense of the Inequality

$$
\mathrm { I f } \quad a > b \ \mathrm { h o l d s } , \quad \mathrm { t h e n } \quad b < a \quad \mathrm { i s ~ v a l i d } ,\tag{1.97a}
$$

$$
{ \mathrm { i f } } \quad a < b { \mathrm { ~ h o l d s } } , \quad { \mathrm { t h e n } } \quad b > a \quad { \mathrm { ~ i s ~ v a l i d } } .\tag{1.97b}
$$

2. Transitivity

$$
\mathrm { I f } \quad a > b \quad \mathrm { a n d } \quad b > c \ \mathrm { h o l d } , \quad \mathrm { t h e n } \quad a > c \ \quad \mathrm { i s ~ v a l i d } ;\tag{1.98a}
$$

$$
{ \mathrm { i f } } \quad a < b \quad { \mathrm { a n d } } \quad b < c { \mathrm { ~ h o l d } } , \quad { \mathrm { t h e n } } \quad a < c \quad { \mathrm { i s ~ v a l i d } } .\tag{1.98b}
$$

3. Addition and Subtraction of a Quantity

$$
\mathrm { I f } \quad a > b \ \mathrm { h o l d s } , \quad \mathrm { t h e n } \quad a \pm c > b \pm c \quad \mathrm { i s \ v a l i d } ;\tag{1.99a}
$$

$$
{ \mathrm { i f } } \quad a < b { \mathrm { ~ h o l d s , } } \quad { \mathrm { t h e n } } \quad a \pm c < b \pm c \quad { \mathrm { i s ~ v a l i d } } .\tag{1.99b}
$$

By adding or subtracting the same amount to the both sides of inequality, the sense of the inequality does not change.

4. Addition of Inequalities

$$
\mathrm { I f } \quad a > b \quad \mathrm { a n d } \quad c > d \mathrm { ~ h o l d } , \quad \mathrm { t h e n } \quad a + c > b + d \quad \mathrm { ~ i s ~ v a l i d } ;\tag{1.100a}
$$

$$
{ \mathrm { i f } } \quad a < b \quad { \mathrm { a n d } } \quad c < d { \mathrm { ~ h o l d } } , \quad { \mathrm { t h e n } } \quad a + c < b + d \quad { \mathrm { ~ i s ~ v a l i d } } .\tag{1.100b}
$$

Two inequalities of the same sense can be added.

5. Subtraction of Inequalities

$$
\mathrm { I f } \quad a > b \quad \mathrm { a n d } \quad c < d \mathrm { ~ h o l d } , \quad \mathrm { t h e n } \quad a - c > b - d \quad \mathrm { i s ~ v a l i d } ;\tag{1.101a}
$$

$$
{ \mathrm { i f } } \quad a < b \quad { \mathrm { a n d } } \quad c > d { \mathrm { ~ h o l d } } , \quad { \mathrm { t h e n } } \quad a - c < b - d \quad { \mathrm { i s ~ v a l i d } } .\tag{1.101b}
$$

Inequalities of the opposite sense can be subtracted; the result keeps the sense of the first inequality.   
Subtracting inequalities of the same sense is not allowed.

6. Multiplication and Division of an Inequality by a Quantity

$$
\mathrm { I f } \quad a > b \quad \mathrm { a n d } \quad c > 0 \mathrm { ~ h o l d , } \quad \mathrm { t h e n } \quad a c > b c \quad \mathrm { a n d } \quad \frac { a } { c } > \frac { b } { c } \mathrm { ~ a r e ~ v a l i d , }\tag{1.102a}
$$

$$
{ \mathrm { i f } } \quad a < b \quad { \mathrm { a n d } } \quad c > 0 { \mathrm { ~ h o l d , } } \quad { \mathrm { t h e n } } \quad a c < b c \quad { \mathrm { a n d } } \quad { \frac { a } { c } } < { \frac { b } { c } } { \mathrm { ~ a r e ~ v a l i d , } }\tag{1.102b}
$$

$$
{ \mathrm { i f } } \quad a > b \quad { \mathrm { a n d } } \quad c < 0 { \mathrm { ~ h o l d , } } \quad { \mathrm { t h e n } } \quad a c < b c \quad { \mathrm { a n d } } \quad { \frac { a } { c } } < { \frac { b } { c } } { \mathrm { ~ a r e ~ v a l i d , } }\tag{1.102c}
$$

$$
{ \mathrm { i f } } \quad a < b \quad { \mathrm { a n d } } \quad c < 0 { \mathrm { ~ h o l d , } } \quad { \mathrm { t h e n } } \quad a c > b c \quad { \mathrm { a n d } } \quad { \frac { a } { c } } > { \frac { b } { c } } { \mathrm { a r e ~ v a l i d } } .\tag{1.102d}
$$

Multiplication or division of both sides of an inequality by a positive value does not change the sense of the inequality. Multiplication or division by a negative value changes the sense of the inequality.

7. Inequalities and Reciprocal Values

$$
\mathrm { I f } \quad 0 < a < b \quad \mathrm { o r } \quad a < b < 0 \mathrm { ~ h o l d , } \quad \mathrm { t h e n } \quad { \frac { 1 } { a } } > { \frac { 1 } { b } } \mathrm { ~ i s ~ v a l i d } .\tag{1.103}

#### 1.4.2 Special Inequalities

##### 1.4.2.1 Triangle Inequality for Real Numbers

For arbitrary real numbers $a , b , a _ { 1 } , a _ { 2 } , \ldots , a _ { n }$ , there are the inequalities

$$
\left| a + b \right| \leq \left| a \right| + \left| b \right| ; \qquad \left| a _ { 1 } + a _ { 2 } + \cdot \cdot \cdot + a _ { n } \right| \leq \left| a _ { 1 } \right| + \left| a _ { 2 } \right| + \cdot \cdot \cdot + \left| a _ { n } \right| .\tag{1.104}
$$

The absolute value of the sum of two or more real numbers is less than or equal to the sum of their absolute values. The equality holds only if the summands have the same sign.

##### 1.4.2.2 Triangle Inequality for Complex Numbers

For n complex numbers $z _ { 1 } , z _ { 2 } , \ldots , z _ { n } \in \mathbb { C }$

$$
\left| \sum _ { k = 1 } ^ { n } z _ { k } \right| = | z _ { 1 } + z _ { 2 } + \cdot \cdot \cdot + z _ { n } | \leq | z _ { 1 } | + | z _ { 2 } | + \cdot \cdot \cdot + | z _ { n } | = \sum _ { k = 1 } ^ { n } | z _ { k } | .\tag{1.105}
$$

##### 1.4.2.3 Inequalities for Absolute Values of Differences of Real and Complex Numbers

For arbitrary real numbers $a , b \in \mathbb { R }$ , there are the inequalities

$$
| | a | - | b | | \leq | a - b | \leq | a | + | b | .\tag{1.106}
$$

The absolute value of the diference of two real numbers is less than or equal to the sum of their absolute values, but greater than or equal to the absolute value of the diference of their absolute values. For two arbitrary complex numbers $z _ { 1 } , z _ { 2 } \in \mathbb { C }$

$$
\left| \left| z _ { 1 } \right| - \left| z _ { 2 } \right| \right| \leq \left| z _ { 1 } - z _ { 2 } \right| \leq \left| z _ { 1 } \right| + \left| z _ { 2 } \right| .\tag{1.107}
$$

##### 1.4.2.4 Inequality for Arithmetic and Geometric Means

$$
{ \frac { a _ { 1 } + a _ { 2 } + \cdot \cdot \cdot + a _ { n } } { n } } \geq { \sqrt [ n ] { a _ { 1 } a _ { 2 } \cdot \cdot \cdot a _ { n } } } \quad { \mathrm { f o r } } \quad a _ { i } > 0 .\tag{1.108}
$$

The arithmetic mean of n positive numbers is greater than or equal to their geometric mean. Equality holds only if all the n numbers are equal.

##### 1.4.2.5 Inequality for Arithmetic and Quadratic Means

$$
\left| \frac { a _ { 1 } + a _ { 2 } + \cdot \cdot \cdot + a _ { n } } { n } \right| \le \sqrt { \frac { { a _ { 1 } } ^ { 2 } + { a _ { 2 } } ^ { 2 } + \cdot \cdot \cdot + { a _ { n } } ^ { 2 } } { n } } .\tag{1.109}
$$

The absolute value of the arithmetic mean of numbers is less than or equal to their quadratic mean.

##### 1.4.2.6 Inequalities for Diferent Means of Real Numbers

For the harmonic, geometric, arithmetic, and quadratic means of two positive real numbers a and b with $a < b$ the following inequalities hold (see also 1.2.5.5, p. 20):

$$
a < x _ { H } < x _ { G } < x _ { A } < x _ { Q } < b .\tag{1.110a}
$$

Here

$$
x _ { A } = \frac { a + b } { 2 } , x _ { G } = \sqrt { a b } , x _ { H } = \frac { 2 a b } { a + b } , x _ { Q } = \sqrt { \frac { a ^ { 2 } + b ^ { 2 } } { 2 } } .\tag{1.110b}
$$

##### 1.4.2.7 Bernoulli’s Inequality

For every real number $a \geq - 1$ and integer $n \geq 1$ holds

$$
( 1 + a ) ^ { n } \geq 1 + n a .\tag{1.111}
$$

The equality holds only for $n = 1$ , or $a = 0$

##### 1.4.2.8 Binomial Inequality

For arbitrary real numbers $a , b \in \mathbb { R }$ holds

$$
| a b | \leq \frac { 1 } { 2 } ( a ^ { 2 } + b ^ { 2 } ) .\tag{1.112}
$$

##### 1.4.2.9 Cauchy-Schwarz Inequality

1. Cauchy-Schwarz Inequality for Real Numbers

The Cauchy-Schwarz inequality holds for arbitrary real numbers $a _ { i } , b _ { j } \in \mathbb { R }$

$$
\left| a _ { 1 } b _ { 1 } + a _ { 2 } b _ { 2 } + \cdot \cdot \cdot + a _ { n } b _ { n } \right| \leq { \sqrt { { a _ { 1 } } ^ { 2 } + { a _ { 2 } } ^ { 2 } + \cdot \cdot \cdot + { a _ { n } } ^ { 2 } } } { \sqrt { { b _ { 1 } } ^ { 2 } + { b _ { 2 } } ^ { 2 } + \cdot \cdot \cdot + { b _ { n } } ^ { 2 } } }\tag{1.113a}
$$

or

$$
( a _ { 1 } b _ { 1 } + a _ { 2 } b _ { 2 } + \cdot \cdot \cdot + a _ { n } b _ { n } ) ^ { 2 } \leq ( { a _ { 1 } } ^ { 2 } + { a _ { 2 } } ^ { 2 } + \cdot \cdot \cdot + a _ { n } ^ { 2 } ) ( { b _ { 1 } } ^ { 2 } + { b _ { 2 } } ^ { 2 } + \cdot \cdot \cdot + b _ { n } ^ { 2 } ) .\tag{1.113b}
$$

For two finite sequences of n real numbers, the sum of the pairwise products is less than or equal to the product of the square roots of the sums of the squares of these numbers. Equality holds only if $a _ { 1 } : b _ { 1 } = a _ { 2 } : b _ { 2 } = \cdot \cdot \cdot = a _ { n } : b _ { n } .$

If $n = 3$ and $\{ a _ { 1 } , a _ { 2 } , a _ { 3 } \}$ and $\{ b _ { 1 } , b _ { 2 } , b _ { 3 } \}$ are considered as vectors in a Cartesian coordinate system, then the Cauchy-Schwarz inequality means that the absolute value of the scalar product of two vectors is less than or equal to the product of absolute values of these vectors. If $n > 3 .$ , then this statement can be extended for vectors in n-dimensional Euclidean space.

##### 1.4.2.12 H¨older Inequality

1. H¨older Inequality for Series

If p and q are two real numbers such that $\frac { 1 } { p } + \frac { 1 } { q } = 1$ is fulfilled, and if $x _ { 1 } , x _ { 2 } , \ldots , x _ { n }$ and $y _ { 1 } , y _ { 2 } , \ldots , y _ { n }$ are arbitrary 2n complex numbers, then the following inequality holds:

$$
\sum _ { k = 1 } ^ { n } | x _ { k } y _ { k } | \leq \left[ \sum _ { k = 1 } ^ { n } | x _ { k } | ^ { p } \right] ^ { \frac { 1 } { p } } \left[ \sum _ { k = 1 } ^ { n } | y _ { k } | ^ { q } \right] ^ { \frac { 1 } { q } } .\tag{1.118a}
$$

This inequality is also valid for countable infinite pairs of numbers:

$$
\sum _ { k = 1 } ^ { \infty } | x _ { k } y _ { k } | \leq \left[ \sum _ { k = 1 } ^ { \infty } | x _ { k } | ^ { p } \right] ^ { \frac { 1 } { p } } \left[ \sum _ { k = 1 } ^ { \infty } | y _ { k } | ^ { q } \right] ^ { \frac { 1 } { q } } ,\tag{1.118b}
$$

where from the convergence of the series on the right-hand side the convergence of the left-hand side follows.

2. H¨older Inequality for Integrals

If $f ( x )$ and $g ( x )$ are two measurable functions on the measure space $( \mathrm { X } , \mathcal { A } , \mu )$ (see 12.9.2, p. 695), then the following inequality holds:

$$
\int _ { X } | f ( x ) g ( x ) | d \mu \leq \left[ \int | f ( x ) | ^ { p } d \mu \right] ^ { \frac { 1 } { p } } \left[ \int | g ( x ) | ^ { q } d \mu \right] ^ { \frac { 1 } { q } } .\tag{1.118c}
$$

##### 1.4.2.13 Minkowski Inequality

1. Minkowski Inequality for Series

If $p \geq 1$ holds, and $\scriptstyle \{ x _ { k } \} _ { k = 1 } ^ { k = \infty }$ and $\{ y _ { k } \} _ { k = 1 } ^ { \infty }$ with $x _ { k } , y _ { k } \in \mathbb { C }$ are two sequences of numbers, then holds:

$$
\left[ \sum _ { k = 1 } ^ { \infty } | x _ { k } + y _ { k } | ^ { p } \right] ^ { \frac { 1 } { p } } \leq \left[ \sum _ { k = 1 } ^ { \infty } | x _ { k } | ^ { p } \right] ^ { \frac { 1 } { p } } + \left[ \sum _ { k = 1 } ^ { \infty } | y _ { k } | ^ { p } \right] ^ { \frac { 1 } { p } } .\tag{1.119a}
$$

2. Minkowski Inequality for Integrals

If $f ( x )$ and $g ( x )$ are two measurable functions on the measure space $( \mathrm { X } , \mathcal { A } , \mu )$ (see 12.9.2, p. 695), then holds:

$$
\left[ \int | f ( x ) + g ( x ) | ^ { p } d \mu \right] ^ { \frac { 1 } { p } } \leq \left[ \int | f ( x ) | ^ { p } d \mu \right] ^ { \frac { 1 } { p } } + \left[ \int | g ( x ) | ^ { p } d \mu \right] ^ { \frac { 1 } { p } } .\tag{1.119b}
$$
