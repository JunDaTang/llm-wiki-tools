##### 9.2.2.2 Classification and Properties of Linear Second-Order Differential Equations with More than Two Independent Variables

1. General Form

A diferential equation of this kind for $u = u ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } )$ has the form

$$
\sum _ { i , k } a _ { i k } { \frac { \partial ^ { 2 } u } { \partial x _ { i } \partial x _ { k } } } + \cdot \cdot \cdot = 0 ,\tag{9.86}
$$

where $a _ { i k }$ are given functions of the independent variables and the dots in (9.86) mean terms not containing second-order derivatives of the unknown function.

In general, the diferential equation (9.86) cannot be reduced to a simple canonical form by transforming the independent variables. However, there is an important classification, similar to the one introduced above in 9.2.2.1, p. 576 (see [9.5]).

2. Linear Second-Order Partial Diferential Equations with Constant Coeficients If all coeficients $a _ { i k }$ in (9.86) are constants, then the equation can be reduced by a linear homogeneous transformation of the independent variables into a simpler canonical form

$$
\sum _ { i } \kappa _ { i } \frac { \partial ^ { 2 } u } { \partial { x _ { i } } ^ { 2 } } + \cdot \cdot \cdot = 0 ,\tag{9.87}
$$

where the coeficients $\kappa _ { i }$ are 1 or 0. Several characteristic cases have to be distinguished.

1. Elliptic Diferential Equation If all coeficients $\kappa _ { i }$ are diferent from zero, and they have the same sign, then it is the case of an elliptic diferential equation.

2. Hyperbolic and Ultra-Hyperbolic Diferential Equation If all coeficients $\kappa _ { i }$ are diferent from zero, but one has a sign diferent from the other’s, then it is the case of a hyperbolic diferential equation. If both types of signs occur at least twice, then it is an ultra-hyperbolic diferential equation.

3. Parabolic Diferential Equation If one of the coeficients $\kappa _ { i }$ is equal to zero, the others are different from zero and they have the same sign, then it is the case of a parabolic diferential equation.

4. Simple Case for Elliptic and Hyperbolic Diferential Equations If not only the coeficients of the second order derivatives of the unknown function are constants, but also those of the first order derivatives, then it is possible to eliminate the terms of the first order derivatives, for which $\kappa _ { i } \neq 0$ , by substitution. For this purpose is

$$
u = v \exp \left( - \frac { 1 } { 2 } \sum \frac { b _ { k } } { \kappa _ { k } } x _ { k } \right) ,\tag{9.88}
$$

substituted where $b _ { k }$ is the coeficient of $\frac { \partial u } { \partial x _ { k } }$ in (9.87) and the summation is performed for all $\kappa _ { i } \neq 0$ In this way, every elliptic and hyperbolic diferential equation with constant coeficients can be reduced to a simple form:

$$
\mathrm { a ) { \ E l l i p t i c ~ C a s e : } } \quad \Delta v + k v = g . \quad ( 9 . 8 9 ) \qquad \mathrm { b ) { \ H y p e r b o l i c ~ C a s e : } } \quad \frac { \partial ^ { 2 } v } { \partial t ^ { 2 } } - \Delta v + k v = g .\tag{9.90}
$$

Here $\Delta$ denotes the Laplace operator (see 13.2.6.5, p. 716).
