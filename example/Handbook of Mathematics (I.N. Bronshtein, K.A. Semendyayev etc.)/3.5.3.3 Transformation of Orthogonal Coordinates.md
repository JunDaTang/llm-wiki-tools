##### 3.5.3.3 Transformation of Orthogonal Coordinates

1. Parallel Translation

If the original coordinates are x, y, z, and a, b, c denote the coordinates of the origin of the new coordinate system in the old system (Fig. 3.175), then the new coordinates $x ^ { \prime } , y ^ { \prime } , z ^ { \prime }$ satisfy the relations

$$
x = x ^ { \prime } + a , \quad y = y ^ { \prime } + b , \quad z = z ^ { \prime } + c , \quad x ^ { \prime } = x - a , \quad y ^ { \prime } = y - b , \quad z ^ { \prime } = z - c .\tag{3.359}
$$

2. Rotation of the Coordinate System

The relation between the original coordinates $x , y , z$ and the new coordinates $x ^ { \prime } , y ^ { \prime } , z ^ { \prime }$ after rotation is given by

$$
\underline { { \mathbf { x } } } ^ { \prime } = \left( \begin{array} { l } { x ^ { \prime } } \\ { y ^ { \prime } } \\ { z ^ { \prime } } \end{array} \right) = \mathbf { D } \left( \begin{array} { l } { x } \\ { y } \\ { z } \end{array} \right) = \mathbf { D } \underline { { \mathbf { x } } } .\tag{3.360a}
$$

D is called the rotation matrix ofthe coordinate system. The special rotation matrix

$$
{ \bf D } _ { x } ( \alpha ) = \left( \begin{array} { c c c } { { 1 } } & { { 0 } } & { { 0 } } \\ { { 0 } } & { { \cos \alpha } } & { { \sin \alpha } } \\ { { 0 } } & { { - \sin \alpha \ \cos \alpha } } \end{array} \right)\tag{3.360b}
$$

describes rotations of the $x , y , z$ system around the x-axis by the angel $\alpha$ . In analogy rotations of the x, y, z system around the y-axis by the angel $\beta$ or around the z-axis by the angel γ describe the following rotation matrices:

$$
\begin{array} { r } { \mathbf D _ { y } ( \beta ) = \left( \begin{array} { c c } { \cos \beta 0 - \sin \beta } \\ { 0 1 } & { 0 } \\ { \sin \beta 0 } & { \cos \beta } \end{array} \right) , \qquad \quad ( 3 . 3 6 0 \mathrm { c } ) \qquad \mathbf D _ { z } ( \gamma ) = \left( \begin{array} { c c } { \cos \gamma \sin \gamma 0 } \\ { - s i n \gamma \cos \gamma 0 } \\ { 0 } & { 0 } \end{array} \right) . } \end{array}\tag{3.360d}
$$

Remark:The rotation of the x, y, z system around an arbitrary axis through the origin can be described with the help of direction cosines (see 3.5.3.4), Cardan angels (3.5.3.5) or Euler angels (3.5.3.6).

3. Rotation of an Object

In geometry two types of transformations are distinguished (see also 3.5.4, p. 229):

a) coordinate transformations (the coordinate system is transformed), and

b) geometric transformations (the position of a geometric object is changed in a fixed coordinate system).

Consequently, at the rotation around an arbitrary axis through the origin the following rotations are distinguished

a) rotation of the coordinate system (see (3.360a-d)) and

b) rotation of an object in a fixed coordinate system. In this case:

$$
\underline { { \mathbf { x } } } _ { P } ^ { \prime } = \mathbf { R } \underline { { \mathbf { x } } } _ { P }
$$

$$
\begin{array} { r } { ( 3 . 3 6 1 \mathrm { a } ) \qquad \mathbf { R } = \mathbf { D } ^ { - 1 } = \mathbf { D } ^ { \mathrm { T } } . } \end{array}\tag{3.361b}
$$

Here the formulas (3.361a,b) describe the relation between the coordinates $x _ { P } , y _ { P } , z _ { P }$ of the initial position of the object and its coordinates $x _ { P } ^ { \prime } , y _ { P } ^ { \prime } , z _ { P } ^ { \prime }$ after the rotation. R is called the rotation matrix of the object.

Remarks:

1. Rotations around an arbitrary axis through the origin will have a suitable description with quaternions (see 4.4.2.5, p. 297).

2. Rotations around an arbitrary axis not running through the origin, will be discussed in the example on p. 235.
