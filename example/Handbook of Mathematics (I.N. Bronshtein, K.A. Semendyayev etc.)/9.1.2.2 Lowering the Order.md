##### 9.1.2.2 Lowering the Order

One of the most important solution methods for n-th order diferential equations

$$
f \left( x , y , y ^ { \prime } , \ldots , y ^ { ( n ) } \right) = 0\tag{9.27}
$$

is the substitution of variables in order to obtain a simpler diferential equation, especially one of lower order. Diferent cases can be distinguished.

1. $f = f ( y , y ^ { \prime } , \ldots , y ^ { ( n ) } )$ , i.e., x does not appear explicitly:

$$
f \left( y , y ^ { \prime } , \ldots , y ^ { ( n ) } \right) = 0 .\tag{9.28a}
$$

By substitution

$$
{ \frac { d y } { d x } } = p , \ { \frac { d ^ { 2 } y } { d x ^ { 2 } } } = p { \frac { d p } { d y } } , . . .\tag{9.28b}
$$

the order of the diferential equation can be reduced from n to $( n - 1 )$

Reducing the order of the diferential equation $y y ^ { \prime \prime } - y ^ { \prime 2 } = 0$ to one, with the substitution $y ^ { \prime } =$ $p , p d p / d y = y ^ { \prime \prime }$ it becomes a first-order diferential equation $~ y p d p / d y - p ^ { 2 } = 0$ , and $y d p / d y - p = 0$ results in $p = C y = d y / d x , y = C _ { 1 } e ^ { C x }$ . Canceling $p$ does not result in a loss of a solution, since $p = 0$ gives the solution $y = C _ { 1 }$ , which is included in the general solution with $C = 0$

2. $f = f ( x , y ^ { \prime } , \ldots , y ^ { ( n ) } )$ , i.e., y does not appear explicitly:

$$
f \left( x , y ^ { \prime } , . . . , y ^ { ( n ) } \right) = 0 .\tag{9.29a}
$$

The order of the diferential equation can be reduced from n to (n 1) by the substitution

$$
y ^ { \prime } = p .\tag{9.29b}
$$

If the first k derivatives are missing in the initial equation, then a suitable substitution is

$$
y ^ { ( k + 1 ) } = p .\tag{9.29c}
$$

The order of the diferential equation $y ^ { \prime \prime } - x y ^ { \prime \prime \prime } + ( y ^ { \prime \prime \prime } ) ^ { 3 } = 0$ will be reduced by the substitution $y ^ { \prime \prime } = p ,$ , so one gets a Clairaut diferential equation $p - x { \frac { d p } { d x } } + \left( { \frac { d p } { d x } } \right) ^ { 3 } = 0$ whose general solution is $p = C _ { 1 } x + C _ { 1 } ^ { \ 3 }$ . Therefore, $y = \frac { C _ { 1 } x ^ { 3 } } { 6 } - \frac { { C _ { 1 } } ^ { 3 } x ^ { 2 } } { 2 } + C _ { 2 } x + C _ { 3 }$ . From the singular solution of the Clairaut diferential equation $p \ = \ { \frac { 2 { \sqrt { 3 } } } { 9 } } x ^ { 3 / 2 }$ one gets the singular solution of the original equation: $y = \frac { 8 \sqrt { 3 } } { 3 1 5 } x ^ { 7 / 2 } + C _ { 1 } x + C _ { 2 } .$

3. $f \left( x , y , y ^ { \prime } , \ldots , y ^ { ( n ) } \right)$ is a homogeneous function (see 2.18.2.4, 4., p. 122)

in $y , y ^ { \prime } , y ^ { \prime \prime } , \ldots , y ^ { ( n ) }$

$$
f \left( x , y , y ^ { \prime } , \ldots , y ^ { ( n ) } \right) = 0 .\tag{9.30a}
$$

One can reduce the order by the substitution

$$
z = { \frac { y ^ { \prime } } { y } } , \quad { \mathrm { i . e . , } } \quad y = e ^ { \int z d x } .\tag{9.30b}
$$

Transforming the diferential equation $y y ^ { \prime \prime } - { y ^ { \prime } } ^ { 2 } = 0$ by the substitution $z = y ^ { \prime } / y$ , results in ${ \frac { d z } { d x } } =$ ${ \frac { y y ^ { \prime \prime } - y ^ { \prime 2 } } { y ^ { 2 } } } = 0$ so the order is reduced by one. One gets $z = C _ { 1 }$ , therefore, ln $| y | = C _ { 1 } x + C _ { 2 }$ , or $y = C e ^ { C _ { 1 } x }$ with ln $| C | = C _ { 2 }$

4. $f = f ( x , y , y ^ { \prime } , \ldots , y ^ { ( n ) } )$ is a function of only x:

$$
y ^ { ( n ) } = f ( x ) .\tag{9.31a}
$$

One gets the general solution by n repeated integrations. It has the form

$$
y = C _ { 1 } + C _ { 2 } x + C _ { 3 } x ^ { 2 } + \cdot \cdot \cdot + C _ { n } x ^ { n - 1 } + \psi ( x )\tag{9.31b}
$$

with

$$
\psi ( x ) = \iint \cdots \int f ( x ) ( d x ) ^ { n } = { \frac { 1 } { ( n - 1 ) ! } } \int _ { x _ { 0 } } ^ { x } f ( t ) ( x - t ) ^ { n - 1 } d t .\tag{9.31c}
$$

It has to be mentioned here that $x _ { 0 }$ is not an additional arbitrary constant, since the change in $x _ { 0 }$ results in the change of $C _ { k }$ because of the relation

$$
C _ { k } = { \frac { 1 } { ( k - 1 ) ! } } y ^ { ( k - 1 ) } ( x _ { 0 } ) .\tag{9.31d}
$$
