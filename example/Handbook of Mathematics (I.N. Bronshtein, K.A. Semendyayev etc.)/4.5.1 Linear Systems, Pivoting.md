#### 4.5.1 Linear Systems, Pivoting

##### 4.5.1.1 Linear Systems

A linear system contains m linear forms

$$
{ \begin{array} { r l r l } & { y _ { 1 } = \ a _ { 1 1 } x _ { 1 } + \ a _ { 1 2 } x _ { 2 } + \cdots + \ a _ { 1 n } x _ { n } + \ a _ { 1 } } \\ & { y _ { 2 } = \ a _ { 2 1 } x _ { 1 } + \ a _ { 2 2 } x _ { 2 } + \cdots + \ a _ { 2 n } x _ { n } + \ a _ { 2 } } \\ & { \underbrace { \phantom { 2 } \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots } } \\ & { y _ { m } = a _ { m 1 } x _ { 1 } + a _ { m 2 } x _ { 2 } + \cdots + a _ { m n } x _ { n } + a _ { m } } \end{array} } \quad { \mathrm { o r } } \quad { \underline { { \mathbf { y } } } } = \mathbf { A } { \underline { { \mathbf { x } } } } + { \underline { { \mathbf { a } } } }\tag{4.174a}
$$

with

$$
\mathbf { A } = \left( \begin{array} { c c c } { a _ { 1 1 } } & { a _ { 1 2 } } & { \cdots } & { a _ { 1 n } } \\ { a _ { 2 1 } } & { a _ { 2 2 } } & { \cdots } & { a _ { 2 n } } \\ { \vdots } & & & { \vdots } \\ { a _ { m 1 } } & { a _ { m 2 } } & { \cdots } & { a _ { m n } } \end{array} \right) , \quad \underline { { \mathbf { a } } } = \left( \begin{array} { c } { a _ { 1 } , } \\ { a _ { 2 } , } \\ { \vdots } \\ { a _ { m } } \end{array} \right) , \qquad \underline { { \mathbf { x } } } = \left( \begin{array} { c } { x _ { 1 } , } \\ { x _ { 2 } , } \\ { \vdots } \\ { x _ { n } } \end{array} \right) , \qquad \underline { { \mathbf { y } } } = \left( \begin{array} { c } { y _ { 1 } , } \\ { y _ { 2 } , } \\ { \vdots } \\ { y _ { m } } \end{array} \right) .\tag{4.174b}
$$

The elements $a _ { \mu \nu }$ of the matrix A of size $( m , n )$ and the components $a _ { \mu } \ ( \mu = 1 , 2 , \ldots , m )$ of the column vector a are constants. The components $x _ { \nu } \ ( m = 1 , 2 , \ldots , n )$ of the column vector x are the independent variables, the components $y _ { \mu } \ ( \mu = 1 , 2 , \ldots , m )$ of the column vector y are the dependent variables.

##### 4.5.1.2 Pivoting

1. Scheme of Pivoting

If an element $a _ { i k }$ is not equal to zero in (4.174a), the variable $y _ { i }$ can be exchanged for an independent one and the variable $x _ { k }$ for a dependent one in a so-called pivoting step. The pivoting step is the basic element of pivoting, the method by which for instance systems of linear equations and linear optimization problems can be solved. The pivoting step is achieved by the schemes

$$
\begin{array}{c} \begin{array} { r l } &  \frac { | \begin{array} { l l l l l l } { x _ { 1 } } & { x _ { 2 } } & { \cdots } & { x _ { k } } & { \cdots } & { x _ { n } } & { 1 } \\ { y _ { 1 } | a _ { 1 1 } } & { a _ { 1 2 } } & { \cdots } & { a _ { 1 k } } & { \cdots } & { a _ { 1 n } } & { a _ { 1 } } \end{array} | } \\ & { y _ { 2 } | \begin{array} { l l l l l l } { a _ { 2 1 } } & { a _ { 2 2 } } & { \cdots } & { a _ { 2 k } } & { \cdots } & { a _ { 2 n } } & { a _ { 2 } } \\ { \vdots } & { \cdots } & { \cdots } & { \cdots } & { \cdots } & { \cdots } & { \cdots } \\ { y _ { i } | a _ { i 1 } } & { a _ { i 2 } } & { \cdots } & { [ a _ { i k } ] } & { \ddots } & { a _ { i n } } & { a _ { i } } \end{array} | } \\ & { \vdots } & { \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad } \\ & { \frac { y _ { m } | a _ { m 1 } } { x _ { k } } & { a _ { m 2 } } & { \cdots } & { a _ { m k } } & { \cdots } & { a _ { m n } } & { a _ { m } } \end{array} | } \\ &  \frac { \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad \quad } { x _ { k } | \begin{array} { l l l l l l } { a _ { i 1 } } & { a _ { i 2 } } & { \cdots } & { a _ { k } } & { \cdots } & { a _ { m } } \\ { \cdots } & { \cdots } & { \cdots } & { \cdots } & { \cdots } & { a _ { k n } } & { a _ { i } } \end{array} | } \end{array}
$$

$$
\begin{array} { r } { \frac { \mid x _ { 1 } \quad x _ { 2 } \quad \cdots \quad y _ { i } \quad \cdots \quad x _ { n } \quad 1 } { y _ { 1 } \mid \alpha _ { 1 1 } \quad \alpha _ { 1 2 } \quad \cdots \quad \alpha _ { 1 k } \quad \cdots \quad \alpha _ { 1 n } \quad \alpha _ { 1 } } } \\ {  \begin{array} { l } { y _ { 2 } } \\ { \vdots } \\ { x \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots } \\ { x _ { k } } \end{array}  , } \\ {  \begin{array} { l } { \vdots } \\ { z _ { 1 } \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots } \\ { y _ { m } } \end{array}  \alpha _ { m } } \\ {   \begin{array} { l } { \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots } \\ { \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots \dots } \\ { y _ { m } } \end{array}  \alpha _ { m } } \end{array} ,\tag{4.175}
$$

where the left scheme corresponds to the system (4.174a).

2. Pivoting Rules

The framed element in the scheme $a _ { i k } \left( a _ { i k } \neq 0 \right)$ is called the pivot element; it is at the intersection of the pivot column and pivot row. The elements $\alpha _ { \mu \nu }$ and $\alpha _ { \mu }$ of the new scheme on the right-hand side will be calculated by the following pivoting rules:

$$
\mathbf { 1 . } \quad \alpha _ { i k } = \frac { 1 } { a _ { i k } } ,
$$

$$
( 4 . 1 7 6 \mathrm { a } ) 2 . \alpha _ { \mu k } = \frac { a _ { \mu k } } { a _ { i k } } ( \mu = 1 , . . . , m ; \mu \neq i ) ,\tag{4.176b}
$$

$$
{ \bf 3 . } \quad \alpha _ { i \nu } = - { \frac { a _ { i \nu } } { a _ { i k } } } , \quad \alpha _ { i } = - { \frac { a _ { i } } { a _ { i k } } } \quad ( \nu = 1 , 2 , \ldots , n ; \nu \not = k ) ,\tag{4.176c}
$$

$$
4 . \quad \alpha _ { \mu \nu } = a _ { \mu \nu } - a _ { \mu k } { \frac { a _ { i \nu } } { a _ { i k } } } = a _ { \mu \nu } + a _ { \mu k } \alpha _ { i \nu } , \quad \alpha _ { \mu } = a _ { \mu } + a _ { \mu k } \alpha _ { i }
$$

$$
( \mathrm { f o r e v e r y } \mu \neq i \mathrm { a n d } \mathrm { e v e r y } \nu \neq k ) .\tag{4.176d}
$$

To make the calculations easier (rule 4) one writes the elements $\alpha _ { i \nu }$ in the $( m + 1 )$ -th row of the pivoting scheme (cellar row). With this pivoting rule one can change further variables.
