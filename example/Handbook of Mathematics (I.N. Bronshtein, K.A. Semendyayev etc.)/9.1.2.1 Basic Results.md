##### 9.1.2.1 Basic Results

1. Existence of a Solution

1. Reduction to a System of Diferential Equations Every explicit n-th order diferential equation

$$
y ^ { ( n ) } = f \left( x , y , y ^ { \prime } , \ldots , y ^ { ( n - 1 ) } \right)\tag{9.22a}
$$

by introducing the new variables

$$
y _ { 1 } = y ^ { \prime } , \quad y _ { 2 } = y ^ { \prime \prime } , \ldots , y _ { n - 1 } = y ^ { ( n - 1 ) }\tag{9.22b}
$$

can be reduced to a system of n first-order diferential equations

$$
{ \frac { d y } { d x } } = y _ { 1 } , \quad { \frac { d y _ { 1 } } { d x } } = y _ { 2 } , \ldots , { \frac { d y _ { n - 1 } } { d x } } = f ( x , y , y _ { 1 } , \ldots , y _ { n - 1 } ) .\tag{9.22c}
$$

2. Existence of a System of Solutions The system of n diferential equations

$$
\frac { d y _ { i } } { d x } = f _ { i } ( x , y _ { 1 } , y _ { 2 } , \ldots , y _ { n } ) \qquad ( i = 1 , 2 , \ldots , n ) ,\tag{9.23a}
$$

which is more general than system (9.22c), has a unique system of solutions

$$
y _ { i } = y _ { i } ( x ) \quad ( i = 1 , 2 , \ldots , n ) ,\tag{9.23b}
$$

which is defined in an interva $x _ { 0 } - h \leq x \leq x _ { 0 } + h$ and for $x = x _ { 0 }$ takes the previously given initial values $y _ { i } ( x _ { 0 } ) = y _ { i } ^ { \mathrm { ~ 0 ~ } } ( i = 1 , 2 , \ldots , n )$ , if the functions $f _ { i } ( x , y _ { 1 } , y _ { 2 } , \dots , y _ { n } )$ are continuous with respect to all variables and satisfy the following Lipschitz condition.

3. Lipschitz condition For the values $x , y _ { i }$ and $y _ { i } + \Delta y _ { i }$ , which are in a certain neighborhood of the given initial values, the functions $f _ { i }$ satisfy the following inequalities:

$$
\begin{array} { r l } & { | f _ { i } ( x , y _ { 1 } + \Delta y _ { 1 } , y _ { 2 } + \Delta y _ { 2 } , \dotsc , y _ { n } + \Delta y _ { n } ) - f _ { i } ( x , y _ { 1 } , y _ { 2 } , \dotsc , y _ { n } ) | } \\ & { \qquad \leq K \left( | \Delta y _ { 1 } | + | \Delta y _ { 2 } | + \dotsc + | \Delta y _ { n } | \right) } \end{array}\tag{9.24a}
$$

with a common constant K (see also 9.1.1.1, 2., p. 541).

This fact implies that if the function $f ( x , y , y ^ { \prime } , \ldots , y ^ { ( n - 1 ) } )$ is continuous and satisfies the Lipschitz condition (9.24a), then the equation

$$
y ^ { ( n ) } = f \left( x , y , y ^ { \prime } , \ldots , y ^ { ( n - 1 ) } \right)\tag{9.24b}
$$

has a unique solution with the initial values $y ( x _ { 0 } ) = y _ { 0 } , y ^ { \prime } ( x _ { 0 } ) = y _ { 0 } { ' } , \ldots , y ^ { ( n - 1 ) } ( x _ { 0 } ) = y _ { 0 } { } ^ { ( n - 1 ) }$ , and it is $( n - 1 )$ times continuously diferentiable.

2. General Solution

1. The general solution of the diferential equation (9.24b) contains n independent arbitrary constants:

$$
y = y ( x , C _ { 1 } , C _ { 2 } , \dots , C _ { n } ) .\tag{9.25a}
$$

2. In the geometrical interpretation the equation (9.25a) defines a family of curves depending on n parameters. Every single one of these integral curves, i.e., the graph of the corresponding particular solution, can be obtained by a suitable choice of the constants ${ \overline { { C _ { 1 } , } } } { \overline { { C _ { 2 } } } } , \dots , C _ { n }$ . If the solution has to satisfy the above initial conditions, then the values $C _ { 1 } , C _ { 2 } , \ldots , C _ { n }$ are determined from the following equations:

$$
\left[ { \frac { d } { d x } } y ( x , C _ { 1 } , \ldots , C _ { n } ) \right] _ { x = x _ { 0 } } = y _ { 0 } ^ { \prime } ,\tag{9.25b}
$$

$$
\left[ \frac { d ^ { n - 1 } } { d x ^ { n - 1 } } y ( x , C _ { 1 } , \ldots , C _ { n } ) \right] _ { x = x _ { 0 } } = y _ { 0 } { } ^ { ( n - 1 ) } .
$$

If these equations are inconsistent for any initial values in a certain domain, then the solution is not general in this domain, i.e., the arbitrary constants cannot be chosen independently.

3. The general solution of system (9.23a) also contains n arbitrary constants. This general solution can be represented in two diferent ways: Either it is given in a form which is solved for the unknown functions

$$
y _ { 1 } = F _ { 1 } ( x , C _ { 1 } , \ldots , C _ { n } ) , y _ { 2 } = F _ { 2 } ( x , C _ { 1 } , \ldots , C _ { n } ) , \ldots , y _ { n } = F _ { n } ( x , C _ { 1 } , \ldots , C _ { n } )\tag{9.26a}
$$

or in the form which is solved for the constants

$$
\varphi _ { 1 } ( x , y _ { 1 } , \ldots , y _ { n } ) = C _ { 1 } , \varphi _ { 2 } ( x , y _ { 1 } , \ldots , y _ { n } ) = C _ { 2 } , \ldots , \varphi _ { n } ( x , y _ { 1 } , \ldots , y _ { n } ) = C _ { n } .\tag{9.26b}
$$

In the case of (9.26b) each relation

$$
\varphi _ { i } ( x , y _ { 1 } , \dots , y _ { n } ) = C _ { i }\tag{9.26c}
$$

is a first integral of the system (9.23a). The first integral can be defined independently of the general solution as a relation (9.26c). That is, (9.26c) will be an identity replacing $y _ { 1 } , y _ { 2 } , \ldots , y _ { n }$ by any particular solution of the given system and replacing the constant by the arbitrary constant $C _ { i }$ determined by this particular solution.

If any first integral is known in the form (9.26c), then the function $\varphi _ { i } ( x , y _ { 1 } , \dots , y _ { n } )$ satisfies the partial diferent equation

$$
{ \frac { \partial \varphi _ { i } } { \partial x } } + f _ { 1 } ( x , y _ { 1 } , \ldots , y _ { n } ) { \frac { \partial \varphi _ { i } } { \partial y _ { 1 } } } + \cdots + f _ { n } ( x , y _ { 1 } , \ldots , y _ { n } ) { \frac { \partial \varphi _ { i } } { \partial y _ { n } } } = 0 .\tag{9.26d}
$$

Conversely, each solution $\varphi _ { i } ( x , y _ { 1 } , \dots , y _ { n } )$ of the partial diferential equation (9.26d) defines a first integral of the system (9.23a) in the form (9.26c). The general solution of the system $\mathrm { ( 9 . 2 3 a ) }$ can be represented as a system of n first integrals of system (9.23a), if the corresponding functions $\varphi _ { i } ( x , y _ { 1 } , \dots , y _ { n } )$ $( i = 1 , 2 , \ldots , n )$ are linearly independent (see 9.1.2.3, 2., p. 553).
