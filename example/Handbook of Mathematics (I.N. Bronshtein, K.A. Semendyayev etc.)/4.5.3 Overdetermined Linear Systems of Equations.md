#### 4.5.3 Overdetermined Linear Systems of Equations

##### 4.5.3.1 Overdetermined Linear Systems of Equations and Linear Least Squares Problems

1. Overdetermined System of Equations

Consider the linear system of equations

$$
\mathbf { A } \mathbf { \underline { { x } } } = \mathbf { \underline { { b } } }\tag{4.187}
$$

with the rectangular matrix of coeficients $\mathbf { A } \ = \ ( a _ { i j } ) \ ( \ i \ = \ 1 , 2 , \ldots , m ; \ j \ = \ 1 , 2 , \ldots , n ; \ m \ > \ n )$ The matrix A and the vector $\mathbf { \underline { { b } } } = ( b _ { 1 } , b _ { 2 } , \ldots , b _ { m } ) ^ { \mathrm { T } }$ on the right-hand side are given, and the vector $\mathbf { \underline { { x } } } ~ = ~ ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ) ^ { \mathrm { T } }$ is unknown. Because $m \ > \ n$ holds this system is called an over-determined system. One can tell the existence and uniqueness of the solution and sometimes also the solution, for instance by pivoting.

2. Linear Least Squares Problem

If (4.187) is the mathematical model representing a practical problem (i.e., A, b, x are reals), then because of measuring or other errors it is impossible to find an exact solution of (4.187) such that it satisfies all of the equations. Substituting any vector x there will be a residual vector $\underline { { \mathbf { r } } } = ( r _ { 1 } , r _ { 2 } , \ldots , r _ { m } ) ^ { \mathrm { T } }$ given as

$$
\underline { { \mathbf { r } } } = \mathbf { A } \underline { { \mathbf { x } } } - \underline { { \mathbf { b } } } , \quad \underline { { \mathbf { r } } } \neq \underline { { \mathbf { 0 } } } .\tag{4.188}
$$

In this case x is to be determined to make the norm of the residual vector r as small as possible. Suppose now A, b, x are real. If considering the Euclidean norm, then

$$
\sum _ { i = 1 } ^ { m } r _ { i } ^ { 2 } = { \underline { { \mathbf { r } } } } ^ { \mathrm { T } } { \underline { { \mathbf { r } } } } = ( \mathbf { A } { \underline { { \mathbf { x } } } } - { \underline { { \mathbf { b } } } } ) ^ { \mathrm { T } } ( \mathbf { A } { \underline { { \mathbf { x } } } } - { \underline { { \mathbf { b } } } } ) = \operatorname* { m i n }\tag{4.189}
$$

must be valid, i.e., the residual sum of squares must be minimal. Gauss already had this idea. The formula (4.189) is called a linear least squares problem. The norm $| | \underline { { \mathbf { r } } } | | = \sqrt { \underline { { \mathbf { r } } } ^ { \mathrm { T } } \underline { { \mathbf { r } } } }$ of the residual vector r is called the residue.

3. Gauss Transformation

The vector x is the solution of (4.189) if the residual vector r is orthogonal to every column of A. That is:

$$
\mathbf { A } ^ { \mathrm { T } } \underline { { \mathbf { r } } } = \mathbf { A } ^ { \mathrm { T } } ( \mathbf { A } \underline { { \mathbf { x } } } - \underline { { \mathbf { b } } } ) = \underline { { \mathbf { 0 } } } \qquad \mathrm { o r } \qquad \mathbf { A } ^ { \mathrm { T } } \mathbf { A } \underline { { \mathbf { x } } } = \mathbf { A } ^ { \mathrm { T } } \underline { { \mathbf { b } } } .\tag{4.190}
$$

Equation (4.190) is actually a linear system of equations with a square matrix of coeficients. One refers to it as the system of normal equations. It has dimension n. The transition from (4.187) to (4.190) is called Gauss transformation. The matrix ${ \bf A } ^ { \mathrm { T } } { \bf A }$ is symmetric.

If the matrix A has the rank n (because m > n all columns of A are independent), then the matrix ${ \bf A } ^ { \mathrm { T } } { \bf A }$ is positive definite and also regular, i.e., the system of normal equations has a unique solution if the rank of A is equal to the number of unknowns.

##### 4.5.3.2 Suggestions for Numerical Solutions of Least Squares Problems

1. Cholesky Method

Because the matrix ${ \bf A } ^ { \mathrm { T } } { \bf A }$ is symmetric and positive definite in the case rank $( \mathbf { A } ) = n ,$ , in order to solve the normal system of equations one can use the Cholesky method (see 19.2.1.2, p. 958). Unfortunately this algorithm is numerically fairly unstable although it works fairly well in the cases of a $\mathrm { \dot { \bar { \ t b i g } } ^ { \mathrm { 3 5 } } }$ residue r and a “small” solution $| | \underline { { \mathbf { x } } } | |$

2. Householder Method

Numerically useful procedures in order to solve the least squares problem are the orthogonalization methods which are based on the decomposition $\mathbf { A } = \mathbf { Q } \mathbf { R }$ . Especially useful is the Householder method, where Q is an orthogonal matrix of size $( m , m )$ and R is a triangular matrix of size (m, n) (see 4.1.2, 11., p. 271).

3. Regularized Problem

In the case of rank deficiency, i.e., if rank $( \mathbf { A } ) < n$ holds, then the normal system of equations no longer has a unique solution, and the orthogonalization method gives useless results. Then instead of (4.189) the so-called regularized problem is considered:

$$
\underline { { \mathbf { r } } } ^ { \mathrm { T } } \underline { { \mathbf { r } } } + \alpha \underline { { \mathbf { x } } } ^ { \mathrm { T } } \underline { { \mathbf { x } } } = \mathrm { m i n } !\tag{4.191}
$$

Here $\alpha > 0$ is a regularization parameter. The normal equations for (4.191) are:

$$
( \mathbf { A } ^ { \mathrm { T } } \mathbf { A } + \alpha \mathbf { I } ) \underline { { \mathbf { x } } } = \mathbf { A } ^ { \mathrm { T } } \underline { { \mathbf { b } } } .\tag{4.192}
$$

The matrix of coeficients of this linear system of equations is positive definite and regular for $\alpha > 0$ but the appropriate choice of the regularization parameter α is a dificult problem (see [4.7]).
