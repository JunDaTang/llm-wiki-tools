##### 12.3.1.2 Some Properties of Normed Spaces

Among the linear metric spaces, those spaces are normable (i.e., a norm can be introduced by means of the metric, if one defines $\lVert x \rVert = \rho ( x , 0 ) )$ whose metric satisfies the conditions (12.82a) and (12.82b). Two normed spaces X and Y are called norm isomorphic if there is a bijective linear mapping $T \colon \mathrm { X } \longrightarrow$ Y with $\| T x \| \overset { \cdot } { = } \| x \|$ for all $x \in \mathrm { X }$ . Let $\| \cdot \| _ { 1 }$ and $\| \cdot \| _ { 2 }$ be two norms on the vector space X, and denote the corresponding normed spaces by $\dot { \mathrm { X _ { 1 } } }$ and $\mathrm { X _ { 2 } , \overset { \cdot } { i . e . } , \mathrm { X _ { 1 } } = ( X , \parallel \cdot \parallel _ { 1 } ) }$ and $\mathrm { X } _ { 2 } = ( X , \overset { \cdot } { \| } \cdot \| _ { 2 } )$ The norm $\| \cdot \| _ { 1 }$ is stronger than the norm $\| \cdot \| _ { 2 }$ , if there is a number $\gamma > 0$ such that $\| x \| _ { 2 } \leq \gamma \| x \| _ { 1 }$ for all $x \in \mathrm { X }$ . In this case, the convergence of a sequence $\{ x _ { n } \} _ { n = 1 } ^ { \infty }$ to x with respect to the stronger norm $\| \cdot \| _ { 1 } , \mathrm { i . e . , } \| x _ { n } - x \| _ { 1 } \longrightarrow 0$ , implies the convergence to x with respect to the norm $\| \cdot \| _ { 2 } ,$ , i.e., $\Vert { x } _ { n } - { x } \Vert _ { 2 } \longrightarrow 0$

Two norms $\lVert \cdot \rVert$ and $\lVert \cdot \rVert _ { 1 }$ are called equivalent if there are two numbers $\gamma _ { 1 } > 0 , \gamma _ { 2 } > 0$ such that $\forall x \in \mathrm { X }$ there holds $\dot { \gamma _ { 1 } } \dot { \| } x \| \leq \| x \| _ { 1 } \leq \gamma _ { 2 } \| x \|$ . In a finite dimensional vector space all norms are equivalent to each other.

A subspace ofa normed space is a closed linear subspace of the space.

#### 12.3.2 Banach Spaces

A complete normed space is called a Banach space. Every normed space X can be completed into a Banach space $\tilde { \mathrm { X } }$ by the completion procedure given in 12.2.2.5, p. 668, and by the natural extension of its algebraic operations and the norm to $\tilde { \mathrm { X } } .$

##### 12.3.2.1 Series in Normed Spaces

In a normed space X infinite series can be considered. That means for a given sequence $\{ x _ { n } \} _ { n = 1 } ^ { \infty }$ of elements $x _ { n } \in \mathrm { X }$ a new sequence $\{ s _ { k } \} _ { k = 1 } ^ { \infty }$ is constructed by

$$
s _ { 1 } = x _ { 1 } , s _ { 2 } = x _ { 1 } + x _ { 2 } , \ldots , s _ { k } = x _ { 1 } + \cdot \cdot \cdot + x _ { k } = s _ { k - 1 } + x _ { k } , \ \ldots .\tag{12.87}
$$

If the sequence $\{ s _ { k } \} _ { k = 1 } ^ { \infty }$ is convergent, ${ \mathrm { i . e . , ~ } } \| s _ { k } - s \| \longrightarrow 0 ~ ( k  \infty )$ for some $s \in X$ , then a convergent series is defined. The elements $s _ { 1 } , s _ { 2 } , \ldots , s _ { k } , \ldots$ . are called the partial sums of the series. The limit

$$
s = \operatorname* { l i m } _ { k \to \infty } \sum _ { n = 1 } ^ { k } x _ { n }\tag{12.88}
$$

is the sum of the series, and it is denoted by $s = \sum _ { n = 1 } ^ { \infty } x _ { n }$ . A series $\sum _ { n = 1 } ^ { \infty } x _ { n }$ is called absolutely convergent if the number series $\sum _ { n = 1 } ^ { \infty } \| x _ { n } \|$ is convergent. In a Banach space every absolutely convergent series is convergent, and $\| s \| \leq \sum _ { n = 1 } ^ { \infty } \| x _ { n } \|$ holds for its sum s.

##### 12.3.2.3 Sobolev Spaces

Let $\Omega \subset \mathbb { R } ^ { n }$ be a bounded domain, i.e., an open connected set, with a suficiently smooth boundary ∂Ω. For $n = 1$ or $n = 2$ , 3 one can imagine Ω being something similar to an interval $( a , b )$ or a bounded convex set.

A function $f \colon \overline { { \Omega } } \longrightarrow \mathbb { R }$ is k-times continuously diferentiable on the closed domain $\overline { { \Omega } }$ if f is k-times continuously diferentiable on Ω and each of its partial derivatives has a finite limit on the boundary, i.e., if x approaches an arbitrary point of $\partial \Omega$ . In other words, all partial derivatives can be continuously extended on the boundary of Ω, i.e., each partial derivative is a continuous function on Ω. In this vector space (for $p \in [ 1 , \infty ) )$ and with the Lebesgue measure λ in $\mathbb { R } ^ { n }$ (see example C in 12.9.1, 2., p. 695) the following norm is defined:

$$
\| f \| _ { k , p } = \| f \| = \left( \int | f ( x ) | ^ { p } d \lambda + \sum _ { 1 \leq | \alpha | \leq k } \int | D ^ { \alpha } f | ^ { p } d \lambda \right) ^ { \frac { 1 } { p } } .\tag{12.90}
$$

The resulting normed space is denoted by $\tilde { W } ^ { k , p } ( \Omega )$ or also by $\tilde { W } _ { p } ^ { k } ( \Omega )$ (in contrast to the space $\mathcal { C } ^ { ( k ) } ( [ a , b ] )$ which has a quite diferent norm). Here α means a multi-index, i.e., an ordered n-tuple $( \alpha _ { 1 } , \ldots , \alpha _ { n } )$ of non-negative integers, where the sum of the components of α is denoted by $| \alpha | = \alpha _ { 1 } + \alpha _ { 2 } + \cdot \cdot \cdot + \alpha _ { n }$ For a function $f ( x ) = f ( \xi _ { 1 } , \ldots , \xi _ { n } )$ with $x = ( \xi _ { 1 } , \ldots , \xi _ { n } ) \in \overline { { \Omega } }$ the brief notation is used as in (12.90):

$$
D ^ { \alpha } f = { \frac { \partial ^ { | \alpha | } f } { \partial \xi _ { 1 } ^ { \alpha _ { 1 } } \cdot \cdot \cdot \partial \xi _ { n } ^ { \alpha _ { n } } } } .\tag{12.91}
$$

The normed space $\tilde { W } ^ { k , p } ( \Omega )$ is not complete. Its completion is denoted by $W ^ { k , p } ( \Omega )$ or in the case of $p = 2$ by $\mathbb { H } ^ { k } ( \Omega )$ and it is called a Sobolev space.

#### 12.3.3 Ordered Normed Spaces

1. Cones in a Normed Space

Let X be a real normed space with the norm $\| \cdot \|$ . A cone $\mathrm { X } _ { + } \subset \mathrm { X }$ (see 12.1.4.2, p. 657) is called solid, $\mathrm { i f } \mathrm { X _ { + } }$ contains a ball (with positive radius), or equivalently, $\mathrm { \dot { X } _ { + } }$ contains at least one interior point.

The usual cones are solid in the spaces IR, $\mathcal { C } ( [ a , b ] )$ , c, but in the spaces $L ^ { p } ( ( a , b ) )$ and $1 ^ { p } \left( 1 \leq p < \infty \right)$ they are not solid.

A cone $\mathrm { X } _ { + }$ is called normal if the norm in X is semi-monotonic, i.e., there exists a constant $M > 0$ such that

$$
0 \leq x \leq y \implies \| x \| \leq M \| y \| .\tag{12.92}
$$

If X is a Banach space ordered by a cone $\mathrm { X } _ { + }$ , then every (o)-interval is bounded with respect to the norm if and only if the cone $\mathrm { X } _ { + }$ is normal.

The cones of the vectors with non-negative components and of the non-negative functions in the spaces $\mathbb { R } ^ { n }$ , m, ${ \bf c } , { \bf c _ { 0 } } , \mathcal { C } , { \bf l } ^ { p }$ and $L ^ { p }$ , respectively, are normal.

A cone is called regular if every monotonically increasing sequence which is bounded above,

$$
x _ { 1 } \leq x _ { 2 } \leq \cdot \cdot \cdot \leq x _ { n } \leq \cdot \cdot \cdot \leq z\tag{12.93}
$$

is a Cauchy sequence in X. In a Banach space every closed regular cone is normal.

The cones in $\mathbb { R } ^ { n } , \mathbb { P }$ and L<sup>p</sup> for $1 \le p <$ are regular, but in and m they are not.

2. Normed Vector Lattices and Banach Lattices

Let X be a vector lattice, which is a normed space at the same time. X is called a normed lattice or normed vector lattice (see [12.15], [12.19], [12.22], [12.23]), if the norm satisfies the condition

$| x | \le | y |$ implies $\| x \| \leq \| y \| \quad \forall x , y \in \mathrm { X }$ (monotonicity of the norm).

(12.94)

A complete (with respect to the norm) normed lattice is called a Banach lattice.

The spaces $\mathcal { C } ( [ a , b ] ) , \ L ^ { p } , \ 1 ^ { p } , \ B ( [ a , b ] )$ are Banach lattices.

#### 12.3.4 Normed Algebras

A vector space X over IF is called an algebra, if in addition to the operations defined in the vector space X and satisfying the axioms $\scriptstyle ( \mathbf { V 1 } ) - ( \mathbf { V 8 } )$ (see 12.1.1, p. 654), a product $x \cdot y \in \mathrm { X }$ is defined for every two elements $x , y \in \mathrm { X }$ (or with a simplified notation by a product xy), such that for arbitrary $x , y , z \in \mathrm { X }$ and $\alpha \in \mathbb { F }$ the following conditions are satisfied:

$$
\begin{array} { r l } { ( \mathbf { A } \mathbf { 1 } ) } & { { } x ( y z ) = ( x y ) z , } \end{array}\tag{12.95}
$$

$$
( \mathbf { A 2 } ) \quad x ( y + z ) = x y + x z ,\tag{12.96}
$$

$$
\begin{array} { r l } { ( \mathbf { A } \mathbf { 3 } ) } & { { } ( x + y ) z = x z + y z , } \end{array}\tag{12.97}
$$

$$
( \mathbf { A 4 } ) \quad \alpha ( x y ) = ( \alpha x ) y = x ( \alpha y ) .\tag{12.98}
$$

An algebra is commutative if $x y = y x$ holds for two arbitrary elements $x , y .$ A linear operator (see (12.21), p. 658) T: $\Chi \longrightarrow \Upsilon$ of the algebra X into the algebra Y is called an algebra homomorphism if for any $x _ { 1 } , x _ { 2 } \in \mathrm { X }$

$$
T ( x _ { 1 } \cdot x _ { 2 } ) = T x _ { 1 } \cdot T x _ { 2 } .\tag{12.99}
$$

An algebra X is called a normed algebra or a Banach algebra if it is a normed vector space or a Banach space and the norm has the additional property

$$
\| x \cdot y \| \leq \| x \| \cdot \| y \| .\tag{12.100}
$$

In a normed algebra all the operations are continuous, i.e., additionally to (12.85), if $x _ { n } \implies$ x and $y _ { n } \longrightarrow y$ , then also $x _ { n } y _ { n } \longrightarrow x y$ (see [12.20]).

Every normed algebra can be completed to a Banach algebra, where the product is extended to the norm completion with respect to (12.100).
