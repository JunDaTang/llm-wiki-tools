### 12.6 Adjoint Operators in Normed Spaces

#### 12.6.1 Adjoint of a Bounded Operator

For a given linear continuous operator $T \colon \mathrm { X } \longrightarrow \mathrm { Y } \quad \mathrm { ( X , Y }$ are normed spaces) to every $g \in \mathbb { Y } ^ { * }$ there is assigned a functional $f \in \mathrm { X ^ { * } \bar { b } y } f ( x ) = g ( T x ) , \forall x \in \bar { \mathrm { X } }$ . In this way, a linear continuous operator

$$
T ^ { * } \colon \mathrm { { \mathbb { Y } } } ^ { * } \longrightarrow \mathrm { { \mathbb { X } } } ^ { * } , \quad ( T ^ { * } g ) ( x ) = g ( T x ) , \quad \forall g \in \mathrm { { \mathbb { Y } } } ^ { * } { \mathrm { ~ a n d ~ } } \forall x \in \mathrm { { \mathbb { X } } }\tag{12.177}
$$

is obtained which is called the adjoint operator of T and has the following properties:

$( T + S ) ^ { \ast } = T ^ { \ast } + S ^ { \ast } , ( S T ) ^ { \ast } = S ^ { \ast } T ^ { \ast } , \| T ^ { \ast } \| = \| T \|$ , where for the linear continuous operators $T \colon \mathrm { X }  \mathrm { Y }$ and $S \colon \mathbb { Y }  \mathbb { Z } \quad ( \mathrm { X } , \mathrm { Y } , \mathbb { Z }$ normed spaces), the operator $S T : \mathrm { X }  \mathrm { Z }$ is defined in the natural way

as $S T ( x ) = S ( T ( x ) )$ (see $1 2 . 3 . 4 , \equiv \mathrm { C } , \mathrm { p . ~ 6 7 2 } )$ . With the notation introduced in 12.1.5, p. 658, and 12.5.4.2, p. 682, the following identities are valid for an operator $T \in B ( \mathrm { X } , \mathrm { Y } )$ :

$$
{ \overline { { I m ( T ) } } } = \ker ( T ^ { * } ) ^ { \perp } , \quad { \overline { { I m ( T ^ { * } ) } } } = \ker ( T ) ^ { \perp } ,\tag{12.178}
$$

where the closedness of $I m ( T )$ implies the closedness of $I m ( T ^ { * } )$

The operator $T ^ { * * } \colon \mathrm { X } ^ { * * } \to \mathrm { Y } ^ { * * }$ , obtained as $( T ^ { * } ) ^ { * }$ from $T ^ { * }$ , is called the second adjoint of $T$ . Due to $( T ^ { * * } ( \hat { F } _ { x } ) ) g = F _ { x } ( T ^ { * } g ) = ( T ^ { * } g ) ( x ) = g ( T x ) \stackrel { . } { = } \check { F } _ { T x } ( g )$ the operator $T ^ { * * }$ has the following property: If $F _ { x } \in \mathrm { X } ^ { * * }$ , then $T ^ { * * } \bar { F _ { x } } = F _ { T x } \in \bar { \mathrm { Y } } ^ { * * }$ . Hence, the operator $\smash { T ^ { * * } \colon  { \mathrm { X } ^ { * * } } \to  { \mathrm { Y } ^ { * * } } }$ is an extension of $T .$

In a Hilbert space IH the adjoint operator can also be introduced by means of the scalar product $( T x , y ) = ( x , \bar { T } ^ { * } y )$ $x , y \in \mathbb { H }$ This is based on the Riesz representation theorem, where the identification of IH and $\mathbb { H } ^ { * * }$ implies $( \lambda T ) ^ { * } = { \bar { \lambda } } T ^ { * } , I ^ { * } = I$ and even $T ^ { * * } = T$ . If $T$ is bijective, then the same holds for $T ^ { * }$ , and also $( T ^ { * } ) ^ { - 1 } = ` ( T ^ { - 1 } ) ^ { * }$ . For the resolvents of $T$ and $T ^ { * }$ there holds

$$
[ R _ { \lambda } ( T ) ] ^ { * } = R _ { \overline { { { \lambda } } } } ( T ^ { * } ) ,\tag{12.179}
$$

from which $\sigma ( T ^ { * } ) = \lbrace \overline { { \lambda } } colon \lambda \in \sigma ( T ) \rbrace$ follows for the spectrum of the adjoint operator.

A: Let T be an integral operator in the space $L ^ { p } ( [ a , b ] ) \ \left( 1 < p < \infty \right)$

$$
( T x ) ( s ) = \int _ { a } ^ { b } K ( s , t ) x ( t ) d t\tag{12.180}
$$

with a continuous kernel $K ( s , t )$ . The adjoint operator of $T$ is also an integral operator, namely

$$
( T ^ { * } g ) ( t ) = \int _ { a } ^ { b } K ^ { * } ( t , s ) y _ { g } ( s ) d s\tag{12.181}
$$

with the kernel $K ^ { * } ( s , t ) = K ( t , s )$ , where $y _ { g }$ is the element from $L ^ { q }$ associated to $g \in ( L ^ { p } ) ^ { * }$ according to (12.167).

B: In a finite dimensional complex vector space the adjoint of an operator represented by the matrix $\mathbf { A } = \left( a _ { i j } \right)$ is defined by the matrix $\mathbf { A } ^ { * }$ with $a _ { i j } ^ { * } = \overline { { a _ { j i } } }$

#### 12.6.2 Adjoint Operator of an Unbounded Operator

Let X and Y be real normed spaces and $T \textrm { a }$ (not necessarily bounded) linear operator with a (linear) domain $D ( T ) \subset \mathbf { X }$ and values in Y. For a given $g \in \mathbb { Y } ^ { * }$ , the expression $g ( T x )$ , depending obviously linearly on x, is meaningful. Now the question is: Does there exist a well-defined functional $f \in \mathbf { X } ^ { * }$ such that

$$
f ( x ) = g ( T x ) \quad \forall x \in D ( T ) .\tag{12.182}
$$

Let $D ^ { * } \subset \mathbb { Y } ^ { * }$ be the set of all those $g \in \mathrm { Y } ^ { * }$ for which the representation (12.182) holds for a certain $f \in \mathbf { X } ^ { * }$ . If $\overline { { D ( T ) } } = \mathrm { X }$ , then for given g the functional $f$ is uniquely defined. So a linear operator $T ^ { * }$ is defined by $f = T ^ { * } g$ with $D ( T ^ { * } ) \bar { = } D ^ { * }$ . Then for arbitrary $x \in D ( \dot { T } )$ and $g \in D ( T ^ { * } )$

$$
g ( T x ) = ( T ^ { * } g ) ( x ) .\tag{12.183}
$$

The operator $T ^ { * }$ turns out to be closed and is called the adjoint of T. The naturalness of this general procedure stems from the fact that $D ( T ^ { * } ) = \mathbb { Y } ^ { * }$ holds if and only if T is bounded on $D ( T )$ . In this case $\mathsf { \bar { T } ^ { * } } \in B ( \mathsf { Y } ^ { * } , \mathsf { X } ^ { * } )$ and $\| T ^ { * } \| = \| T \|$ hold.

#### 12.6.3 Self-Adjoint Operators

An operator $T \in B ( \mathbb { H } )$ (IH is a Hilbert space) is called self-adjoint if $T ^ { * } = T$ . In this case

$$
( T x , y ) = ( x , T y ) , \ x , y \in \mathbb { H }\tag{12.184a}
$$

$$
\| T \| = \operatorname* { s u p } _ { \| x \| = 1 } | ( T x , x ) |
$$

is valid and the number $( T x , x )$ is real for each $x \in \mathbb { H }$ . Then the equality

(12.184b)

holds and with $m = m ( T ) = \operatorname* { i n f } _ { \| x \| = 1 } ( T x , x )$ and $M = M ( T ) = \operatorname* { s u p } _ { \| x \| = 1 } ( T x , x )$ also the relations

$$

$$

are valid. The equality (12.184a) characterizes the self-adjoint operators. The spectrum of a self-adjoint (bounded) operator lies in the interval [m, M] and m, $M \in \sigma ( \bar { T } )$ holds.

##### 12.6.3.1 Positive Definite Operators

A partial ordering can be introduced in the set of all self-adjoint operators of $B ( \mathbb { H } )$ by defining

$T \geq 0$ if and only if $( T x , x ) \geq 0 \quad \forall x \in \mathbb { H } .$

(12.186)

An operator T with $T \geq 0$ is called positive (or, more exactly positive definite). For any self-adjoint operator T (with (H1) from 12.4.1.1, p. 673), $( T ^ { 2 } x , x ) = ( T x , T x ) \ge 0$ , so $T ^ { 2 }$ is positive definite. Every positive definite operator T possesses a square root, i.e., there exists a unique positive definite operator $W$ such that $W ^ { 2 } = T$ . Moreover, the vector space of all self-adjoint operators is a K-space (Kantorovich space, see 12.1.7.4, p. 660), where the operators

$$
| T | = \sqrt { T ^ { 2 } } , \quad T ^ { + } = \frac { 1 } { 2 } ( | T | + T ) , \quad T ^ { - } = \frac { 1 } { 2 } ( | T | - T )\tag{12.187}
$$

are the corresponding elements with respect to (12.37). They are of particular importance for the spectral decomposition and spectral and integral representations of self-adjoint operators by means of some Stieltjes integral (see 8.2.3.1, 2., p. 506, and [12.1], [12.11], [12.12], [12.15], [12.18]).

##### 12.6.3.2 Projectors in a Hilbert Space

Let $\mathbb { H } _ { 0 }$ be a subspace of a Hilbert space IH. Then every element $x \in \mathbb { H }$ has its projection $x ^ { \prime }$ onto $\mathbb { H } _ { 0 }$ according to the projection theorem (see 12.4.2, p. 674), and therefore, an operator $\dot { P }$ with $P x = x ^ { \prime }$ is defined on IH with values in $\mathbb { H } _ { 0 } . ~ P$ is called a projector onto $\mathbb { H } _ { 0 }$ . Obviously, $\dot { P }$ is linear, continuous, and $\| P \| = 1$ . A continuous linear operator P in IH is a projector (onto a certain subspace) if and only if: a) $P = P ^ { * }$ , i.e., P is self-adjoint, and

b) $P ^ { 2 } = P , { \mathrm { i . e . , } } P$ is idempotent.
