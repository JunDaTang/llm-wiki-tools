#### 19.6.4 Harmonic Analysis

A periodic function $f ( x )$ with period 2π, which is given formally or empirically, should be approximated by a trigonometric polynomial or a Fourier sum of the form

$$
g ( x ) = { \frac { a _ { 0 } } { 2 } } + \sum _ { k = 1 } ^ { n } ( a _ { k } \cos k x + b _ { k } \sin k x ) ,\tag{19.210}
$$

where the coeficients $a _ { 0 } , a _ { k }$ and $b _ { k }$ are unknown real numbers. The determination of the coeficients is the topic of harmonic analysis.

##### 19.6.4.1 Formulas for Trigonometric Interpolation

1. Formulas for the Fourier Coeficients

Since the function system 1, cos kx, sin kx $( k = 1 , 2 , \ldots , n )$ is orthogonal in the interval $[ 0 , 2 \pi ]$ with respect to the weight function $\omega \equiv 1$ , the formulas for the coeficients are obtained as

$$
a _ { k } = { \frac { 1 } { \pi } } \intop _ { 0 } ^ { 2 \pi } f ( x ) \cos { k x } d x , \quad b _ { k } = { \frac { 1 } { \pi } } \intop _ { 0 } ^ { 2 \pi } f ( x ) \sin { k x } d x \quad ( k = 0 , 1 , 2 , \ldots , n )\tag{19.211}
$$

by applying the continuous least squares method according to (19.172). The coeficients $a _ { k }$ and $b _ { k }$ calculated by formulas (19.211) are called Fourier coeficients of the periodic function $f ( x )$ (see 7.4, p. 474).

If the integrals in (19.211) are complicated or the function $f ( x )$ is known only at discrete points, then the Fourier coeficients can be determined only approximately by numerical integration.

Using the trapezoidal formula (see 19.3.2.2, p. 964) with $N + 1$ equidistant nodes

$$
x _ { \nu } = \nu h \quad ( \nu = 0 , 1 , \ldots , N ) , \quad h = \frac { 2 \pi } { N }\tag{19.212}
$$

the approximation formula

$$
a _ { k } \approx { \tilde { a } } _ { k } = { \frac { 2 } { N } } \sum _ { \nu = 1 } ^ { N } f ( x _ { \nu } ) \cos k x _ { \nu } , \quad b _ { k } \approx { \tilde { b } } _ { k } = { \frac { 2 } { N } } \sum _ { \nu = 1 } ^ { N } f ( x _ { \nu } ) \sin k x _ { \nu } \quad ( k = 0 , 1 , 2 , \dots , n ) ,\tag{19.213}
$$

is obtained. The trapezoidal formula becomes the very simple rectangular formula in the case of periodic functions. It has higher accuracy here as a consequence of the following fact: If $f ( x )$ is periodic and $( 2 m + 2 )$ times diferentiable, then the trapezoidal formula has an error of order ${ \check { O } } ( { \check { h } } ^ { 2 m + 2 } )$

2. Trigonometric Interpolation

Some special trigonometric polynomials formed with the approximation coeficients $\tilde { a } _ { k }$ and $\tilde { b } _ { k }$ have important properties. Two of them are mentioned here:

1. Interpolation Suppose $N = 2 n$ holds. The special trigonometric polynomial

$$
\tilde { g } _ { 1 } ( x ) = \frac { 1 } { 2 } \tilde { a } _ { 0 } + \sum _ { k = 1 } ^ { n - 1 } ( \tilde { a } _ { k } \cos k x + \tilde { b } _ { k } \sin k x ) + \frac { 1 } { 2 } \tilde { a } _ { n } \cos n x\tag{19.214}
$$

with coeficients (19.213) satisfies the interpolation conditions

$$
\tilde { g } _ { 1 } ( x _ { \nu } ) = f ( x _ { \nu } ) \qquad ( \nu = 1 , 2 , \ldots , N )\tag{19.215}
$$

at the interpolation nodes $x _ { \nu } \left( 1 9 . 2 1 2 \right)$ . Because of the perodicity of $f ( x ) \ f ( x _ { 0 } ) = f ( x _ { N } )$ holds.

2. Approximation in Mean Suppose $N = 2 n$ . The special trigonometric polynomial

$$
\tilde { g } _ { 2 } ( x ) = \frac { 1 } { 2 } \tilde { a } _ { 0 } + \sum _ { k = 1 } ^ { m } ( \tilde { a } _ { k } \cos k x + \tilde { b } _ { k } \sin k x )\tag{19.216}
$$

for $m < n$ and with the coeficients (19.213) approximates the function $f ( x )$ in discrete quadratic mean with respect to the N nodes $x _ { \nu }$ (19.212), that is, the residual sum of squares

$$
F = \sum _ { \nu = 1 } ^ { N } { [ f ( x _ { \nu } ) - \tilde { g } _ { 2 } ( x _ { \nu } ) ] } ^ { 2 }\tag{19.217}
$$

is minimal. The formulas (19.213) are the originating point for the diferent ways of efective calculation of Fourier coeficients.

##### 19.6.4.2 Fast Fourier Transformation (FFT)

1. Computation costs of computing Fourier coeficients

The sums in the formulas (19.213) also occur in connection with discrete Fourier transformation, $\mathrm { e . g . } .$ in electrotechnics, in impulse and picture processing. Here N can be very large, so the occurring sums must be calculated in a rational way, since the calculation of the N approximating values (19.213) of the Fourier coeficients requires about $N ^ { 2 }$ additions and multiplications.

$$
N = 2 ^ { p }
$$

be largely reduced from $N ^ { 2 } ( = 2 ^ { 2 p } )$ to $p N ( = p 2 ^ { p } )$ with the help of the so-called fast Fourier transformation FFT. The magnitude of this reduction is demonstrated on the example on the right-hand side.

$$
\begin{array} { c } { {  \frac { p } { 1 0 } |  \sim 1 0 ^ { 6 } | \sim 1 0 ^ { 4 } } } \\ { {  2 0 | \sim 1 0 ^ { 1 2 } | \sim 1 0 ^ { 7 } } } \end{array}\tag{19.218}
$$

By this method, the computation costs and computation time are reduced so efectively that in some important application fields even a smaller computer is suficient.

The FFT uses the properties of the N-th unit roots, i.e., the solutions of equation $z ^ { N } = 1$ to a successive sum up in (19.213).

2. Complex Representation of the Fourier Sum

The principle of FFT can be described fairly easily if the Fourier sum (19.210) is rewritten with the formulas

$$
\cos k x = { \frac { 1 } { 2 } } \left( e ^ { \mathrm { i } k x } + e ^ { - \mathrm { i } k x } \right) , \quad \sin k x = { \frac { \mathrm { i } } { 2 } } \left( e ^ { - \mathrm { i } k x } - e ^ { \mathrm { i } k x } \right)\tag{19.219}
$$

into the complex form

$$
g ( x ) = { \frac { 1 } { 2 } } a _ { 0 } + \sum _ { k = 1 } ^ { n } ( a _ { k } \cos k x + b _ { k } \sin k x ) = { \frac { 1 } { 2 } } a _ { 0 } + \sum _ { k = 1 } ^ { n } \left( { \frac { a _ { k } - \mathrm { i } b _ { k } } { 2 } } e ^ { \mathrm { i } k x } + { \frac { a _ { k } + \mathrm { i } b _ { k } } { 2 } } e ^ { - \mathrm { i } k x } \right) .\tag{19.220}
$$

By substitution

$$
c _ { k } = { \frac { a _ { k } - \mathrm { i } b _ { k } } { 2 } } , { \mathrm { ~ ( 1 9 . 2 2 1 a ) } } \quad { \mathrm { b e c a u s e ~ o f ~ ( 1 9 . 2 1 1 ) } } \quad c _ { k } = { \frac { 1 } { 2 \pi } } \int _ { 0 } ^ { 2 \pi } f ( x ) e ^ { - \mathrm { i } k x } d x ,\tag{19.221b}
$$

so (19.220) becomes the complex representation ofthe Fourier sum:

$$
g ( x ) = \sum _ { k = - n } ^ { n } c _ { k } e ^ { \mathrm { i } k x } \quad { \mathrm { w i t h } } \quad c _ { - k } = { \bar { c } } _ { k } .\tag{19.222}
$$

If the complex coeficients $c _ { k }$ are known, then the required real Fourier coeficients can be got in the following simple way:

$$
a _ { 0 } = 2 c _ { 0 } , \quad a _ { k } = 2 \mathrm { R e } ( c _ { k } ) , \quad b _ { k } = - 2 \mathrm { I m } ( c _ { k } ) \quad ( k = 1 , 2 , \ldots , n ) .\tag{19.223}
$$

3. Numerical Calculation of the Complex Fourier Coeficients For the numerical determination of $c _ { k }$ the trapezoidal formula can be applied for (19.221b) analogously to (19.212) and (19.213), and the discrete complex Fourier coeficients $\tilde { c } _ { k }$ are obtained:

$$
\tilde { c } _ { k } = \frac { 1 } { N } \sum _ { \nu = 0 } ^ { N - 1 } f ( x _ { \nu } ) e ^ { - \mathrm { i } k x _ { \nu } } = \sum _ { \nu = 0 } ^ { N - 1 } f _ { \nu } \omega _ { N } ^ { k \nu } \quad ( k = 0 , 1 , 2 , \dots , n ) \quad \mathrm { w i t h }\tag{19.224a}
$$

$$
f _ { \nu } = \frac { 1 } { N } f ( x _ { \nu } ) , \quad x _ { \nu } = \frac { 2 \pi \nu } { N } \quad ( \nu = 0 , 1 , 2 , \ldots , N - 1 ) , \quad \omega _ { N } = e ^ { - \frac { 2 \pi \mathrm { i } } { N } } .\tag{19.224b}
$$

Relation (19.224a) with the quantities (19.224b) is called the discrete complex Fourier transformation of length N of the values $f _ { \nu } ( \bar { \nu } = 0 , 1 , 2 , \dots , N - 1 )$

The powers $\omega _ { N } ^ { \nu } = z ~ \left( \nu = 0 , 1 , 2 , \ldots , N - 1 \right)$ satisfy equation $z ^ { N } = 1$ . So, they are called the N-th unit roots. Since $e ^ { - 2 \pi \mathrm { i } } = 1$

$$
\omega _ { N } ^ { N } = 1 , \omega _ { N } ^ { N + 1 } = \omega _ { N } ^ { 1 } , \omega _ { N } ^ { N + 2 } = \omega _ { N } ^ { 2 } , . . . ~ .\tag{19.225}
$$

The efective calculation of the sum (19.224a) uses the fact that a discrete complex Fourier transformation of length $N = 2 n$ can be reduced to two transformations with length ${ \frac { N } { 2 } } = n$ in the following way:

a) For every coeficient $\tilde { c } _ { k }$ with an even index, i.e., $k = 2 l$

$$
\tilde { c } _ { 2 l } = \sum _ { \nu = 0 } ^ { 2 n - 1 } f _ { \nu } \omega _ { N } ^ { 2 l \nu } = \sum _ { \nu = 0 } ^ { n - 1 } \left[ f _ { \nu } \omega _ { N } ^ { 2 l \nu } + f _ { n + \nu } \omega _ { N } ^ { 2 l ( n + \nu ) } \right] = \sum _ { \nu = 0 } ^ { n - 1 } \left[ f _ { \nu } + f _ { n + \nu } \right] \omega _ { N } ^ { 2 l \nu }\tag{19.226}
$$

holds. Here the equality $\omega _ { N } ^ { 2 l ( n + \nu ) } = \omega _ { N } ^ { 2 l n } \omega _ { N } ^ { 2 l \nu } = \omega _ { N } ^ { 2 l \nu }$ is used.

Substituting

$$
y _ { \nu } = f _ { \nu } + f _ { n + \nu } \quad ( \nu = 0 , 1 , 2 , \ldots , n - 1 )\tag{19.227}
$$

and considering that $\omega _ { N } ^ { 2 } = \omega _ { n }$ , the sum

$$
\tilde { c } _ { 2 l } = \sum _ { \nu = 0 } ^ { n - 1 } y _ { \nu } \omega _ { n } ^ { l \nu } \quad ( \nu = 0 , 1 , 2 , \dots , n - 1 )\tag{19.228}
$$

is the discrete complex Fourier transformation of the values y $( \nu = 0 , 1 , 2 , \ldots , n - 1 )$ with length $n = { \frac { N } { 2 } } .$

b) For every coeficient $\tilde { c } _ { k }$ with an odd index, i.e., with $k = 2 l + 1$

$$
\tilde { c } _ { 2 l + 1 } = \sum _ { \nu = 0 } ^ { 2 n - 1 } f _ { \nu } \omega _ { N } ^ { ( 2 l + 1 ) \nu } = \sum _ { \nu = 0 } ^ { n - 1 } \left[ ( f _ { \nu } - f _ { n + \nu } ) \omega _ { N } ^ { \nu } \right] \omega _ { N } ^ { 2 l \nu }\tag{19.229}
$$

is obtained analogously. Substituting

$$
y _ { n + \nu } = ( f _ { \nu } - f _ { n + \nu } ) \omega _ { N } ^ { \nu } \quad ( \nu = 0 , 1 , 2 , \ldots , n - 1 )\tag{19.230}
$$

and considering that $\omega _ { N } ^ { 2 } = \omega _ { n }$ , the sum

$$
\tilde { c } _ { 2 l + 1 } = \sum _ { \nu = 0 } ^ { n - 1 } y _ { n + \nu } \omega _ { n } ^ { l \nu } \quad ( \nu = 0 , 1 , 2 , \ldots , n - 1 )\tag{19.231}
$$

is the discrete complex Fourier transformation of the values $y _ { n + \nu } ~ ( \nu = 0 , 1 , 2 , \ldots , n - 1 )$ with length $n = { \frac { N } { 2 } } .$

The reduction according to a) and b), i.e., the reduction of a discrete complex Fourier transformation to two discrete complex Fourier transformations of half the length, can be continued if N is a power of 2, i.e., if $N = 2 ^ { p } ( p$ is a natural number). The application of the reduction after p times is called the FFT.

Since every reduction step requires $\frac { N } { 2 }$ complex multiplications because of (19.230), the computation cost of the FFT method is

$$
\frac { N } { 2 } p = \frac { N } { 2 } \log _ { 2 } N .\tag{19.232}
$$
