### 10.3 Variational Problems of One Variable

#### 10.3.1 Simple Variational Problems and Extremal Curves

A simple variational problem is to determine the extreme value of the integral expression given in the form

$$
I [ y ] = \int _ { a } ^ { b } F ( x , y ( x ) , y ^ { \prime } ( x ) ) d x ,\tag{10.11}
$$

where $y ( x )$ is a twice continuously diferentiable function satisfying the boundary conditions $y ( a ) = A$ and $y ( \boldsymbol { b } ) = B$ . The yalues a. b and $A , B$ , and the function $F$ are given.

The integral expression $\left( 1 0 . 1 1 \right)$ is an example of a so-called functional. A functional assigns a rea number to every function $y ( x )$ from a certain class of functions.

If the functional $I [ y ]$ in (10.11) takes, e.g., its relative maximum for a function $y _ { 0 } ( x )$ , then

$$
I [ y _ { 0 } ] \geq I [ y ]\tag{10.12}
$$

for every twice continuously diferentiable function y satisfying the boundary conditions. The curve $y = y _ { 0 } ( x )$ is called an extremal curve. Sometimes all the solutions of the Euler diferential equation of the variational calculus are called extremal curves.

#### 10.3.3 Variational Problems with Side Conditions

These problems are usually isoperimetric problems (see 10.2.1, p. 611): The simple variational problem (see 10.2.1, p. 611), given by the functional (10.11), is completed by a further side condition in the form

$$
\int _ { a } ^ { b } G ( x , y ( x ) , y ^ { \prime } ( x ) ) d x = l \quad ( l \ \mathrm { c o n s t } )\tag{10.25}
$$

where the constant l and the function G are given. A method to solve this problem is given by Lagrange (extreme values with side conditions in equation form, see 6.2.5.6, p. 456). Considering the expression

$$
H ( x , y ( x ) , y ^ { \prime } ( x ) , \lambda ) = F ( x , y ( x ) , y ^ { \prime } ( x ) ) + \lambda G ( x , y ( x ) , y ^ { \prime } ( x ) ) ,\tag{10.26}
$$

where λ is a parameter, and solving the problem

$$
\int _ { a } ^ { b } H ( x , y ( x ) , y ^ { \prime } ( x ) , \lambda ) d x = { \mathrm { e x t r e m e l } } ,\tag{10.27}
$$

as an extreme value problem without side condition. The corresponding Euler diferential equation is:

$$
\frac { \partial H } { \partial y } - \frac { d } { d x } \left( \frac { \partial H } { \partial y ^ { \prime } } \right) = 0 .\tag{10.28}
$$

The solution $y = y ( x , \lambda )$ depends on the parameter λ, which must be determined by substituting $y ( x , \lambda )$ into the side condition (10.25).

For the isoperimetric problem 10.2.1, p. 611, one gets

$$
H ( x , y ( x ) , y ^ { \prime } ( x ) , \lambda ) = y + \lambda { \sqrt { 1 + y ^ { \prime 2 } } } .\tag{10.29a}
$$

Because the variable x does not appear in H, instead of the Euler diferential equation (10.28), analogously to (10.22c), one gets the diferential equation

$$
y + \lambda \sqrt { 1 + y ^ { \prime 2 } } - \frac { \lambda y ^ { \prime 2 } } { \sqrt { 1 + y ^ { \prime 2 } } } = c _ { 1 } \quad \mathrm { o r } \quad y ^ { \prime 2 } = \frac { \sqrt { \lambda ^ { 2 } - ( c _ { 1 } - y ) ^ { 2 } } } { c _ { 1 } - y } \quad ( c _ { 1 } \ \mathrm { c o n s t } ) ,\tag{10.29b}
$$

whose solution is a family of circles

$$
( x - c _ { 2 } ) ^ { 2 } + ( y - c _ { 1 } ) ^ { 2 } = \lambda ^ { 2 } \quad ( c _ { 1 } , c _ { 2 } , \lambda \mathrm { \ c o n s t } ) .\tag{10.29c}
$$

The values $c _ { 1 } , c _ { 2 }$ and λ are determined from the conditions $y ( a ) = 0 , y ( b ) = 0$ and from the requirement that the arclength between A and B should be l. The result is a non-linear equation for λ, which should be solved by an appropriate iterative method.

#### 10.3.6 Variational Problems using Parametric Representation

For some variational problems it is useful to determine the extremal, not in the explicit form $y = y ( x )$ but in the parametric form

$$
\begin{array} { r } { x = x ( t ) , \quad y = y ( t ) \quad ( t _ { 1 } \leq t \leq t _ { 2 } ) , } \end{array}\tag{10.38}
$$

where $t _ { 1 }$ and $t _ { 2 }$ are the parameter values corresponding to the points $( a , A )$ and (b, B). Then the simple variational problem (see 10.3.1, p. 611) is

$$
I [ x , y ] = \int _ { t _ { 1 } } ^ { t _ { 2 } } F ( x ( t ) , y ( t ) , \dot { x } ( t ) , \dot { y } ( t ) ) d t = \mathrm { e x t r e m e l }\tag{10.39a}
$$

with the boundary conditions

$$
x ( t _ { 1 } ) = a , \quad x ( t _ { 2 } ) = b , \quad y ( t _ { 1 } ) = A , \quad y ( t _ { 2 } ) = B .\tag{10.39b}
$$

Here ˙x and ˙y denote the derivatives of x and y with respect to the parameter t, as usual in the parametric representation.

The variational problem (10.39a) makes sense only if the value of the integral is independent of the parametric representation of the extremal curve. To ensure the integral in (10.39a) is independent of the parametric representation of the curve connecting the points $( a , { \tilde { A } } )$ and (b, B), F must be a positive homogeneous function of first order, i.e.,

$$
F ( x , y , \mu \dot { x } , \mu \dot { y } ) = \mu F ( x , y , \dot { x } , \dot { y } ) \quad ( \mu > 0 )\tag{10.40}
$$

must hold.

Because the variational problem (10.39a) can be considered as a special case of (10.34), the corresponding Euler diferential equations are

$$
{ \frac { \partial F } { \partial x } } - { \frac { d } { d t } } \left( { \frac { \partial F } { \partial { \dot { x } } } } \right) = 0 , \quad { \frac { \partial F } { \partial y } } - { \frac { d } { d t } } \left( { \frac { \partial F } { \partial { \dot { y } } } } \right) = 0 .\tag{10.41}
$$

They are not independent of each other, but they are equivalent to the so-called Weierstrass form of the Euler diferential equation:

$$
\frac { \partial ^ { 2 } F } { \partial x \partial \dot { y } } - \frac { \partial ^ { 2 } F } { \partial \dot { x } \partial y } + M ( \dot { x } \ddot { y } - \ddot { x } \dot { y } ) = 0\tag{10.42a}
$$

with

$$
M = { \frac { 1 } { { \dot { y } } ^ { 2 } } } { \frac { \partial ^ { 2 } F } { \partial { \dot { x } } ^ { 2 } } } = - { \frac { 1 } { \dot { x } { \dot { y } } } } { \frac { \partial ^ { 2 } F } { \partial { \dot { x } } \partial { \dot { y } } } } = { \frac { 1 } { { \dot { x } } ^ { 2 } } } { \frac { \partial ^ { 2 } F } { \partial { \dot { y } } ^ { 2 } } } .\tag{10.42b}
$$

Analogous to the calculation of the radius of curvature R of a curve given in parametric representation (see 3.6.1.1, 1., p. 243), the calculation of the radius of curvature of the extremal curve is to be made, considering (10.42a), with

$$

$$

$$

$$

This variational problem with the side condition becomes an unconstrained variational problem according to (10.26) with

$$
