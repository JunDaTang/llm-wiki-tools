#### 15.3.2 Solution of Differential Equations using the Fourier Transformation

Analogously to Laplace transformation, an important field of application of the Fourier transformation is the solution of diferential equations, since these equations can be transformed by the integral transformation into a simple form. In the case of ordinary diferential equations one gets algebraic equations, in the case of partial diferential equations one gets ordinary diferential equations.

##### 15.3.2.2 Partial Differential Equations

1. General Remarks

The solution of a partial diferential equation is a function of at least two variables: $u = u ( x , t )$ . As the Fourier transformation is an integration with respect to only one variable, the other variable is considered a constant during the transformation. Here the variable x is kept constant and the transformation is to be performed with respect to t:

$$
\mathcal { F } \{ { u ( x , t ) \} } = \int _ { - \infty } ^ { + \infty } e ^ { - \mathrm { i } \omega t } u ( x , t ) d t = U ( x , \omega ) .\tag{15.97}
$$

During the transformation of the derivatives the variable x is again kept constant:

$$
\mathcal { F } \bigg \{ \frac { \partial ^ { ( n ) } u ( x , t ) } { \partial t ^ { n } } \bigg \} = ( \mathrm { i } \omega ) ^ { n } \mathcal { F } \{ u ( x , t ) \} = ( \mathrm { i } \omega ) ^ { n } U ( x , \omega ) .\tag{15.98}
$$

The diferentiation with respect to x is supposed to be interchangeable with the Fourier integral:

$$
\mathcal { F } \left\{ \frac { \partial u ( x , t ) } { \partial x } \right\} = \frac { \partial } { \partial x } \mathcal { F } \{ u ( x , t ) \} = \frac { \partial } { \partial x } U ( x , \omega ) .\tag{15.99}
$$

In this way an ordinary diferential equation is obtained in the image space. Furthermore the boundary and initial conditions are to be transformed into the image space.

2. Solution of the One-Dimensional Wave Equation for a Homogeneous Medium 1. Formulation of the Problem The one-dimensional wave equation with vanishing perturbation term and for a homogeneous medium is:

$$
u _ { x x } - u _ { t t } = 0 .\tag{15.100a}
$$

Like the three-dimensional wave equation (see 9.2.3.2,p. 590), the equation (15.100a) is a partial differential equation of hyperbolic type. The Cauchy problem is correctly defined by the following initial conditions

$$
u ( x , 0 ) = f ( x ) \quad ( - \infty < x < \infty ) , \quad u _ { t } ( x , 0 ) = g ( x ) \quad ( 0 \leq t < \infty ) .\tag{15.100b}
$$

2. Fourier Transformation The Fourier transformation is to be performed with respect to x where the time coordinate is kept constant:

$$
{ \mathcal { F } } \{ u ( x , t ) \} = U ( \omega , t ) .\tag{15.101a}
$$

One gets:

$$
( \mathrm { i } \omega ) ^ { 2 } U ( \omega , t ) - \frac { d ^ { 2 } U ( \omega , t ) } { d t ^ { 2 } } = 0 \qquad \mathrm { w i t h }\tag{15.101b}
$$

$$
{ \mathcal { F } } \{ u ( x , 0 ) \} = U ( \omega , 0 ) = { \mathcal { F } } \{ f ( x ) \} = F ( \omega ) ,\tag{15.101c}
$$

$$
\mathcal { F } \{ u _ { t } ( \boldsymbol { x } , 0 ) \} = U ^ { \prime } ( \omega , 0 ) = \mathcal { F } \{ g ( \boldsymbol { x } ) \} = G ( \omega ) .\tag{15.101d}
$$

$$
\omega ^ { 2 } U + U ^ { \prime \prime } = 0 .\tag{15.101e}
$$

The result is an ordinary diferential equation with respect to t with the parameter ω of the transform. The general solution of this known diferential equation with constant coeficients is

$$
U ( \omega , t ) = C _ { 1 } e ^ { \mathrm { i } \omega t } + C _ { 2 } e ^ { - \mathrm { i } \omega t } .\tag{15.102a}
$$

Determining the constants $C _ { 1 }$ and $C _ { 2 }$ from the initial values

$$
U ( \omega , 0 ) = C _ { 1 } + C _ { 2 } = F ( \omega ) , \quad U ^ { \prime } ( \omega , 0 ) = \mathrm { i } \omega C _ { 1 } - \mathrm { i } \omega C _ { 2 } = G ( \omega ) ,\tag{15.102b}
$$

gives

$$
C _ { 1 } = \frac { 1 } { 2 } [ F ( \omega ) + \frac { 1 } { \mathrm { i } \omega } G ( \omega ) ] , \quad C _ { 2 } = \frac { 1 } { 2 } [ F ( \omega ) - \frac { 1 } { \mathrm { i } \omega } G ( \omega ) ] .\tag{15.102c}
$$

The solution is therefore

$$
U ( \omega , t ) = \frac 1 2 [ F ( \omega ) + \frac { 1 } { \mathrm { i } \omega } G ( \omega ) ] e ^ { \mathrm { i } \omega t } + \frac 1 2 [ F ( \omega ) - \frac { 1 } { \mathrm { i } \omega } G ( \omega ) ] e ^ { - \mathrm { i } \omega t } .\tag{15.102d}
$$
