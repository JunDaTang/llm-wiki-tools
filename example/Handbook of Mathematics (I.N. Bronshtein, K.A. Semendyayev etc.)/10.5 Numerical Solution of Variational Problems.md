### 10.5 Numerical Solution of Variational Problems

Most often two ways are used to solve variational problems in practice.

1. Solution of the Euler Diferential Equation and Fitting the Found Solution to the Boundary Conditions

Usually, an exact solution of the Euler diferential equation is possible only in the simplest cases, so numerical methods are to be used solving the boundary value problem for ordinary or for partial differential equations (see 19.5, p. 976 or 20.3.4, p. 1042f).

2. Direct Methods

The direct methods start directly from the variational problem and do not use the Euler diferential equation. The most popular and probably the oldest procedure is the Ritz method. It belongs to the socalled approximation methods which are also used to get approximate solutions of diferential equations (see 19.4.2.2, p. 974 and 19.5.2, p. 977). The following example demonstrates this method.

Solve numerically the isoperimetric problem

$$
\int _ { 0 } ^ { 1 } y ^ { \prime 2 } ( x ) d x = { \mathrm { e x t r e m e l ~ } } ( 1 0 . 5 2 { \mathrm { a } } ) \qquad { \mathrm { f o r } } \quad \int _ { 0 } ^ { 1 } y ^ { 2 } ( x ) d x = 1 \quad { \mathrm { a n d } } \quad y ( 0 ) = y ( 1 ) = 0 .\tag{10.52b}
$$

The corresponding variational problem without integral side condition according to 10.3.3, p. 614, is:

$$
I [ y ] = \int _ { 0 } ^ { 1 } \left[ y ^ { \prime 2 } ( x ) - \lambda y ^ { 2 } ( x ) \right] d x = \mathrm { e x t r e m e l }\tag{10.52c}
$$

As starting approach to find an approximation solution can be used

$$
y ( x ) = a _ { 1 } x ( x - 1 ) + a _ { 2 } x ^ { 2 } ( x - 1 ) .\tag{10.52d}
$$

Both approximation functions $\boldsymbol { { x } } ( \boldsymbol { { x } } - 1 )$ and $x ^ { 2 } ( x { - } 1 )$ are linearly independent, and satisfy the boundary conditions. Reducing (10.52c) with (10.52d) gives

$$
I ( a _ { 1 } , a _ { 2 } ) = \frac { 1 } { 3 } a _ { 1 } ^ { 2 } + \frac { 2 } { 1 5 } a _ { 2 } ^ { 2 } + \frac { 1 } { 3 } a _ { 1 } a _ { 2 } - \lambda \left( \frac { 1 } { 3 0 } a _ { 1 } ^ { 2 } + \frac { 1 } { 1 0 5 } a _ { 2 } ^ { 2 } + \frac { 1 } { 3 0 } a _ { 1 } a _ { 2 } \right) ,\tag{10.52e}
$$

and the necessary conditions $\frac { \partial I } { \partial a _ { 1 } } = \frac { \partial I } { \partial a _ { 2 } } = 0$ result in he homogeneous linear equation system

$$
\left( { \frac { 2 } { 3 } } - { \frac { \lambda } { 1 5 } } \right) a _ { 1 } + \left( { \frac { 1 } { 3 } } - { \frac { \lambda } { 3 0 } } \right) a _ { 2 } = 0 , \qquad \left( { \frac { 1 } { 3 } } - { \frac { \lambda } { 3 0 } } \right) a _ { 1 } + \left( { \frac { 4 } { 1 5 } } - { \frac { 2 \lambda } { 1 0 5 } } \right) a _ { 2 } = 0 .\tag{10.52f}
$$

This system has a non-trivial solution only if the determinant of the coeficient matrix is equal to zero:

$$
\lambda ^ { 2 } - 5 2 \lambda + 4 2 0 = 0 , \quad \mathrm { i . e . , } \quad \lambda _ { 1 } = 1 0 , \ \lambda _ { 2 } = 4 2 .\tag{10.52g}
$$

For $\lambda = \lambda _ { 1 } = 1 0$ from (10.52f) follows $a _ { 2 } = 0 , a _ { 1 }$ arbitrary, so the normalized solution belonging to $\lambda _ { 1 } = 1 0$ is:

$$
y = 5 . 4 8 x ( x - 1 ) .\tag{10.52h}
$$

To make a comparison, consider the Euler diferential equation belonging to (10.52f). Here the boundary value problem

$$
y ^ { \prime \prime } + \lambda y = 0 \quad \mathrm { w i t h } \quad y ( 0 ) = y ( 1 ) = 0\tag{10.52i}
$$

holds with the eigenvalues $\lambda _ { k } = k ^ { 2 } \pi ^ { 2 } ( k = 1 , 2 , . . . )$ and the solution $y _ { k } = c _ { k }$ sin kπx. The normalized solution, e.g., for the case $k = 1 , { \mathrm { i . e . , } } \lambda _ { 1 } = \pi ^ { 2 } \approx 9 . 8 7$ is

$$
y = { \sqrt { 2 } } \sin \pi x ,\tag{10.52j}
$$

which is really very close to the approximate solution (10.52h).

Remark: With today’s level of computers and science first of all, the finite element method (FEM) is to be applied for numerical solutions of variational problems.

The basic idea of this method is given in 19.5.3, p. 978, for numerical solutions of diferential equations. The correspondence between diferential and variational equations will be used there, e.g., by Euler diferential equations or bilinear forms according to (19.146a,b).

Also the gradient method can be used for the numerical solution of variational problems as an eficient numerical method for non-linear optimization problems (see 18.2.7, p. 936).
