##### 9.1.2.5 Systems of Linear Differential Equations with Constant Coefficients

1. Normal Form

The following simple case of a system of first-order linear diferential equations with constant coeficients is called a normal system or a normal form:

$$
\left. \begin{array} { c } { { y _ { 1 } } ^ { \prime } = a _ { 1 1 } y _ { 1 } + a _ { 1 2 } y _ { 2 } + \cdot \cdot \cdot + a _ { 1 n } y _ { n } , } \\ { { y _ { 2 } } ^ { \prime } = a _ { 2 1 } y _ { 1 } + a _ { 2 2 } y _ { 2 } + \cdot \cdot \cdot + a _ { 2 n } y _ { n } , } \\ { . . . . . . \cdot . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . } \\ { { y _ { n } } ^ { \prime } = a _ { n 1 } y _ { 1 } + a _ { n 2 } y _ { 2 } + \cdot \cdot \cdot \cdot + a _ { n n } y _ { n } . } \end{array} \right\}\tag{9.45a}
$$

To find the general solution of such a system, one has to find first the roots of the characteristic equation

$$
\left| \begin{array} { l l } { a _ { 1 1 } - r \ a _ { 1 2 } \qquad \ldots \ a _ { 1 n } } \\ { a _ { 2 1 } \qquad a _ { 2 2 } - r \ \ldots \ a _ { 2 n } } \\ { \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots \ldots } \\ { a _ { n 1 } \qquad a _ { n 2 } \qquad \ldots \ a _ { n n } - r } \end{array} \right| = 0 .\tag{9.45b}
$$

To every single root $r _ { i }$ of this equation there is a system of particular solutions

$$
y _ { 1 } = A _ { 1 } e ^ { r _ { i } x } , \quad y _ { 2 } = A _ { 2 } e ^ { r _ { i } x } , \ldots , y _ { n } = A _ { n } e ^ { r _ { i } x } ,\tag{9.45c}
$$

whose coeficients $A _ { k } \ ( k = 1 , 2 , \ldots , n )$ are determined from the homogeneous linear equation system

$$
\begin{array} { r } { ( a _ { 1 1 } - r _ { i } ) A _ { 1 } + a _ { 1 2 } A _ { 2 } + \cdots \cdot \cdot + a _ { 1 n } A _ { n } = 0 , } \\ { , . . . \ldots . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . . } \\ { a _ { n 1 } A _ { 1 } + a _ { n 2 } A _ { 2 } + \cdots \cdot + ( a _ { n n } - r _ { i } ) A _ { n } = 0 . } \end{array}\tag{9.45d}
$$

This system gives the relations between the values of the coeficients $A _ { k }$ (see Trivial Solution and Fundamental System in 4.5.2.1, 2., p. 309). For every $r _ { i } .$ the particular solutions determined this way will contain an arbitrary constant. If all the roots of the characteristic equation are diferent, the sum of these particular solutions contains n independent arbitrary constants, so in this way one gets the general solution. If a root $r _ { i }$ has a multiplicity m in the characteristic equation, the system of particular solutions corresponding to this root has the form

$$
y _ { 1 } = A _ { 1 } ( x ) e ^ { r _ { i } x } , \quad y _ { 2 } = A _ { 2 } ( x ) e ^ { r _ { i } x } , \ldots , y _ { n } = A _ { n } ( x ) e ^ { r _ { i } x } ,\tag{9.45e}
$$

where $A _ { 1 } ( x ) , \ldots , A _ { n } ( x )$ are polynomials of degree at most $m - 1$ . After substituting these expressions with unknown coeficients of the polynomials $A _ { k } ( x )$ into the diferential equation system one first can cancel the factor $e ^ { r _ { i } x }$ , then one compares the coeficients of the diferent powers of x to have linear equations for the unknown coeficients of the polynomials, and among them m can be chosen freely. In this way, one gets a part of the solution with m arbitrary constants. The degree of the polynomials can be less than $m - 1$

In the special case when the system (9.45a) is symmetric, i.e., when $a _ { i k } = a _ { k i }$ , then it is suficient to substitute $A _ { i } ( x ) = \mathrm { c o n s t }$ . 2. Homogeneous Systems of First-Order Linear Diferential Equations with Constant Coeficients

have the general form

$$
\sum _ { k = 1 } ^ { n } a _ { i k } { y _ { k } } ^ { \prime } + \sum _ { k = 1 } ^ { n } b _ { i k } y _ { k } = 0 \quad ( i = 1 , 2 , \ldots , n ) .\tag{9.46a}
$$

If the determinant det $\left( { a } _ { i k } \right)$ does not disappear, i.e.,

$$
\operatorname* { d e t } ( a _ { i k } ) \neq 0 ,\tag{9.46b}
$$

then the system (9.46a) can be transformed into the normal form (9.45a).

In the case of $\operatorname* { d e t } ( a _ { i k } ) = 0$ further investigations are necessary (see [9.15]).

The solution can be determined from the general form in the same way as shown for the normal form. The characteristic equation has the form

$$
\operatorname* { d e t } ( a _ { i k } r + b _ { i k } ) = 0 .\tag{9.46c}
$$

The coeficients $A _ { i }$ in the solution (9.45c) corresponding to a single root $r _ { j }$ are determined from the equation system

$$
\sum _ { k = 1 } ^ { n } ( a _ { i k } r _ { j } + b _ { i k } ) A _ { k } = 0 \quad ( i = 1 , 2 , \ldots , n ) .\tag{9.46d}
$$

Otherwise the solution method follows the same ideas as in the case of the normal form.

The characteristic equation of the two diferential equations $5 y _ { 1 } { ' } + 4 y _ { 1 } - 2 y _ { 2 } { ' } - y _ { 2 } = 0 , y _ { 1 } { ' } + 8 y _ { 1 } - 3 y _ { 2 } =$ 0 is:

$$
{ \left| \begin{array} { l l } { 5 r + 4 } & { - 2 r - 1 } \\ { r + 8 } & { - 3 } \end{array} \right| } = 2 r ^ { 2 } + 2 r - 4 = 0 , \quad r _ { 1 } = 1 , \quad r _ { 2 } = - 2 .
$$

The coeficients $A _ { 1 }$ and $A _ { 2 }$ for $r _ { 1 } = 1$ can be got from the equations $9 A _ { 1 } - 3 A _ { 2 } = 0 , 9 A _ { 1 } - 3 A _ { 2 } = 0$ so $A _ { 2 } = 3 A _ { 1 } = 3 C _ { 1 }$ . For $r _ { 2 } = - 2$ one gets analogously $\overline { { A } } _ { 2 } ^ { - } = 2 \overline { { A } } _ { 1 } = 2 C _ { 2 }$ . The general solution is $y _ { 1 } = \bar { C } _ { 1 } e ^ { x } + \bar { C } _ { 2 } e ^ { - 2 x } , y _ { 2 } = 3 \bar { C } _ { 1 } e ^ { x } + 2 C _ { 2 } e ^ { - \tilde { 2 } x }$

3. Inhomogeneous Systems of First-Order Linear Diferential Equations have the general form

$$
\sum _ { k = 1 } ^ { n } a _ { i k } y _ { k } { ' } + \sum _ { k = 1 } ^ { n } b _ { i k } y _ { k } = F _ { i } ( x ) \quad ( i = 1 , 2 , \ldots , n ) .\tag{9.47}
$$

1. Superposition Principle If $y _ { j } ^ { ( 1 ) }$ and $y _ { j } ^ { ( 2 ) } \left( j = 1 , 2 , \ldots , n \right)$ are solutions of inhomogeneous systems which difer from each other only in their right-hand sides $F _ { i } ^ { ( 1 ) }$ and $F _ { i } ^ { \ ( 2 ) }$ , then the sum $y _ { j } = { y _ { j } } ^ { ( 1 ) } +$ $y _ { j } ^ { ( 2 ) } \ ( j = 1 , 2 , \ldots , n )$ is a solution of this system with the right-hand side $F _ { i } ( x ) = F _ { i } ^ { ( 1 ) } ( x ) + F _ { i } ^ { ( 2 ) } ( x )$ Because of this, to get the general solution of an inhomogeneous system it is enough to add a particular solution to the general solution of the corresponding homogeneous system.

2. The Variation of Constants can be used to get a particular solution of the inhomogeneous diferential equation system. To do this one uses the general solution of the homogeneous system, and considers the constants $C _ { 1 } , C _ { 2 } , \ldots , C _ { n }$ as unknown functions $C _ { 1 } ( x ) , C _ { 2 } ( x ) , \dots , { \check { C } } _ { n } ( x )$ Then it is to be substituted into the inhomogeneous system. In the expressions of the derivatives of $y _ { k } ^ { \prime }$ there is the derivative of the new unknown functions $\dot { C } _ { k } ( x )$ . Because $y _ { 1 } , y _ { 2 } , \ldots , y _ { n }$ are solutions of the homogeneous system, the terms containing the new unknown functions will be canceled; only their derivatives remain in the equations. This gives for the functions ${ C _ { k } } ^ { \prime } ( x )$ an inhomogeneous linear algebraic equation system which always has a unique solution. After n integrations one gets the functions $\bar { C } _ { 1 } ( x ) , \bar { C } _ { 2 } ( x ) , \ldots , \bar { C } _ { n } ( x )$ Substituting them into the solution of the homogeneous system instead of the constants results in the particular solution of the inhomogeneous system.

4. Second-Order Systems

The methods introduced above can also be used for diferential equations of higher order. For the system

$$
\sum _ { k = 1 } ^ { n } a _ { i k } y _ { k } { } ^ { \prime \prime } + \sum _ { k = 1 } ^ { n } b _ { i k } y _ { k } { } ^ { \prime } + \sum _ { k = 1 } ^ { n } c _ { i k } y _ { k } = 0 \quad ( i = 1 , 2 , \ldots , n )\tag{9.48}
$$

one can determine particular solutions in the form $y _ { i } = A _ { i } e ^ { r _ { i } x }$ . To do this, one gets $r _ { i }$ from the characteristic equation det $( a _ { i k } r ^ { 2 } + b _ { i k } r + c _ { i k } ) = 0$ , and $A _ { i }$ from the corresponding linear homogeneous algebraic equations.
