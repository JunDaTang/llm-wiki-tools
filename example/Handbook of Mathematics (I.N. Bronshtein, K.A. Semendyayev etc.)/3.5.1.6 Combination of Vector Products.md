##### 3.5.1.6 Combination of Vector Products

1. Double Vector Product

The double vector product $\vec { \bf a } \times ( \vec { \bf b } \times \vec { \bf c } )$ results in a vector coplanar to $\vec { \mathbf { b } }$ and $\vec { \mathbf { c } } \mathbf { : }$

$$
\vec { \bf a } \times ( \vec { \bf b } \times \vec { \bf c } ) = \vec { \bf b } ( \vec { \bf a } \vec { \bf c } ) - \vec { \bf c } ( \vec { \bf a } \vec { \bf b } ) .\tag{3.258}
$$

2. Mixed Product

The mixed product $( \vec { \mathbf { a } } \times \vec { \mathbf { b } } ) \vec { \mathbf { c } } ,$ which is also called the triple product, results in a scalar whose absolute value is numerically equal to the volume of the parallelepipedon defined by the three vectors; the result is positive if a, $\vec { \mathbf { b } } ,$ and c form a right-hand system, negative otherwise. Parentheses and crosses can be

omitted:

$$
( { \vec { \mathbf { a } } } \times { \vec { \mathbf { b } } } ) { \vec { \mathbf { c } } } = { \vec { \mathbf { a } } } ( { \vec { \mathbf { b } } } \times { \vec { \mathbf { c } } } ) = { \vec { \mathbf { a } } } { \vec { \mathbf { b } } } { \vec { \mathbf { c } } } = { \vec { \mathbf { b } } } { \vec { \mathbf { c } } } { \vec { \mathbf { a } } } = { \vec { \mathbf { c } } } { \vec { \mathbf { a } } } { \vec { \mathbf { b } } } = - { \vec { \mathbf { a } } } { \vec { \mathbf { c } } } { \vec { \mathbf { b } } } = - { \vec { \mathbf { b } } } { \vec { \mathbf { a } } } { \vec { \mathbf { c } } } = - { \vec { \mathbf { c } } } { \vec { \mathbf { b } } } { \vec { \mathbf { a } } } ,\tag{3.259}
$$

The interchange of any two terms results in a change of sign; the cyclic permutation of all three terms does not afect the result.

For coplanar vectors, i.e., if a is parallel to the plane defined by $\vec { \mathbf { b } }$ and ${ \vec { \mathbf { c } } } ,$ holds:

$$
\vec { \bf a } ( \vec { \bf b } \times \vec { \bf c } ) = 0 .\tag{3.260}
$$

3. Formulas for Multiple Products

a) Lagrange Identity: $( \vec { \bf a } \times \vec { \bf b } ) ( \vec { \bf c } \times \vec { \bf d } ) = ( \vec { \bf a } \vec { \bf c } ) ( \vec { \bf b } \vec { \bf d } ) - ( \vec { \bf b } \vec { \bf c } ) ( \vec { \bf a } \vec { \bf d } ) ,$

(3.261)

$$
\mathbf { b } ) \vec { \mathbf { a } } \vec { \mathbf { b } } \vec { \mathbf { c } } \cdot \vec { \mathbf { e } } \vec { \mathbf { f } } \vec { \mathbf { g } } = \left| \begin{array} { l l l } { \vec { \mathbf { a } } \vec { \mathbf { e } } } & { \vec { \mathbf { a } } \vec { \mathbf { f } } } & { \vec { \mathbf { a } } \vec { \mathbf { g } } } \\ { \vec { \mathbf { b } } \vec { \mathbf { e } } } & { \vec { \mathbf { b } } \vec { \mathbf { f } } } & { \vec { \mathbf { b } } \vec { \mathbf { g } } } \\ { \vec { \mathbf { c } } \vec { \mathbf { e } } } & { \vec { \mathbf { c } } \vec { \mathbf { f } } } & { \vec { \mathbf { c } } \vec { \mathbf { g } } } \end{array} \right| .\tag{3.262}
$$

4. Formulas for Products in Cartesian Coordinates

If the vectors a, <sup></sup>b, c are given by Cartesian coordinates as

$$
\vec { \mathbf { a } } = \left\{ a _ { x } , a _ { y } , a _ { z } \right\} , \quad \vec { \mathbf { b } } = \left\{ b _ { x } , b _ { y } , b _ { z } \right\} , \quad \vec { \mathbf { c } } = \left\{ c _ { x } , c _ { y } , c _ { z } \right\} ,\tag{3.263}
$$

the calculation of the products can be made by the following formulas:

1. Scalar Product: ${ \vec { \mathbf { a } } } { \vec { \mathbf { b } } } = a _ { x } b _ { x } + a _ { y } b _ { y } + a _ { z } b _ { z } .$

(3.264)

2. Vector Product: ${ \vec { \mathbf { a } } } \times { \vec { \mathbf { b } } } = ( a _ { y } b _ { z } - a _ { z } b _ { y } ) { \vec { \mathbf { i } } } + ( a _ { z } b _ { x } - a _ { x } b _ { z } ) { \vec { \mathbf { j } } } + ( a _ { x } b _ { y } - a _ { y } b _ { x } ) { \vec { \mathbf { k } } }$

$$
= \left| \begin{array} { c } { \vec { \mathbf i } \vec { \textbf { j } } \vec { \mathbf k } } \\ { a _ { x } a _ { y } a _ { z } } \\ { b _ { x } b _ { y } b _ { z } } \end{array} \right| .\tag{3.265}
$$

3. Mixed Product: ${ \vec { \mathbf { a } } } { \vec { \mathbf { b } } } { \vec { \mathbf { c } } } = { \left| \begin{array} { l l } { a _ { x } \ a _ { y } \ a _ { z } } \\ { b _ { x } \ b _ { y } \ b _ { z } } \\ { c _ { x } \ c _ { y } \ c _ { z } } \end{array} \right| }$

(3.266)

5. Formulas for Products in Afine Coordinates

1. Metric Coeficients and Reciprocal System of Vectors If the afine coordinates of two vectors a and $\vec { \mathbf { b } }$ in the system of $\vec { \mathbf { e } } _ { 1 } , \vec { \mathbf { e } } _ { 2 } , \vec { \mathbf { e } } _ { 3 }$ are given, i.e.,

$$
{ \vec { \mathbf { a } } } = a ^ { 1 } { \vec { \mathbf { e } } } _ { 1 } + a ^ { 2 } { \vec { \mathbf { e } } } _ { 2 } + a ^ { 3 } { \vec { \mathbf { e } } } _ { 3 } , \quad { \vec { \mathbf { b } } } = b ^ { 1 } { \vec { \mathbf { e } } } _ { 1 } + b ^ { 2 } { \vec { \mathbf { e } } } _ { 2 } + b ^ { 3 } { \vec { \mathbf { e } } } _ { 3 } ,\tag{3.267}
$$

and there is to calculate the scalar product

$$
{ \begin{array} { r l } & { { \vec { \mathbf { a } } } { \vec { \mathbf { b } } } = a ^ { 1 } b ^ { 1 } { \vec { \mathbf { e } } } _ { 1 } { \vec { \mathbf { e } } } _ { 1 } + a ^ { 2 } b ^ { 2 } { \vec { \mathbf { e } } } _ { 2 } { \vec { \mathbf { e } } } _ { 2 } + a ^ { 3 } b ^ { 3 } { \vec { \mathbf { e } } } _ { 3 } { \vec { \mathbf { e } } } _ { 3 } } \\ & { \qquad + \left( a ^ { 1 } b ^ { 2 } + a ^ { 2 } b ^ { 1 } \right) { \vec { \mathbf { e } } } _ { 1 } { \vec { \mathbf { e } } } _ { 2 } + \left( a ^ { 2 } b ^ { 3 } + a ^ { 3 } b ^ { 2 } \right) { \vec { \mathbf { e } } } _ { 2 } { \vec { \mathbf { e } } } _ { 3 } + \left( a ^ { 3 } b ^ { 1 } + a ^ { 1 } b ^ { 3 } \right) { \vec { \mathbf { e } } } _ { 3 } { \vec { \mathbf { e } } } _ { 1 } } \end{array} }\tag{3.268}
$$

or the vector product

$$
{ \vec { \mathbf { a } } } \times { \vec { \mathbf { b } } } = \left( a ^ { 2 } b ^ { 3 } - a ^ { 3 } b ^ { 2 } \right) { \vec { \mathbf { e } } } _ { 2 } \times { \vec { \mathbf { e } } } _ { 3 } + \left( a ^ { 3 } b ^ { 1 } - a ^ { 1 } b ^ { 3 } \right) { \vec { \mathbf { e } } } _ { 3 } \times { \vec { \mathbf { e } } } _ { 1 } + \left( a ^ { 1 } b ^ { 2 } - a ^ { 2 } b ^ { 1 } \right) { \vec { \mathbf { e } } } _ { 1 } \times { \vec { \mathbf { e } } } _ { 2 } ,\tag{3.269a}
$$

with the equalities

$$
{ \vec { \mathbf { e } } } _ { 1 } \times { \vec { \mathbf { e } } } _ { 1 } = { \vec { \mathbf { e } } } _ { 2 } \times { \vec { \mathbf { e } } } _ { 2 } = { \vec { \mathbf { e } } } _ { 3 } \times { \vec { \mathbf { e } } } _ { 3 } = { \vec { \mathbf { 0 } } } ,\tag{3.269b}
$$

then the pairwise products of the coordinate vectors must be known. For the scalar product these are the six metric coeficients (numbers)

$$
g _ { 1 1 } = \vec { \bf e } _ { 1 } \vec { \bf e } _ { 1 } , \quad g _ { 2 2 } = \vec { \bf e } _ { 2 } \vec { \bf e } _ { 2 } , \quad g _ { 3 3 } = \vec { \bf e } _ { 3 } \vec { \bf e } _ { 3 } ,
$$

$$
g _ { 1 2 } = { \vec { \mathbf { e } } } _ { 1 } { \vec { \mathbf { e } } } _ { 2 } = { \vec { \mathbf { e } } } _ { 2 } { \vec { \mathbf { e } } } _ { 1 } , \quad g _ { 2 3 } = { \vec { \mathbf { e } } } _ { 2 } { \vec { \mathbf { e } } } _ { 3 } = { \vec { \mathbf { e } } } _ { 3 } { \vec { \mathbf { e } } } _ { 2 } , \quad g _ { 3 1 } = { \vec { \mathbf { e } } } _ { 3 } { \vec { \mathbf { e } } } _ { 1 } = { \vec { \mathbf { e } } } _ { 1 } { \vec { \mathbf { e } } } _ { 3 }\tag{3.270}
$$

and for the vector product the three vectors

$$
\vec { \mathbf { e } } ^ { 1 } = \varOmega \left( \vec { \mathbf { e } } _ { 2 } \times \vec { \mathbf { e } } _ { 3 } \right) , \quad \vec { \mathbf { e } } ^ { 2 } = \varOmega \left( \vec { \mathbf { e } } _ { 3 } \times \vec { \mathbf { e } } _ { 1 } \right) , \quad \vec { \mathbf { e } } ^ { 3 } = \varOmega \left( \vec { \mathbf { e } } _ { 1 } \times \vec { \mathbf { e } } _ { 2 } \right) ,\tag{3.271a}
$$

which are the three reciprocal vectors with respect to $\vec { \mathbf { e } } _ { 1 } , \vec { \mathbf { e } } _ { 2 } , \vec { \mathbf { e } } _ { 3 }$ , where the coeficient

$$
\varOmega = \frac { 1 } { \vec { \bf e } _ { 1 } \vec { \bf e } _ { 2 } \vec { \bf e } _ { 3 } } ,\tag{3.271b}
$$

is the reciprocal value of the mixed product of the coordinate vectors. This notation serves only as a shorter way of writing in the following discussion. Calculations with the coeficients will be easy to perform with the help of the multiplication Tables 3.13 and 3.14 for the basis vectors .

2. Application to Cartesian Coordinates The Cartesian coordinates are a special case of afine coordinates. From Tables 3.15 and 3.16 for the basis vectors holds

$$
\vec { \bf e } _ { 1 } = \vec { \bf i } , \quad \vec { \bf e } _ { 2 } = \vec { \bf j } , \quad \vec { \bf e } _ { 3 } = \vec { \bf k }\tag{3.272a}
$$

with the metric coeficients

$$
g _ { 1 1 } = g _ { 2 2 } = g _ { 3 3 } = 1 , \quad g _ { 1 2 } = g _ { 2 3 } = g _ { 3 1 } = 0 , \quad \Omega = \frac { 1 } { \vec { \bf i } \vec { \bf j } \vec { \bf k } } = 1 ,\tag{3.272b}
$$

and the reciprocal basis vectors

$$
\vec { \bf e } ^ { 1 } = \vec { \bf i } , \quad \vec { \bf e } ^ { 2 } = \vec { \bf j } , \quad \vec { \bf e } ^ { 3 } = \vec { \bf k } .\tag{3.272c}
$$

So the basis vectors coincide with the reciprocal basis vectors of the coordinate system, or, in other words, in the Cartesian coordinate system the basis vector system is its own reciprocal system.

3. Scalar Product of Vectors Given by Coordinates

$$
\overrightarrow { \mathbf { a } } \overrightarrow { \mathbf { b } } = \sum _ { m = 1 } ^ { 3 } \sum _ { n = 1 } ^ { 3 } g _ { m n } a ^ { m } b ^ { n } = g _ { \alpha \beta } a ^ { \alpha } b ^ { \beta } .\tag{3.273}
$$

For Cartesian coordinates (3.273) coincides with (3.264).

After the second equality in (3.273) a shorter notation for the sum was applied which is often used in tensor calculations (see 4.3.1, 2., p. 280): instead of the complete sum one writes only a characteristic term so that the sum should be calculated for repeated indices, i.e., for the indices appearing once down and once up. Sometimes the summation indices are denoted by Greek letters; here they have the values from 1 until 3. Consequently holds

$$
\begin{array} { c } { { g _ { \alpha \beta } a ^ { \alpha } b ^ { \beta } = g _ { 1 1 } a ^ { 1 } b ^ { 1 } + g _ { 1 2 } a ^ { 1 } b ^ { 2 } + g _ { 1 3 } a ^ { 1 } b ^ { 3 } + g _ { 2 1 } a ^ { 2 } b ^ { 1 } + g _ { 2 2 } a ^ { 2 } b ^ { 2 } + g _ { 2 3 } a ^ { 2 } b ^ { 3 } } } \\ { { { } } } \\ { { + g _ { 3 1 } a ^ { 3 } b ^ { 1 } + g _ { 3 2 } a ^ { 3 } b ^ { 2 } + g _ { 3 3 } a ^ { 3 } b ^ { 3 } . } } \end{array}\tag{3.274}
$$

4. Vector Product of Vectors Given by Coordinates In accordance with (3.269a)

$$
{ \begin{array} { r l } & { { \vec { \mathbf { a } } } \times { \vec { \mathbf { b } } } = { \vec { \mathbf { e } } } _ { 1 } { \vec { \mathbf { e } } } _ { 2 } { \vec { \mathbf { e } } } _ { 3 } \left| { \begin{array} { l } { { \vec { \mathbf { e } } } ^ { 1 } { \vec { \mathbf { e } } } ^ { 2 } { \vec { \mathbf { e } } } ^ { 3 } } \\ { a ^ { 1 } a ^ { 2 } a ^ { 3 } } \\ { b ^ { 1 } b ^ { 2 } b ^ { 3 } } \end{array} } \right| } \\ & { \qquad = { \vec { \mathbf { e } } } _ { 1 } { \vec { \mathbf { e } } } _ { 2 } { \vec { \mathbf { e } } } _ { 3 } \left[ \left( a ^ { 2 } b ^ { 3 } - a ^ { 3 } b ^ { 2 } \right) { \vec { \mathbf { e } } } ^ { 1 } + \left( a ^ { 3 } b ^ { 1 } - a ^ { 1 } b ^ { 3 } \right) { \vec { \mathbf { e } } } ^ { 2 } + \left( a ^ { 1 } b ^ { 2 } - a ^ { 2 } b ^ { 1 } \right) { \vec { \mathbf { e } } } ^ { 3 } \right] } \end{array} }\tag{3.275}
$$

is valid. For Cartesian coordinates (3.275) coincides with (3.265).

5. Mixed Product of Vectors Given by Coordinates In accordance with (3.269a) holds

$$
\vec { \bf a } \vec { \bf b } \vec { \bf c } = \vec { \bf e } _ { 1 } \vec { \bf e } _ { 2 } \vec { \bf e } _ { 3 } \left| \begin{array} { l } { { a ^ { 1 } a ^ { 2 } a ^ { 3 } } } \\ { { b ^ { 1 } b ^ { 2 } b ^ { 3 } } } \\ { { c ^ { 1 } c ^ { 2 } c ^ { 3 } } } \end{array} \right| .\tag{3.276}
$$

For Cartesian coordinates (3.276) coincides with (3.266).
