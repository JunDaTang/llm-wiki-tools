#### 19.5.2 Approximation by Given Functions

The solution $u ( x , y )$ is approximated by a function in the form

$$
u ( x , y ) \approx v ( x , y ) = v _ { 0 } ( x , y ) + \sum _ { i = 1 } ^ { n } a _ { i } v _ { i } ( x , y ) .\tag{19.140}
$$

Here, two cases are distinguished:

1. $v _ { 0 } ( x , y )$ satisfies the given inhomogeneous diferential equation, and the further functions $v _ { i } ( x , y ) \ ( i =$ $1 , 2 , \ldots , n )$ satisfy the corresponding homogeneous diferential equation (then the linear combination has to be found which approximates the given boundary conditions as well as possible).

2. $v _ { 0 } ( x , y )$ satisfies the inhomogeneous boundary conditions and the other functions $v _ { i } ( x , y ) \ ( i \ =$ $1 , 2 , \ldots , n )$ satisfy the homogeneous boundary conditions (then the linear combination has to be found which approximates the solution of the diferential equation on the considered domain as well as possible).

In both cases substituting the approximating function $v ( x , y )$ from (19.140) in the first case into the boundary conditions, in the second case into the diferential equation results in an error term, the socalled defect:

$$
\varepsilon = \varepsilon ( x , y ; a _ { 1 } , a _ { 2 } , . ~ . ~ . ~ , a _ { n } ) .\tag{19.141}
$$

To determine the unknown coeficients $a _ { i }$ one of the following methods can be applied.

1. Collocation Method

The defect ε should be zero in n reasonably distributed points, at the collocation points $\left( x _ { \nu } , y _ { \nu } \right) \left( \nu = \right.$ $1 , 2 , \ldots , n )$

$$
\varepsilon ( x _ { \nu } , y _ { \nu } ; a _ { 1 } , a _ { 2 } , \ldots , a _ { n } ) = 0 \quad ( \nu = 1 , 2 , \ldots , n ) .\tag{19.142}
$$

The collocation points in the first case are boundary points (it is called boundary collocation), in the second case they are interior points of the integration domain (it is called domain collocation).

From (19.142) are obtained n equations for the coeficients. Boundary collocation is usually preferred to domain collocation.

2. Least Squares Method

Depending on whether the approximation function (19.140) satisfies the diferential equation or the boundary conditions, it is required

1. either the line integral over the boundary C

$$
I = \int _ { ( C ) } \varepsilon ^ { 2 } ( x ( t ) , y ( t ) ; a _ { 1 } , \ldots , a _ { n } ) d t = { \mathrm { m i n } } ,\tag{19.143a}
$$

where the boundary curve C is given by a parametric representation $x = x ( t ) , y = y ( t )$

2. or the double integral over the domain G

$$
I = \iint _ { ( G ) } \varepsilon ^ { 2 } ( x , y ; a _ { 1 } , \ldots , a _ { n } ) d x d y = \operatorname* { m i n } .\tag{19.143b}
$$

From the necessary conditions, ${ \frac { \partial I } { \partial a _ { i } } } = 0 ~ ( i = 1 , 2 , \ldots , n )$ , n equations are obtained for computing the parameters $a _ { 1 } , a _ { 2 } , \ldots , a _ { n } .$
