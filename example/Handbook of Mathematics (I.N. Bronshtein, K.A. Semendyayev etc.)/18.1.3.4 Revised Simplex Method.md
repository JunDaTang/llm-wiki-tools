##### 18.1.3.4 Revised Simplex Method

1. Revised Simplex Tableau

Suppose the linear programming problem is given in normal form:

OF: $f ( \underline { { { \bf x } } } ) = c _ { 1 } x _ { 1 } + \cdot \cdot \cdot + c _ { n - m } x _ { n - m } + c _ { 0 } = \operatorname* { m a x } !$

(18.19a)

CT:

$$
\begin{array} { r l r } {  { \alpha _ { 1 , 1 } x _ { 1 } + \cdots + \alpha _ { 1 , n - m } x _ { n - m } + x _ { n - m + 1 } } } & { = \beta _ { 1 } , } \\ & { \vdots } & { \vdots \ddots \qquad \vdots \quad } \\ { \alpha _ { m , 1 } x _ { 1 } + \cdots + \alpha _ { m , n - m } x _ { n - m } } & { \qquad + x _ { n } = \beta _ { m } , } \\ & { x _ { 1 } \geq 0 , \ldots , x _ { n } \geq 0 . } & \end{array}\tag{18.19b}
$$

Obviously, the coeficient vectors $\underline { { \alpha } } _ { n - m + i } ~ ( i = 1 , \ldots , n )$ ⎪⎪⎭are the i-th unit vectors.

In order to change into another normal form and therefore to reach another extreme point, it is suficient to multiply the system of equations (18.19b) by the corresponding basis inverse. (Recall the fact that if $\mathbf { A } _ { B }$ denotes a new basis, then the coordinates of a vector $\mathbf { \underline { { X } } }$ can be expressed in this new basis as $\mathbf { A } _ { B } ^ { - 1 } \underline { { \mathbf { x } } } .$ If the inverse of the new basis is known, then any column as well as the objective function from the very first tableau can be got by simple multiplication.) The simplex method can be modified so that only the basis inverse is determined in every step instead of a new tableau. From every tableau

required to find the new pivot element. If the number of variables is considerably larger than the number of constraints $( n \ > \ 3 m )$ then the revised simplex method requires considerably less computing cost and therefore has better accuracy.

The quantities of the scheme have the following meaning:

$x _ { 1 } ^ { B } , \ldots , x _ { m } ^ { B }$ : Actual basic variables (in the first step the same as $x _ { n - m + 1 } \cdot \cdot \cdot x _ { n } )$

$c _ { 1 } , \ldots , c _ { n }$ : Coeficients of the objective function (the coeficients associated to the basic variables are zeros).

$b _ { 1 } , \dots , b _ { m }$ : Right-hand side of the actual normal form.

c<sub>0</sub> : Value of the objective function at the extreme point $( x _ { 1 } ^ { B } , \ldots , x _ { m } ^ { B } ) = ( b _ { 1 } , \ldots , b _ { m } )$

$\underline { { \mathbf { r } } } = ( r _ { 1 } , \ldots , r _ { m } ) ^ { \mathrm { T } } ;$ : Actual pivot column.

2. Revised Simplex Step

a) The tableau is not optimal when at least one of the coeficients $\boldsymbol c _ { j } \ ( j = 1 , 2 , \dots , n )$ is positiv. A pivot column q is chosen for a $c _ { q } > 0$

b) One calculates the pivot column r by multiplying the q-th column of the original coeficient matrix (18.19b) by $\mathbf { A } ^ { * }$ and introduces the new vector as the last vector of the tableau.

The pivot row k is determined in the same way as in the simplex algorithm (18.17).

c) The new tableau is calculated by the pivoting step (18.16a–d), where $a _ { i q }$ is formally replaced by $r _ { i }$ and the indices are restricted for $n - m + 1 \leq j \leq n$ . The column ˜r is omitted. $x _ { q }$ becomes a basic variable. For $j = 1 , \ldots , n - m$ , the results are $\tilde { c } _ { j } = c _ { j } + \underline { { \alpha } } _ { j } ^ { \mathrm { T } } \tilde { \underline { { \mathbf { c } } } }$ , where $\underline { { \tilde { \mathbf { c } } } } = ( \tilde { c } _ { n - m + 1 } , \dots , \tilde { c } _ { n } ) ^ { \mathrm { T } }$ , and α is $\underline { { \alpha } } _ { j }$ the j-th column of the coeficient matrix of (18.19b).
