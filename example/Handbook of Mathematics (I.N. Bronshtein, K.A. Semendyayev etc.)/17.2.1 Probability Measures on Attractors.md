5. Power Spectrum

The Fourier transform of $C _ { h } ( \tau )$ is called a power spectrum (see also 15.3.1.2, 5., p. 786) and is denoted by $P _ { h } ( \omega )$ . In the time-continuous case, under the assumption that $\int _ { - \infty } ^ { + \infty } | C _ { h } ( \tau ) | d \tau < \infty ,$

$$
P _ { h } ( \omega ) = \intop _ { - \infty } ^ { + \infty } C _ { h } ( \tau ) e ^ { - \mathrm { i } \omega \tau } d \tau = 2 \intop _ { 0 } ^ { \infty } C _ { h } ( \tau ) \cos ( \omega \tau ) d \tau .\tag{17.35a}
$$

In the time-discrete case, $\operatorname* { i f } \sum _ { k = - \infty } ^ { + \infty } | C _ { h } ( k ) | < + \infty$ holds, then

$$
P _ { h } ( \omega ) = C _ { h } ( 0 ) + 2 \sum _ { k = 1 } ^ { \infty } C _ { h } ( k ) \cos \omega k\tag{17.35b}
$$

holds. If the absolute integrability or summability of $C _ { h } ( \cdot )$ does not hold, then, in the most important cases, $P _ { h }$ can be considered as a distribution. The power spectrum corresponding to the periodic motions of a dynamical system is characterized by equidistant impulses. For quasiperiodic motions, there occur impulses in the power spectrum, which are linear combinations with integer coeficients of the basic impulses of the quasiperiodic motion. A “wide-band spectrum with singular peaks” can be considered as an indicator of chaotic behavior.
