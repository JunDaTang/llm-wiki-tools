#### 4.1.6 Vector and Matrix Norms

The norm of a vector or of a matrix can be considered as a generalization of the absolute value (magnitude) of numbers. Therefore a real number is assigned as $\left| \left| x \right| \right| \left( N o r m \underline { { \mathbf { x } } } \right)$ to the vector x or as $| | \mathbf { A } | |$

(Norm A) to a matrix A. These numbers must satisfy the norm axioms (see 12.3.1.1, p. 669). For vectors $\mathbf { x } \in \mathbb { R } ^ { n }$ they are:

$$
\mathbf { 1 . } \ | | \mathbf { x } | | \geq 0 \ \mathrm { f o r } \ \mathrm { e v e r y } \ \underline { { \mathbf { x } } } ; \quad | | \underline { { \mathbf { x } } } | | = 0 \quad \ \mathrm { i f } \ \mathrm { a n d \ o n l y \ i f } \ \underline { { \mathbf { x } } } = 0 .\tag{4.45}
$$

2. $| | \lambda \mathbf { \underline { { x } } } | | = | \lambda | | \mathbf { \underline { { x } } } | |$ for every x and every real number λ.

(4.46)

3. $| | \underline { { \mathbf { x } } } + \underline { { \mathbf { y } } } | | \leq \ | | \underline { { \mathbf { x } } } | | + | | \underline { { \mathbf { y } } } | |$ for every x and $\underline { { \mathbf { y } } }$ (triangle inequality) (see also 3.5.1.1, 1., p. 182).

(4.47)

There are many diferent ways to define norms for vectors and matrices. But for practical reasons it is better to define a matrix norm $| | \mathbf { A } | |$ and a vector norm $| | \underline { { \mathbf { x } } } | |$ so that they might satisfy the inequality

$$
\| \mathbf { A } \mathbf { \underline { { x } } } \| \leq \| \mathbf { A } \| \| \mathbf { \underline { { x } } } \| .\tag{4.48}
$$

This inequality is very useful for error estimations. If the matrix and vector norms satisfy this inequality, then one says that they are consistent with each other. If there is a non-zero vector $\underline { { \mathbf { x } } }$ for every A such that the equality holds in (4.48), then one says the matrix norm $| | \mathbf { A } | |$ is the subordinate to the vector norm $| | \underline { { \mathbf { x } } } | |$

##### 4.1.6.1 Vector Norms

$\operatorname { I f } \underline { { \mathbf { x } } } = ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ) ^ { \mathrm { T } }$ is a real vector of n dimensions, i.e., $\mathbf { x } \in \mathbb { R } ^ { n }$ , then the most often used vector norms are:

1. Euclidean Norm

$$
\lvert \lvert \underline { { \mathbf { x } } } \rvert \rvert = \lvert \lvert \underline { { \mathbf { x } } } \rvert \rvert _ { 2 } : = \sqrt { \sum _ { i = 1 } ^ { n } x _ { i } ^ { 2 } } .\tag{4.49}
$$

2. Supremum or Uniform Norm

$$
| | \underline { { \mathbf { x } } } | | = | | \underline { { \mathbf { x } } } | | _ { \infty } : = \operatorname* { m a x } _ { 1 \leq i \leq n } | x _ { i } | .\tag{4.50}
$$

3. Sum Norm

$$
| | \underline { { \mathbf { x } } } | | = | | \underline { { \mathbf { x } } } | | _ { 1 } : = \sum _ { i = 1 } ^ { n } | \underline { { \mathbf { x } } } _ { i } | .\tag{4.51}
$$

In $\mathbb { R } ^ { 3 }$ , in elementary vector calculus $| | \underline { { \mathbf { x } } } | | _ { 2 }$ is considered as the magnitude of the vector $\underline { { \mathbf { X } } } .$ . The magnitude $| x | = | | \underline { { \mathbf { x } } } | | _ { 2 }$ gives the length of the vector x.

##### 4.1.6.2 Matrix Norms

1. Spectral Norm for Real Matrices

$$
| | \mathbf { A } | | = | | \mathbf { A } | | _ { 2 } : = { \sqrt { \lambda _ { \operatorname* { m a x } } ( \mathbf { A } ^ { \mathrm { T } } \mathbf { A } ) } } .\tag{4.52}
$$

Here $\lambda _ { \operatorname* { m a x } } ( \mathbf { A } ^ { \mathrm { T } } \mathbf { A } )$ denotes the greatest eigenvalue (see 4.6.1, p. 314) of the matrix $\mathbf { A } ^ { \mathrm { T } } \mathbf { A }$

2. Row-Sum Norm

$$
| | \mathbf { A } | | = | | \mathbf { A } | | _ { \infty } : = \operatorname* { m a x } _ { 1 \leq i \leq n } \quad \sum _ { j = 1 } ^ { n } | a _ { i j } | .\tag{4.53}
$$

3. Column-Sum Norm

$$
| | \mathbf { A } | | = | | \mathbf { A } | | _ { 1 } : = \operatorname* { m a x } _ { 1 \leq j \leq n } \quad \sum _ { i = 1 } ^ { n } | a _ { i j } | .\tag{4.54}
$$

It can be proved that the matrix norm (4.52) is the subordinate norm to the vector norm (4.49). The same is true for (4.53) and (4.50), and for (4.54) and (4.51).
