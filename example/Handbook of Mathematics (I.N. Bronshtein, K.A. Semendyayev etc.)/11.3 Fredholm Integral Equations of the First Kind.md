### 11.3 Fredholm Integral Equations of the First Kind

#### 11.3.1 Integral Equations with Degenerate Kernels

1. Formulation of the Problem

Consider the Fredholm integral equation of the first kind with degenerate kernel

$$
f ( x ) = \int _ { a } ^ { b } ( \alpha _ { 1 } ( x ) \beta _ { 1 } ( y ) + \ldots + \alpha _ { n } ( x ) \beta _ { n } ( y ) ) \varphi ( y ) d y \quad ( c \leq x \leq d ) ,\tag{11.38a}
$$

and introduce the notation similar to that used in 11.2, p. 622,

$$
A _ { j } = \int _ { a } ^ { b } \beta _ { j } ( y ) \varphi ( y ) d y \quad ( j = 1 , 2 , \ldots , n ) .\tag{11.38b}
$$

Then (11.38a) has the form

$$
f ( x ) = A _ { 1 } \alpha _ { 1 } ( x ) + \ldots + A _ { n } \alpha _ { n } ( x ) ,\tag{11.38c}
$$

i.e., the integral equation has a solution only if $f ( x )$ is a linear combination of the functions $\alpha _ { 1 } ( x ) , \ldots ,$ $\alpha _ { n } ( x )$ . If this assumption is fulfilled, the constants $A _ { 1 } , \ldots , A _ { n }$ are known.

2. Initial Approach

Looking for the solution in the form

$$
\varphi ( x ) = c _ { 1 } \beta _ { 1 } ( x ) + . . . + c _ { n } \beta _ { n } ( x )\tag{11.39a}
$$

where the coeficients $c _ { 1 } , \ldots , c _ { n }$ are unknown, substituting in (11.38b)

$$
A _ { i } = c _ { 1 } \int _ { a } ^ { b } \beta _ { i } ( y ) \beta _ { 1 } ( y ) d y + \ldots + c _ { n } \int _ { a } ^ { b } \beta _ { i } ( y ) \beta _ { n } ( y ) d y \quad ( i = 1 , 2 , \ldots , n ) ,\tag{11.39b}
$$

and introducing the notation

$$
K _ { i j } = \int _ { a } ^ { b } \beta _ { i } ( y ) \beta _ { j } ( y ) d y\tag{11.39c}
$$

gives the following system of equations for the unknown coeficients $c _ { 1 } , \ldots , c _ { n } ;$

$$
\begin{array} { r l r } & { } & { K _ { 1 1 } c _ { 1 } + . . . + K _ { 1 n } c _ { n } = A _ { 1 } , } \\ & { } & { \vdots \qquad \vdots \qquad \vdots \qquad \vdots } \\ & { } & { K _ { n 1 } c _ { 1 } + . . . + K _ { n n } c _ { n } = A _ { n } . } \end{array}\tag{11.39d}
$$

3. Solutions

The matrix of the coeficients is non-singular if the functions $\beta _ { 1 } ( y ) , \ldots , \beta _ { n } ( y )$ are linearly independent (see 12.1.3, p. 656). However, the solution obtained in (11.39a) is not the only one. Unlike the integral equations of the second kind with a degenerate kernel, the homogeneous integral equation belonging to (11.38a) always has a non-trivial solution. Suppose $\varphi ^ { h } ( x )$ is such a solution of the homogeneous equation and $\varphi ( \dot { x } )$ is a solution of (11.38a). Then $\bar { \varphi } ( x ) + \bar { \varphi } ^ { \bar { h } } ( \bar { x } )$ is also a solution of (11.38a). To determine all the solutions of the homogeneous equation, consider the equation (11.38c) with $f ( x ) =$ 0. If the functions $\alpha _ { 1 } ( x ) , \ldots , \alpha _ { n } ( x )$ are linearly independent, the equation holds if and only if

$$
A _ { j } = \int _ { a } ^ { b } \beta _ { j } ( y ) \varphi ( y ) d y = 0 \quad ( j = 1 , 2 , \ldots , n ) ,\tag{11.40}
$$

i.e., every function $\varphi ^ { h } ( y )$ orthogonal to every function $\beta _ { j } ( y )$ is a solution of the homogeneous integral equation.

#### 11.3.2 Analytic Basis

1. Initial Approach

Several methods for the solution of Fredholm integral equations of the first kind

$$
f ( x ) = \int _ { a } ^ { b } K ( x , y ) \varphi ( y ) d y \quad ( c \leq x \leq d )\tag{11.41}
$$

determine the solution $\varphi ( y )$ as a function series of a given system of functions $\displaystyle ( \beta _ { n } ( y ) ) = \{ \beta _ { 1 } ( y ) , \beta _ { 2 } ( y )$ $\cdots \}$ , i.e., looking for the solution in the form

$$
\varphi ( y ) = \sum _ { j = 1 } ^ { \infty } c _ { j } \beta _ { j } ( y )\tag{11.42}
$$

where there are to determine the unknown constants $c _ { j }$ . Choosing the system of functions it is to be considered that the functions $( \beta _ { n } ( y ) )$ should generate the whole space of solutions, and also that the

calculation of the coeficients $c _ { j }$ should be easy.

For an easier survey only real functions are discussed in this section. All of the statements can be extended to complex-valued functions, too. Because of the solution method there are to establish certain requirements for properties of the kernel function $K ( x , y )$ (see [11.3], [11.11], [11.12]). It is to be assumed that these requirements are always fulfilled. Next, there are to discuss some relevant information.

2. Quadratically Integrable Functions

A function $\psi ( y )$ is quadratically integrable over the interval [a, b] if

$$
\int \displaylimits _ { a } ^ { b } | \psi ( y ) | ^ { 2 } d y < \infty\tag{11.43}
$$

holds. For example, every continuous function on $[ a , b ]$ is quadratically integrable. The space of quadratically integrable functions over $[ a , b ]$ will be denoted by $\mathring { L } ^ { 2 } [ a , b ]$

3. Orthonormal System

Two quadratically integrable functions $\beta _ { i } ( y ) , \beta _ { j } ( y ) , y \in [ a , b ]$ are considered orthogonal to each other if the equality

$$
\intop _ { a } ^ { b } \beta _ { i } ( y ) \beta _ { j } ( y ) d y = 0\tag{11.44a}
$$

holds. A system of functions $\left( \beta _ { n } ( y ) \right)$ in the space $L ^ { 2 } [ a , b ]$ is called an orthonormal system if the following equalities are true:

$$
\int _ { a } ^ { b } \beta _ { i } ( y ) \beta _ { j } ( y ) d y = { \left\{ \begin{array} { l l } { 1 } & { { \mathrm { f o r } } \quad i = j , } \\ { 0 } & { { \mathrm { f o r } } \quad i \neq j . } \end{array} \right. }\tag{11.44b}
$$

An orthonormal system of functions is complete if there is no function $\tilde { \beta } ( y ) \neq 0$ in $L ^ { 2 } [ a , b ]$ orthogonal to every function of this system. A complete orthonormal system contains countably many functions. These functions form a basis of the space $L ^ { 2 } [ a , b ]$ . To transform a system of functions $\left( \beta _ { n } ( y ) \right)$ into an orthonormal system $\left( \beta _ { n } ^ { * } ( y ) \right)$ ) the Schmidt orthogonalization procedure can be used. This determines the coeficients $b _ { n 1 } , b _ { n 2 } , \ldots { } , b _ { n n }$ for $n = 1 , 2 , \ldots$ . successively so that the function

$$
\beta _ { n } ^ { * } ( y ) = \sum _ { j = 1 } ^ { n } b _ { n j } \beta _ { j } ( y )\tag{11.44c}
$$

is normalized and orthogonal to every function $\beta _ { 1 } ^ { * } ( y ) , \ldots , \beta _ { n - 1 } ^ { * } ( y )$

4. Fourier Series

If $\left( \beta _ { n } ( y ) \right)$ is an orthonormal system and $\psi ( y ) \in L ^ { 2 } [ a , b ]$ , then one calls the series

$$
\sum _ { j = 1 } ^ { \infty } d _ { j } \beta _ { j } ( y ) = \psi ( y )\tag{11.45a}
$$

the Fourier series of $\psi ( y )$ with respect to $\left( \beta _ { n } ( y ) \right)$ , and the numbers $d _ { j }$ are the corresponding Fourier coeficients. Based on (11.44b)

$$
\int _ { a } ^ { b } \beta _ { k } ( y ) \psi ( y ) d y = \sum _ { j = 1 } ^ { \infty } d _ { j } \int _ { a } ^ { b } \beta _ { j } ( y ) \beta _ { k } ( y ) d y = d _ { k }\tag{11.45b}
$$

holds. If $( \beta _ { n } ( y ) )$ is complete, the Parseval equality holds:

$$
\int _ { a } ^ { b } | \psi ( y ) | ^ { 2 } d y = \sum _ { j = 1 } ^ { \infty } | d _ { j } | ^ { 2 } .\tag{11.45c}
$$

$$

$$

$$

$$

then the sum $\varphi ( y ) + \varphi ^ { h } ( y )$ is a solution of the inhomogeneous integral equation. Therefore there are to determine all the solutions of the homogeneous integral equation. This problem is the same as determining all the non-trivial solutions of the linear system of equations

$$
\sum _ { j = 1 } ^ { \infty } K _ { i j } c _ { j } = 0 \quad ( i = 1 , 2 , \ldots ) .\tag{11.49}
$$

As sometimes this system is not so easy to solve, the following method can be used for the calculations. If there is a complete orthonormal system $\left( \alpha _ { n } ( x ) \right)$ ), take the functions

$$
K _ { i } ( y ) = \int _ { c } ^ { d } K ( x , y ) \alpha _ { i } ( x ) d x \quad ( i = 1 , 2 , \ldots ) .\tag{11.50a}
$$

If $\varphi ^ { h } ( y )$ is an arbitrary solution of the homogeneous equation, i.e.,

$$
\intop _ { a } ^ { b } K ( x , y ) \varphi ^ { h } ( y ) d y = 0\tag{11.50b}
$$

holds, then multiplying this equality by $\alpha _ { i } ( x )$ and performing an integration with respect to x, gives

$$
0 = \int _ { a } ^ { b } \varphi ^ { h } ( y ) \int _ { c } ^ { d } K ( x , y ) \alpha _ { i } ( x ) d x d y = \int _ { a } ^ { b } \varphi ^ { h } ( y ) K _ { i } ( y ) d y \quad ( i = 1 , 2 , \dots ) ,\tag{11.50c}
$$

i.e., every solution $\varphi ^ { h } ( y )$ of the homogeneous equation must be orthogonal to every function $K _ { i } ( y )$ Replacing the system $\left( K _ { n } ( y ) \right)$ by an orthonormal system $\left( K _ { n } ^ { * } ( y ) \right)$ and using an orthogonalization procedure, instead of (11.50c) follows

\int _ { a } ^ { b } \varphi ^ { h } ( y ) K _ { i } ^ { * } ( y ) d y = 0 .\tag{11.50d}
$$

#### 11.3.5 Construction of Two Specia lOrthonormal Systems for a Given Kernel

1. Preliminaries

The solution of infinite systems of linear equations (see 11.3.3, p. 638) is not usually easier than the solution of the original problem. Choosing suitable orthonormal systems $( \alpha _ { n } ( x ) )$ and $\left( \beta _ { n } ( y ) \right)$ one can change the structure of the kernel matrix K in such a way that the system of equations can be solved easily. By the following method two orthonormal systems can be constructed such that the coeficients

$K _ { i j }$ of the kernel matrix are non-zero only for $i = j$ and $i = j + 1$

Using the method given in the previous paragraph, first two orthonormal systems $\left( \beta _ { n } ^ { h } ( y ) \right)$ and $\left( \alpha _ { n } ^ { h } ( x ) \right)$ are to determine, i.e., the solution systems of the homogeneous and the corresponding adjoint homogeneous integral equations respectively. This means that it can be given all the solutions of these two integral equations by a linear combination of the functions $\beta _ { n } ^ { h } ( y )$ and $\alpha _ { n } ^ { h } ( x )$ . These orthonormal systems are not complete. By the following method these systems are to be completed step by step into complete orthonormal systems $\alpha _ { j } ( x ) , \beta _ { j } ( y ) ~ ( j = 1 , 2 , . . . )$

2. Procedure

First a normalized function $\alpha _ { 1 } ( x )$ is determined, which is orthogonal to every function $\left( \alpha _ { n } ^ { h } ( x ) \right)$ . Then the following steps are performed for $j = 1 , 2 , \dots$

1. Determination of the function $\beta _ { j } ( y )$ and the number $\nu _ { j }$ from the formulas

$$
\begin{array} { l l l } { \displaystyle \nu _ { 1 } \beta _ { 1 } ( y ) = \int _ { c } ^ { d } K ( x , y ) \alpha _ { 1 } ( x ) d x \quad \mathrm { o r } } \\ { \displaystyle \nu _ { j } \beta _ { j } ( y ) = \int _ { c } ^ { d } K ( x , y ) \alpha _ { j } ( x ) d x - \mu _ { j - 1 } \beta _ { j - 1 } ( y ) \quad ( j \neq 1 ) , } \end{array}\tag{11.51a}
$$

(11.51b)

so that $\nu _ { j }$ is never equal to zero and $\beta _ { j } ( y )$ is normalized. Then $\beta _ { j } ( y )$ is orthogonal to the functions $\Big ( ( \beta _ { n } ^ { h } ( y ) ) , \beta _ { 1 } ( y ) , \dots , \beta _ { j - 1 } ( y ) \Big )$

2. Determination of the function $\alpha _ { j + 1 } ( x )$ and the number $\mu _ { j }$ from the formula

$$
\mu _ { j } \alpha _ { j + 1 } ( x ) = \intop _ { a } ^ { b } K ( x , y ) \beta _ { j } ( y ) d y - \nu _ { j } \alpha _ { j } ( x ) .\tag{11.51c}
$$

There are two possibilities:

a) $\mu _ { j } \neq 0 ;$ : The function $\alpha _ { j + 1 } ( x )$ is orthogonal to the functions $\Big ( ( \alpha _ { n } ^ { h } ( x ) ) , \alpha _ { 1 } ( x ) , \ldots , \alpha _ { j } ( x ) \Big )$

b) $\mu _ { j } = 0$ : Then the function $\alpha _ { j + 1 } ( x )$ is not uniquely defined. Here again there are two cases:

$\mathbf { b _ { 1 } } )$ The system $\big ( ( \alpha _ { n } ^ { h } ( x ) ) , \alpha _ { 1 } ( x ) , \ldots , \alpha _ { j } ( x ) \big )$ is already complete. Then the system $\Big ( ( \beta _ { n } ^ { h } ( y ) ) , \beta _ { 1 } ( y ) , \ldots ,$ $\beta _ { j } ( y ) )$ is also complete, and the procedure is finished.

$\mathbf { b _ { 2 } } )$ The system $\big ( ( \alpha _ { n } ^ { h } ( x ) ) , \alpha _ { 1 } ( x ) , \dots , \alpha _ { j } ( x ) \big )$ is not complete. Then again one chooses an arbitrary function $\alpha _ { j + 1 } ( x )$ orthogonal to the previous functions.

This procedure is repeated until the orthonormal systems are complete. It is possible that after a certain step the case b) does not occur during a countable number of steps, but the system of this countable number of functions $\left( ( \alpha _ { n } ^ { h } ( x ) ) , \alpha _ { 1 } ( x ) , \ldots \right)$ is still not complete. Then again one can start the procedure by a function $\tilde { \alpha _ { 1 } } ( x )$ , which is orthogonal to every function of the previous system.

If the functions $\alpha _ { j } ( x ) , \beta _ { j } ( y )$ and the numbers $\nu _ { j } , \mu _ { j }$ are determined by the procedure given above, the kernel matrix K has the form

$$
\mathbf { K } = \left( \begin{array} { c c c } { 0 } & { 0 } & { 0 } & { \cdots } \\ { 0 } & { \mathbf { K } ^ { 1 } } & { 0 } & { \cdots } \\ { 0 } & { 0 } & { \mathbf { K } ^ { 2 } } & { \cdots } \\ { \vdots } & { \ddots } & { \vdots } \end{array} \right) \qquad \mathrm { w i t h } \qquad \mathbf { K } ^ { m } = \left( \begin{array} { c c c } { \nu _ { 1 } ^ { ( m ) } } & { 0 } & { 0 } & { \cdots } \\ { \mu _ { 1 } ^ { ( m ) } } & { \nu _ { 2 } ^ { ( m ) } } & { 0 } & { \cdots } \\ { 0 } & { \mu _ { 2 } ^ { ( m ) } } & { \nu _ { 3 } ^ { ( m ) } } & { \cdots } \\ { \vdots } & { \hphantom { 0 } } & { \vdots } \end{array} \right) .\tag{11.52}
$$

The matrices $\mathbf { K } ^ { m } \ ( m = 1 , 2 , \ldots )$ are finite if during the procedure $\mu _ { j } ^ { ( m ) }$ = 0 holds after a finite number of steps. They are infinite if for countably many values of $j , \mu _ { j } ^ { ( m ) } \neq 0$ holds. The number of zero rows and zero columns in K corresponds to the number of functions in the systems $\left( \alpha _ { n } ^ { h } ( x ) \right)$ and $\left( \beta _ { n } ^ { h } ( y ) \right)$ . A very simple case happens if the matrices $\mathbf { K } ^ { m }$ contain one number $\nu _ { 1 } ^ { ( m ) } = \nu _ { m }$ only, i.e., all numbers $\mu _ { j } ^ { ( m ) }$ are equal to zero.

Using the notation of 11.3.3, p. 638, for the solution of the infinite system of equations under the assumptions $f _ { j } = 0$ for $\alpha _ { j } ( x ) \in { \mathsf { \tilde { ( } } } \alpha _ { n } ^ { h } ( x ) )$ ) it holds:

$$

$$

#### 11.3.6 Iteration Method

To solve the integral equation

$$
f ( x ) = \int _ { a } ^ { b } K ( x , y ) \varphi ( y ) d y \quad ( c \leq x \leq d ) ,\tag{11.54a}
$$

starting with $\alpha _ { 0 } ( x ) = f ( x )$ one determines the functions

$$
\beta _ { n } ( y ) = \int _ { c } ^ { d } K ( x , y ) \alpha _ { n - 1 } ( x ) d x \quad { \mathrm { ( 1 1 . 5 4 b ) } } \qquad \mathrm { a n d } \quad \alpha _ { n } ( x ) = \int _ { a } ^ { b } K ( x , y ) \beta _ { n } ( y ) d y ,\tag{11.54c}
$$

$$
\begin{array} { l } { \displaystyle \int _ { a } ^ { b } \varphi ( y ) \beta _ { n } ( y ) d y = \int _ { a } ^ { b } \int \varphi ( y ) K ( x , y ) \alpha _ { n - 1 } ( x ) d x d y } \\ { \displaystyle = \int _ { c } ^ { d } f ( x ) \alpha _ { n - 1 } ( x ) d x \qquad ( n = 1 , 2 , \ldots ) . } \end{array}\tag{11.54d}

Using the Schmidt orthogonalization method then $\beta _ { n } ^ { * } ( y )$ has the form

$$

Now it is assumed that the solution $\varphi ( y )$ of (11.54a) has the representation by the series

$$
