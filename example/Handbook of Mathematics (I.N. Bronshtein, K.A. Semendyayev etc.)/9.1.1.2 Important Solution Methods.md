3. Exact Diferential Equations

An exact diferential equation is an equation of the form

$$
M ( x , y ) d x + N ( x , y ) d y = 0 \quad { \mathrm { o r } } \quad N ( x , y ) y ^ { \prime } + M ( x , y ) = 0 ,\tag{9.9a}
$$

if there exists a function $\varPhi ( x , y )$ of two variables such that

$$
M ( x , y ) d x + N ( x , y ) d y \equiv d \phi ( x , y ) ,\tag{9.9b}
$$

i.e., if the left side of $\left( 9 . 9 \mathrm { a } \right)$ is the total diferential of a function $\varPhi ( x , y )$ (see 6.2.2.1, p. 447). If functions $M ( x , y )$ and $N ( x , y )$ and their first-order partial derivatives are continuous on a connected domain $G ,$ then the equality

$$
\frac { \partial M } { \partial y } = \frac { \partial N } { \partial x }\tag{9.9c}
$$

is a necessary and suficient condition for equation (9.9a) to be exact. In this case the general solution of (9.9a) is the function

$$
\begin{array} { r } { \phi ( x , y ) = C \quad ( C = \mathrm { c o n s t } ) , } \end{array}\tag{9.9d}
$$

which can be calculated according to (8.3.4), 8.3.4.4, p. 522 as the integral

$$
\varPhi ( x , y ) = \int _ { x _ { 0 } } ^ { x } M ( \xi , y ) d \xi + \int _ { y _ { 0 } } ^ { y } N ( x _ { 0 } , \eta ) d \eta ,\tag{9.9e}

4. Integrating Factor

A function $\mu ( x , y )$ is called an integrating factor or a multiplier if the equation

$$
M d x + N d y = 0\tag{9.10a}
$$

multiplied by $\mu ( x , y )$ becomes an exact diferential equation. The integrating factor satisfies the diferential equation

$$
N \frac { \partial \ln \mu } { \partial x } - M \frac { \partial \ln \mu } { \partial y } = \frac { \partial M } { \partial y } - \frac { \partial N } { \partial x } .\tag{9.10b}
$$

Every particular solution $\mu$ of this equation is an integrating factor. To give a general solution of this partial diferential equation is much more complicated than to solve the original equation, so usually one is looking for the solution $\mu ( x , y )$ in a special form, e.g., $\mu ( x ) , \mu ( y ) , \mu ( x y )$ or $\mu (  { \hat { x } } ^ { 2 } +  { y } ^ { 2 } )$

To solve the diferential equation $( x ^ { 2 } + y ) d x - x d y = 0$ , the equation for the integrating factor is $- x { \frac { \partial \ln \mu } { \partial x } } - ( x ^ { 2 } + y ) { \frac { \partial \ln \mu } { \partial y } } = 2$ . An integrating factor which is independent of y must satisfy $x \frac { \partial \ln \mu } { \partial x } =$ $- 2 ,$ so $\mu = { \frac { 1 } { x ^ { 2 } } }$ . Multiplication of the given diferential equation by $\mu$ yields $\left( 1 + { \frac { y } { x ^ { 2 } } } \right) d x - { \frac { 1 } { x } } d y = 0$ The general solution according to (9.9e) with the selection of $x _ { 0 } = 1 , y _ { 0 } = 0$ is then:

5. First-Order Linear Diferential Equations

A first-order linear diferential equation has the form

$$
y ^ { \prime } + P ( x ) y = Q ( x ) ,\tag{9.11a}
$$

where the unknown function and its derivative occur only in first degree, and $P ( x )$ and $Q ( x )$ are given functions. If $P ( x )$ and $Q ( x )$ are continuous functions on a finite, closed interval, then the diferential equation satisfies the conditions of the Picard-Lindel¨of theorem (see 12.2.2.4,4., p. 668) in this region. An integrating factor is here

$$
\mu = \exp \left( \int P d x \right) ,\tag{9.11b}

7. Riccati Diferential Equations

The Riccati diferential equation

$$
y ^ { \prime } = P ( x ) y ^ { 2 } + Q ( x ) y + R ( x ) ,\tag{9.13a}
$$

usually cannot be solved by elementary integration, i.e., not by using a final number of successive elementary integrations. However it is possible to transform it by suitable substitutions into diferential equations for which solutions often can be found.

Method 1: By the substitution

$$
y = \frac { u ( x ) } { P ( x ) } + \beta ( x )\tag{9.13b}
$$

the Riccati diferential equation can be transformed into the normal form

$$
\frac { d u } { d x } = u ^ { 2 } + R _ { 0 } ( x ) \qquad \mathrm { ( 9 . 1 3 c ) } \qquad \mathrm { w i t h } \quad R _ { 0 } ( x ) = P ^ { 2 } \beta ^ { 2 } + Q P \beta + P R - P \beta ^ { \prime } .\tag{9.13d}
