#### 4.1.2 Square Matrices

1. Definition

Square matrices have the same number of rows and columns, i.e., $m = n$

$$
\mathbf { A } = \mathbf { A } _ { ( n , n ) } = \left( \begin{array} { l l l } { a _ { 1 1 } \cdot \cdot \cdot \ a _ { 1 n } } \\ { \vdots \cdot \cdot \cdot \vdots } \\ { a _ { n 1 } \cdot \cdot \cdot \ a _ { n n } } \end{array} \right) .\tag{4.6}
$$

The elements $a _ { \mu \nu }$ of a matrix A in the diagonal from the left upper corner to the right lower one are the elements ofthe main diagonal. They are denoted by $a _ { 1 1 } , a _ { 2 2 } , \dotsc , a _ { n n } .$ i.e., they are all the elements $a _ { \mu \nu }$ with $\mu = \nu$

2. Diagonal Matrices

A square matrix D is called a diagonal matrix if all of the non-diagonal elements are equal to zero:

$$
a _ { \mu \nu } = 0 \quad \mathrm { f o r } \quad \mu \neq \nu : \quad \mathbf { D } = \left( \begin{array} { c c c c } { a _ { 1 1 } } & { 0 } & { \cdots } & { 0 } \\ { 0 } & { a _ { 2 2 } \cdots } & { 0 } \\ { \vdots } & { \vdots } & { \vdots } & { \vdots } \\ { 0 } & { 0 } & { \cdots } & { a _ { n n } } \end{array} \right) = \left( \begin{array} { c c c c } { a _ { 1 1 } } & { } & { 0 } & { } \\ { a _ { 2 2 } } & { } & { } & { } \\ { } & { \ddots } & { } & { } \\ { \mathbf { 0 } } & { } & { a _ { n n } } \end{array} \right) .\tag{4.7}
$$

3. Scalar Matrix

A diagonal matrix S is called a scalar matrix if all the diagonal elements are the same real or complex number c:

$$
\begin{array} { r } { { \bf S } = \left( \begin{array} { l } { c \ 0 \ \cdots \ 0 } \\ { 0 \ c \ \cdots \ 0 } \\ { \vdots \ \vdots \ \vdots \ \vdots } \\ { 0 \ 0 \ \cdots \ c } \end{array} \right) . } \end{array}\tag{4.8}
$$

4. Trace or Spur of a Matrix

For a square matrix, the trace or spur of the matrix is defined as the sum of the main diagonal elements:

$$
\operatorname { T r } \left( \mathbf { A } \right) = a _ { 1 1 } + a _ { 2 2 } + \dotsc + a _ { n n } = \sum _ { \mu = 1 } ^ { n } a _ { \mu \mu } .\tag{4.9}
$$

5. Symmetric Matrices

A square matrix A is symmetric if it is equal to its own transpose:

$$
\mathbf { A } = \mathbf { A } ^ { \mathrm { T } } .\tag{4.10}
$$

For the elements lying in symmetric positions with respect to the main diagonal

$$
a _ { \mu \nu } = a _ { \nu \mu }\tag{4.11}
$$

is valid.

6. Normal Matrices

satisfy the equality

$$
\mathbf { A } ^ { \mathrm { H } } \mathbf { A } = \mathbf { A } \mathbf { A } ^ { \mathrm { H } } .\tag{4.12}
$$

(For the product of matrices see 4.1.4, p. 272.)

7. Antisymmetric or Skew-Symmetric Matrices

are the square matrices A with the property:

$$
\mathbf { A } = - \mathbf { A } ^ { \mathrm { T } } .\tag{4.13a}
$$

For the elements $a _ { \mu \nu }$ of an antisymmetric matrix the equalities

$$
a _ { \mu \nu } = - a _ { \nu \mu } , \quad a _ { \mu \mu } = 0\tag{4.13b}
$$

are valid, so the trace of an antisymmetric matrix vanishes:

$$
\operatorname { T r } \left( \mathbf { A } \right) = 0 .\tag{4.13c}
$$

The elements lying in symmetric positions with respect to the main diagonal difer from each other only in sign.

Every square matrix A can be decomposed into the sum of a symmetric matrix ${ \bf A } _ { \bf s }$ and an antisymmetric matrix $\mathbf { A } _ { \mathrm { a s } }$

$$
\mathbf { A } = \mathbf { A } _ { \mathrm { s } } + \mathbf { A } _ { \mathrm { a s } } \qquad \mathrm { w i t h } \qquad \mathbf { A } _ { \mathrm { s } } = { \frac { 1 } { 2 } } ( \mathbf { A } + \mathbf { A } ^ { \mathrm { T } } ) ; \ \mathbf { A } _ { \mathrm { a s } } = { \frac { 1 } { 2 } } ( \mathbf { A } - \mathbf { A } ^ { \mathrm { T } } ) .\tag{4.13d}
$$

8. Hermitian Matrices or Self-Adjoint Matrices

are square matrices A equal to their own adjoints :

$$
\mathbf { A } = ( \mathbf { A } ^ { * } ) ^ { \mathrm { T } } = \mathbf { A } ^ { \mathrm { H } } .\tag{4.14}
$$

Over the real numbers the conce ts of s mmetric and Hermitian matrices are the same. The determinant of a Hermitian matrix is real.

9. Anti-Hermitian or Skew-Hermitian Matrices

are the square matrices equal to their negative adjoints:

$$
\mathbf { A } = - ( \mathbf { A } ^ { * } ) ^ { \mathrm { T } } = - \mathbf { A } ^ { \mathrm { H } } .\tag{4.15a}
$$

For the elements $a _ { \mu \nu }$ and the trace of an anti-Hermitian matrix the equalities

$$
a _ { \mu \nu } = - a _ { \mu \nu } ^ { * } , \ a _ { \mu \mu } = 0 ; \ \mathrm { T r } \left( { \bf A } \right) = 0\tag{4.15b}
$$

are valid. Every square matrix A can be decomposed into a sum of a Hermitian matrix $\mathbf { A _ { h } }$ and an anti-Hermitian matrix $\mathbf { A } _ { \mathbf { a } \mathbf { h } }$

$$
\mathbf { A } = \mathbf { A } _ { \mathrm { h } } + \mathbf { A } _ { \mathrm { a h } } \quad \mathrm { w i t h } \quad \mathbf { A } _ { \mathrm { h } } = { \frac { 1 } { 2 } } ( \mathbf { A } + \mathbf { A } ^ { \mathrm { H } } ) , ~ \mathbf { A } _ { \mathrm { a h } } = { \frac { 1 } { 2 } } ( \mathbf { A } - \mathbf { A } ^ { \mathrm { H } } ) .\tag{4.15c}
$$

10. Identity Matrix I

is a diagonal matrix such that every diagonal element is equal to 1 and all of the non-diagonal elements are equal to zero:

$$
\mathbf { I } = { \left( \begin{array} { l l l } { 1 0 \cdots 0 } \\ { 0 1 \cdots 0 } \\ { \vdots \vdots \vdots \vdots } \\ { 0 0 \cdots 1 } \end{array} \right) } = ( \delta _ { \mu \nu } ) \qquad { \mathrm { w i t h } } \qquad \delta _ { \mu \nu } = { \Bigl \{ } _ { 1 } ^ { 0 } { \mathrm { f o r } } \mu \neq \nu ,\tag{4.16}
$$

The symbol $\delta _ { \mu \nu }$ is called the Kronecker symbol.

11. Triangular Matrix

1. Upper Triangular Matrix, U, is a square matrix such that all the elements under the main diagonal are equal to zero:

$$
{ \bf R } = ( r _ { \mu \nu } ) \mathrm { w i t h } r _ { \mu \nu } = 0 \mathrm { f o r } \mu > \nu .\tag{4.17}
$$

2. Lower Triangular Matrix, L, is a square matrix such that all the elements above the main diagonal are equal to zero:

$$
{ \bf L } = ( l _ { \mu \nu } ) \mathrm { w i t h } l _ { \mu \nu } = 0 \mathrm { f o r } \mu < \nu .\tag{4.18}
$$
