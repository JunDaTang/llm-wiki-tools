#### 4.6.3 Singular Value Decomposition

1. Singular Values and Singular Vectors Let A be a real matrix of size $( m , n )$ and its rank be equal to r. The matrices $\mathbf { A A } ^ { \mathrm { T } }$ and ${ \bf A } ^ { \mathrm { T } } { \bf A }$ have r non-zero eigenvalues $\lambda _ { \nu }$ and they are the same for both of the matrices. The positive square roots $d _ { \nu } = \sqrt { \lambda _ { \nu } } \quad ( \nu = 1 , 2 , \ldots , r )$ of the eigenvalues $\lambda _ { \nu }$ of the matrix ${ \bf A } ^ { \mathrm { T } } { \bf A }$ are called the singular values of the matrix A. The corresponding eigenvectors $\underline { { \mathbf { u } } } _ { \nu }$ of ${ \bf A } ^ { \mathrm { T } } { \bf A }$ are called right-singular vectors of A, the corresponding eigenvectors $\underline { { \mathbf { v } } } _ { \nu }$ of $\overset \vartriangle { \mathbf { A } } \mathbf { A } ^ { \overleftarrow { \boldsymbol { \mathrm { T } } } }$ left-singular vectors:

$$
\mathbf { A } ^ { \mathrm { T } } \mathbf { A } \underline { { \mathbf { u } } } _ { \nu } = \lambda _ { \nu } \underline { { \mathbf { u } } } _ { \nu } , \quad \mathbf { A } \mathbf { A } ^ { \mathrm { T } } \underline { { \mathbf { v } } } _ { \nu } = \lambda _ { \nu } \underline { { \mathbf { v } } } _ { \nu } \quad ( \nu = 1 , 2 , \ldots , r ) .\tag{4.222a}
$$

The relations between the right and left-singular vectors are:

$$
\mathbf { A } \underline { { \mathbf { u } } } _ { \nu } = d _ { \nu } \underline { { \mathbf { v } } } _ { \nu } , \quad \mathbf { A } ^ { \mathrm { T } } \underline { { \mathbf { v } } } _ { \nu } = d _ { \nu } \underline { { \mathbf { u } } } _ { \nu } .\tag{4.222b}
$$

A matrix A of size $( m , n )$ with rank r has r positive-singular values $\begin{array} { r l } { d _ { \nu } } & { { } ( \nu = 1 , 2 , \ldots , r ) } \end{array}$ . There exist r orthonormalized right-singular vectors $\underline { { \mathbf { u } } } _ { \nu }$ and r orthonormalized left-singular vectors $\underline { { \mathbf { v } } } _ { \nu }$ . Furthermore, there exist to the zero-singular value $n - r$ orthonormalized right-singular vectors $\underline { { \mathbf { u } } } _ { \nu } ( \nu = r + 1 , \dots , n )$ and $m - r$ orthonormalized left-singular vectors $\begin{array} { r l } { \underline { { \mathbf { v } } } _ { \nu } } & { { } ( \nu = r + 1 , \dots , m ) } \end{array}$ . Consequently, a matrix of size $( m , n )$ has n right-singular vectors and m left-singular vectors, and two orthogonal matrices can be made from them (see 4.1.4, 9., p. 275):

$$
{ \bf U } = ( \underline { { \bf u _ { 1 } } } , \underline { { \bf u _ { 2 } } } , \ldots , \underline { { \bf u _ { n } } } ) , \quad { \bf V } = ( \underline { { \bf v _ { 1 } } } , \underline { { \bf v _ { 2 } } } , \ldots , \underline { { \bf v _ { m } } } ) .\tag{4.223}
$$

2. Singular-Value Decomposition The representation

$$
\mathbf { A } = \mathbf { V } \hat { \mathbf { A } } \mathbf { U } ^ { \mathrm { T } } ( 4 . 2 2 4 \mathbf { a } ) \qquad \mathrm { w i t h } \ \hat { \mathbf { A } } = ( \begin{array} { l l } { d _ { 1 } \ 0 \ 0 \ \cdots \ } & { 0 } \\ { 0 \ d _ { 2 } } & { } \\ { \vdots \ \cdots \ } & { \vdots } \\ { 0 \ } & { \cdots \ } & { 0 } \\ { 0 \ \ 0 \cdots \ } & { 0 \ d _ { r } | 0 \cdots \ 0 } \\ { 0 \ } & { } & { \cdots \ } & { 0 } \\ { 0 \ } & { } & { 0 } \\ { \vdots \ } & { } & { \vdots } \\ { 0 \ 0 \ \cdots \ } & { 0 \ | 0 \cdots \ 0 } \end{array} ) \qquad \} \mathrm { m } - r \mathrm { r o w s }\tag{4.224b}
$$

is called the singular-value decomposition of the matrix A. The matrix $\hat { \bf A }$ , as the matrix A, is of size $( m , n )$ and has only zero elements except the first r diagonal elements $\begin{array} { r l } { a _ { \nu \nu } = d _ { \nu } } & { { } ( \nu = 1 , 2 , \dots , r ) } \end{array}$ . The values $d _ { \nu }$ are the singular values of A.

Remark: If substituting $A ^ { \mathrm { H } }$ instead of $A ^ { \mathrm { T } }$ and consider unitary matrices U and V instead of orthogonals, then all the statements about singular-value decomposition are valid also for matrices with complex elements.

3. Application Singular-value decomposition can be used to determine the rank of the matrix A of size $( m , n )$ and to calculate an approximate solution of the over-determined system of equations

$\mathbf { A } \mathbf { \underline { { x } } } = \mathbf { \underline { { b } } }$ (see 4.5.3.1, p. 313) with the so-called regularization method, i.e., to solve the problem

$$
| | \mathbf { A } \mathbf { x } - \mathbf { b } | | ^ { 2 } + \alpha | | \mathbf { x } | | ^ { 2 } = \sum _ { i = 1 } ^ { m } \left[ \sum _ { k = 1 } ^ { n } a _ { i k } x _ { k } - b _ { i } \right] ^ { 2 } + \alpha \sum _ { k = 1 } ^ { n } x _ { k } ^ { 2 } = \operatorname* { m i n } ! ,\tag{4.225}
$$

where $\alpha > 0$ is a regularization parameter.
