##### 4.6.2.1 Characteristic Polynomial

The eigenvalue equation (4.194) yields a homogeneous system of equations which has non-trivial solutions $\underline { { \mathbf { x } } } \neq \underline { { \mathbf { 0 } } }$ only if

$$

$$

By the expansion of det $( \mathbf { A } - \lambda \mathbf { I } )$ one gets

(4.195a)

$$
{ \begin{array} { r l } & { \operatorname* { d e t } \left( \mathbf { A } - \lambda \mathbf { I } \right) = { \left| \begin{array} { l l l l } { a _ { 1 1 } - \lambda } & { a _ { 1 2 } } & { a _ { 1 3 } \cdots a _ { 1 n } } \\ { a _ { 2 1 } } & { a _ { 2 2 } - \lambda } & { a _ { 2 3 } \cdots a _ { 2 n } } \\ { \vdots } & { \vdots } & { \vdots } & { \vdots } \\ { a _ { n 1 } } & { a _ { n 2 } } & { a _ { n 3 } \cdots a _ { n n } - \lambda } \end{array} \right| } } \\ & { \qquad = P _ { n } ( \lambda ) = ( - 1 ) ^ { n } \lambda ^ { n } + a _ { n - 1 } \lambda ^ { n - 1 } + \cdots + a _ { 1 } \lambda + a _ { 0 } = 0 . } \end{array} }\tag{4.195b}

So the determination of the eigenvalues is equivalent to the solution of a polynomial equation. For an arbitrary square matrix A of size $( n , n )$ the following statements hold:

Case 1: The matrix $\mathbf { A } _ { ( n , n ) }$ has exactly n eigenvalues $\lambda _ { 1 } , \lambda _ { 2 } , \ldots , \lambda _ { n }$ , because a polynomial of degree n has n roots if they are considered with their multiplicity. The eigenvalues of a real symmetric matrix are real numbers, in other cases the eigenvalues can also be complex.

2. Transformation of Principal Axes, Similarity Transformation

For every real symmetric matrix A, there is an orthogonal matrix U and a diagonal matrix D such that

$$
\mathbf { A } = \mathbf { U } \mathbf { D } \mathbf { U } ^ { \mathrm { T } } .\tag{4.198}
$$

The diagonal elements of D are the eigenvalues of A, and the columns of U are the corresponding normed eigenvectors. From (4.198) it is obvious that

$$
\mathbf { D } = \mathbf { U } ^ { \mathrm { T } } \mathbf { A } \mathbf { U } .\tag{4.199}
$$

Transformation (4.199) is called the transformation of principal axes. In this way A is reduced to a diagonal matrix (see also 4.1.2, 2., p. 270).

If the square matrix A (not necessarily symmetric) is transformed by a square regular matrix G such a way that

$$
\mathbf { G } ^ { - 1 } \mathbf { A } \mathbf { G } = \tilde { \mathbf { A } }\tag{4.200}
$$

then it is called a similarity transformation. The matrices A and $\tilde { \mathbf { A } }$ are called similar and they have the following properties:

1. The matrices A and $\tilde { \mathbf { A } }$ have the same eigenvalues, i.e., the similarity transformation does not afect the eigenvalues.

2. If A is symmetric and G is orthogonal, then $\tilde { \mathbf { A } }$ is symmetric, too:

$$
\tilde { \mathbf { A } } = \mathbf { G } ^ { \mathrm { T } } \mathbf { A } \mathbf { G } \qquad \mathrm { w i t h } \qquad \mathbf { G } ^ { \mathrm { T } } \mathbf { G } = \mathbf { I } .\tag{4.201}
$$

The relation (4.201) is called an orthogonal-similarity transformation. In this context (4.199) means that a real symmetric matrix A can be transformed orthogonally similar to a real diagonal form D.

##### 4.6.2.3 Transformation of Principal Axes of Quadratic Forms

1. Real Quadratic Form, Definition

A real quadratic form $Q$ of variables $x _ { 1 } , x _ { 2 } , \ldots , x _ { n }$ has the form

$$
Q = \sum _ { i = 1 } ^ { n } \sum _ { j = 1 } ^ { n } a _ { i j } x _ { i } x _ { j } = { \underline { { \mathbf { x } } } } ^ { \mathrm { T } } { \underline { { \mathbf { A } } } } { \underline { { \mathbf { x } } } } ,\tag{4.202}
$$

where $\underline { { \mathbf { x } } } = ( x _ { 1 } , x _ { 2 } , \ldots , x _ { n } ) ^ { \mathrm { T } }$ is the vector of real variables and the matrix $\mathbf { A } = \left( a _ { i j } \right)$ is a real symmetric matrix.

The form Q is called positive definite or negative definite, if it takes only positive or only negative values respectively, and it takes the zero value only in the case $x _ { 1 } = x _ { 2 } = \ldots = x _ { n } = 0$

The form Q is called positive or negative semidefinite, if it takes non-zero values only with the sign according to its name, but it can take the zero value for non-zero vectors, too.

A real quadratic form is called indefinite if it takes both positive and negative values. According to the behavior of Q the associated real symmetric matrix A is called positive or negative definite, semidefinite or indefinite.

2. Real Positive Definite Quadratic Form, Properties

1. In a real positive definite quadratic form Q all elements of the main diagonal of the corresponding real symmetric matrix A are positive, i.e.,

$$
a _ { i i } > 0 \quad ( i = 1 , 2 , \ldots , n )\tag{4.203}
$$

holds. (4.203) represents a very important property of positive definite matrices.

2. A real quadratic form Q is positive definite if and only if all eigenvalues of the corresponding matrix A are positive.

3. Suppose the rank of the matrix A corresponding to the real quadratic form $Q = \underline { { \mathbf { x } } } ^ { \mathrm { T } } \mathbf { A } \underline { { \mathbf { x } } }$ is equal to r. Then the quadratic form can be transformed by a linear transformation

$$
\begin{array} { r } { \underline { { \mathbf { x } } } = \mathbf { C } \tilde { \underline { { \mathbf { x } } } } } \end{array}\tag{4.204}
$$

into a sum of pure quadratic terms, into the so-called normal form

$$
Q = \underline { { \tilde { \mathbf { x } } } } ^ { \mathrm { T } } \mathbf { K } \underline { { \tilde { \mathbf { x } } } } = \sum _ { i = 1 } ^ { r } p _ { i } \tilde { x _ { i } } ^ { 2 }\tag{4.205}
$$

where $p _ { i } = ( \mathrm { s i g n } \lambda _ { i } ) k _ { i }$ and $k _ { 1 } , k _ { 2 } , \ldots , k _ { r }$ are arbitrary, previously given, positive constants.

Remark: Regardless of the non-singular transformation (4.204) that transforms the real quadratic form of rank r into the normal form (4.205), the number p of positive coeficients and the number $q = r - p$ of negative coeficients among the $p _ { i }$ of the normal form are invariant (the inertia theorem of Sylvester). The value p is called the index ofinertia ofthe quadratic form.

3. Generation of the Normal Form

A practical method to use the transformation (4.205) follows from the transformation of principal axes (4.199). First it is to perform a rotation on the coordinate system by the orthogonal matrix U, whose columns are the eigenvectors of A (i.e., the directions of the axes of the new coordinate system are the directions of the eigenvectors). This gives the form

$$
Q = { \underline { { \tilde { \mathbf { x } } } } } ^ { \mathrm { T } } \mathbf { L } { \underline { { \tilde { \mathbf { x } } } } } = \sum _ { i = 1 } ^ { r } \lambda _ { i } { \tilde { x _ { i } } } ^ { 2 } .\tag{4.206}
$$

Here L is a diagonal matrix with the eigenvalues of A in the diagonal. Then a dilatation is performed by the diagonal matrix D whose diagonal elements are $d _ { i } = \sqrt { \frac { k _ { i } } { \vert \lambda _ { i } \vert } }$ . The whole transformation is now given by the matrix

$$
\mathbf { C } = \mathbf { U } \mathbf { D } ,\tag{4.207}
$$

and one gets:

$$
\begin{array} { r l } & { Q = \tilde { \underline { { \mathbf { x } } } } ^ { \mathrm { T } } \mathbf { A } \tilde { \underline { { \mathbf { x } } } } = ( \mathbf { U } \mathbf { D } \tilde { \underline { { \mathbf { x } } } } ) ^ { \mathrm { T } } \mathbf { A } ( \mathbf { U } \mathbf { D } \tilde { \underline { { \mathbf { x } } } } ) = \tilde { \underline { { \mathbf { x } } } } ^ { \mathrm { T } } ( \mathbf { D } ^ { \mathrm { T } } \mathbf { U } ^ { \mathrm { T } } \mathbf { A } \mathbf { U } \mathbf { D } ) \tilde { \underline { { \mathbf { x } } } } } \\ & { \quad = \tilde { \underline { { \mathbf { x } } } } ^ { \mathrm { T } } \mathbf { D } ^ { \mathrm { T } } \mathbf { L } \mathbf { D } \tilde { \underline { { \mathbf { x } } } } = \tilde { \underline { { \mathbf { x } } } } ^ { \mathrm { T } } \mathbf { K } \tilde { \underline { { \mathbf { x } } } } . } \end{array}\tag{4.208}
$$

Remark: The transformation of principal axes of quadratic forms plays an essential role at the classification of curves and surfaces of second order (see 3.5.2.11, p. 206 and 3.5.3.14, p. 228).

4. Jordan Normal Form

Let A be an arbitrary real or complex $( n , n )$ matrix. Then there exists a non-singular matrix T such that

$$
\mathbf { T } ^ { - 1 } \mathbf { A } \mathbf { T } = \mathbf { J }\tag{4.209}
$$

holds, where J is called the Jordan matrix or Jordan normal form of A. The Jordan matrix has a block diagonal structure of the form (4.210), where the elemnts $\mathbf { J } _ { j }$ of J are called Jordan blocks:

$$
\mathbf { J } = \left( \begin{array} { l l l } { \mathbf { J } _ { 1 } } & & & { 0 } \\ & { \mathbf { J } _ { 2 } } & & { 0 } \\ & & { \ddots } & \\ { 0 } & & & { \mathbf { J } _ { k - 1 } } \\ & & & { \mathbf { J } _ { k } } \end{array} \right) .\tag{4.210}
$$

$$
{ \bf J } = \left( \begin{array} { l l l } { \lambda _ { 1 } } & { } & { } \\ { } & { \lambda _ { 2 } } & { { \bf O } } \\ { } & { } & { \ddots } \\ { { \bf O } } & { } & { \lambda _ { n - 1 } } \\ { } & { } & { } & { \lambda _ { n } } \end{array} \right) .\tag{4.211}
$$

They have the following structure:

1. If A has only single eigenvalues $\lambda _ { j }$ , then $\mathbf { J } _ { j } = \lambda _ { j }$ and $k = n$ , i.e., J is a diagonal matrix (4.211).

2. If $\lambda _ { j }$ is an eigenvalue of multiplicity $p _ { j }$ , then there are one or more blocks of the form (4.212) where the sum of the sizes of all such blocks is equal to $p _ { j }$ and $\textstyle \sum _ { j = 1 } ^ { k } p _ { j } = n$ holds. ##### 4.6.2.4 Suggestions for the Numerical Calculations of Eigenvalues

1. Eigenvalues can be calculated as the roots of the characteristic equation (4.195b) (see examples on p. 315). In order to get them the coeficients $a _ { i } ( i = 0 , 1 , 2 , \dots , n - 1 )$ of the characteristic polynomial of the matrix A must be determined. However, one should avoid this method of calculation, because this procedure is extremely unstable, i.e., small changes in the coeficients $a _ { i }$ of the polynomial result in big changes in the roots $\lambda _ { j }$

2. There are many algorithms for the solution of the eigenvalue problem of symmetric matrices. Two types can be distinguished (see [4.7]):

a) Transformation methods, for instance the Jacobi method, Householder tridiagonalization, QR algorithm.

b) Iterative methods, for instance vector iteration, the Rayleigh-Ritz algorithm, inverse iteration, the Lanczos method, the bisection method. As an example the power method ofMises is discussed here.

3. The Power Method of Mises Assume that A is real and symmetric and has a unique dominant eigenvalue. This iteration method determines this eigenvalue and the associated eigenvector. Let the dominant eigenvalue be denoted by $\lambda _ { 1 }$ , that is,

$$
| \lambda _ { 1 } | > | \lambda _ { 2 } | \geq | \lambda _ { 3 } | \geq \cdot \cdot \cdot \geq | \lambda _ { n } | .\tag{4.213}
$$

Let $\underline { { \mathbf { x } } } _ { 1 } , \underline { { \mathbf { x } } } _ { 2 } , \ldots , \underline { { \mathbf { x } } } _ { n }$ be the associated linearly independent eigenvectors. Then:

1. $\mathbf { A } \underline { { \mathbf { x } } } _ { i } = \lambda _ { i } \underline { { \mathbf { x } } } _ { i } \quad ( i = 1 , 2 , \ldots , n )$

(4.214)

2. Each element $\mathbf { x } \in \mathbb { R } ^ { n }$ can be expressed as a linear combination of these eigenvectors $\underline { { \mathbf { x } } } _ { i } \mathrm { : }$

$$
\underline { { \mathbf { x } } } = c _ { 1 } \underline { { \mathbf { x } } } _ { 1 } + c _ { 2 } \underline { { \mathbf { x } } } _ { 2 } + \cdot \cdot \cdot + c _ { n } \underline { { \mathbf { x } } } _ { n } \quad ( c _ { i } \mathrm { c o n s t } ; \ i = 1 , 2 , \dots , n ) .\tag{4.215}
$$

Multiplying both sides of (4.215) by A k times, then using (4.214) follows

$$
\mathbf { A } ^ { k } \underline { { \mathbf { x } } } = c _ { 1 } \lambda _ { 1 } ^ { k } \underline { { \mathbf { x } } } _ { 1 } + c _ { 2 } \lambda _ { 2 } ^ { k } \underline { { \mathbf { x } } } _ { 2 } + \cdots + c _ { n } \lambda _ { n } ^ { k } \underline { { \mathbf { x } } } _ { n } = \lambda _ { 1 } ^ { k } [ c _ { 1 } \underline { { \mathbf { x } } } _ { 1 } + c _ { 2 } \left( \frac { \lambda _ { 2 } } { \lambda _ { 1 } } \right) ^ { k } \underline { { \mathbf { x } } } _ { 2 } + \cdots + c _ { n } \left( \frac { \lambda _ { n } } { \lambda _ { 1 } } \right) ^ { k } \underline { { \mathbf { x } } } _ { n } ] .\tag{4.216}
$$

From this relation and (4.213) one can see that

$$
\frac { { \bf A } ^ { k } { \bf \underline { { x } } } } { \lambda _ { 1 } ^ { k } c _ { 1 } } \longrightarrow { \bf \underline { { x } } } _ { 1 } \mathrm { a s } k  \infty , \quad \mathrm { t h a t i s , ~ } { \bf A } ^ { k } { \bf \underline { { x } } } \approx c _ { 1 } \lambda _ { 1 } ^ { k } { \bf \underline { { x } } } _ { 1 } .\tag{4.217}
$$

This is the basis of the following iteration procedure:

Step 1: Select an arbitrary starting vector $\underline { { \mathbf { x } } } ^ { ( 0 ) } \in \mathbb { R } ^ { n }$

Step 2: Iterative computation of

$$
\underline { { \mathbf { x } } } ^ { ( k + 1 ) } = \mathbf { A } \underline { { \mathbf { x } } } ^ { ( k ) } \quad ( k = 0 , 1 , 2 , \ldots ; \underline { { \mathbf { x } } } ^ { ( 0 ) } \mathrm { i s ~ g i v e n } ) .\tag{4.218}
$$

From (4.218) and keeping in mind (4.217) follows:

$$
\underline { { \mathbf { x } } } ^ { ( k ) } = \mathbf { A } ^ { k } \underline { { \mathbf { x } } } ^ { ( 0 ) } \approx c _ { 1 } \lambda _ { 1 } ^ { k } \underline { { \mathbf { x } } } _ { 1 } .\tag{4.219}
$$

$$

that is, for large values of k the consecutive vectors $\underline { { \mathbf { x } } } ^ { ( k + 1 ) }$ and $\underline { { \mathbf { x } } } ^ { ( k ) }$ difer approximately by a factor $\lambda _ { 1 }$ Step 4: Relations (4.219) and (4.220) imply for $\mathbf { \Delta } \mathbf { x } _ { 1 }$ and $\lambda _ { 1 }$

$$

Remarks:

1. Since eigenvectors are unique only up to a constant multiplier, it is preferable to normalize the vectors $\underline { { x } } ^ { ( k ) }$ as shown in the example.

2. The eigenvalue with the smallest absolute value and the associated eigenvector can be obtained by using the power method of Mises for ${ { \bf A } ^ { - 1 } }$ . If ${ { \bf A } ^ { - 1 } }$ does not exist, then 0 is this eigenvalue and any vector from the null-space of A can be selected as an associated eigenvector.

3. The other eigenvalues and the associated eigenvectors of A can be obtained by repeated application of the following idea. Select a starting vector which is orthogonal to the known vector $\underline { { \mathbf { x } } } _ { 1 }$ , and in this subspace $\lambda _ { 2 }$ becomes the dominant eigenvalue that can be obtained by using the power method. In order to obtain $\lambda _ { 3 }$ , the starting vector has to be orthogonal to both $\underline { { \mathbf { x } } } _ { 1 }$ and $\underline { { \mathbf { X } } } _ { 2 } .$ , and so on. This procedure is known as matrix deflation.

4. Based on (4.218) the power method is sometimes called vector iteration.
