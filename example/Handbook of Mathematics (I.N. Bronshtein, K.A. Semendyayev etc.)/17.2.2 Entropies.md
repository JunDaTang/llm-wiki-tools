##### 17.2.2.1 Topological Entropy

Let $( M , \rho )$ be a compact metric space and $\{ \varphi ^ { k } \} _ { k \in T }$ be a continuous dynamical system with discrete time on M. A distance function $\rho _ { n }$ on M for arbitrary $n \in \mathbb N$ is defined by

$$
\rho _ { n } ( x , y ) : = \operatorname* { m a x } _ { 0 \leq i \leq n } \rho ( \varphi ^ { i } ( x ) , \varphi ^ { i } ( y ) ) .\tag{17.36}
$$

Furthermore, let $N ( \varepsilon , \rho _ { n } )$ be the largest number of points from M which have in the metric $\rho _ { n }$ a distance at least $\varepsilon$ from each other. The topological entropy of the discrete dynamical system $( 1 7 . 3 )$ or of the mapping $\varphi \mathrm { i s } h ( \varphi ) = \operatorname* { l i m } _ { \varepsilon \to 0 } \operatorname* { l i m } _ { n \to \infty } \operatorname* { s u p } _ { n } \frac { 1 } { n } \ln N ( \varepsilon , \rho _ { n } )$ . The topological entropy is a measure for the complexity of the mapping. Let $( M _ { 1 } , \rho _ { 1 } )$ be a further compact metric space and $\varphi _ { 1 } \colon M _ { 1 } \to M _ { 1 }$ be a continuous mapping. If both mappings $\varphi$ and $\varphi _ { 1 }$ are topologically conjugate, then their topological entropies coincide. In particular, the topological entropy does not depend on the metric. For arbitrary $n \in \mathbb N$ $h \left( \varphi ^ { n } \right) = n \bar { h ( \varphi ) }$ holds. If $\varphi$ is a homeomorphism, then $i ( \dot { \varphi } ^ { k } ) = | k | h ( \varphi )$ for all $k \in \mathbb { Z }$ . Based on the last property the topological entropy $h ( \varphi ^ { t } ) : = \dot { h } \left( \varphi ^ { 1 } \right)$ is defined for a flow $\varphi ^ { t } = \varphi ( t , \cdot )$ of (17.1) on $M \subset \mathbb { R } ^ { \bar { n } }$

##### 17.2.2.2 Metric Entropy

Let $\{ \varphi ^ { t } \} _ { t \in T }$ be a dynamical system on M with attractor Λ and with an invariant probability measure $\mu$ concentrated on Λ. For an arbitrary $\varepsilon > 0$ consider the cubes $Q _ { 1 } ( \varepsilon ) , \ldots , Q _ { n ( \varepsilon ) } ( \varepsilon )$ of the form $\{ ( x _ { 1 } , \ldots , x _ { n } ) : k _ { i } \varepsilon \leq x _ { i } < ( k _ { i } + 1 ) \varepsilon ( i = 1 , 2 , \ldots , n ) \}$ with $k _ { i } \in \mathbb { Z }$ , for which $\mu ( Q _ { i } ) > 0$ . For arbitrary x from a $Q _ { i }$ the semiorbit $\{ \varphi ^ { t } ( x ) \} _ { t = 0 } ^ { \infty }$ is followed for increasing t. In time-distances of $\tau > 0 ( \tau = \bar { 1 }$ in discrete systems), the $N$ cubes, in which the semiorbit is found is denoted by $i _ { 1 } , \dots , i _ { N }$ after each other. Let $\dot { E } _ { i _ { 1 } , \dots , i _ { N } }$ be the set of all starting points in the neighborhood of $\Lambda$ whose semiorbits at the times $t _ { i } = i \tau ~ ( i = 1 , 2 , \ldots , N )$ are always in $Q _ { i _ { 1 } } , \ldots , Q _ { i _ { N } }$ and let $p ( i _ { 1 } , \cdots , i _ { N } ) = \mu ( E _ { i _ { 1 } , \cdots , i _ { N } } )$ be the probability that a (typical) starting point is in $E _ { i _ { 1 } , \cdots , i _ { N } }$

The entropy gives the increment of the information on average by an experiment which shows that among a finite number of disjoint events which one has really happened. In the above situation this is

$$
H _ { N } = - \sum _ { ( i _ { 1 } , \cdots , i _ { N } ) } p ( i _ { 1 } , \cdots , i _ { N } ) \ln p ( i _ { 1 } , \cdots , i _ { N } ) ,\tag{17.37}
$$

where the summation is over all symbol sequences $( i _ { 1 } , \cdots , i _ { N } )$ with length N, which are realized by the orbits described above.

The metric entropy or Kolmogorov-Sinai entropy $h _ { \mu }$ of the attractor Λ of $\{ \varphi ^ { t } \}$ with respect to the invariant measure $\mu$ is the quantity $h _ { \mu } = \operatorname * { l i m } _ { \varepsilon  0 } \operatorname * { l i m } _ { N  \infty } \frac { H _ { N } } { \tau N }$ .
