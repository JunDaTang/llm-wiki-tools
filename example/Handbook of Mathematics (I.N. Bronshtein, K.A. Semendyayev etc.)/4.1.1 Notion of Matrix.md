#### 4.1.1 Notion of Matrix

1. Matrices A of Size $( m , n )$ or Briefly $\mathbf { A } _ { ( m , n ) }$

are systems of m times n elements, e.g., real or complex numbers, or functions, derivatives, vectors, arranged in m rows and n columns:

$$
\mathbf { A } = ( a _ { i j } ) = ( { \begin{array} { c c c } { a _ { 1 1 } } & { a _ { 1 2 } \cdots a _ { 1 n } } \\ { a _ { 2 1 } } & { a _ { 2 2 } \cdots a _ { 2 n } } \\ { \vdots } & { \vdots } & { \vdots } \\ { a _ { m 1 } } & { a _ { m 2 } \cdots a _ { m n } } \end{array} } ) \quad \begin{array} { r c l } {  } & { { \mathrm { 1 s t ~ r o w } } } \\ {  } & { { \mathrm { 2 n d ~ r o w } } } \\ {  } & { \vdots } \\ {  } & { m { \mathrm { - t h ~ r o w } } } \end{array}\tag{4.1}
$$

With the notion size ofa matrix matrices are classified according to their number of rows m and number of columns n: A of size $( m , n )$ . A matrix is called a square matrix if the number of rows and columns is equal, otherwise it is a rectangular matrix.

2. Real and Complex Matrices

Real matrices have real elements, complex matrices have complex elements. If a matrix has complex elements

$$
a _ { \mu \nu } + \mathrm { i } b _ { \mu \nu }\tag{4.2a}
$$

it can be decomposed into the form

$$
\mathbf { A } + \mathrm { i } \mathbf { B }\tag{4.2b}
$$

where A and B have real elements only (arithmetical operations see 4.1.4, p. 272).

If a matrix A has complex elements, then its conjugate complex matrix $\mathbf { A } ^ { * }$ has the elements

$$
a _ { \mu \nu } ^ { \ast } = \operatorname { R e } { ( a _ { \mu \nu } ) } - \mathrm { i } \operatorname { I m } { ( a _ { \mu \nu } ) } .\tag{4.2c}
$$

3. Transposed Matrices ${ \mathbf A } ^ { \mathbf T }$

Changing the rows and columns of a matrix A of size $( m , n )$ gives the transposed matrix ${ \bf A } ^ { \mathrm { T } }$ . This has the size $( n , m )$ and

$$
( a _ { \nu \mu } ) ^ { \mathrm { T } } = ( a _ { \mu \nu } )\tag{4.3}
$$

is valid.

4. Adjoint Matrices

The adjoint matrix ${ \bf A } ^ { \mathrm { H } }$ of a complex matrix A is the transpose of its conjugate complex matrix $\mathbf { A } ^ { * }$ (which can not be confused with the adjoint matrix $\mathbf { A } _ { a d j }$ , see 4.2.2, p. 278):

$$
\mathbf { A } ^ { \mathrm { H } } = ( \mathbf { A } ^ { * } ) ^ { \mathrm { T } } .\tag{4.4}
$$

5. Zero Matrix

A matrix 0 is called a zero matrix if it has only zero elements:

$$
\mathbf { 0 } = \left( \begin{array} { l l l l } { 0 ~ 0 } & { \cdots } & { 0 } \\ { 0 ~ 0 } & { \cdots } & { 0 } \\ { \vdots ~ \vdots } & { \vdots } & { \vdots } \\ { 0 ~ 0 } & { \cdots } & { 0 } \end{array} \right) .\tag{4.5}
$$
