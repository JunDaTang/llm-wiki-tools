$$
{ \frac { \partial \vec { \bf V } } { \partial \vec { \bf a } } } = \vec { \bf a } \cdot \mathrm { g r a d } ( V _ { x } \vec { \bf e } _ { x } + V _ { y } \vec { \bf e } _ { y } + V _ { z } \vec { \bf e } _ { z } ) = \vec { \bf a } \cdot \mathrm { g r a d } \vec { \bf V }\tag{13.47a}
