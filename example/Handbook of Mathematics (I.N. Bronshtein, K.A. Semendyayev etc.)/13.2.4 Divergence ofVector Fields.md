#### 13.2.4 Divergence ofVector Fields

##### 13.2.4.1 Definition of Divergence

To a vector field $\vec { \mathbf { V } } ( \vec { \mathbf { r } } )$ a scalar field can be assigned which is called its divergence. The divergence is defined as a space derivative of the vector field at a point $\vec { \mathbf { r } } ;$

$$
\operatorname { d i v } \vec { \mathbf { V } } = \operatorname* { l i m } _ { V \to 0 } \frac { \iiint \vec { \mathbf { V } } \cdot d \vec { \mathbf { S } } } { V } .\tag{13.48}
$$

If the vector field $\vec { \bf V }$ is considered as a stream field, then the divergence can be considered as the fluid output or source, because it gives the amount of fluid given in a unit of volume during a unit of time flowing by the considered point of the vector field $\vec { \mathbf { V } } .$ In the case div $\vec { \mathbf { V } } > 0$ the point is called a source, in the case div $\vec { \mathbf { V } } < \boldsymbol { 0 }$ it is called a sink.

##### 13.2.4.2 Divergence in Different Coordinates

1. Divergence in Cartesian Coordinates

$$
\operatorname { d i v } \vec { \mathbf { V } } = \frac { \partial V _ { x } } { \partial x } + \frac { \partial V _ { y } } { \partial y } + \frac { \partial V _ { z } } { \partial z } \qquad \mathrm { ( 1 3 . 4 9 a ) } \qquad \mathrm { w i t h } \quad \vec { \mathbf { V } } ( x , y , z ) = V _ { x } \vec { \mathbf { i } } + V _ { y } \vec { \mathbf { j } } + V _ { z } \vec { \mathbf { k } } .\tag{13.49b}
$$

The scalar field div $\vec { \bf V }$ can be represented as the dot product of the nabla operator $\nabla$ and the vector $\vec { \bf V }$ as

$$
\operatorname { d i v } \vec { \mathbf V } = \nabla \cdot \vec { \mathbf V }\tag{13.49c}
$$

and it is translation and rotation invariant, i.e., scalar invariant (see 4.3.3.2, p. 283).

2. Divergence in Cylindrical Coordinates

$$
\operatorname { d i v } \vec { \mathbf { V } } = \frac { 1 } { \rho } \frac { \partial ( \rho V _ { \rho } ) } { \partial \rho } + \frac { 1 } { \rho } \frac { \partial V _ { \varphi } } { \partial \varphi } + \frac { \partial V _ { z } } { \partial z } \quad ( 1 3 . 5 0 \mathrm { a } ) \quad \mathrm { w i t h } \quad \vec { \mathbf { V } } ( \rho , \varphi , z ) = V _ { \rho } \vec { \mathbf { e } } _ { \rho } + V _ { \varphi } \vec { \mathbf { e } } _ { \varphi } + V _ { z } \vec { \mathbf { e } } _ { z } .\tag{13.50b}
$$

$$
\operatorname { d i v } { \vec { \mathbf { V } } } = { \frac { 1 } { r ^ { 2 } } } { \frac { \partial ( r ^ { 2 } V _ { r } ) } { \partial r } } + { \frac { 1 } { r \sin \vartheta } } { \frac { \partial ( \sin \vartheta V _ { \vartheta } ) } { \partial \vartheta } } + { \frac { 1 } { r \sin \vartheta } } { \frac { \partial V _ { \varphi } } { \partial \varphi } }\tag{13.51a}
$$

$$
\mathrm { w i t h } \vec { \mathbf { V } } ( r , \vartheta , \varphi ) = V _ { r } \vec { \mathbf { e } } _ { r } + V _ { \vartheta } \vec { \mathbf { e } } _ { \vartheta } + V _ { \varphi } \vec { \mathbf { e } } _ { \varphi } .\tag{13.51b}
$$

##### 13.2.4.3 Rules for Evaluation of the Divergence

$$
\operatorname { d i v } { \vec { \mathbf { c } } } = 0 , \quad \operatorname { d i v } \left( { \vec { \mathbf { V } } } _ { 1 } + { \vec { \mathbf { V } } } _ { 2 } \right) = \operatorname { d i v } { \vec { \mathbf { V } } } _ { 1 } + \operatorname { d i v } { \vec { \mathbf { V } } } _ { 2 } , \quad \operatorname { d i v } \left( c { \vec { \mathbf { V } } } \right) = c \operatorname { d i v } { \vec { \mathbf { V } } } .\tag{13.53}
$$

$$
\operatorname { d i v } \left( U { \vec { \mathbf { V } } } \right) = U \operatorname { d i v } { \vec { \mathbf { V } } } + { \vec { \mathbf { V } } } \cdot \operatorname { g r a d } U \qquad \left( \operatorname { e s p e c i a l l y } \operatorname { d i v } ( r { \vec { \mathbf { c } } } ) = { \frac { { \vec { \mathbf { r } } } \cdot { \vec { \mathbf { c } } } } { r } } \right) .\tag{13.54}
$$

$$
\operatorname { d i v } \left( { \vec { \mathbf { V } } } _ { 1 } \times { \vec { \mathbf { V } } } _ { 2 } \right) = { \vec { \mathbf { V } } } _ { 2 } \cdot \operatorname { r o t } { \vec { \mathbf { V } } } _ { 1 } - { \vec { \mathbf { V } } } _ { 1 } \cdot \operatorname { r o t } { \vec { \mathbf { V } } } _ { 2 } .\tag{13.55}
$$
