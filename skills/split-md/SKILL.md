# split-md

把整本大 md（书、长文档、讲义）按**章级标题**拆成多个独立 md：章级一页、下级标题内联；超过大小阈值的章自动下探一级标题二次拆分，所有页面平铺在书目录下，得到 wiki/RAG 友好的页面粒度。全部能力由自带脚本 `scripts/split_md.py` 承载（纯标准库，uv 拉起，下文以 `<skill>/scripts/` 指代）。与 `mineru-pdf2md` 是上下游关系：其产物 `{书名}/{书名}.md + {书名}.toc.json` 是本 skill 的理想输入，但任何带标题的 md 都能拆。

## When to use this

- 「把这个 md 拆成多个 md」「按章节拆分」「每章一个文件」
- 「md 太大不好给 LLM/wiki 用，拆开」
- 不适用：按固定 token/字数切块的无语义 RAG chunking；只想抽取纯文本。

## 拆分规则（脚本已固化，汇报时按此口径）

- **章级一页**：每个章级标题一个文件 = 该标题行 + 到下一章级标题之前的全部正文；三级及更深标题**内联**，不单独成页。
- **大小感知二次拆分**：章页超过 `--max-kb`（默认 32KB，`0` 关闭）时下探一级标题：`{章}.md` 只留章标题行 + 章引言（章头到首个子节之间的内容），直接子节各自成页——与章同级、平铺在书目录下，层级交给 index.md/toc.json 表达；子节仍超限则按标题层级继续下探（最深至 H6），叶子仍超限按空行段落边界兜底硬切成 `-2/-3` 多个文件（单段超长如整张表格不切，宁可整段落块超限）。被拆页末尾追加「本节包含的小节」/「本节续页」链接清单，自身即成为可导航的目录页（产物只增不删）。
- **index.md = 全量标题树**：源 md 的所有标题都列出（缩进表层级），独立成页的加链接，内联标题只列文字，硬切续页以「（续N）」缩进列出。
- **浅层伪章节不下探**：层级比章级更浅的节（如章级=H3 的书里 H2 的「目录」「参考文献」「Part N」）只占自己的直接正文，不吞并后面的真实章；它与下一章之间散落的更深标题（孤儿节）并入该文件，保持行守恒。
- **图片统一书根**：平铺后所有 md 与书根 `images/` 同目录，`images/xxx.jpg` 相对引用天然可解析（llm_wiki 摄取同样按源文件所在目录解析相对引用）；`images/` 源目录存在则整目录复制。
- **章级判层（auto）**：H2 数量 ≥4，或 H2 全部形似「第 N 章 / N. / Chapter N」→ 章级=H2；否则下探 H3（例：MfML 的 H2 是 Part、数学手册的 H2 是 目录/参考文献，真正的章在 H3）。`--level 2..6` 可强制。
- **书名根 H1 → `{书名}.md`**（封面/前言正文归它）；首个标题前的散落正文并入它。该页始终列入 index.md，末尾附「本书包含的章」链接清单，作为书目录页；内容一字不丢——源内容行全部保留，拆分页只追加链接清单。**封面页不做大小拆分**。
- 代码块内的 `#` 行不算标题（围栏感知）。
- 文件名 = 标题清洗（去非法字符、截 100 字符；上限是 Windows 路径护栏，曾用 60 把 65 字符书名腰斩成 `…Semendyayev e` 且与根页名/上游目录名不一致。书名超 100 时目录名仍截断而根页保持原文 stem，属已知取舍）；**撞名判定双重口径**——严格小写 + `namekey`（loose 之上再去点号：`7 Infinite Series` 与 `7. Infinite Series` 这类正文章 vs 书末 Bibliography 区同名小节必须视为撞名），撞名先冠父章前缀、再退 `-2/-3` 数字后缀；占用表按小写与 namekey 双登记并预占 `index`——Windows 文件名大小写不敏感，曾有「Index」章被导航文件覆盖的事故。

## Workflow

### 第 1 步：确认输入形态（两者皆可）

- **单文件**：`--input 某本书.md` → 输出 `{输出}/{书名}/`。
- **目录**：`{书名}/{书名}.md` 产物布局逐本拆；顶层散装 `*.md` 也认（`index`/`toc_review` 自动排除）。

### 第 2 步：运行

```bash
uv run python <skill>/scripts/split_md.py \
    --input outputs/mineru-pdf2md --output outputs/mineru-pdf2md-split
# 单文件：--input 某本书.md --output outputs/split
# 强制章级：--level 2 ；关闭大小拆分：--max-kb 0
```

### 第 3 步：验证与汇报

1. 看退出码与 `[OK] {书名}: 章级=H{n}，拆出 N 页，M 处超限二次拆分`。**章级被下探到 H3 的书要在汇报里点名说明**（因为 H2 不是章）；二次拆分数 >0 时点名哪些章被下探拆分。
2. 源目录带 `{书名}.toc.json` 时脚本自动锁步校验（标题数、层级、宽松文本一致），不一致会拒绝拆分退出——先修源产物（mineru-pdf2md 场景重跑 build_book.py），不要绕过校验。
3. 抽查任一章文件：应以章标题开头、下级小节内联其中（被拆章只有引言）；`images/` 相对引用可解析。
4. 汇报：输出路径、各书页数、章级层级、二次拆分数、同名冲突改名情况。

## 产物布局

```
{输出}/{书名}/
├── {书名}.md           # 封面/前言页（书目录页：末尾附「本书包含的章」链接清单）
├── {章标题}.md         # 每章一页（下级标题内联；被拆章留引言 + 子节链接清单）
├── {子节标题}.md       # 超限章下探出的子节页，与章同级平铺（同名冲突冠父章前缀/-2）
│                       #   引言页末尾附「本节包含的小节」清单；硬切首页附「本节续页」清单
├── index.md            # 全量标题树（独立成页加链接，内联只列文字）
├── {书名}.toc.json     # 仅当源目录有 toc.json：原结构 + 每个节点补 file 字段
│                       #   （file = 该标题内容所在的文件，内联标题指向归属页）
└── images/             # 源目录存在则整目录复制（所有 md 的相对引用都指向它）
```

## 常见坑

- **输出目录整体重建**：脚本先 rmtree 再写，产物可从源 md 幂等再生；输出必须与输入分开（脚本有守卫），别把其他文件放输出目录。
- **32KB 阈值依据**：llm_wiki 摄取"分析"步的 max_tokens 固定 4096，实测 12.5KB 的章能过、47KB 的章会让思考型模型烧完预算空手而归；阈值可用 `--max-kb` 调。
- **toc 锁步校验用宽松口径**：toc 标题来自 PDF 书签、md 标题来自解析器，仅宽松相等（`2. LLM 简介` ≡ `2. LLM简介`）；改校验逻辑时不要用严格相等。
- **同章多节必须累积后统一落盘**：逐节 write_text 会互相覆盖、只剩末节（历史事故，脚本已修，重构时勿回退）。
- 搬动产物目录时连 `images/` 一起搬。
